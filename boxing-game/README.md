## ระบบฟิสิกส์และการเคลื่อนไหว
- **ร่างกายขับด้วยสปริง**: สะโพก ลำตัว การโน้มตัว และศีรษะเป็นสปริงหน่วง (damped spring) ทุกท่าจึงมีแรงเฉื่อย การส่ายตัว และการคืนตัวเหมือนคน
- **หมัดมีจังหวะจริง**: ง้าง (anticipation) → ปล่อย → ค้าง → ดึงกลับ สะโพกและไหล่บิดส่งแรง น้ำหนักตัวถ่ายไปข้างหน้า
- **IK แขนและขา**: แขนใช้ two-bone IK จากไหล่จริง ระยะหมัดจึงขึ้นกับการบิดตัว ส่วนขาใช้ IK กับเท้าที่ยืนอยู่บนพื้น
- **ก้าวเท้าจริง**: เท้าวางอยู่กับพื้นและก้าวทีละข้างเมื่อจุดศูนย์ถ่วงเคลื่อนไปไกล ไม่มีการไถลบนพื้น
- **การชนแบบกายภาพ**: นวมเป็นทรงกลมที่ชนกับหัว ลำตัว นวม และแขนของคู่ชก ถ้าก้มหรือเอียงตัวทัน หมัดก็วืดจริง
- **แรงกระแทก**: ดาเมจคิดจากความเร็วนวมตอนกระทบ หัวสะบัดตามทิศของหมัด ฮุคทำให้ตัวบิด หมัดลำตัวทำให้งอตัว
- **ล้มแบบ ragdoll**: ตอนน็อก ร่างจะเปลี่ยนเป็น Verlet ragdoll ที่รับแรงจากหมัดสุดท้าย และเกมเข้าโหมดสโลว์โมชัน
- **สตามินา**: ต่อยรัวหรือโดนหมัดลำตัวจะทำให้การ์ดตก หมัดช้าลงและเบาลง

## ท่าหมัดจาก motion capture
ตัวละครและท่าหมัดมาจากไฟล์ GLB ที่ผู้ใช้ส่งมา (หุ่น 78 กระดูก พร้อมคลิปท่าหมัด 2 วินาที)
- `assets/mannequin.json` คือโมเดลหุ่น (glTF แบบฝังข้อมูลในไฟล์เดียว ตัดคลิปออกแล้ว) ตอนโหลด เกมจะขยายกล้ามให้หนาขึ้น ลงสีผิวและรองเท้า แล้วใส่กางเกงมวย นวม ผม และหน้าทับ
- ตารางท่าหมัด `MOCAP` ฝังอยู่ใน `index.html` เป็นทิศของกระดูกทีละเฟรม (กระดูกสันหลัง หัว ไหปลาร้า แขนบน แขนล่าง) ที่แปลงเป็นสแตนซ์ orthodox แล้ว เพราะคลิปส่วนใหญ่เป็น southpaw จึงต้องกลับซ้าย-ขวา
  - แย็บ: "Straight Right Hand" (กลับซ้าย-ขวา) · ตรงขวา: "Centerline Punch" และ "Combination Sequence" (สุ่มสลับกัน)
  - ฮุค: "Rear-hand Hook" · ฮุคลำตัว: "Body Whip" · อัปเปอร์ขวา: ช่วงท้ายของ "Combination Sequence"
- ตอนเล่น เกมจะยืดหดเวลาของคลิปให้ตรงจังหวะ ง้าง/ปล่อย/ค้าง/ดึงกลับ ของเกม แล้วแก้ทิศหมัดให้เข้าเป้าที่ล็อกไว้ตอนเริ่มง้าง ส่วนช่วงล่าง ฟุตเวิร์ค การหลบ แรงกระแทก และ ragdoll ยังเป็นฟิสิกส์เหมือนเดิม
- โครงกระดูกในเกมใช้สัดส่วนที่วัดจากหุ่น (แขนบน 0.287 ม., แขนล่าง 0.271 ม., ต้นขา 0.434 ม., หน้าแข้ง 0.423 ม.)
- ถ้าโหลดโมเดลไม่ได้ เกมจะกลับไปใช้ตัวละครแคปซูลแบบเดิม

## เกณฑ์อ้างอิง: Undisputed / UFC 6
ระบบการเคลื่อนไหวออกแบบโดยใช้สองเกมนี้เป็นเกณฑ์ แต่ทำทั้งหมดแบบ procedural (ไม่มีไฟล์ motion capture)
- **ฟุตเวิร์ค step-drag**: ก้าวเป็นจังหวะสั้นๆ ทีละก้าว ไม่ไถลบนพื้น เดินหน้าหรือไปซ้ายจะก้าวเท้าหน้าก่อน ถอยหลังหรือไปขวาจะก้าวเท้าหลังก่อน แล้วลากอีกเท้าตามโดยยกเท้าต่ำ
- **ถ่ายน้ำหนัก**: สะโพกย้ายไปอยู่เหนือเท้าที่รับน้ำหนัก และโยกตัวหน้า-หลังเป็นจังหวะระหว่างแลกหมัด
- **Kinetic chain**: สะโพกออกตัวก่อนไหล่ ~35ms น้ำหนักถ่ายตามหลัง ส้นเท้าหลังยกและเท้าหมุนบนปลายเท้าตอนต่อยตรงขวา เท้าหน้าหมุนตอนต่อยฮุค
- **รายละเอียดหมัด**: ไหล่ฝั่งที่ต่อยยกขึ้นบังคาง คางหลบหลังไหล่ มืออีกข้างแนบคาง กำปั้นหมุนคว่ำตอนหมัดตรงสุด ฮุคเป็นกำปั้นตั้ง อัปเปอร์หงายเข้าหาตัว
- **หมัดล็อกเป้าตอนเริ่มง้าง**: หลบให้ตรงจังหวะคือหมัดวืดจริง แต่ถ้าเอียงค้างไว้ก่อน คู่ชกจะเล็งตามได้
- **วืด = เสียหลัก**: หมัดหนักที่วืดใกล้หัวทำให้ผู้ต่อยเสียหลักและดึงหมัดกลับช้า ส่วนผู้หลบได้จังหวะสวน (COUNTER ×1.3)
- **ปฏิกิริยาตามระดับ**: สะดุ้ง → หัวสะบัดและเซถอย → มึน (ROCKED: ขาอ่อน การ์ดตก เซไปมา) → ล้ม (ragdoll) → กรรมการนับ 10 แล้วลุกขึ้นได้ (ผู้เล่นกดหมัดรัวๆ เพื่อลุกเร็วขึ้น) → ล้มครบ 3 ครั้งเป็น TKO
- **สไตล์มวย**: ผู้เล่นเป็น out-boxer เด้งเท้าเบาๆ ส่วน CPU เป็นสายบุก ย่อต่ำ โยกตัวน้อย

## CPU
ระดับง่าย/ปกติ/ยาก ต่างกันที่เวลาตอบสนอง โอกาสป้องกัน ความถี่ในการบุก และความเร็วหมัด CPU อ่านจังหวะง้างหมัดของเราแล้วเลือกวิธีหลบให้เหมาะกับหมัด (slip หมัดตรง, ก้มส่ายลอดฮุค, เอนหลบอัปเปอร์) หลบพ้นแล้วสวน และรุกหนักเมื่อเราเริ่มมึน
