# Po — เพื่อนบอทใน Minecraft Bedrock (มือถือ)

Po เป็นตัวละครเพื่อนที่เดินตาม คุ้มกัน คุยภาษาไทย ฝากของ จำเรื่องที่เล่นด้วยกันได้
และ **ไปหาของให้เอง**: ตัดไม้ตามชนิด ขุดแร่ตามชนิด คราฟต์อุปกรณ์ เผาแร่ ทำของใหม่เมื่ออุปกรณ์พัง
ใช้บนมือถือเครื่องเดียว ไม่ต้องมีคอม ไม่ต้องมีเน็ต ไม่ต้องเปิดโหมดทดลอง (Experimental)

![หน้าตา Po](docs/po_preview.png)

**เวอร์ชันนี้:** 1.1.0 (ช่วงสอง — นักหาของ) · ต้องใช้ Minecraft Bedrock **1.21.130 ขึ้นไป**

---

## ติดตั้งบน Android

1. ดาวน์โหลดไฟล์ [`dist/Po.mcaddon`](dist/Po.mcaddon)
   (บน GitHub กดที่ไฟล์ → ปุ่มดาวน์โหลด หรือโหลดจากแชตที่ Claude ส่งให้)
2. เปิดแอป **Files / ไฟล์** → โฟลเดอร์ **Download** → แตะที่ `Po.mcaddon` → เลือกเปิดด้วย **Minecraft**
   - เกมจะขึ้นว่า *Import started…* แล้ว *Successfully imported "Po - เพื่อนบอท"*
   - ถ้าเครื่องเปลี่ยนชื่อไฟล์เป็น `.zip` ให้เปลี่ยนกลับเป็น `.mcaddon` ก่อนแตะ
3. ในเกม: **สร้างโลกใหม่** (หรือกดดินสอแก้ไขโลกเดิม) → **Behavior Packs** → **Available** →
   แตะ **Po - เพื่อนบอท** → **Activate**
   (Resource Pack "Po - เพื่อนบอท (หน้าตา)" จะเปิดตามให้เอง)
4. เข้าโลก — จะได้ **นกหวีดเรียก Po** ในกระเป๋าเอง

> โลกที่เปิด add-on จะเก็บ achievement ไม่ได้ (เป็นกฎของเกม)
> ถ้าอัปเดต Po เป็นเวอร์ชันใหม่ ให้ import ไฟล์ใหม่ทับได้เลย ข้อมูล Po ในโลกยังอยู่

## เริ่มเล่น

| ทำอะไร | ได้อะไร |
|---|---|
| ถือ **นกหวีด** แล้วกดใช้ (แตะค้างที่จอ) | ครั้งแรก: เรียก Po ออกมา · ครั้งต่อไป: เปิดเมนู Po |
| แตะที่ตัว Po (ปุ่ม **คุยกับ Po**) | เปิดเมนู |
| แตะ Po ตอนถือขนมปัง/เนื้อสุก | ป้อนอาหาร เลือด Po เพิ่ม |
| พิมพ์ในแชต `/po:po ข้อความ` | คุยกับ Po โดยไม่ต้องเปิดเมนู เช่น `/po:po ตามมา` |
| นกหวีดหาย | คราฟต์ใหม่: **ขนมปัง 1 + ไม้แท่ง 1** |

### ปุ่มในเมนู
- **คุยกับ Po** — พิมพ์อะไรก็ได้
- **ตามมา / คุ้มกัน / รอตรงนี้** — เปลี่ยนโหมด (คุ้มกัน = เข้าไปตีมอนสเตอร์ใกล้ๆ เอง ยกเว้นครีปเปอร์)
- **เรียกมาหา** — วาร์ป Po มาข้างตัว
- **งาน** — ตัดไม้ (เลือกชนิด + จำนวน) · ขุดแร่ (เลือกแร่ + จำนวน) · คราฟต์ของให้ · เผา/ย่าง ·
  อุปกรณ์ของ Po · หีบคลังของ · หยุดงาน
- **กระเป๋า** — ฝากของที่ถืออยู่ / เอาคืนทีละอย่าง / คืนทั้งหมด (27 ช่อง)
- **ความจำ** — สถิติ บ้าน จุดที่ตาย ของดีที่เคยเจอ เรื่องที่จำได้ + ปุ่มนำทาง
- **ตั้งค่า** — ความช่างพูด (เงียบ / ปกติ / ช่างคุย), เปลี่ยนชื่อ, ให้ใช้เพชร/ทองได้เลยไม่ต้องถาม,
  ทำงานเร็ว 2 เท่า, เผาแร่ดิบอัตโนมัติ

## งานหาของ (ช่วงสอง)

| พิมพ์ | Po จะ |
|---|---|
| `ตัดไม้ 20` `ตัดไม้เบิร์ช 10` `หาไม้เชอร์รี่ 5` | หาต้นไม้ชนิดนั้นแถวนี้ เดินไปโค่นทั้งต้น ปลูกต้นใหม่คืน (ถ้ามีกล้า) |
| `หาเหล็ก 10` `ขุดเพชร 3` `ขุดหิน 32` `หาถ่าน` | ดูแร่ที่โผล่ใกล้ๆ ก่อน ถ้าไม่มี **ขุดบันไดวนลงไป** ถึงชั้นที่แร่นั้นอยู่ แล้ว **ขุดอุโมงค์แบบ branch mining** |
| `ขอไม้ 10` (ตอนไม่มีในกระเป๋า) | ไปตัดมาแล้วส่งให้ |
| `เผาเหล็ก` `เผาแร่` `ย่างเนื้อ` `ทำถ่าน 8` `เผาทราย` | ใช้เตาเผาในกระเป๋า + เชื้อเพลิงจริง ชิ้นละ 10 วินาที ระหว่างนั้นทำอย่างอื่นได้ |
| `ทำดาบเหล็กให้หน่อย` `ทำคบไฟ 16` `ทำเตาเผา` `ทำหมวกเหล็ก` | คราฟต์จากของในกระเป๋า Po (แปลงไม้เป็นแผ่นไม้/ไม้แท่งเองได้) แล้วส่งให้ |
| `อุปกรณ์` | บอกอุปกรณ์ของ Po และความทนทานที่เหลือ |
| `อัปเกรด` | ทำอุปกรณ์ที่ดีกว่าเดิมให้ตัวเอง |
| `ทำอะไรอยู่` | บอกความคืบหน้างาน และเตาเผา |
| `หยุด` `พอแล้ว` | หยุดงาน กลับมาเดินตาม |
| `ตั้งหีบนี้` (มองที่หีบ) · `เอาของเข้าหีบ` | ตั้งหีบคลังของ / เดินไปเอาของเข้าหีบ (เก็บของจำเป็นไว้กับตัว) |
| `นำทางไปต้นเชอร์รี่` `เคยเห็นเพชรที่ไหน` | Po จดที่ที่เคยเห็นต้นไม้/แร่ไว้ และพาไปได้ |
| `ใช้ได้เลย` | อนุญาตให้ Po ใช้ของที่หามาให้คุณ ทำอุปกรณ์ตัวเองได้ |

**อุปกรณ์ของ Po:** Po เริ่มมือเปล่าเหมือนผู้เล่นใหม่ ต้องมีอีเต้อก่อนถึงขุดหินได้
ต้องมีอีเต้อหินถึงขุดเหล็กได้ ต้องมีอีเต้อเหล็กถึงขุดเพชรได้ (ตามกติกาเกมจริง)
- ถ้ายังไม่มีอีเต้อ Po จะ **ไปตัดไม้มาทำเอง** ก่อน
- ระหว่างขุด Po เก็บแร่อื่นที่เจอ (ถ่าน เหล็ก ฯลฯ) เผาเอง แล้ว **อัปเกรดอุปกรณ์เอง** ทีละขั้น ไม้ → หิน → เหล็ก
- อุปกรณ์มีความทนทานจริง (อีเต้อไม้ 59 ครั้ง หิน 131 เหล็ก 250 เพชร 1,561) พังแล้ว **ทำใหม่เอง** ถ้าวัสดุพอ
- ดาบทำให้ Po ตีแรงขึ้น ชุดเกราะทำให้โดนตีเจ็บน้อยลง มีธนู + ลูกธนู Po จะ **ยิงครีปเปอร์จากไกล**
- **ของที่หามาให้คุณ Po จะไม่เอาไปใช้เอง** (เช่น สั่งหาเหล็ก 10 ก็ได้เหล็ก 10) จนกว่าคุณจะเอาไป หรือพิมพ์ `ใช้ได้เลย`
- **ถามก่อนใช้เพชรหรือทอง** ("ขอใช้ได้ไหม?" ตอบ `ได้` หรือ `ไม่`) ปิดการถามได้ในตั้งค่า
- ให้อุปกรณ์ Po: ถืออุปกรณ์แล้วกด "ฝากของ" Po จะใส่ใช้เอง (ของเอนชานต์ไม่รับ เพราะเวทมนตร์จะหาย)

**ความปลอดภัยตอนขุด:** ขุดเฉพาะบล็อกธรรมชาติ (ไม่แตะของที่คุณสร้าง) · เจอลาวา/น้ำเอาหินปิดก่อน ·
ไม่ขุดใกล้บ้าน (ในรัศมี 12 บล็อกจากเตียง) · ปักคบไฟตลอดทาง (ถ้ามีถ่าน) · เจอมอนสเตอร์หยุดสู้ก่อนแล้วค่อยทำต่อ ·
บันไดวนกว้าง 3x3 เดินขึ้นลงตามได้ · Po ทำงานห่างคุณได้ไม่เกิน ~40 บล็อก (ไกลกว่านั้นจะรอ หรือหยุดงาน)

### ตัวอย่างประโยคที่ Po เข้าใจ
- สั่งงาน: `ตามมา` `คุ้มกัน` `รอตรงนี้` `มาหา` `ช่วยด้วย` `ไม่ต้องตามมา` `หยุดสู้`
- กระเป๋า: `ฝากของ` (ของที่ถือ) `มีขนมปังไหม` `ขอขนมปัง 2` `ขอไม้สิบ` `คืนของ` `หิว`
- ความจำ: `บ้านอยู่ไหน` `ตายที่ไหน` `จำอะไรได้บ้าง` `เล่นด้วยกันกี่วันแล้ว`
- ถามเรื่องเกม (ประมาณ 50 เรื่อง): `เพชรอยู่ชั้นไหน` `ทำเตียงยังไง` `ไปเนเธอร์ยังไง` `ครีปเปอร์รับมือยังไง`
- คุยเล่น: `สวัสดี` `ขอบคุณ` `เล่ามุก` `เบื่อ` `เต้น` `เป็นใคร` `ทำอะไรได้บ้าง`

### สิ่งที่ Po ทำเอง
- เดินตาม และ **วาร์ปตาม** เมื่อคุณไปไกลเกิน 20 บล็อก หรือเข้า Nether / End
- **สู้กลับ** เมื่อโดนตี และ **ช่วยคุณ** เมื่อมีอะไรมาทำร้าย · หนีครีปเปอร์ที่เข้าใกล้
- **เตือนครีปเปอร์พร้อมบอกทิศ** เช่น "ระวัง! ครีปเปอร์อยู่ข้างหลัง!"
- เตือนเมื่อเลือดคุณน้อย มอนสเตอร์มาเป็นกลุ่ม ลงลึกใต้ดิน พายุ
- ทักตอนเช้า ตอนค่ำ ตอนคุณเข้าเกม ตอนนอน ตอนเจอเพชร และชวนคุยเรื่อยๆ
- **จำ**: บ้าน (จากเตียง) จุดที่คุณตาย ของดีที่เจอ สถิติ — ปิดเกมก็ไม่ลืม
- หลังคุณตายแล้วเกิดใหม่ Po บอกว่าของตกอยู่ทางไหน ห่างกี่บล็อก
- เลือดฟื้นเองช้าๆ · ไม่โดนดาเมจจากผู้เล่นและจากการตก
- ถ้า Po ตาย: ของในกระเป๋าตกอยู่ตรงนั้น รอ 1 นาทีแล้วใช้นกหวีดเรียกกลับมา

## รายการทดสอบช่วงสอง (ลองแล้วบอก Claude ว่าข้อไหนได้/ไม่ได้)

1. [ ] `ตัดไม้ 10` — Po เดินไปหาต้นไม้ ท่าทางฟันขวาน ต้นไม้หายทีละท่อน ได้ไม้ในกระเป๋า
2. [ ] `ตัดไม้เบิร์ช 5` — ตัดเฉพาะต้นเบิร์ช
3. [ ] `หาเหล็ก 3` ตอน Po ยังไม่มีอะไรเลย — ไปตัดไม้ → ทำอีเต้อไม้ → ขุดบันไดวนลง → อัปเกรดเป็นอีเต้อหิน → ได้เหล็ก
4. [ ] เดินตามบันไดวนลงไปได้ และเดินกลับขึ้นมาได้
5. [ ] มีคบไฟปักระหว่างทาง (ถ้า Po มีถ่าน)
6. [ ] `เผาเหล็ก` แล้วขึ้นข้อความความคืบหน้า และได้แท่งเหล็ก
7. [ ] `ทำดาบเหล็กให้หน่อย` / `ทำคบไฟ 16` ได้ของจริงในกระเป๋าคุณ
8. [ ] `อุปกรณ์` บอกความทนทาน · ขุดไปเรื่อยๆ จนอีเต้อพังแล้ว Po ทำอันใหม่เอง
9. [ ] `ขุดเพชร 2` — ลงไปถึงชั้นลึก ขุดอุโมงค์ เจอเพชร (ใช้เวลาหลายนาที)
10. [ ] เจอลาวาระหว่างขุด แล้ว Po เอาหินปิด
11. [ ] มีซอมบี้มาระหว่างทำงาน แล้ว Po หยุดสู้ก่อน แล้วกลับไปทำต่อ
12. [ ] `หยุด` ระหว่างงาน แล้ว Po กลับมาเดินตาม
13. [ ] มองหีบแล้ว `ตั้งหีบนี้` → `เอาของเข้าหีบ` ของเข้าหีบจริง
14. [ ] ให้ Po ถือธนูกับลูกธนู (ฝากธนู + ฝากลูกธนู) แล้วมีครีปเปอร์ Po ยิง
15. [ ] เมนู → งาน → ตัดไม้/ขุดแร่ เลือกชนิดและจำนวนด้วยแถบเลื่อนได้

## รายการทดสอบช่วงแรก

1. [ ] import ไฟล์ได้ และเปิด Behavior Pack ได้
2. [ ] เข้าโลกแล้วได้นกหวีด + ข้อความต้อนรับ
3. [ ] ใช้นกหวีดแล้ว Po โผล่มา หน้าตาถูก (ผมดำ เสื้อฮู้ดส้ม) โบกมือทัก
4. [ ] Po เดินตาม ท่าเดินแกว่งแขนขาปกติ หันหัวมองคุณ
5. [ ] แตะ Po แล้วเมนูเปิด กดปุ่มต่างๆ ได้
6. [ ] กด "รอตรงนี้" แล้ว Po นั่งรอ · กด "ตามมา" แล้วลุกเดินตาม
7. [ ] โหมดคุ้มกัน: Po ไปตีซอมบี้/โครงกระดูกเอง
8. [ ] ตีคุณด้วยมอนสเตอร์ แล้ว Po เข้ามาช่วย
9. [ ] มีครีปเปอร์เข้าใกล้ แล้ว Po เตือนพร้อมบอกทิศ
10. [ ] คุยผ่านปุ่ม "คุยกับ Po" และผ่าน `/po:po` ได้
11. [ ] ฝากของ / ขอของ / คืนของ ได้ของครบ
12. [ ] ป้อนขนมปังแล้วเลือด Po เพิ่ม มีหัวใจลอย
13. [ ] เดินไปไกลหรือเข้า Nether แล้ว Po ตามมา
14. [ ] นอนเตียง แล้วถาม "บ้านอยู่ไหน" ได้คำตอบ + ประกายสีเขียวนำทาง
15. [ ] ปิดเกมแล้วเปิดใหม่ Po ยังอยู่ ของในกระเป๋ายังอยู่ ความจำยังอยู่
16. [ ] ข้อความเหนือหัว Po ตอนพูด แสดงผลปกติ (ไม่ใช่ตัวอักษรแปลกๆ)

## แผนต่อไป
1. **ช่วงแรก — รากฐาน** (1.0.0)
2. **ช่วงสอง — นักหาของ** (เวอร์ชันนี้ 1.1.0): หาไม้/แร่ตามชนิด ขุดอุโมงค์ อุปกรณ์มีความทนทาน คราฟต์เอง เผาแร่เอง พังแล้วทำใหม่ หีบคลังของที่บ้าน
3. **ช่วงสาม — ฟาร์มและสร้าง:** ทำฟาร์ม ล่าสัตว์ ทำอาหาร สร้างตามแบบ 6 แบบ
4. **ช่วงสี่ — ความคิด:** ตัดสินใจเองตามสิ่งที่คุณทำ อารมณ์ ภารกิจ คลังคำถามเพิ่ม

## สำหรับคนแก้โค้ด
```
addon/Po_BP/   behavior pack: entities/po.json, items/, recipes/, scripts/
  scripts/main.js       ต่อ event ของเกม (นกหวีด, แตะ Po, เข้าเกม, ลูป)
  scripts/po.js         ตัว Po: เรียก, โหมด, ตาม/วาร์ป, ฟื้นเลือด, ท่าทาง, ตาย, ลบตัวซ้ำ
  scripts/brain.js      เข้าใจข้อความไทย → ทำงาน/ตอบ
  scripts/watch.js      Po สังเกตเหตุการณ์เอง (กลางคืน, ครีปเปอร์, เลือดน้อย, เพชร ...)
  scripts/menu.js       เมนูปุ่ม
  scripts/store.js      ความจำ (บันทึกใน world dynamic properties ต่อเจ้าของ)
  scripts/bag.js        กระเป๋า Po (เก็บเป็น {itemId: จำนวน})
  scripts/lines.js      ประโยคที่ Po พูด · knowledge.js คำตอบเรื่องเกม · names.js ชื่อไทย
  scripts/tasks.js      งาน: ตัดไม้, ขุดแร่ (บันไดวน + อุโมงค์), เอาของเข้าหีบ — ทำงานทุก tick
  scripts/path.js       หาเส้นทาง A* บนบล็อก · view.js อ่าน/แก้บล็อกในโลก (มี cache)
  scripts/blocks.js     ความรู้เรื่องบล็อก: ชนิดไม้, แร่, ความแข็ง, เครื่องมือ, ชั้น Y
  scripts/gear.js       อุปกรณ์ของ Po · craft.js สูตรคราฟต์ + วางแผน · smelt.js เตาเผา · equip.js อัปเกรด/ซ่อม
  scripts/storage.js    หีบคลังของ และเก็บของที่ตกพื้น
addon/Po_RP/   resource pack: model, animations, skin, ไอคอน, ภาษา
tools/make_textures.py  วาดสกิน/ไอคอนใหม่
tools/build.py          ตรวจไฟล์ + สร้าง dist/Po.mcaddon
tools/sim/run.sh        รันสคริปต์จริงของ Po ในโลกจำลอง (ไม่ต้องมีเกม): wood | mine | diamond | lava | fight | chest | craft | talk | phase1
```
ใช้ Script API แบบ stable เท่านั้น: `@minecraft/server` 2.4.0, `@minecraft/server-ui` 2.0.0
แก้แล้วให้ขยับเลขเวอร์ชันใน manifest ทั้งสองไฟล์ (ทั้ง header และ dependency) แล้วรัน `python3 tools/build.py`
