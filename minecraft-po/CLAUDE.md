# งาน Po (เพื่อนบอท Minecraft Bedrock)

อ่าน `README.md` ก่อน (วิธีติดตั้ง, รายการทดสอบ, โครงสร้างไฟล์)

## สิ่งที่เจ้าของ repo เลือกไว้แล้ว
- เล่นบน **Android** มือถืออย่างเดียว ไม่มีคอม → ห้ามใช้อะไรที่ต้องมีเซิร์ฟเวอร์/คอม/อินเทอร์เน็ต
- ชื่อ **Po** ผู้ชาย แทนตัวเองว่า **"ผม"** เรียกผู้เล่นด้วยชื่อในเกม นิสัยร่าเริง ขี้เล่น ใจดี
- หน้าตา: ผมดำ เสื้อฮู้ดส้ม กางเกงยีนส์ (วาดใน `tools/make_textures.py`)
- อยากได้ "ล้ำที่สุดเท่าที่ทำได้" แต่ **วางแผนก่อน แล้วรอให้เจ้าของสั่ง "เริ่ม"** ก่อนลงมือแต่ละช่วงใหญ่

## แผน 4 ช่วง
1. รากฐาน — เสร็จแล้ว (v1.0.0)
2. นักหาของ — **เสร็จแล้ว (v1.1.0)** ยังไม่ได้ผลทดสอบในเกมจริงจากเจ้าของ (ทั้งช่วง 1 และ 2) — หาไม้/แร่ระบุชนิดและจำนวน, ขุดบันไดลง + ขุดอุโมงค์หาแร่ตามชั้นที่ถูกต้อง,
   อุปกรณ์ของ Po มีระดับและความทนทานจริง (เริ่มมือเปล่า), คราฟต์เองจากกระเป๋า (ต้องมีโต๊ะคราฟต์),
   เผาแร่เอง (ต้องมีเตา + เชื้อเพลิงจริง, 10 วิ/ชิ้น), พังแล้วทำใหม่/อัปเกรด, หีบคลังของที่บ้าน, จำแหล่งทรัพยากร
   - ค่าเริ่มต้นที่ใช้ (เจ้าของไม่ได้ค้าน): ไม่มองทะลุผนัง, ถามก่อนใช้เพชร/ทอง/เนเธอไรต์, ความเร็วสมจริง,
     ของเก็บในกระเป๋า Po แล้วเต็มค่อยเอาเข้าหีบบ้าน
3. ฟาร์มและสร้าง — ฟาร์ม, ล่าสัตว์ (เหลือไว้ ≥2 ตัว), ทำอาหาร, สร้างตามแบบ 6 แบบ
4. ความคิด — utility AI ตัดสินใจเองตามสิ่งที่ผู้เล่นทำ, อารมณ์/ความสนิท, ภารกิจแนะนำขั้นต่อไป, คลังคำถามเพิ่ม

## สิ่งที่ตัดสินใจไว้ในช่วงสอง
- Po เดินด้วยการ teleport ทีละนิดตามเส้นทาง A* ของเราเอง (path.js) ไม่ใช้ AI เดินของเกม ระหว่างทำงานเปลี่ยนเป็นโหมด `po:mode_work`
  และใส่ busy flag เพื่อไม่ให้ระบบเดินตามดึงกลับ
- ขุดแร่: ดูแร่ที่โผล่ใกล้ๆ ก่อน → บันไดวน 3x3 รอบเสากลาง (Po ไม่ไปไกลจากผู้เล่นในแนวราบ พื้นที่จึงยังโหลดอยู่)
  → อุโมงค์ branch mining (ยาว 20 เว้น 3) จำกัดไม่เกิน 36 บล็อกจากผู้เล่น
- ขุดเฉพาะบล็อกธรรมชาติ (`isNaturalDiggable`), ไม่ขุดในรัศมี 12 จากบ้าน, ปิดลาวา/น้ำด้วยหินก่อนเปิด
- ของที่ Po หามาให้เจ้าของถูกจดใน `data.keep` — `autoGear` จะไม่ใช้ จนกว่าเจ้าของเอาไปหรือพิมพ์ "ใช้ได้เลย"
- ตอน Po ตาย ทุกอย่างรวมอุปกรณ์ (พร้อมความสึก) และของในเตา ตกพื้นเหมือนผู้เล่น
- ยังไม่มี: ถือเครื่องมือในมือ (ภาพ), ตัดไม้ใน Nether, ขึ้นภูเขาไปหามรกต, ตีเหล็กเป็นเนเธอไรต์

## กฎทางเทคนิค
- ใช้ Script API แบบ **stable เท่านั้น** (ตอนนี้ `@minecraft/server` 2.4.0 / `-ui` 2.0.0, min engine 1.21.130) ไม่พึ่ง Beta APIs
- ทดสอบในเกมจริงไม่ได้: ก่อนส่งทุกครั้งให้ type-check สคริปต์กับ typings ของเวอร์ชันที่ใช้ (`npm i @minecraft/server@<ver>`
  แล้ว `tsc --checkJs`), เช็ก id บล็อก/ไอเทมกับ `@minecraft/vanilla-data`, และดูรูปแบบ JSON จาก Mojang `bedrock-samples`
  ที่ tag ของเวอร์ชันเกมที่รองรับ
- กระเป๋า Po เก็บใน world dynamic property ของเจ้าของ (ไม่ใช้ inventory component) เพื่อไม่ให้ของหาย/ซ้ำตอน Po ตายหรือถูกเรียกใหม่
- มีโลกจำลองสำหรับทดสอบโดยไม่ต้องมีเกม: `bash tools/sim/run.sh <scenario>` (ดูรายการ scenario ใน README)
  แก้ mock ใน `tools/sim/mock-server.js` ถ้าสคริปต์ใช้ API ใหม่
- ทุกครั้งที่ปล่อยเวอร์ชันใหม่: ขยับ version ใน manifest ทั้ง BP/RP (header + dependency) แล้ว `python3 tools/build.py`
  และ commit `dist/Po.mcaddon` ด้วย (เจ้าของดาวน์โหลดจาก GitHub/แชต)
