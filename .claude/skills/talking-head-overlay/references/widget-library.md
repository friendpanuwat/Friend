# คลังวิดเจ็ต (โค้ดจริงใน `examples/timeline_example.js`)

**วิดเจ็ตต้องทำใหม่ให้คลิปนั้น (ผู้ใช้สั่ง)** — 1–11 คือวิดเจ็ตที่ออกแบบให้คลิปตัวอย่าง (ค้น `/* 1 ·` ถึง `/* 11 ·` ในไฟล์ตัวอย่าง):
ใช้ดูระดับงาน ภาษาภาพ และวิธีใช้ฟังก์ชัน **ไม่ใช่เทมเพลตให้คัดลอกแล้วเปลี่ยนเวลา/ข้อความ/ไอคอน**. ทุกคลิปให้คิดใหม่ทีละประโยค:
(1) พูดถึงอะไร — ของ คน หรือการกระทำที่ถ้าปิดเสียงแล้วยังเข้าใจ (จากคำพูดของคลิปนี้) (2) อะไรเกิดตรงคำสำคัญ
(3) ประกอบจากชิ้นใน kit ในภาษาภาพเดิม (การ์ดมืด ชิป ไอคอน สี accent). เวลาให้ตรงกับคำใน chunks.json, ตำแหน่งอยู่ในโซนวิดเจ็ตของคลิป.
ตารางด้านล่างคือตัวอย่างวิธีคิด.
ตำแหน่งในตัวอย่างออกแบบสำหรับโซนเหนือหัว y ≈ 130–540 (หัวเริ่ม ~y 580).

จังหวะ: วิดเจ็ตขึ้นก่อนคำที่มันอธิบาย ~0.1–0.3 วินาที หรือพร้อมคำ; อยู่บนจอ 1–4 วินาที; เว้นช่องไม่มีวิดเจ็ตบ้าง (≥ 3 วินาที 1–2 ช่องต่อคลิป).
เสียง: ทุกวิดเจ็ตมี softswish -25 อัตโนมัติ, ขีดฆ่าใช้ stamp -20/-22, จุดล็อกใช้ thud + sub. ไม่ใส่ pop/tick ทุกชิ้น.

## ออกแบบวิดเจ็ตใหม่

ภาษาเดียวกัน: **องค์ประกอบหลัก 1 ชิ้น** (การ์ด `.mini` / ชิป `.minichip` / ไอคอนเส้น / เส้น SVG) + การเคลื่อนไหวที่สื่อความหมาย
(เติม, วาด, ขีดฆ่า, หด, ส่าย, ล็อก). ข้อความในวิดเจ็ตสั้น (≤ 3 คำ) เพราะซับเล่าประโยคเต็มอยู่แล้ว. ใช้เฉพาะสีจากแบรนด์ (`BLUE`, ขาว, ความโปร่งใส).
ขนาดไม่เกิน ~600×420 และอยู่ในโซนวิดเจ็ตทั้งหมด. ห้าม backdrop-filter, ห้ามของตกแต่งที่ไม่สื่ออะไร (บาร์โค้ด, กลิตช์, อีโมจิ).
preview วิดเจ็ตใหม่อย่างน้อย 3 เวลา (เพิ่งขึ้น, กลาง, ก่อนหาย) แบบ crop โซนบนให้เห็นชัด.
