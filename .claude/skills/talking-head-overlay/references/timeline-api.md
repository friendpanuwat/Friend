# timeline.js API (overlay style)

`timeline.js` คือสคริปต์ JavaScript ธรรมดา; ตอน build จะถูกต่อเป็น `engine_head + overlay_kit.js + timeline.js + engine_tail`
ทุกฟังก์ชันด้านล่างเรียกได้ตรง ๆ. หน่วยเวลาเป็น **วินาทีของคลิป** ทั้งหมด; ทุกอย่างคำนวณจากเวลา (seekable) จึงห้ามใช้
`Math.random()` / `Date` (ถ้าต้องการสุ่ม ใช้ตัวสุ่มแบบมี seed).

พิกัด: ผืนงาน 1080×1920 px, (0,0) มุมซ้ายบน. วิดเจ็ตและซับอยู่ชั้นเดียวกัน (`G`) เหนือวิดีโอ — **ไม่ถูกซูม** ตามกล้อง.

## ลำดับในไฟล์

```js
block({...}); keyHit(...); zoom(...);   // 1) ซับทั้งคลิป + ซูม + เสียงคำเน้น (เรียงตามเวลา)
badge(...);                              // 2) ไอคอนเดี่ยวในวงกลม (ถ้ามี)
{ const w = widget(...); ... }           // 3) วิดเจ็ต ชิ้นละหนึ่งบล็อก { } เรียงตามเวลา
```
**ไม่ต้องเรียก `scenes()` / `scene()`** — สไตล์นี้ไม่มีฉากเต็มจอ (ถ้าเรียก `scene()` จะได้พื้นกรมท่าทับคลิปทั้งจอ).

## ซับ (โซนล่าง)

```js
block({t0, t1, top?, lines: [
  [['เวลาลูกค้า', 's', 0.03]],                 // หนึ่งบรรทัด = หลายวลีต่อกัน
  [['ทักมาถาม', 'k', 0.5]],                    // [ข้อความ, สไตล์, เวลาขึ้น, ขนาด px (ไม่ใส่ก็ได้)]
]});
```
- สไตล์: `'s'` คำเชื่อม (60px) · `'m'` เนื้อหา (90px) · `'k'` คำสำคัญ (136px, สี accent + glow) — 1 คำเน้นต่อก้อนเป็นหลัก.
- `top` ค่าเริ่ม 1225. ก้อนกว้างเกิน 960 / สูงเกิน 440 จะย่อเอง — ถ้าย่อมาก ให้แยกก้อน.
- ก้อนเบลอหายเองที่ `t1` → ตั้ง `t1` = เวลาก้อนถัดไปเริ่ม − 0.02. ก้อนสุดท้ายให้ `t1` เกินความยาวคลิป.
- ซับต้องครอบคลุมทุกคำพูด (ไม่มีฉากเต็มจอมาแทน). 2–3 บรรทัดต่อก้อน.

```js
keyHit(t, db = -21)     // เสียงวูบนุ่มตอนคำสำคัญขึ้น (ใส่ทุกครั้งที่มี 'k')
zoom(t, scale, dur)     // ซูมกล้อง: วลีปกติ 1.04–1.06 dur .5–.8, คำเน้น 1.07–1.10 dur .12; อย่าเกิน 1.12
                        // กลับด้วย zoom(t, 1.0, .3–.5) ตอนก้อนใหม่เริ่ม — ห้าม dur .01 (จะกระตุกเพราะไม่มีการตัดฉาก)
bloom(t, opacity=.3)    // แสงฟุ้งเบา ๆ เฉพาะประโยคแรง 1–2 จุด (สไตล์นี้ใช้ ≤ .35)
sfx(name, t, db, pitch?)// วางเสียงเอง — ชื่อเสียงดู standards.md
badge(name, t0, t1, top = 110)  // ไอคอนในวงกลมกระจก (ใช้ชื่อใน IC เช่น 'search', 'bulb', 'heart')
```

## Overlay kit (`assets/overlay_kit.js`)

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `widget(css, t0, t1, {card, round, sound})` | กล่อง absolute บนชั้น G: เด้งขึ้น (spring + เบลอ→ชัด) ที่ `t0`, เบลอหายที่ `t1`, เสียง softswish อัตโนมัติ. `card:true` (ค่าเริ่ม) ใส่พื้นการ์ด `.mini`; `card:false` สำหรับชิป/ไอคอนลอย; `round:true` เป็นวงกลม; `sound:false` ปิดเสียง (ใช้เมื่อขึ้นพร้อมกันหลายชิ้น). คืนค่า element — ใส่ของลงไปด้วย `innerHTML` / `div(css, w)` |
| `popIn(el, t)` | ชิ้นส่วนในวิดเจ็ตเด้งขึ้นที่ `t` (el ต้องมี `opacity:0` ใน css) |
| `ICON(nameOrPath, size, color='#fff', sw=6)` | สตริง `<svg>` ไอคอนเส้น; ใช้ชื่อใน `IC` หรือ path เอง |
| `IC` | `q` (?), `search`, `tag`, `box`, `alert`, `shield`, `scale`, `check`, `down`, `up`, `cross`, `bulb`, `heart`, `glass` — เพิ่มเองได้: `IC.x = 'M..'` (viewBox 100, stroke) |
| `QMARK` | = `IC.q` |
| `strikeChip(label, t0, t1, tCut, {top, size, icon})` | ชิปกลางจอที่โดนขีดฆ่าตอน `tCut` + เสียง stamp ("ไม่ใช่ X") |
| `iconChip(icon, label, t, parent, {size})` | ชิปมีไอคอน (วาดเส้น) ใส่ใน flex row; คุณ `fadeOut()` เอง |
| คลาส `.mini` | การ์ดพื้นมืดโปร่งแสง ขอบบาง เงา — **ไม่มี backdrop-filter** |
| คลาส `.minichip` | ป้ายแคปซูลเล็ก (30px) — ปรับ `font-size` / `padding` inline ได้; ใส่ `<span class="dot"></span>` นำหน้าได้ |

ตัวช่วยจากเอนจินที่ใช้ในวิดเจ็ต:
| ฟังก์ชัน | ทำอะไร |
|---|---|
| `div(css, parent, html='')` | สร้าง element `position:absolute` |
| `kinetic(parent, txt, cls, t)` | ข้อความพลิกทีละตัวใส่ใน element (ตั้ง `k.style.fontSize` เอง: ในวิดเจ็ตใช้ 40–56px) |
| `svg(w, h, inner, css, parent)` / `draw(pathEl, t, d)` | ห่อ SVG / วาดเส้น (trim path) |
| `A(el, keyframes, t, d, {e, f, it, dir, c})` | Web Animation มีเวลาเริ่ม; `c:'add'` ซ้อน transform บน animation เดิม (เช่นเด้งตอนโดนขีด) |
| `fadeOut(el, t)` / `ripple(G, x, y, t, scale)` | เบลอหาย / วงคลื่น (พิกัดจอ) |
| `HOOKS.push(t => {...})` | โค้ดที่รันทุกเฟรม (เช่นเปลี่ยนข้อความสถานะ "ออนไลน์→ออฟไลน์") |
| `BLUE` | สี accent ของแบรนด์ (build เปลี่ยนตาม brand.json ให้เอง) |

## กับดักที่พบบ่อย

- **keyframe แรกคือสถานะก่อนเริ่ม** (fill `'both'`) — element ลูกที่จะ `popIn` ต้องมี `opacity:0` ใน css ไม่งั้นโผล่ตั้งแต่ต้นวิดเจ็ต.
- **animation ที่ `f:'none'`** (ส่าย/เต้นซ้ำ) ใช้กับ transform ของ element ลูก ไม่ใช่ตัว widget (จะไปทับ animation เข้า/ออก) — หรือใช้ `c:'add'`.
- **วิดเจ็ตซ้อนกัน** — เช็กว่า `t1` ของชิ้นก่อน ≤ `t0` ของชิ้นถัดไป (fadeOut เริ่ม t1−0.18).
- **ตำแหน่งเทียบหัว** — ตรวจกับเฟรมที่ซูมมากที่สุดของช่วงนั้น; วิดเจ็ตไม่ซูมตาม แต่หัวขยับขึ้น.
- **ข้อความไทย** — ส่งเป็นวลีเต็ม เอนจินแยก grapheme ให้เอง. ชิปไม่ตัดบรรทัด — ข้อความยาวให้ลด `font-size`.
- **ข้อความบนชิปที่ไม่ใช่คำพูด** (เช่น "อ่านแล้ว", "ลูกค้าที่ทักมา", "SALE") ใช้ได้ถ้าเป็นป้าย UI ที่อธิบายภาพ — ห้ามเป็นตัวเลข/ข้อมูลใหม่.
