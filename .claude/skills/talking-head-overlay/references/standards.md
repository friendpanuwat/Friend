# มาตรฐานงาน (overlay — อิง v9)

## Brand (`brand.json`)

คัดลอก `assets/brand.default.json` → `<project>/brand.json` แล้วแก้. ซับ วิดเจ็ต ไอคอน และ glow เปลี่ยนตามอัตโนมัติตอน build (รวมสีใน overlay_kit.js และ timeline.js).

| คีย์ | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `text` | `#FFFFFF` | สีตัวอักษรทั่วไป |
| `accent` | `#8FD3FF` | สีคำสำคัญ + glow + เส้น/จุดเรืองแสง |
| `accent2` | `#4E9BFF` | สีรองของไล่เฉด (ควรเข้มกว่า accent) |
| `ink` | `#05070D` | (สไตล์นี้แทบไม่ใช้ — ไม่มีฉากเต็มจอ) |
| `fonts.key/mid/body/small` | Mitr Bold / SemiBold / Medium / Sriracha | ไฟล์ .ttf/.otf — path อิงจากที่อยู่ของ brand.json |
| `sfx_db` | `-17` | ระดับแทร็กเสียงประกอบทั้งหมดตอนมิกซ์ (ผู้ใช้ให้เบาลงจาก −11) |

แนะนำ: accent สว่างพอให้อ่านบนพื้นเข้ม; ฟอนต์ไทยต้องรองรับสระ/วรรณยุกต์ครบ. ฟอนต์ที่ผู้ใช้ส่งมาต้องมีสิทธิ์ใช้งานเชิงพาณิชย์.

## ตัวอักษร

| ชั้น | ฟอนต์ | ขนาด | สี | ใช้ |
|---|---|---|---|---|
| คำสำคัญ `k` | key | 136 (statement 150–250) | accent + glow | 1–2 คำต่อประโยค |
| เนื้อหา `m` | mid | 90 | text | วลีเนื้อหา |
| คำเชื่อม `s` | small | 60 | text | คำเชื่อม/คำนำ |
| คำในวิดเจ็ต | key | 40–56 | accent | คำเน้นในแถว/ฟอง |
| minichip / UI | body | 24–54 (ปกติ 30) | text บนพื้น accent 12% | ป้ายในการ์ด, ชิปลอย |

Motion ตัวอักษร: แยก grapheme พลิก rotateX 60–85° + เบลอ 10px → ชัด, spring, ไล่ทีละตัว 16 ms (คำสำคัญ 32 ms),
คำสำคัญขึ้นเป็นสีขาวแล้วเปลี่ยนเป็น accent ใน 0.35 วินาที; จบก้อนเบลอลอยขึ้น 0.16 วินาที.

## โซนบนจอ (1080×1920)

- **โซนวิดเจ็ต** (หาจาก contact sheet ทุกคลิป): ปกติเหนือหัว y ≈ 130 → ยอดหัว − 40 px (ตัวอย่าง: 130–540, หัวเริ่ม ~580).
  เผื่อซูม: ซูม 1.10 ดันยอดหัวขึ้น ~20 px. เหนือหัวแคบ (< 250 px) → ใช้ข้างลำตัวซ้าย x 40–330 และย่อวิดเจ็ต.
  อย่าวางวิดเจ็ตเหนือ y 120 (แท็บ "Following / For You" ของแอป).
- y ≈ 580–1200: ใบหน้า/ลำตัว — ห้ามมีอะไรทับ.
- y 1225–1660: ซับ (กว้าง ≤ 960, สูง ≤ 440).
- ล่าง 300 px และขวา 140 px (ช่วง y > 900): เว้นให้ UI ของ TikTok/Reels.

## กล้องและวิดเจ็ต

- คลิปต้นฉบับแสดงตลอด **ตามที่ถ่าย** (ผู้ใช้สั่ง: ไม่ปรับสี — ไม่มี filter สี / ไล่สี / vignette / เกรน), ซูมตามคำ — **ไม่เบลอ ไม่หรี่**.
- ซูมเข้า 4–5 ครั้งต่อคลิป ค่อย ๆ ดัน (dur 1–1.5) และกลับ 1.0 ช้า ๆ (dur ~1) เพราะไม่มีจังหวะตัดฉากไปซ่อน (ผู้ใช้สั่ง).
- วิดเจ็ตเข้า = `SOFT` จาก scale .9 + เลื่อนขึ้น 26 px + เบลอ 10px→0 ใน 0.8 วินาที; ออก = เบลอหาย 0.4 วินาที;
  การเคลื่อนไหวหลัก 0.6–1.0 วินาทีชิ้นละอย่างแล้วค้างนิ่ง ไม่วนซ้ำเร็ว (ผู้ใช้สั่ง).
- การ์ด `.mini` พื้นมืดโปร่งแสง (ไม่มี backdrop-filter); ทีละ 1 วิดเจ็ต; ขนาด ≤ ~600×420.
- ไม่ใช้ `scene()`, กลิตช์ RGB, ซูมพุ่ง, whip transition, เคอร์เซอร์.

## เสียง

ความดังรวม **-14 LUFS ±0.5, peak ≤ -1.5 dBTP** (pipeline ทำ loudnorm + limiter ให้ — ได้ ≈ -14.3 LUFS / -2 dBTP; วัดไฟล์ MP4 จริงด้วย `ebur128=peak=true` ก่อนส่ง). เสียงพูดผ่าน highpass 80 Hz → denoise → compressor 3:1 → EQ +2 dB @3.5 kHz.
เสียงประกอบสังเคราะห์จาก `scripts/sfx.py` (ไม่มีปัญหาลิขสิทธิ์) แล้วลดทั้งแทร็ก `sfx_db`.

| จังหวะ | เสียง | dB ใน cue |
|---|---|---|
| คำสำคัญขึ้น | `softswish` (ผ่าน `keyHit`) | -19 ถึง -23 |
| วิดเจ็ตเด้งขึ้น | `softswish` (อัตโนมัติจาก `widget`) | -25 |
| ประโยคแรง | `swell` (ก่อน 0.6 วิ) + `sub` | -24 / -14 |
| ขีดฆ่า / ประทับ | `stamp` | -20 ถึง -22 |
| จุดล็อกเป้า (ตอนจบ) | `thud` + `sub` | -22 / -14 |

เสียงที่มีให้: whoosh, whoosh_long, swipe, softswish, swell, riser, sub, impact, thud, stamp, tick, pop, pop_hi, pop_lo, ding, sparkle, heart, boing, womp, glitch.
**เสียงประกอบแบบเบาและไม่จุกจิก (ผู้ใช้สั่ง):** ตอน mix เอนจินตัดเสียง `pop` / `pop_hi` / `pop_lo` / `tick` ทิ้งทั้งหมด
(ภาพเด้งก็พอ) และในทุกช่วง 0.9 วินาทีเหลือเสียงเดียวที่สำคัญที่สุด (`sub` > `stamp`/`thud` > `whoosh` > `swipe` > `softswish`) —
`calmSfx()` ใน engine_head.html; ตารางด้านบนคือเสียงที่ "ขอ" ได้ ไม่ใช่ทุกเสียงที่จะได้ยิน.
**ไม่ใช้** glitch, sparkle, boing, womp, pop บนไอคอน หรือ tick ทุกคำ — ทำให้งานดูการ์ตูน.
เพลงประกอบไม่ใส่ในไฟล์ (ลิขสิทธิ์) — แนะนำผู้ใช้เลือกในแอปตอนโพสต์; เสียงประกอบตั้งไว้เบาพอเผื่อเพลงแล้ว.

## ส่งงานและรับฟีดแบ็ก

ส่ง MP4 + ตารางสรุป (วินาที · วิดเจ็ต) + บอกตรง ๆ ว่าคุณตรวจจากภาพนิ่ง ความลื่นและเสียงต้องให้ผู้ใช้ยืนยัน.
ขอฟีดแบ็กแบบระบุวินาที ("วิ 14 เสียงดังไป"). แก้เฉพาะจุด, preview จุดนั้น, แล้วเรนเดอร์ใหม่เป็นเวอร์ชันถัดไป.
