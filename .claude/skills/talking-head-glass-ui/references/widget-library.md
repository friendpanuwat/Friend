# จากความหมาย → ภาพ (คอมโพเนนต์)

เริ่มจากประโยค ไม่ใช่จากคอมโพเนนต์: เขียนความหมายเป็นบรรทัดเดียว ("ไอเดียยังไม่ผ่าน 3 ข้อ", "แก้ไปเรื่อย ๆ ไม่จบ", "วันแรกไม่ได้ดีแบบนี้")
แล้วเลือกภาพที่ทำให้เข้าใจเร็วที่สุด. ถ้าไม่มีภาพไหนช่วยจริง → ซับอย่างเดียว.
โค้ดจริงอยู่ใน `examples/timeline_example.js` (ค้น `/* 3 ·`, `/* 4 ·`, `/* 6 ·`, `/* 9 ·`).

| ความหมายของประโยค | ภาพ | คอมโพเนนต์ | เหตุการณ์ตรงคำ |
|---|---|---|---|
| รายการ 2–4 ข้อ (ข้อดี/ข้อเสีย, ผ่าน/ไม่ผ่าน, ต้องมี) | การ์ดลิสต์ที่ขยายตามข้อ | `gcard` + `rows` (+ `hand`) | แถวขึ้นตรงแต่ละข้อ, มือกด badge, `strike` ขีดฆ่าตอน "ไม่ใช่" |
| ทำซ้ำ / แก้ไปเรื่อย ๆ / ทีละเวอร์ชัน | สำรับการ์ดซ้อน | `versions` | ใบใหม่ลงตรงคำ "อีก / ดีกว่าเดิม" |
| ก่อน → หลัง, เมื่อก่อน vs ตอนนี้, A แทน B | สองการ์ด + ลูกศร | `compare` | ฝั่ง B ลงตรงคำเปลี่ยน |

| คำถามกับคนดู / โพล / ลิสต์สั้นที่อยากให้ "หยุดดู" | ฉากไอคอนแอป | `screen` + `bigWord` / `srow` | บรรทัดพิมพ์ตรงคำพูด |
| เหตุการณ์ที่มีรูป/คลิปจริงจากผู้ใช้ | รูปเต็มจอ / โพลารอยด์ / viewfinder | `cutaway` · `polaroid` · `viewfinder` | เข้าตรงคำที่อ้างถึง |

## องค์ประกอบที่ทำให้ดูโปร

- **ก้อนเดียวกึ่งกลาง** — `stack(top, w, h, …)` ใต้ซับ; ซับ + UI อ่านจากบนลงล่างเป็นประโยคเดียว.
- **ขนาด** — การ์ด/สำรับกว้าง 460–860 px, ตัวหนังสือในการ์ด 44–52 px, หัวข้อ 52 px. ถ้าการ์ดดูเล็กในเฟรม แปลว่าเล็กเกินไป.
- **การ์ดโตตามเนื้อหา** — ไม่มีกล่องว่างรอแถว; แถวใหม่ทำให้การ์ดยืดลง (`gcard` ทำให้แล้ว).
- **ทีละชิ้น ทีละจุดสนใจ** — ช่วงที่มี UI ซับเหลือแค่คำนำ; หลังชิ้นหนึ่งออก ให้ว่าง ≥ 1 วิ ก่อนชิ้นถัดไป (ยกเว้นต่อเนื่องเรื่องเดียวกัน).
- **ค้างให้อ่าน** — UI อยู่บนจอ ≥ 1.2 วิ หลังแถวสุดท้ายขึ้น; ออกด้วยเบลอ 0.18 วิ.
- **จังหวะเสียง** — ทุกการเข้าออกมีเสียงเบา ๆ ให้อัตโนมัติ; อย่าใส่เสียงเพิ่มซ้อน.

## ออกแบบคอมโพเนนต์ใหม่

ภาษาเดียวกัน: **หน้าจอแอปมือถือแบบ liquid glass** — แคปซูล/การ์ดมุมมน 44–48, `GLASS.dark|blue|light` ขอบขาวบาง + ไฮไลต์บน,
ไอคอนแอป (`appIcon`) หรือ badge (`badge`) จาก Lucide, Kanit ตัวเอียง (UiBold หัวข้อ / UiIt เนื้อหา / LeadIt รอง), ฟ้า + ขาว (+ เขียว/แดงเมื่อหมายถึงใช่/ไม่ใช่).
การเคลื่อนไหว: สไลด์/ลอย + เบลอ→ชัด (SPRING ~0.4 วิ), ของในชิ้นขึ้นตามคำ. ข้อความ ≤ 3–4 คำต่อบรรทัด. **ห้ามอีโมจิ.**
สร้างจาก `glass()` / `div()` + `A()` แล้ว preview อย่างน้อย 3 เวลา (เพิ่งขึ้น, ตอนเหตุการณ์ตรงคำ, ก่อนหาย) แบบ crop โซนอก.
