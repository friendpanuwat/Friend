# มาตรฐานงาน (glass-ui)

## Brand (`brand.json`)

คัดลอก `assets/brand.default.json` → `<project>/brand.json` แล้วแก้. ซับ วิดเจ็ต พื้น screen เปลี่ยนตามตอน build.

| คีย์ | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `sky` / `accent` / `deep` | `#8FDCFF` / `#2F8CFF` / `#1557E6` | ไล่สีของคำใหญ่ (บน→ล่าง), การ์ด progress, ป้ายเน้น, badge, พื้น screen |
| `good` / `bad` | `#34C759` / `#FF3B30` | ติ๊กเขียว / กากบาทแดง / ป้ายแดงโพลารอยด์ — ใช้เฉพาะความหมาย ใช่/ไม่ใช่ |
| `navy` | `#0E1B33` | ตัวอักษรบนพื้นสว่าง (screen, ป้ายกระจกขาว) |
| `fonts.key / lead / ui / ui_bold / ui_plain` | Kanit Black Italic / Medium Italic / SemiBold Italic / ExtraBold Italic / Medium | ไฟล์ .ttf — path อิงจาก brand.json แล้วจึง assets/ |
| `sfx_db` | `-11` | ระดับแทร็กเสียงประกอบทั้งหมด |

แบรนด์สีอื่นได้ (เช่น ม่วง/ชมพู) แต่ต้องเป็น **ไล่สีตระกูลเดียว** สว่าง→เข้ม และคำใหญ่ต้องอ่านออกบนเสื้อ/พื้นหลังของคลิป.
ฟอนต์ไทยต้องมีตัวเอียงและรองรับสระครบ, ใช้เชิงพาณิชย์ได้ (Kanit = OFL — `assets/licenses/OFL-kanit.txt`; ไอคอน Lucide = ISC). **ไม่ใช้อีโมจิ.**

| การ์ด: หัวข้อ / แถว / รอง | Kanit ExtraBold / SemiBold / Medium Italic | 52 / 52 / 36 | ขาวบนกระจกเข้ม |
| ป้ายกระจก | Kanit SemiBold Italic ตัวพิมพ์ใหญ่ | 54 | ขาวบนกระจกเข้ม |

Motion: คำนำ/ท้าย = ลอยขึ้น 12 px + เบลอ 6→0 ใน 0.2 วิ ทีละคำ; คำใหญ่ = ปาดจากซ้าย (clip) + เลื่อน 30 px + เบลอ 9→0 ใน 0.3 วิ;
ก้อนหาย = เบลอ + จาง 0.15 วิ. วิดเจ็ตเข้า = สไลด์/ลอยขึ้น + เบลอ→ชัด (SPRING 0.42 วิ) หรือเด้ง; ออก = เบลอ + จาง 0.18 วิ.

## โซนบนจอ (1080×1920)

- **แกนกลาง**: ซับ + UI กึ่งกลาง x 540 เป็นก้อนเดียว (`stack`). วางข้างหัวเฉพาะชิ้นเล็กที่ต้องชี้ถึงหน้า.

- **ซับ**: `top` = คาง + ~40 (ref: ใต้คาง ระดับคอ/อกบน, ประมาณ y 1000–1180). กว้าง ≤ 980.
- **วิดเจ็ต**: ใต้ซับถึง y 1620 (ระดับอก ทับเสื้อได้) หรือข้างหัว/เหนือหัวถ้ามีที่ว่าง ≥ 200 px. ห้ามทับตา/ปาก/จมูก.
  ถ้าวิดเจ็ตสูงเกินที่ว่าง ให้ซับช่วงนั้นเหลือแค่คำนำ แล้ววางวิดเจ็ตสูงขึ้น (ref ทำแบบนี้).
- ล่าง 300 px (y > 1620) และขวา 140 px: เว้นให้ UI ของ TikTok/Reels. อย่าวางอะไรเหนือ y 110.

## กล้องและทรานสิชัน

- **ไม่เกรดสีเป็นลุค** — คลิปคมตามต้นฉบับ (เบลอเฉพาะช่วงทรานสิชันไม่กี่เฟรม). คลิปมืด/ทึบ: `LOOK=clean` ตอน frames (gamma 1.12, contrast 1.06, saturation 1.08) แล้วบอกผู้ใช้.
- `blurIn` ที่ต้นเรื่อง/ประโยคใหม่ ทุก 3–6 วิ · `whip` ≤ 2 ครั้ง/คลิป · `push` 1.2–2.0 เท่า สำหรับคำเด็ด (ไม่เกิน 1–2 ครั้ง) · `shake` คำกระแทก ·
  `zoom` 1.04–1.10 นุ่ม ๆ ระหว่างประโยค. ห้ามซ้อนทรานสิชันติดกันน้อยกว่า ~1 วิ.
- `screen` ≤ 1 ครั้ง/30 วิ, ยาว 2.5–4.5 วิ · `cutaway` ≤ 1–2 ครั้ง/30 วิ, ยาว 1–3 วิ, ต้องมีรูปจริง.

## เสียง

ความดังรวม **−14 LUFS ±0.5, peak ≤ −1.5 dBTP** (pipeline ทำให้). เสียงประกอบสังเคราะห์จาก `scripts/sfx.py` (ไม่มีลิขสิทธิ์).

| จังหวะ | เสียง | dB |
|---|---|---|
| คำใหญ่ | `softswish` (ผ่าน `keyHit`) | −22 |
| blurIn / whip / screen | `whoosh` อัตโนมัติ | −27 / −24 / −24 |
| push | `softswish` อัตโนมัติ | −24 |
| shake / ชิ้นตก | `thud` | −22 |
| ป้ายกระจก | `pop_lo` + `glint` อัตโนมัติ | −26 / −31 |
| มือกด | `click` อัตโนมัติ | −21 |
| ฟอง / ไอคอนแตก | `pop_hi` อัตโนมัติ | −26 / −28 |
| สีปาด / วงล้อม | `swipe` อัตโนมัติ | −26 / −28 |
| cutaway | `paper` + `whoosh` อัตโนมัติ | −20 / −26 |
| ปิดคลิป | `sub` (ใส่เอง) | −16 ถึง −18 |
**ไม่ใช้** glitch, boing, womp, เสียงการ์ตูน. เพลงประกอบไม่ใส่ (ลิขสิทธิ์) — แนะนำให้ผู้ใช้เลือกในแอปตอนโพสต์.

## ส่งงานและรับฟีดแบ็ก

ส่ง MP4 + ลิงก์ HQ + ตารางสรุป (ช่วงเวลา · ซับ · วิดเจ็ต/กล้อง) + บอกจุดที่ตัดสินใจเอง (แก้คำผิด, รูปที่ใช้/ไม่ได้ใช้, เฟรมที่ crop มาเป็นรูป, HOLD)
+ บอกตรง ๆ ว่าตรวจจากภาพนิ่ง. ขอฟีดแบ็กแบบระบุวินาที; แก้เฉพาะจุด, preview จุดนั้น แล้วเรนเดอร์เวอร์ชันถัดไป.
