# Core — หัวใจของ skill นี้ (ผู้ใช้ยืนยันแล้ว ห้ามเปลี่ยนเองโดยไม่ถาม)

สกิลนี้คือ `minimal-talking-shorts` แบบ overlay (ผู้ใช้สั่งแยก เหมือน talking-head-motion กับ talking-head-overlay):
กฎทุกข้อเหมือนตัวเดิม ต่างแค่ **ไม่มีฉากเต็มจอ** — หน้าคนพูดอยู่บนจอตลอด และภาพประกอบเป็นการ์ดชิ้นเล็กเด้งขึ้นเหนือหัว.

## ขั้นตอนฝั่งลูกค้า
- **ไม่ตัดช่วงเงียบ** และไม่ให้ลูกค้าตัดเองก่อนส่ง — ใช้คลิปตามที่ส่งมา.
- ลูกค้าส่งคลิป + บทพูดพร้อมเวลา แล้วสั่ง — ที่เหลือ Claude ทำบนคลาวด์. ห้ามเพิ่มขั้นตอนให้ลูกค้า.

## วิธีเล่าเรื่อง
1. **หน้าคนพูดอยู่บนจอตลอดทั้งคลิป** — ไม่ตัดไปฉากพื้นขาว ไม่เบลอ ไม่ทำให้คลิปมืดลง.
2. **ประโยคไหนมีภาพให้เล่า → การ์ดเด้งขึ้นเหนือหัว** (`pop()` ใน `assets/overlay_kit.js`): ของที่ประโยคพูดถึง
   (ป้ายราคา, ปุ่มจ่ายเงิน, คนที่หายไป, ตาชั่ง, เป้า …) ส่วนประกอบในการ์ดขึ้นตามคำพูด (แถวที่ 2 ขึ้นตอนพูดข้อที่ 2).
   ถามตัวเองว่า "ถ้าปิดเสียง การ์ดนี้ยังสื่อไหม".
3. **ทีละใบ** — ใบก่อนต้องหายก่อนใบถัดไปขึ้น; ประมาณ 1 ใบต่อ 3–4 วินาที เฉพาะประโยคที่ภาพช่วยเล่า,
   เว้นช่วงไม่มีการ์ดบ้าง (เช่น 2 วินาที) ให้คนดูพักสายตา.
4. **รายการเหตุผล = บรรทัดไล่ทีละข้อในการ์ดเดียว** พร้อมไอคอนนำหน้า; ข้อที่ผ่านแล้วเป็นสีเทา; คำดี/คำร้ายแยกสีให้ชัด.
5. **คำเปลี่ยนเรื่อง** ("แต่…", "เพราะฉะนั้น…") — ใช้ `beat()` เลื่อนเนื้อหาในการ์ดไปจังหวะใหม่ แทนการตัดฉาก.

## กล้อง
- **ซูมแบบเดียวกับ talking-head-motion ทุกอย่าง** (ผู้ใช้สั่ง): `zoom(t, scale, dur)` — วลีปกติ 1.04–1.06 ค่อย ๆ, คำเน้น 1.07–1.10 เร็ว,
  ไม่เกิน 1.14, กลับ 1.0 (.35) ตอนขึ้นประโยคใหม่; สูตร จุดศูนย์กลาง และการหายใจของกล้องเหมือนกันทุกตัวเลข (`zoom.md`).
  การ์ดไม่ซูมตามกล้อง แต่ `pop()` วัดหัวตอนซูมแล้ว จึงไม่ชนหัว.

## การ์ด (ผู้ใช้สั่ง — สไตล์เดียวกับฉากของ minimal-talking-shorts)
- **มินิมอลแบบมืออาชีพ**: การ์ดขาว เส้นขอบบางสีดำ มุมมน เงานุ่ม · **คนและมือเป็นรูปทรงดำทึบแบบป้ายสัญลักษณ์** · **สิ่งของเป็นเส้นบางสีดำ
  พื้นเทาอ่อน** · เลขเล็กสีเทา, คำไทยตัวหนาสีดำ · **สีแดงจุดเดียวต่อการ์ด**. ไม่ใช้คนก้างปลา.
- **ออกแบบใหม่ทุกการ์ดให้ตรงกับประโยคนั้นของคลิปนั้น** — ไม่ใช้เทมเพลตเดียวเปลี่ยนคำ. ชุดเครื่องมือ: `assets/overlay_kit.js`
  (`pop`, `cv`, `beat`, `txt`) + `assets/minimal_kit.js` (`pic`, `HAND`, `card`, `redQ`, `vanishingPerson`, `countUp`, `rise`, `popIn`, สี);
  ตัวอย่าง: `examples/clip01-customers/graphics.js` — อ่านเป็นไอเดีย อย่าคัดลอกการ์ดไปใช้กับคลิปอื่น.
- ขนาดออกแบบ 800 × 240 (ค่าเริ่มต้นของ `pop()`); ถ้าเหนือหัวมีที่ว่าง การ์ดขยายเองได้ถึงกว้างเต็มช่วงปลอดภัย (×1.15 สูงสุด).
  ตัวหนังสือในการ์ด ≥ 30 px (คำหลัก 44–64 px).

## จังหวะ (retention — ผู้ใช้สั่ง)
- **เปิดคลิปด้วยหน้าคนพูด + hook** เป็นซับตัวใหญ่ใต้คางที่เห็นตั้งแต่เฟรม 0; การ์ดใบแรกมาหลัง ~1.5–2 วิ.
- ตัดต่อให้เข้ากับคนสมาธิสั้น แต่ไม่เร็วเกินไป: การ์ดละ 2–4.5 วิ (หลายจังหวะในการ์ดเดียวด้วย `beat()`), ซับเป็นวลีแบบคาราโอเกะ,
  ซูมเฉพาะคำเน้น; ไม่ใส่เสียงประกอบ ไม่มีแถบความคืบหน้า (`retention.md`).

## ซับ
- **ขึ้นครบทุกคำพูดตลอดทั้งคลิป** (ไม่มีฉากเต็มจอมาช่วยเล่า) ใต้คาง **ห้ามบังหน้า** (`text-and-placement.md`);
  ตัดคำลงท้าย "เนี่ย/อ่ะ/เว้ย" ได้ — บอกผู้ใช้ว่าตัดคำไหน.

## กฎถาวร
- **หลบแถบขวา** (ปุ่มไลก์/ติดตาม/แชร์ของ TikTok/IG — ผู้ใช้สั่ง): ตัวหนังสือและกราฟิกทั้งหมดอยู่ในช่วง x 60–900 (เว้นขวา 180 px), ซับจัดกลางที่ x 480.
- **หลบแถบบน** (แถบ "กำลังติดตาม / สำหรับคุณ" ของ TikTok และหัว Reels ของ IG — ผู้ใช้สั่ง): ไม่มีตัวหนังสือหรือกราฟิกเหนือ y 240 (`SAFE.t`).
  `pop()` แจ้ง error เมื่อการ์ดเลยเส้นบน เลยขอบขวา หรือชนหัว; ตรวจด้วย contact sheet ที่ตีเส้นแดงที่ x 900 และ y 240.
- **เหนือหัวแคบเกินไป** (ยอดหัวสูงกว่า ~y 560): ย่อการ์ด (`h` น้อยลง) หรือวางข้างลำตัวด้วย `{x, y}` เอง — ห้ามบังหน้า.
- ห้ามบังหน้า (ทุกการ์ด ทุกซับ).
- ห้ามแต่งข้อเท็จจริง — ข้อความในการ์ดมาจากคำพูด; คำที่ต้องเติมให้สั้น ไม่มีตัวเลข/ราคา/ชื่อ และบอกผู้ใช้.
- ไม่ใช้โลโก้/หน้าตาแอปจริง.
- ไม่ปรับสีวิดีโอ (no color grading).
