# มาตรฐานงาน (editorial)

## Brand (`brand.json`)

คัดลอก `assets/brand.default.json` → `<project>/brand.json` แล้วแก้. การ์ด ไฮไลต์ ป้าย MG เปลี่ยนตามตอน build.

| คีย์ | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `accent` | `#DDFF45` | สีเดียวของคลิป: คำสำคัญ, กล่องไฮไลต์, ป้ายตัวเลข, ชิป/ปุ่ม MG |
| `navy` | `#14213D` | ตัวอักษรบนการ์ดสว่าง, แท่งกราฟ, tile เข้ม |
| `cream` | `#F2EDE2` | พื้นโปสเตอร์ / frame() |
| `ink` | `#000000` | พื้นการ์ดดำ (ต้องดำสนิทถ้าใช้รูปพื้นดำ) |
| `pill` | `#1B2A52` | ป้ายเม็ดยา |
| `fonts.key_sans / key_serif / lead / card_sans` | Kanit ExtraBold / Trirong SemiBold Italic / Kanit Medium / Kanit Bold | ไฟล์ .ttf — path อิงจาก brand.json แล้วจึง assets/ |
| `sfx_db` | `-11` | ระดับแทร็กเสียงประกอบทั้งหมด |

accent ต้องอ่านออกบนพื้นดำและบนหน้าคนพูด (สีสว่างอิ่ม). ฟอนต์ไทยต้องรองรับสระ/วรรณยุกต์ครบ และใช้เชิงพาณิชย์ได้
(Kanit, Trirong = OFL — ไฟล์ license อยู่ใน `assets/licenses/`; ไอคอน Lucide = ISC).

## ตัวอักษร

| ชั้น | ฟอนต์ | ขนาด | สี |
|---|---|---|---|
| คำนำ `l` | Kanit Medium | 54 (บนการ์ด 60–70) | ขาว / กรมท่า |
| คำสำคัญ `k` | Kanit ExtraBold, letter-spacing −4 | 150 (statement 170–190) | accent |
| คำสำคัญเอียง `i` | Trirong SemiBold Italic | 140 | accent / ขาว / กรมท่า |
| ไฮไลต์ `hl` | Kanit ExtraBold บนกล่อง accent มุม 12 | 90–120 | ดำ |
| ป้ายเม็ดยา | Trirong Italic | 58 | ขาวบน pill |

Motion: คำนำ = ลอยขึ้น 16 px + เบลอ 7→0 ใน 0.2 วิ; คำสำคัญ = ย่อ 1.16→1 + เบลอ 14→0 ใน 0.26 วิ; ก้อนหายแบบตัดทันที.
ซับ A-roll มีเงาดำนุ่ม (ไม่มีกล่องพื้นหลัง).

## โซนบนจอ (1080×1920)

- ซับ A-roll: ระดับอก (ค่าเริ่ม top 1150, ตรวจกับ `grid.jpg`) — ห้ามทับปาก/ตา; กว้าง ≤960, สูง ≤420
- การ์ด: MG/ภาพ y 150–1100 · ข้อความ y 1200–1600 · หัวเรื่องบนสุด y ≥120
- ล่าง 300 px และขวา 140 px: เว้นให้ UI ของ TikTok/Reels

## กล้อง

- **ไม่เกรดสี** ไม่มี vignette ไม่มี grain — ฟุตเทจตามที่ถ่าย (pipeline ทำแค่ denoise/sharpen เบา ๆ).
- ซูมแบบตัดชน 1.06–1.14 ที่คำสำคัญ, กลับ 1.0 ที่ก้อนถัดไป. ห้ามซูมพุ่ง/หมุน/whip/กลิตช์.

## เสียง

ความดังรวม **−14 LUFS ±0.5, peak ≤ −1.5 dBTP** (pipeline ทำให้). เสียงประกอบสังเคราะห์จาก `scripts/sfx.py` (ไม่มีลิขสิทธิ์).

| จังหวะ | เสียง | dB |
|---|---|---|
| คำสำคัญ | `softswish` (ผ่าน `keyHit`) | −22 |
| การ์ดเข้า | `whoosh` (ดำ) / `swipe` (ขาว/ครีม) อัตโนมัติ | −24 |
| tile / bubble / pill เด้ง | `pop` / `pop_hi` / `pop_lo` อัตโนมัติ | −25 ถึง −27 |
| ขีดฆ่า / เส้นกราฟ | `swipe` อัตโนมัติ | −24 |
| กากบาท / x | `stamp` | −21 |
| ลูกศรเข้าเป้า / ชิปตก | `thud` | −16 / −22 |
| ปิดคลิป | `sub` | −16 |
**ไม่ใช้** glitch, boing, womp, sparkle. เพลงประกอบไม่ใส่ (ลิขสิทธิ์) — แนะนำให้ผู้ใช้เลือกในแอปตอนโพสต์.
