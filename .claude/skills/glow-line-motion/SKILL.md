# Glow Line Motion

ลายเส้นขาวเรืองแสงบนพื้นดำที่ผู้ใช้ชอบมาก (ต้นแบบ: "3 WAYS TO SIMPLIFY" — `examples/rows-simplify.html`).
เอนจิน `assets/glowline.js` (SVG ใน Chromium ผ่าน Playwright) ล็อกสไตล์ไว้แล้ว: คุณ (Claude) เขียนแค่ `scene.html`
ซึ่งเป็นสคริปต์สั้น ๆ เรียกเลย์เอาต์ + ภาพวาด แล้ว `scripts/render.js` ถ่ายทีละเฟรมเป็น MP4.

ลายเส้นนี้ **ไม่ได้ผูกกับก่อน→หลัง** — ก่อน→หลังเป็นแค่หนึ่งในหลายแบบที่เล่าได้ (ตาราง "เลือกเลย์เอาต์").

## หัวใจของสไตล์ (สรุป — ฉบับเต็ม `references/style.md` อ่านก่อนวาดอะไรใหม่)

1. **ขาว-ดำล้วน เรืองแสง** — เส้น `#f2f2f2` บนพื้นดำไล่เงา, รูปทรงปิดถม `#171717` เพื่อบังเส้นข้างหลัง (ของซ้อนจึงอ่านออก).
   ไม่มีสีอื่นถ้าผู้ใช้ไม่ขอ.
2. **มองหน้าตรงแบบแบน รายละเอียดน้อย** — ตัดทอนของจริงให้เหลือเส้นที่ทำให้จำได้ (โครง 1 เส้น + รายละเอียด 1–3 เส้น).
   กองของ / ของที่ต้องเห็นปริมาตร ใช้มุมเฉียง isometric (`kit.isoBox`, `GL.iso`, `parts.paperStack`).
3. **ทุกเส้นวาดตัวเอง** — วาดด้วย Pen ของเอนจินเท่านั้น. ห้ามใช้รูป PNG / emoji / ไอคอนจากที่อื่น (จะไม่วาดตัวเอง หลุดสไตล์ทันที).
4. **ใช้ของในชุดก่อนวาดเอง** — คน มือ ลูกศรเชื่อมขั้นตอน badge เคอร์เซอร์ ประกาย กล่อง อยู่ใน `GL.kit` (`references/kit.md`)
   ปรับสัดส่วนไว้แล้ว ทุกคลิปจะสวยเท่ากัน. ของทั่วไป (ซอง มือถือ นาฬิกา ฯลฯ) อยู่ใน `GL.parts`.
5. **ตัวอักษร** — อังกฤษ Inter Display Bold ตัวพิมพ์ใหญ่เรืองแสง, ไทย Anuphan (สลับให้อัตโนมัติ). ซับไทยสีเทาอ่อน ไม่เรืองแสง.
6. **ภาพต้องตรงความหมาย** — ไม่มีภาพที่ตรง ให้วาดใหม่ตาม `style.md` อย่ายัดภาพที่ใกล้ ๆ แต่ความหมายไม่ตรง.
7. **เรืองแสงเป็นจังหวะ = คำตอบ** — หนึ่งครั้งต่อช่วง (เลย์เอาต์ทำให้เอง); หรี่ลง = ลดความสำคัญ; ลูกศร = เวลา/เหตุผล.

## สิ่งที่ต้องรู้ก่อนเริ่ม

- ผู้ใช้สั่งจากมือถือ — ห้ามขอให้ติดตั้ง/รันคำสั่ง. รัน `scripts/check_env.sh` ก่อนเสมอ.
- ข้อความมาจากผู้ใช้: ย่อ แปล ตัด เรียงได้ แต่ห้ามแต่งตัวเลข สถิติ สเปกสินค้า หรือข้ออ้างที่เขาไม่ได้ให้.
  ถ้าได้แค่หัวข้อ ("ทำ 5 วิธีประหยัดเงิน") ให้คิดรายการ + ภาพเอง แล้วทำเลย — บอกตอนส่งงานว่าคิดอะไรเพิ่ม.
- คุณดูงานได้เป็นภาพนิ่ง: เปิด `still.png` + `storyboard.jpg` ทุกครั้ง, ครอปดูจุดที่สงสัยด้วย ffmpeg `crop`.
- ไม่มีเสียง — ผู้ใช้ใส่เพลงในแอปตอนโพสต์ได้ (บอกเขา).

## เลือกเลย์เอาต์

| งาน | เลย์เอาต์ | ความยาวโดยประมาณ |
|---|---|---|
| ก่อน→หลัง 1–4 ข้อ (แบบต้นแบบ) | `GL.rows` | ~2.3 วิ/ข้อ + 2 วิ |
| ก่อน→หลัง 5–12 ข้อ | หลาย `GL.page` × `GL.rows` (3 ข้อ/หน้า) | ~2.3 วิ/ข้อ |
| ก่อน→หลัง 6–20 ข้อ เป็นโปสเตอร์ (แบบ 20 WAYS) | `GL.grid` | ~0.5 วิ/ข้อ + 2 วิ |
| ก่อน→หลัง ข้อเดียวเต็มจอ / B-roll | `GL.hero` (+ `--alpha`) | ~4–5 วิ |
| **ขั้นตอนต่อกัน** (how-to, กระบวนการ, สูตร) | `GL.flow` — ลูกศรเชื่อม + เลขขั้น | ~1.4 วิ/ขั้น |
| ทิป / นิสัย / เช็กลิสต์ (ไม่ต่อกัน) | `GL.steps` | ~1 วิ/ข้อ |
| **เล่าเรื่องเป็นฉาก ๆ** (หนึ่งวันของ…, เคส, ไทม์ไลน์) | `GL.shots` | ~3 วิ/ฉาก |
| **แผนผัง / ระบบ / ใครเชื่อมกับใคร** | `GL.diagram` | ~1 วิ/โหนด |
| **โชว์สินค้า / ฟีเจอร์** | `GL.showcase` — เส้นชี้ทีละฟีเจอร์ | ~2 วิ + 0.6 วิ/ฟีเจอร์ |
| ไม่เข้าแบบไหน (ภาพเปิด/ปิด, วงจร, เทียบ 2 ทาง) | ฉากอิสระ: `GL.place` + `GL.connect` + `GL.text` | — |
| ผสมหลายแบบในคลิปเดียว | ห่อแต่ละช่วงด้วย `GL.page` | — |

วิธีใช้เลย์เอาต์ที่ไม่ใช่ก่อน→หลัง + การวางแผนจังหวะ: `references/scenes.md`.
เร่ง/ชะลอได้ด้วย `ts` (0.7 = เร็วขึ้น 30%). คลิป TikTok/Reels: `rows` / `flow` / `diagram` ใส่ `bottom: GL.H - 220` เว้นที่แคปชัน
(`showcase` / `shots` เว้นให้แล้ว).

## Workflow

ตั้ง `SK=<path ของ skill นี้>` และ `P=<โฟลเดอร์งานใน scratchpad>` (ชื่อสั้นไม่มีช่องว่าง).

1. `bash $SK/scripts/check_env.sh`
2. `bash $SK/scripts/new_scene.sh $P [ตัวอย่าง]` → `$P/scene.html` — เริ่มจากตัวอย่างที่ใกล้ที่สุด:
   ก่อน→หลัง `rows-simplify` · `grid-catalog` · `hero-desk` · `pages-six` (มีตัวอย่างวาดคู่ใหม่) ·
   ทิป `steps-habits` · ขั้นตอน `flow-sell-online` · เรื่องเป็นฉาก `story-freelance` · แผนผัง `diagram-shop` · สินค้า `showcase-tumbler`.
3. **เขียน scene** (แก้แค่ใน `GL.run(() => { ... })`): อ่าน `references/api.md`;
   ภาพ: ดู `references/kit.md` + `kit.jpg` (คน มือ ลูกศร) → `references/pairs.md` + `catalog.jpg` (คู่ก่อน→หลัง ไอคอน) →
   ไม่มีที่ตรง วาดใหม่ตาม `references/style.md` (คู่ก่อน→หลังดู `references/drawing.md` เพิ่ม).
4. **ภาพนิ่งก่อน** (เร็ว ~5 วิ): `node $SK/scripts/render.js $P/scene.html $P/out --still`
   → เปิด `$P/out/still.png` + `storyboard.jpg` ตรวจตาม QC ด้านล่าง, แก้จนผ่าน. ถ้าขึ้น `SCENE ERROR` อ่านข้อความแล้วแก้ scene.
   คลิปหลายหน้า/หลายฉาก: เพิ่ม `--at <เวลาจบของแต่ละหน้า,…>` เพื่อดูทุกหน้า (`still.png` เห็นแค่หน้าสุดท้าย).
5. **MP4**: `node $SK/scripts/render.js $P/scene.html $P/out --name <ชื่องาน>` (~1 นาที ต่อคลิป 10 วิ).
   พื้นใสสำหรับซ้อนบนวิดีโอ: เพิ่ม `--alpha` → `.mov` ProRes 4444 (ไฟล์ใหญ่ ~10 MB/วิ สำหรับ Premiere / Final Cut / DaVinci). แอปตัดต่อบนมือถือส่วนใหญ่อ่าน alpha ไม่ได้ — ถ้าผู้ใช้ตัดในมือถือ ส่ง MP4 พื้นดำ แล้วบอกให้ตั้งโหมดผสม (blend) เป็น Screen ซึ่งจะลบพื้นดำออกเอง.
6. **ส่งงาน**: ถ้า session มี git repo ให้คัดลอก `scene.html`, `<ชื่อ>.mp4`, `still.png`, `storyboard.jpg` ไป `motion/<ชื่องาน>/`
   แล้ว commit + push; ส่ง MP4 + still ในแชท (SendUserFile) พร้อมสรุปสั้น ๆ ว่ามีกี่ข้อ/ฉาก ใช้ภาพอะไร วาดอะไรใหม่
   แล้วขอฟีดแบ็กแบบระบุเลขข้อ/ฉาก. ไฟล์ใหญ่เกินแชท: `bash $SK/scripts/deliver_github.sh <ไฟล์> <ชื่อ>`.
   `scene.html` พกไปที่ไหนก็ render ได้ — `render.js` ชี้หาเอนจินของ skill ให้เอง.

## QC ก่อนส่ง (ดูจาก still + storyboard)

ทุกแบบ:
- ภาพไม่ชนกัน ไม่ล้นช่อง ไม่ทับเส้นแบ่ง; ป้ายไม่ล้น (เอนจินย่อให้ แต่ถ้าย่อจนเล็กเกินไป ให้ตัดคำให้สั้นลง).
- ภาพที่วาดใหม่ดูเป็นชุดเดียวกับของเดิม (หน้าตรง เส้นหนาเท่ากัน ถมดำ มุมมน รายละเอียดน้อย — `style.md`).
- ลูกศรไม่ทับตัวหนังสือ, ตัวหนังสือไม่อยู่ในแถบล่าง 220 px / ขอบขวา 120 px ของ 9:16.
- storyboard: เฟรมแรกมีอะไรขึ้นภายใน ~0.5 วิ, ไม่มีช่วงนิ่งว่างกลางคลิป, จบด้วยค้างภาพเต็ม ~1.5 วิ.
- ไม่มีสีอื่นนอกจากขาว/เทา/ดำ (ยกเว้นผู้ใช้ขอ).

ก่อน→หลัง: ฝั่งรก "รกจริง" (≥ 5 ชิ้น ซ้อน/เอียง), ฝั่งเรียบ "เรียบจริง" (1–3 ชิ้น), ทุกคู่สื่อหัวข้อตรง ๆ.
ขั้นตอน / ฉาก / แผนผัง / สินค้า: ตามหัวข้อ QC ท้าย `scenes.md` (ตรวจทุกหน้าด้วย `--at`, คนสัดส่วนสมจริงกับของรอบตัว).

## ไฟล์ใน skill

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `references/style.md` | **ภาษาของลายเส้น** — มุมมอง การตัดทอน isometric เส้น การจัดวาง การเคลื่อนไหว เล่าแบบไหนใช้อะไร (ใช้กับทุกงาน) |
| `references/api.md` | ทุกฟังก์ชัน: `stage` `title` `text` `caption` + เลย์เอาต์ทั้งหมด + Pen (`tube`) + parts + ตัวเลือก render |
| `references/kit.md` + `kit.jpg` | ชุดสำเร็จรูปที่วาดยาก: คน 10 ท่า, หัว+ไหล่, ทีม, มือ (ชี้ ยกนิ้ว แบมือ แตะ ถือมือถือ), ลูกศร 5 แบบ, badge, เคอร์เซอร์, ประกาย, กล่อง isometric |
| `references/scenes.md` | ขั้นตอน (`flow`), เรื่องเป็นฉาก (`shots`), แผนผัง (`diagram`), โชว์สินค้า (`showcase`), ฉากอิสระ, ผสมหลายแบบ |
| `references/pairs.md` + `catalog.jpg` | คู่ภาพก่อน→หลังสำเร็จรูป 12 คู่ + ไอคอนเดี่ยว |
| `references/drawing.md` | วิธีออกแบบคู่ก่อน→หลังใหม่ (กรอบ, ลำดับชั้น, ทริกทำให้ "รก") |
| `examples/*.html` | ต้นแบบที่ render ผ่านแล้วของทุกเลย์เอาต์ + `kit-catalog.html` (ที่มาของ `kit.jpg`) |
| `assets/glowline.js` | เอนจิน + parts + kit + pairs (เพิ่มชิ้น/คู่ใหม่ที่ใช้บ่อยไว้ที่นี่ได้ เมื่อผู้ใช้พอใจแล้ว — วิธีใน `kit.md`) |
| `assets/template.html` | scene เปล่าเริ่มต้น |
| `scripts/render.js` | scene → MP4 / still / storyboard (`--at`) / MOV alpha |
| `scripts/new_scene.sh` · `check_env.sh` · `deliver_github.sh` | สร้าง scene · ตรวจเครื่อง · ส่งไฟล์ใหญ่ผ่าน GitHub |
