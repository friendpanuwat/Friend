# Glow Line Motion

ลายเส้นขาวเรืองแสงบนพื้นดำ ที่ผู้ใช้ชอบมาก (ต้นแบบ: "3 WAYS TO SIMPLIFY" — `examples/rows-simplify.html`).
เอนจิน `assets/glowline.js` (SVG ใน Chromium ผ่าน Playwright) ล็อกสไตล์ไว้แล้ว: คุณ (Claude) เขียนแค่ `scene.html`
ซึ่งเป็นสคริปต์สั้น ๆ เรียกเลย์เอาต์ + ภาพวาด แล้ว `scripts/render.js` ถ่ายทีละเฟรมเป็น MP4.

## หัวใจของสไตล์ (ทำไมมันดูดี — รักษาไว้)

1. **ขาว-ดำล้วน** — เส้น `#f2f2f2` บนพื้นดำไล่เงา, รูปทรงปิดถม `#171717` เพื่อบังเส้นที่อยู่ข้างหลัง
   (ของซ้อนกันจึงอ่านออก). ไม่มีสีอื่น ถ้าผู้ใช้ไม่ได้ขอ — ความเรืองแสงคือจุดเด่น สีจะไปแย่งมัน.
2. **ทุกเส้นวาดตัวเอง** — วาดทุกอย่างด้วย pen ของเอนจิน. ห้ามใช้รูป PNG / emoji / ไอคอนสำเร็จรูปจากที่อื่น
   เพราะมันจะไม่วาดตัวเอง ไม่เรืองแสงแบบเดียวกัน และหลุดสไตล์ทันที.
3. **ก่อน→หลัง** — ซ้าย = รก (หลายชิ้น ซ้อน เอียง เส้นยุ่ง), ขวา = เรียบ (ชิ้นเดียว ตรง โล่ง).
   ฝั่งรกหรี่ลงเมื่อฝั่งเรียบวาดเสร็จ แล้วฝั่งเรียบ "เรืองแสงเป็นจังหวะ" = จุดจบของแต่ละข้อ (เอนจินทำให้เอง).
4. **ตัวอักษร** — อังกฤษ Inter Display Bold ตัวพิมพ์ใหญ่เรืองแสง, ไทย Anuphan (สลับให้อัตโนมัติตามตัวอักษร).
   ป้ายข้อแบบ `1. INBOX` / `1. กล่องจดหมาย`; ซับไทยสีเทาอ่อน ไม่เรืองแสง.
5. **ภาพต้องตรงความหมาย** — ถ้าหัวข้อไม่มีคู่ภาพสำเร็จรูปที่ตรง ให้วาดคู่ใหม่ (`GL.pair`) ตาม `references/drawing.md`
   อย่ายัดคู่ที่ใกล้ ๆ แต่ความหมายไม่ตรง (เช่น ใช้ `paper` แทน "หนังสือ").

## สิ่งที่ต้องรู้ก่อนเริ่ม

- ผู้ใช้สั่งจากมือถือ — ห้ามขอให้ติดตั้ง/รันคำสั่ง. รัน `scripts/check_env.sh` ก่อนเสมอ.
- ข้อความมาจากผู้ใช้: ย่อ แปล ตัด เรียงได้ แต่ห้ามแต่งตัวเลข สถิติ หรือข้ออ้างที่เขาไม่ได้ให้.
  ถ้าได้แค่หัวข้อ ("ทำ 5 วิธีประหยัดเงิน") ให้คิดรายการข้อ + คู่ภาพเอง แล้วทำเลย — บอกตอนส่งงานว่าคิดอะไรเพิ่ม.
- คุณดูงานได้เป็นภาพนิ่ง: เปิด `still.png` + `storyboard.jpg` ทุกครั้ง, ครอปดูจุดที่สงสัยด้วย ffmpeg `crop`.
- ไม่มีเสียง — ผู้ใช้ใส่เพลงในแอปตอนโพสต์ได้ (บอกเขา).

## เลือกเลย์เอาต์

| งาน | เลย์เอาต์ | ความยาวโดยประมาณ |
|---|---|---|
| 1–4 ข้อ, คลิปเดียวจบ (แบบต้นแบบ) | `GL.rows` | ~2.3 วิ/ข้อ + 2 วิ |
| 5–12 ข้อ ต่อเนื่อง | หลาย `GL.page` × `GL.rows` (3 ข้อ/หน้า) | ~2.3 วิ/ข้อ |
| 6–20 ข้อ เป็นโปสเตอร์รวม (เหมือนรูปอ้างอิง 20 WAYS) | `GL.grid` (2 คอลัมน์) | ~0.5 วิ/ข้อ + 2 วิ |
| ข้อเดียวเต็มจอ / B-roll แทรกคลิปพูด | `GL.hero` (+ `--alpha` ถ้าจะซ้อนบนวิดีโอ) | ~4–5 วิ |
| ทิป / นิสัย / เช็กลิสต์ ที่ไม่ใช่ก่อน→หลัง | `GL.steps` (ไอคอนเดี่ยว + ข้อความ) | ~1 วิ/ข้อ |

เร่ง/ชะลอได้ด้วย `ts` (0.7 = เร็วขึ้น 30%). คลิป TikTok/Reels: ใช้ `bottom: GL.H - 220` เพื่อเว้นที่แคปชันด้านล่าง.

## Workflow

ตั้ง `SK=<path ของ skill นี้>` และ `P=<โฟลเดอร์งานใน scratchpad>` (ชื่อสั้นไม่มีช่องว่าง).

1. `bash $SK/scripts/check_env.sh`
2. `bash $SK/scripts/new_scene.sh $P [ตัวอย่าง]` → `$P/scene.html` — เริ่มจากตัวอย่างที่ใกล้ที่สุด:
   `rows-simplify` · `grid-catalog` · `hero-desk` · `steps-habits` · `pages-six` (มีตัวอย่างวาดคู่ใหม่ `closet`).
3. **เขียน scene** (แก้แค่ใน `GL.run(() => { ... })`): อ่าน `references/api.md`; เลือกคู่ภาพจาก `references/pairs.md`
   (ดูภาพรวมที่ `references/catalog.jpg`); หัวข้อไหนไม่มีคู่ตรง → วาดใหม่ตาม `references/drawing.md`.
4. **ภาพนิ่งก่อน** (เร็ว ~5 วิ): `node $SK/scripts/render.js $P/scene.html $P/out --still`
   → เปิด `$P/out/still.png` + `storyboard.jpg` ตรวจตาม QC ด้านล่าง, แก้จนผ่าน. ถ้าขึ้น `SCENE ERROR` อ่านข้อความแล้วแก้ scene.
5. **MP4**: `node $SK/scripts/render.js $P/scene.html $P/out --name <ชื่องาน>` (~1 นาที ต่อคลิป 10 วิ).
   พื้นใสสำหรับซ้อนบนวิดีโอ: เพิ่ม `--alpha` → `.mov` ProRes 4444 (ไฟล์ใหญ่ ~10 MB/วิ สำหรับ Premiere / Final Cut / DaVinci). แอปตัดต่อบนมือถือส่วนใหญ่อ่าน alpha ไม่ได้ — ถ้าผู้ใช้ตัดในมือถือ ส่ง MP4 พื้นดำ แล้วบอกให้ตั้งโหมดผสม (blend) เป็น Screen ซึ่งจะลบพื้นดำออกเอง.
6. **ส่งงาน**: ถ้า session มี git repo ให้คัดลอก `scene.html`, `<ชื่อ>.mp4`, `still.png`, `storyboard.jpg` ไป `motion/<ชื่องาน>/`
   แล้ว commit + push; ส่ง MP4 + still ในแชท (SendUserFile) พร้อมสรุปสั้น ๆ ว่ามีกี่ข้อ ใช้ภาพอะไร วาดอะไรใหม่
   แล้วขอฟีดแบ็กแบบระบุเลขข้อ. ไฟล์ใหญ่เกินแชท: `bash $SK/scripts/deliver_github.sh <ไฟล์> <ชื่อ>`.
   `scene.html` พกไปที่ไหนก็ render ได้ — `render.js` ชี้หาเอนจินของ skill ให้เอง.

## QC ก่อนส่ง (ดูจาก still + storyboard)

- ภาพไม่ชนกัน ไม่ล้นช่อง ไม่ทับเส้นแบ่ง; ป้ายข้อไม่ล้น (เอนจินย่อให้อัตโนมัติ แต่ถ้าย่อจนเล็กเกินไป ให้ตัดคำให้สั้นลง).
- ฝั่งรก "รกจริง" (≥ 5 ชิ้น ซ้อน/เอียง) และฝั่งเรียบ "เรียบจริง" (1–3 ชิ้น) — คนดูต้องเข้าใจโดยไม่ต้องอ่าน.
- ทุกคู่สื่อหัวข้อของมันตรง ๆ; ภาพที่วาดใหม่ดูเป็นชุดเดียวกับของเดิม (เส้นหนาเท่ากัน ถมดำ มุมมน).
- storyboard: เฟรมแรกมีอะไรขึ้นแล้วภายใน ~0.5 วิ (หัวข้อ), ไม่มีช่วงนิ่งว่างกลางคลิป, จบด้วยค้างภาพเต็ม ~1.5 วิ.
- ไม่มีสีอื่นนอกจากขาว/เทา/ดำ (ยกเว้นผู้ใช้ขอ).

## ไฟล์ใน skill

| ไฟล์ | ใช้เมื่อ |
|---|---|
| `references/api.md` | ทุกฟังก์ชัน: `stage` `title` `rows` `grid` `hero` `steps` `page` `text` + Pen + parts + ตัวเลือก render |
| `references/pairs.md` + `catalog.jpg` | คู่ภาพสำเร็จรูป 12 คู่ + ไอคอนเดี่ยว: แต่ละคู่วาดอะไร เหมาะกับหัวข้อไหน |
| `references/drawing.md` | วิธีออกแบบคู่ภาพใหม่ให้เข้าสไตล์ (กรอบ, ลำดับชั้น, ความหนาเส้น, จังหวะ, ทริกทำให้ "รก") |
| `examples/*.html` | ต้นแบบที่ render ผ่านแล้ว ของทุกเลย์เอาต์ |
| `assets/glowline.js` | เอนจิน + parts + pairs (เพิ่มคู่ใหม่ที่ใช้บ่อยไว้ที่นี่ได้ เมื่อผู้ใช้พอใจแล้ว) |
| `assets/template.html` | scene เปล่าเริ่มต้น |
| `scripts/render.js` | scene → MP4 / still / storyboard / MOV alpha |
| `scripts/new_scene.sh` · `check_env.sh` · `deliver_github.sh` | สร้าง scene · ตรวจเครื่อง · ส่งไฟล์ใหญ่ผ่าน GitHub |
