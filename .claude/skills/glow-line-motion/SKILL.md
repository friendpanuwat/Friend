# Glow Line Motion

สิ่งที่ผู้ใช้ชอบคือ **ลายเส้นและสไตล์**: ไอคอนเส้นมินิมอลแบบมองตรง เส้นขาวปลายมนเรืองแสงเหมือนหลอดนีออน บนพื้นดำโล่ง
ทุกเส้นค่อย ๆ ถูกวาดขึ้นอย่างใจเย็น (ต้นแบบ: "3 WAYS TO SIMPLIFY" — `examples/rows-simplify.html`).
skill นี้ใช้สไตล์นั้นกับ **คลิปได้ทุกแนว** — ก่อน→หลังเป็นแค่หนึ่งในหลายรูปแบบ.

เอนจิน `assets/glowline.js` (SVG ใน Chromium ผ่าน Playwright) ล็อกแสง สี เส้น และจังหวะไว้แล้ว:
คุณ (Claude) เขียนแค่ `scene.html` — สคริปต์สั้น ๆ เรียกเลย์เอาต์ + ภาพวาด แล้ว `scripts/render.js` ถ่ายทีละเฟรมเป็น MP4.

## สไตล์ — อ่าน `references/style.md` ก่อนเริ่มทุกงาน

ไฟล์นั้นคือหัวใจของ skill: แสงและสี, รูปทรงแบบไอคอนเส้น, น้ำหนักเส้น, องค์ประกอบ, ตัวอักษร, การเคลื่อนไหว, สิ่งที่ทำให้หลุดสไตล์
และตารางอุปมา (เรื่องนามธรรม → ภาพ). ย่อ ๆ:

1. **ขาว-เทา-ดำล้วน** — ความสว่าง = ความสำคัญ; ไม่มีสีอื่นถ้าผู้ใช้ไม่ขอ (แสงเรืองคือจุดเด่น สีจะไปแย่งมัน).
2. **ทุกอย่างวาดด้วย pen ของเอนจิน** — ห้ามรูป PNG / emoji / ไอคอนจากที่อื่น: มันไม่วาดตัวเอง ไม่เรืองแสงแบบเดียวกัน หลุดสไตล์ทันที.
3. **ไอคอนเส้นมองตรง** เส้นรอบ + ถมดำ มุมมน รายละเอียด 1–3 อย่าง; คน = พิกโตแกรม.
4. **ไอคอนโผล่มาครบแล้วขยับต่อ** (หัวใจเต้น เข็มหมุน คนโบกมือ — ผู้ใช้เลือกแบบนี้แทนการวาดเส้น); เส้นโยง/ไทม์ไลน์/เส้นใต้ยังวาดตัวเอง;
   เน้นด้วยการเรืองแสงเป็นจังหวะ หรือหรี่ที่เหลือ. ลุคเดิมที่ทุกเส้นวาดตัวเอง: `GL.stage({ icons: 'draw' })`.
5. **ภาพต้องตรงความหมาย** — ไม่มีภาพที่ตรง → วาดใหม่ตาม `references/drawing.md` อย่ายัดภาพที่ใกล้ ๆ แต่ผิดความหมาย.

## ฉากสำเร็จรูป 21 หมวด (B01–B21) — หนึ่งประโยค = หนึ่งฉาก

งานที่มาเป็น **บทพูด / ประโยค** (B-roll แทรกคลิปพูด, คลิปอธิบายทีละประโยค) ให้ใช้ `GL.beat('Bxx', data)` ก่อนเลย์เอาต์อื่น:
ตัวเลขเด่น · เพิ่ม/ลด · เปรียบเทียบ · ขั้นตอน · ถูก/ผิด · คำถาม · คำเตือน · เป้าหมาย · ไทม์ไลน์ · กลุ่มเป้าหมาย · แชต/รีวิว ·
เหตุ→ผล · เคล็ดลับ · ประโยคเด็ด · ชวนทำ · นิยาม · รายการ · เหตุการณ์ · ความรู้สึก · ความสัมพันธ์ · สถานที่.
ทุกหมวดรับแค่ข้อความ ตัวเลข และชื่อไอคอน (คำที่ไม่มีในคลังกลายเป็นป้ายคำเอง) จึงใช้ได้กับทุกเรื่อง.
**อ่าน `references/beats.md`** — ตารางเลือกหมวดจากประโยค (B14 = ตัวเลือกสุดท้าย), ข้อมูลของแต่ละหมวด, กฎความเป็นกลาง.
ตัวอย่างทุกหมวด: `examples/beats/B01.html` … `B21.html` · รวมทั้งหมด: `examples/beats/all.html` · ภาพรวม `references/beats.jpg`.

## เลือกรูปแบบ

| เนื้อหา | เลย์เอาต์ | ความยาวโดยประมาณ |
|---|---|---|
| ก่อน→หลัง 1–4 ข้อ (แบบต้นแบบ) | `GL.rows` | ~2.3 วิ/ข้อ + 2 วิ |
| ก่อน→หลัง 5–12 ข้อ ต่อเนื่อง | หลาย `GL.page` × `GL.rows` (3 ข้อ/หน้า) | ~2.3 วิ/ข้อ |
| โปสเตอร์รวม 6–20 ข้อ (เหมือนรูปอ้างอิง 20 WAYS) | `GL.grid` | ~0.5 วิ/ข้อ + 2 วิ |
| ขั้นตอน / กระบวนการ / เส้นทางลูกค้า | `GL.flow` | ~1.2 วิ/ขั้น |
| เปรียบเทียบ A vs B | `GL.versus` | ~4 วิ |
| ตัวเลขสำคัญ (ตัวเลขของผู้ใช้เท่านั้น) | `GL.stat` | ~3–4 วิ |
| ทิป / นิสัย / เช็กลิสต์ | `GL.steps` | ~1 วิ/ข้อ |
| ประโยคเดียว + ภาพเดียว | `GL.spot` | ~3 วิ |
| ข้อเดียวเต็มจอ ก่อน→หลัง / B-roll แทรกคลิปพูด | `GL.hero` (+ `--alpha`) | ~4–5 วิ |
| เล่าเรื่องเป็นฉาก คน + ของ + ลูกศร + ของเคลื่อนที่ | ฉากอิสระ: `GL.art` + `GL.text` + `GL.connect` + `GL.tween` | ตามเรื่อง |

ผสมกันได้ในคลิปเดียวด้วย `GL.page` (เช่น versus → stat → flow). เร่ง/ชะลอด้วย `ts`.
คลิป TikTok/Reels: ใช้ `bottom: GL.H - 220` เพื่อเว้นที่แคปชัน. ขนาด: `GL.stage({w:1080,h:1920})` (ค่าเริ่ม) ·
`{w:1080,h:1080}` · `{w:1920,h:1080}` — flow เปลี่ยนเป็นแถวเดียวในแนวนอนเอง; rows ในแนวนอนใช้ ≤ 2 ข้อ (หรือใช้ grid `cols: 3–4`).

## สิ่งที่ต้องรู้ก่อนเริ่ม

- ผู้ใช้สั่งจากมือถือ — ห้ามขอให้ติดตั้ง/รันคำสั่ง. รัน `scripts/check_env.sh` ก่อนเสมอ.
- ข้อความมาจากผู้ใช้: ย่อ แปล ตัด เรียงได้ แต่ห้ามแต่งตัวเลข สถิติ หรือข้ออ้างที่เขาไม่ได้ให้ (`stat` ต้องใช้ตัวเลขของเขา).
  ถ้าได้แค่หัวข้อ ("ทำ 5 วิธีประหยัดเงิน") ให้คิดรายการข้อ + เลือกรูปแบบ + ภาพเอง แล้วทำเลย — บอกตอนส่งงานว่าคิดอะไรเพิ่ม.
- คุณดูงานได้เป็นภาพนิ่ง: เปิด `still.png` + `storyboard.jpg` ทุกครั้ง, ครอปดูจุดที่สงสัยด้วย ffmpeg `crop`.
- ไม่มีเสียง — ผู้ใช้ใส่เพลงในแอปตอนโพสต์ได้ (บอกเขา).

## Workflow

ตั้ง `SK=<path ของ skill นี้>` และ `P=<โฟลเดอร์งานใน scratchpad>` (ชื่อสั้นไม่มีช่องว่าง).

1. `bash $SK/scripts/check_env.sh`
2. `bash $SK/scripts/new_scene.sh $P [ตัวอย่าง]` → `$P/scene.html` — เริ่มจากตัวอย่างที่ใกล้ที่สุด:
   `rows-simplify` · `grid-catalog` · `pages-six` (มีวาดคู่ใหม่) · `hero-desk` · `steps-habits` · `flow-process` ·
   `beats/B01`…`beats/B21` · `versus-stat` (2 หน้า) · `scene-free` (ฉากอิสระ ของเคลื่อนที่) · `landscape-flow` (16:9) · `stat-square` (1:1) · `icons-catalog`.
3. **เขียน scene** (แก้แค่ใน `GL.run(() => { ... })`): อ่าน `references/style.md` + `references/api.md`;
   เลือกภาพจาก `references/library.md` (ดูภาพรวม `icons.jpg` + `catalog.jpg`); ไม่มีภาพที่ตรง → วาดใหม่ตาม `references/drawing.md`.
4. **ภาพนิ่งก่อน** (~5 วิ): `node $SK/scripts/render.js $P/scene.html $P/out --still` (คลิปหลายหน้า: เพิ่ม `--at <วินาที>` ดูแต่ละหน้า)
   → เปิด `$P/out/still.png` + `storyboard.jpg` ตรวจตาม QC ด้านล่าง แก้จนผ่าน. `SCENE ERROR` = บั๊กใน scene อ่านข้อความแล้วแก้.
5. **MP4**: `node $SK/scripts/render.js $P/scene.html $P/out --name <ชื่องาน>` (~1 นาที ต่อคลิป 10 วิ).
   พื้นใสสำหรับซ้อนบนวิดีโอ: เพิ่ม `--alpha` → `.mov` ProRes 4444 (~10 MB/วิ สำหรับ Premiere / Final Cut / DaVinci).
   แอปตัดต่อบนมือถือส่วนใหญ่อ่าน alpha ไม่ได้ — ส่ง MP4 พื้นดำ แล้วบอกให้ตั้งโหมดผสม (blend) เป็น Screen ซึ่งจะลบพื้นดำออกเอง.
6. **ส่งงาน**: ถ้า session มี git repo ให้คัดลอก `scene.html`, `<ชื่อ>.mp4`, `still.png`, `storyboard.jpg` ไป `motion/<ชื่องาน>/`
   แล้ว commit + push; ส่ง MP4 + still ในแชท (SendUserFile) พร้อมสรุปสั้น ๆ ว่าใช้รูปแบบไหน ภาพอะไร วาดอะไรใหม่
   แล้วขอฟีดแบ็กแบบระบุเลขข้อ/ฉาก. ไฟล์ใหญ่เกินแชท: `bash $SK/scripts/deliver_github.sh <ไฟล์> <ชื่อ>`.
   `scene.html` พกไปที่ไหนก็ render ได้ — `render.js` ชี้หาเอนจินของ skill ให้เอง.

## QC ก่อนส่ง (ดูจาก still + storyboard)

- เข้าสไตล์ตาม `style.md` ข้อ 7 (ไม่มีสี ไม่มีรูปนอก ไม่มีมุมแหลม/เส้นหนาเกิน ไม่มีของเด้ง).
- ภาพไม่ชนกัน ไม่ล้นช่อง ไม่ทับเส้นแบ่ง; ข้อความไม่ล้น (เอนจินย่อให้ แต่ถ้าเล็กเกินไป ให้ตัดคำให้สั้นลง).
- ทุกภาพสื่อความหมายตรง ๆ; ภาพที่วาดใหม่ดูเป็นชุดเดียวกับของเดิม (เทียบกับ `icons.jpg`).
- ก่อน→หลัง: ฝั่งรก "รกจริง" (≥ 5 ชิ้น) และฝั่งเรียบ "เรียบจริง" (1–3 ชิ้น).
- storyboard: เฟรมแรกมีอะไรขึ้นภายใน ~0.5 วิ, ไม่มีช่วงนิ่งว่างกลางคลิป, จบค้างภาพเต็ม ~1.5 วิ.
