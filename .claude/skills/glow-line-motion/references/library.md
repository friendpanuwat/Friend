# คลังภาพสำเร็จรูป

ภาพรวม: `references/icons.jpg` (ภาพเดี่ยวทั้งหมด — `examples/icons-catalog.html`) · `references/catalog.jpg` (คู่ก่อน→หลังทั้งหมด — `examples/grid-catalog.html`).
ทุกชิ้นวาดตาม `style.md` จึงผสมกันในฉากเดียวได้เลย.

## ภาพเดี่ยว (`icon:` ใน steps / flow / versus / spot / stat, หรือ `GL.art(GL.icons.ชื่อ, …)`)

| หมวด | ชื่อ |
|---|---|
| คน | `person` `wave` `cheer` `point` `think` (คน + กล่องความคิด) `bust` (อวาตาร์) `team` (3 คน) |
| มือ / ตัวชี้ | `hand` (นิ้วชี้กด) `cursor` (เมาส์ + คลิก) |
| เงิน / ขาย / ผลลัพธ์ | `coins` `wallet` `bag` `chart` (แท่ง แท่งสุดท้ายเด่น) `linechart` (เส้นขึ้น) |
| อุปกรณ์ / สื่อสาร | `phone` `laptop` `tablet` `tv` `gamepad` `wifi` `globe` `bell` `envelope` `bubble` |
| งาน / เอกสาร / เวลา | `folder` `doc` `calendar` `clock` `moon` |
| ความหมาย | `check` `star` `bulb` `target` `cross` `warn` `question` `up` `down` `heart` `flag` `chest` `magnifier` `eye` |
| สถานที่ | `store` `house` `building` `map` `pin` |
| โซเชียล | `follow` `bookmark` `share` (+ `heart` `bubble`) |
| อารมณ์ | `face-happy` `face-sad` `face-angry` `face-fear` `face-relief` `face-love` `face-doubt` `face-surprise` `face-tired` `face-neutral` |

ไอคอนชุดสถานที่ / โซเชียล / อารมณ์ และเครื่องหมายใหม่มาจาก `assets/beats.js` (ดู `beats.md`).
ชื่อที่ไม่มีในคลัง (เช่น `'-50%'`, `'ไข่'`) ใช้ได้กับทุกช่อง `icon` ของ beat — จะกลายเป็นป้ายคำเรืองแสง.

ชื่อ pair ใช้แทน icon ได้ (ได้ฝั่งเรียบ), หรือส่งฟังก์ชัน `p => { … }` ที่วาดเอง.

## ชิ้นส่วนสำหรับประกอบฉากเอง (`GL.parts.*` — signature ใน `api.md`)

คน: `person` (5 ท่า, กำหนดความสูง) · `bust` · `team` · `capsule` (แขนขา/ท่อ) ·
ตัวชี้: `hand` · `cursor` (click) · โครงสร้าง: `card` (กล่องป้าย + ข้อความ) · `connect` (ลูกศรโค้ง/จุดไข่ปลา) · `link` ·
ข้อมูล: `bars` · `lineChart` · `coins` · ของใช้: `bag` `wallet` `envelope` `phone` `laptop` `tablet` `folder` `doc` `calendar` `clock` `bulb` `tv` `gamepad` `wifi` `globe` `bell` `moon` `zzz` ·
ลายเส้นยุ่ง: `scribble` `tangle` `paperStack` · ระบบเป้า: `target` `arrow` · เครื่องหมาย: `check` `checkbox` `star` `bubble` `appIcon`

## คู่ก่อน→หลัง (`pair:` ใน rows / grid / hero)

ใช้ใน item: `{ label: '1. INBOX', pair: 'inbox' }`. ชื่อคู่เป็นคำกลาง ๆ — ป้ายข้อจะเขียนอะไรก็ได้ (ไทย/อังกฤษ).

| pair | ฝั่งรก (messy) | ฝั่งเรียบ (clean) | ใช้กับหัวข้อ |
|---|---|---|---|
| `inbox` | ซองจดหมาย 6 ซองกองเอียง + จดหมายโผล่ | ซองเดียว + วงกลมติ๊กถูก | อีเมล, ข้อความค้าง, inbox zero, งานค้าง |
| `phone` | มือถือแอปเต็มจอ 20 แอป + จุดแจ้งเตือน | มือถือ 3 แอป + dock 3 | ลบแอป, digital detox, แจ้งเตือน, screen time |
| `goals` | เป้า + ลูกธนู 9 ดอกปักกระจาย | เป้า + ลูกธนูดอกเดียวกลางเป้า | เป้าหมาย, โฟกัสเรื่องเดียว, ความสำคัญ |
| `desk` | โต๊ะ + แฟ้ม โน้ตบุ๊ก กองกระดาษ ตู้ สายไฟ ถังขยะ ขยะบนพื้น | โต๊ะโล่ง + โน้ตบุ๊ก | โต๊ะทำงาน, ที่ทำงาน, สภาพแวดล้อม |
| `calendar` | ปฏิทินเขียนเต็มทุกช่อง + วงกลม | ปฏิทินว่าง + ดาวหนึ่งวัน | ตารางนัด, ประชุม, ปฏิเสธนัด, วันสำคัญ |
| `files` | แฟ้ม 7 แฟ้มโยงกันมั่ว | แฟ้มเดียว ป้าย `FILES` + เอกสารโผล่ | ไฟล์, จัดระบบ, โฟลเดอร์, เอกสาร |
| `todo` | คลิปบอร์ด 8 รายการ ลายมือยุ่ง | 3 บูลเล็ต เส้นตรง | to-do, งานต่อวัน, ลิสต์, ทำทีละน้อย |
| `wallet` | กระเป๋าตังค์อ้วน แบงก์ + บัตรล้น | ซองการ์ดบาง + บัตรใบเดียว | กระเป๋าตังค์, เงิน, บัตรเครดิต, ใช้จ่าย |
| `idea` | เส้นพันกันเป็นก้อน + กล่องคำพูด 4 อัน | หลอดไฟสว่าง | ความคิด, ไอเดีย, overthinking, ความชัดเจน |
| `routine` | นาฬิการอบตัวด้วยสิ่งรบกวน (ปฏิทิน ทีวี เกม กระดิ่ง นาฬิกาเล็ก) | นาฬิกา + พระจันทร์ Z Z Z | กิจวัตร, การนอน, จัดเวลา, เช้า/ค่ำ |
| `focus` | ไอคอนสิ่งรบกวน 8 อัน (wifi เกม ทีวี โลก อีเมล) | เครื่องหมายถูกใหญ่ | โฟกัส, deep work, ตัดสิ่งรบกวน |
| `paper` | กองกระดาษ 3 กอง | แท็บเล็ต | กระดาษ, เอกสาร, ดิจิทัล, paperless |

ตัวอย่างคู่ที่วาดเองใน scene: `closet` (ตู้เสื้อผ้าแน่น → เสื้อ 5 ตัวบนราว) ใน `examples/pages-six.html`.

## หัวข้อที่ยังไม่มีคู่ — แนวคิดสำหรับวาดใหม่ (ดู `drawing.md`)

| หัวข้อ | ฝั่งรก | ฝั่งเรียบ |
|---|---|---|
| closet / เสื้อผ้า | ตู้แน่น เสื้อกองล่าง | ราว 5 ตัวเท่ากัน |
| kitchen / ครัว | เคาน์เตอร์เต็มหม้อ จาน ไมโครเวฟ | เครื่องชงกาแฟ + แก้ว |
| finance / การเงิน | กราฟวงกลม แท่ง ใบเสร็จ กระจาย | กระปุกออมสิน / แท่งเดียวขึ้น |
| messaging / แชต | หน้าต่างแชตเต็ม bubble | หน้าต่างแชตว่าง |
| meals / อาหาร | วัตถุดิบ หม้อ ขวด กระจาย | ชามเดียว + ช้อน |
| travel / เดินทาง | กระเป๋าเดินทาง + เป้ + ของล้น | เป้ใบเดียว |
| toolkit / เครื่องมือ | กล่องเครื่องมือล้น | มีดพับอเนกประสงค์ |
| subscription / ค่าสมาชิก | การ์ดบริการ 8 ใบ + ป้ายราคา | การ์ด 2 ใบ |
| social / โซเชียล | หน้าฟีดยาว + หัวใจ + แจ้งเตือน | หนังสือหนึ่งเล่ม |
| home / บ้าน | ห้องนั่งเล่นแน่น ทีวี ชั้นหนังสือ กล่อง | เก้าอี้ตัวเดียว + ต้นไม้ |
