# ภาษาของลายเส้น — Glow Line Style Guide

ไฟล์นี้คือ "สไตล์" ที่ผู้ใช้ชอบ แยกออกจากรูปแบบการเล่าเรื่อง: จะทำคลิปแนวไหน (ก่อน→หลัง, ขั้นตอน, เปรียบเทียบ, ตัวเลข, ฉากเล่าเรื่อง)
ทุกภาพและทุกการเคลื่อนไหวต้องพูด "ภาษาเดียวกัน" ตามนี้. อ่านก่อนวาดอะไรใหม่ทุกครั้ง.

ภาพรวมในหนึ่งประโยค: **ไอคอนเส้นมินิมอลแบบมองตรง เส้นขาวปลายมนเรืองแสงเหมือนหลอดนีออน บนพื้นดำโล่ง ทุกเส้นค่อย ๆ ถูกวาดขึ้นอย่างใจเย็น**

---

## 0. มาตรฐานไอคอนที่ผู้ใช้เลือก (ใช้เป็นแบบอย่างของทุกไอคอน)

ผู้ใช้ดูหลายทิศทางแล้วเลือก **ชุด `-pro`** (`assets/pro.js`, ดู `motion/glow-line-pro-icons/pro-icons-grid.mp4`):
- **ลายเส้น**: เส้นหลัก 3 + เส้นรายละเอียด 1.1–1.6 สีเทาอ่อน, ถมดำโปร่ง (ไม่ใช่สีเงิน), เส้นขอบใน/แถบ 1–2 เส้น (ไม่มีแสงสะท้อนเส้นโค้ง+จุด),
  รายละเอียดจริงของวัตถุไม่กี่อย่าง (ขีดสเกลนาฬิกา, เกลียวหลอดไฟ, หมุดจรวด, ขนหางลูกธนู) — ละเอียดพอดี ไม่รก.
- **ใส่รายละเอียดเท่าที่มีความหมาย** (ผู้ใช้สั่งลดทุกไอคอนแล้ว): ไม่ใส่ตะเข็บเส้นประ, หมุด/น็อตเรียงแถว, วงขีดรอบวงกลม,
  เส้นขอบในซ้อน 2 ชั้น, กระดุม/ตะเข็บเสื้อ, บาร์โค้ด/ตราประทับ, ตัวหนังสือจิ๋ว, เส้นเทาบาง (`C.mute` เส้น < 1) ประดับ.
  ถ้ารายละเอียดไหนใส่แล้วไม่ช่วยให้รู้ว่าเป็นอะไร หรือใส่ให้ดูดีไม่ได้ — ไม่ต้องใส่.
- **ไม่ใส่แสงสะท้อน "เส้นโค้ง + จุด"** (ผู้ใช้บอกว่าดูเหมือน "!") และ **ไม่ใส่ดาวระยิบระยับประดับ** — ดาวใส่ได้เฉพาะเมื่อดาวคือตัวความหมาย (sparkles, star) หรือเป็นลวดลายบนวัตถุ.
- **ทรงไอคอน = แบบชุด `-pro` ปัจจุบัน** (ผู้ใช้ดูทั้ง 80 อันแล้วบอกว่า "เอาแบบเดิม ชอบสุด"). ลองแนว "มีมิติ" และ "เส้นเว้นช่อง" แล้ว ผู้ใช้ไม่เลือก
  (`examples/house-style.html`) — ห้ามเปลี่ยนแนวทรงเองโดยไม่ถาม.
  ครั้งที่ 2 (หลังชุด 14): ลอง "style v2" (เส้นหนา + ชั้นแสงเบลอ + ฉากประกอบ + มุม 3/4) และ "light 3D" (ด้านข้าง/ความหนา/เหลี่ยมนูน)
  ผู้ใช้ดูแล้ว **"สรุปคือเอาแบบเดิมครับ"** — ไม่เพิ่มทั้งสองอย่าง.
- **ไอคอนที่เป็นอวัยวะคน** (มือ นิ้ว แขน หู เท้า ตา ฯลฯ): ผู้ใช้ให้พักไว้ก่อน — ข้ามไปทำอันอื่น แล้วค่อยกลับมาทำทีหลัง (รายการใน `HANDOFF.md`).
  **หน้าอิโมจิที่แสดงอารมณ์ (smile, frown) ไม่นับเป็นอวัยวะ** — ทำได้ตามปกติ.
- **การขยับ (ผู้ใช้สั่ง "แบบมืออาชีพ")**: rig แยกชิ้นส่วน + คีย์เฟรม (`GL.kf`) — ย่อก่อนพุ่ง, เด้งเกินแล้วค่อยนิ่ง, ยืดหดตอนกระทบ,
  ชิ้นที่ห้อย/ปลายตามช้ากว่า, ท่ารอง (เส้นความเร็ว ฝุ่น ขีดคลิก ระลอก). ทุกไอคอนมี **ท่าเข้า + ท่าวน + ท่าออก**, ไม่มีชิ้นไหนโผล่ก่อนเวลา
  (`scripts/check_icons.js`). ท่าเข้ากับท่าวนต้องอยู่คนละ group (kf สองอันบน element เดียวกัน อันหลังทับอันแรก).
- **ระดับรายละเอียด = `pro.js` ชุด 1** (ผู้ใช้ชี้ว่าใช้ชุดนี้เป็นหลัก): เส้นขอบในเทา 1 เส้น, แถบ/ฐาน, ขีดบนแกน, จุดบนข้อมูล, ชิ้นเด่นเส้น ink ชิ้นรอง soft —
  ภายใต้กฎ "รายละเอียดเท่าที่มีความหมาย" ข้างบน. ผู้ใช้ชอบให้มีรายละเอียดเล็ก ๆ น้อย ๆ เสมอ.
- **คน**: คนทั้งตัวใช้ `GL.parts.human(q, 'line', pose)` (หัวกลมมีคอ ไหล่กว้างสะโพกแคบ แขนขางอที่ศอก/เข่า — ผู้ใช้: "อยากให้คนดูเป็นคน");
  คนครึ่งตัวใช้ `GL.parts.bizUser(q, soft)` (`assets/people.js` — ผมแสกปัด หู สูท เนคไท; แทน user ทุกอันแล้ว). ใช้แบบ "โปร่งแสง" (เส้นขอบ + ถมดำ) ไม่ใช่ทึบขาว.
  คนทั้งตัว/ครึ่งตัว และหน้าอิโมจิ ไม่นับเป็นอวัยวะ.
- **ภาพอ้างอิงจากผู้ใช้: ห้ามลอก** — เอาแนวคิดมาแล้วออกแบบเอง. ไอคอน "…-off": ขีดฆ่าต้องอยู่ตลอด (ท่าวนห้ามยกขีดออก).
- ทิศทางที่ลองแล้ว **ผู้ใช้ไม่เลือก**: ละเอียดจัด (`-hd`), มินิมอลเส้นเดียว (`-mn`), วัสดุสีเงิน, ชุด `sets.js` — เก็บไว้เป็นทางเลือกเท่านั้น.
- ชื่อธรรมดาชี้ไปที่ตัว `-pro` แล้ว (`heart` `bell` `bulb` `envelope`/`mail` `rocket` `chart` `gears` `target` `alarm` `notify`);
  ตัวเดิมเรียกได้ด้วย `<ชื่อ>-basic`. ไอคอนใหม่ทุกตัวให้ทำแบบเดียวกับ `pro.js`.

## 1. แสงและสี (ล็อกไว้ในเอนจินแล้ว — ห้ามแก้ใน scene)

| token | ค่า | ใช้กับ |
|---|---|---|
| `C.ink` | `#f2f2f2` | เส้นหลักทุกเส้น ตัวหนังสือหลัก จุดเด่น |
| `C.fill` | `#171717` | ถมในรูปทรงปิด — บังเส้นที่อยู่ข้างหลัง |
| `C.soft` | `#bdbdbd` | เส้นรอง: ขอบใน หน้าจอ ตะเข็บ เส้นโยง |
| `C.mute` | `#8a8a8a` | ตัวช่วย: ลูกศรกลาง แกนกราฟ |
| `C.rule` | `#4a4a4a` | เส้นแบ่งช่อง |
| `C.sub` / `C.kicker` | `#a9a9a9` / `#cfcfcf` | ซับไทย / หัวข้อเล็ก |
| พื้นหลัง | radial `#121212` (กลาง 50%, 40%) → `#020202` | ไม่ใช่ดำสนิท — มีแสงนวลกลางจอ |

- **แสงเรือง** = เส้นจริง + เบลอ 3px + เบลอ 11px ซ้อนกัน (ภาพเล็กใช้ 2/6px). ชั้นแคบทำให้เส้นคม ชั้นกว้างให้บรรยากาศนีออน.
  ปรับทั้งคลิปได้ทางเดียว: `GL.stage({ glow: 0.8–1.3 })`.
- **ความสว่าง = ความสำคัญ**: ink > soft > mute > rule. ของที่ต้องการให้คนดูมอง = ink + เรืองแสงเป็นจังหวะ; ของรอง = soft หรือหรี่เหลือ 40%.
- **วัสดุ** (`GL.stage({ material })`): `'ink'` = ถมดำเกือบสนิท เห็นแต่เส้นเรืองแสง (ค่าเริ่ม) · `'silver'` = ถมเทาไล่ระดับ บนสว่าง ล่างเข้ม
  ให้ความรู้สึกโลหะ/กระจกฝ้าแบบอินโฟกราฟิกอ้างอิง "20 … IDEAS" ที่ผู้ใช้ส่งมา (ขอบขาวเรืองแสงเหมือนเดิม).
- **ไม่มีสีอื่น** ถ้าผู้ใช้ไม่ขอ. ไม่มี gradient ในวัตถุ ไม่มีเงาตกกระทบ — แสงเรืองคือ "แสงไฟ" อย่างเดียวของภาพ.

## 2. รูปทรง — ไอคอนเส้น (outline pictogram)

- **มองตรง แบน** (หน้าตรงหรือด้านข้าง) ไม่มีจุดลับตา. ข้อยกเว้นเดียว: ของที่เป็นกอง/ชั้น ใช้ isometric ง่าย ๆ (`paperStack`, `coins`).
- **เส้นรอบ + ถมดำ** — วัตถุทุกชิ้นเป็นเส้นรอบรูป ข้างในถม `C.fill`. ไม่แรเงา ไม่ลายเส้นขนาน ไม่ไล่สี.
- **มุมมนทุกมุม** (`rx` ≈ 4–8% ของขนาดชิ้น, จอ/กรอบใหญ่ 16–32). ปลายเส้นมนอยู่แล้ว.
- **ตัดทอนให้เหลือ เงา (silhouette) + รายละเอียด 1–3 อย่างที่บอกว่าเป็นอะไร**:
  มือถือ = สี่เหลี่ยมมน + ติ่งลำโพง + แอป · โน้ตบุ๊ก = จอ + ฐาน · ถุงช้อปปิ้ง = ตัวถุง + หูหิ้ว + 2 รู.
  ถ้าต้องใส่รายละเอียดเกิน ~6 อย่างถึงจะอ่านออก → เปลี่ยนไปใช้วัตถุ/อุปมาที่ง่ายกว่า (ข้อ 8).
- **ระดับรายละเอียดเท่ากันทั้งฉาก** — ชิ้นใหญ่ไม่ละเอียดกว่าชิ้นเล็ก.
- **สัดส่วนอ้วนกลม เป็นมิตร** แบบไอคอน ไม่ใช่สัดส่วนจริง.
- **คน = พิกโตแกรม**: หัวกลม แขนขาเป็นแคปซูล ลำตัวทรงคางหมูมน ไม่มีหน้า ไม่มีนิ้ว (ยกเว้น part `hand`).
  อารมณ์บอกด้วยท่า (`wave` `cheer` `think` `point`) และของประกอบ (กล่องคำพูด หลอดไฟ เครื่องหมายถูก).
- **ตัวหนังสือในภาพ** แทบไม่มี — ป้ายสั้นตัวพิมพ์ใหญ่คำเดียว (`FILES`) เท่านั้น.

## 3. น้ำหนักเส้น

| ใช้กับ | `sw` | `stroke` |
|---|---|---|
| โครงหลักของวัตถุ | 3 (ค่าเริ่ม) | ink |
| รายละเอียด ขอบใน ฝาซอง | 1.6–2.2 | ink / soft |
| ลายมือ ลวดลาย texture | 1.2–1.6 | ink |
| จุดเด่น (ติ๊ก ลูกศรกลางเป้า แท่งกราฟที่ชนะ) | 3.4–7 | ink |
| เส้นโยง ลูกศรระหว่างภาพ | 2–2.6 | soft / mute |

ไม่ต้องคูณตามขนาดเอง เอนจินชดเชยให้เส้นบนจอหนา ~2.4–4px เสมอ — ภาพเล็กในโปสเตอร์กับภาพเต็มจอจึงดูเป็นชุดเดียวกัน.
ไม่ใช้เส้นหนากว่า 7.

## 4. องค์ประกอบ

- **พื้นดำว่าง ≥ 40% ของเฟรม**. หนึ่งจังหวะ = หนึ่งจุดสนใจ.
- จัด **กึ่งกลาง** หรือ **สองคอลัมน์สมมาตร** (ซ้าย/ขวา = ก่อน/หลัง, A/B). ลำดับการอ่าน บน→ล่าง ซ้าย→ขวา.
- ภาพหลักกว้าง 35–60% ของเฟรม; ขอบจอเว้น ≥ 40px.
- เส้นแบ่งช่องสีเทาบาง (`C.rule`) แบบตารางในภาพต้นแบบ — ใช้เมื่อมีหลายช่อง.
- ป้ายอยู่ เหนือ/ใต้ ภาพแบบกึ่งกลาง; รายการ (steps) ชิดซ้าย.
- TikTok / Reels: ข้อความสำคัญไม่อยู่ล่างสุด 220px และขวาสุด 120px.

## 5. ตัวอักษร

| บทบาท | ฟอนต์ | ขนาด (9:16) | สี / แสง |
|---|---|---|---|
| kicker (`3 WAYS TO`) | Inter Display Bold, ตัวพิมพ์ใหญ่, ระยะห่าง 10 | 50 | `C.kicker`, เรือง |
| หัวเรื่อง (`SIMPLIFY`) | Inter Display Bold, ตัวพิมพ์ใหญ่ | 110–142 | ink, เรือง |
| ป้ายข้อ / label | Inter Display หรือ Anuphan 700 | 40–60 | ink, เรือง |
| ซับ / คำอธิบาย | Anuphan 500–600 | 30–50 | `C.sub` / `C.soft`, ไม่เรือง |
| ตัวเลขใหญ่ | Inter Display Bold | 220–340 | ink, เรือง + pulse |

- ภาษาอังกฤษตัวพิมพ์ใหญ่เสมอ (ลุคป้ายนีออน). ภาษาไทยสลับฟอนต์ให้อัตโนมัติ.
- ไม่เกิน 3 ขนาดต่อฉาก, ไม่เกิน 2 บรรทัดต่อข้อความ, ไม่มีย่อหน้า.

## 6. การเคลื่อนไหว (motion grammar)

ผู้ใช้เลือกแล้ว: **ไอคอนต้องขยับได้ ไม่ใช่วาดเส้น** (ค่าเริ่ม `GL.stage({ icons: 'motion' })`).

- **ทุกไอคอนต้องมีท่าออกด้วย** (ผู้ใช้ย้ำ): ท่าออกสะท้อนท่าเข้า — หล่นลงมา → ลอยขึ้นหาย, ลอยขึ้นมา → จมลง, เลื่อนเข้าจากซ้าย → เลื่อนออกขวา,
  จรวด → พุ่งขึ้น, หลอดไฟ/สายฟ้า → กะพริบดับ, เฟือง/ดาว → หมุนหด, กล่อง/กราฟ → ยุบลงพื้น, ที่เหลือ → ขยายนิดแล้วหดหาย. ยาว 0.4–0.6 วิ.
- **ไอคอนเข้า = โผล่มาครบทั้งชิ้น** — ขยายจาก 55% → 100% พร้อมจางเข้า 0.5 วิ เลยไปนิดเดียว (~6%) แล้วเข้าที่. ไม่วาดเส้นทีละเส้น.
- **แล้วขยับต่อตามนิสัยของมัน** (idle motion, วนไปเรื่อย ๆ จนจบฉาก): หัวใจเต้น · กระดิ่งแกว่ง · เข็มนาฬิกาหมุน ·
  คนโบกมือ / ชูแขน · ธงสะบัด · แว่นขยายส่องวน · ตากะพริบ · มือ/เคอร์เซอร์กด · หมุดกระโดด · ลูกศรขึ้น/ลงขยับตามทิศ ·
  แท่งกราฟยืดหด · wifi ไล่สัญญาณ · Z Z Z ลอยขึ้น · หน้าแต่ละอารมณ์ขยับต่างกัน (ดีใจกระโดด กลัวสั่น ลังเลเอียงหัว).
  ขยับเบา ๆ เสมอ: ระยะ 3–18px, หมุน 3–18°, ขยาย 2–14% — ให้มีชีวิต ไม่ใช่ให้วุ่น.
- **เส้นที่เป็นเส้นจริง ๆ ยังวาดตัวเอง**: เส้นแบ่ง, จุดไข่ปลา, ลูกศรโยง, ไทม์ไลน์, เส้นใต้คำ — เพราะการ "ลาก" คือความหมายของมัน.
- ต้องการลุคเดิม (ทุกเส้นวาดตัวเอง ใจเย็น ไม่ขยับ) ใช้ `GL.stage({ icons: 'draw' })` — idle motion ยังทำงานหลังวาดเสร็จ ปิดด้วย `idle: false` ต่อชิ้น.
- **ลำดับในฉาก**: ข้างหลัง → ข้างหน้า, ซ้าย → ขวา, บน → ล่าง; ไอคอนโผล่ห่างกัน 0.1–0.3 วิ.
- **easing**: โผล่ = ease-out แบบเลยนิดเดียว, เส้น = ease-in-out cubic, จาง/เลื่อน = ease-out cubic. ไม่ใช้เด้งแรง ๆ หรือสั่นทั้งจอ.
- **เน้น** = เรืองแสงเป็นจังหวะ (`pulse`) ครั้งละจุด หรือหรี่ที่เหลือลงเหลือ 40%.
- **ของเคลื่อนที่ข้ามจอ**: เลื่อนช้า (≥ 0.6 วิ) แบบผ่อน (`GL.tween` ที่ `wrap`). เลื่อนข้ามจอพร้อมกันไม่เกิน 1–2 ชิ้น (idle motion ไม่นับ).
- **ออก** = จางทั้งหน้า 0.45 วิ (`page`). ไม่ลบเส้นถอยหลัง.
- **จังหวะ**: มีเรื่องใหม่ทุก 1.5–2.5 วิ, ฉากแรกมีอะไรขึ้นภายใน 0.5 วิ, จบค้างภาพเต็ม ~1.5 วิ.
- เส้นโยง/ลำดับขั้น = จุดไข่ปลาที่วาดตามทิศทางการไหล.

## 7. สิ่งที่ทำให้หลุดสไตล์ทันที

สีสด · gradient ในวัตถุ · emoji / PNG / รูปถ่าย / clip art · ภาพเหมือนจริง · เงาตกกระทบ · เส้นหนาเกิน 7 · มุมแหลม ·
ขยับแรง/เร็วเกิน (เด้งสูง สั่นทั้งจอ หมุนเร็ว) · ตัวอักษรหลายฟอนต์ · ย่อหน้ายาว · ฉากที่ไม่มีที่ว่างให้หายใจ.

## 8. อุปมา — เปลี่ยนเรื่องนามธรรมเป็นภาพ

| ความหมาย | วาดเป็น |
|---|---|
| เงิน / ออม / รายได้ | `coins`, `wallet`, `chart` (แท่ง), `linechart` |
| เวลา / กิจวัตร | `clock`, `calendar`, `moon` |
| ความคิด / ไอเดีย / ความชัดเจน | `bulb` (ชัด) ↔ `tangle` (ยุ่ง) |
| ลูกค้า / คน / ทีม | `bust`, `team`, `person` + ท่า |
| ขาย / ซื้อ / ร้าน | `bag`, `cursor` + click, `card` ป้ายราคา |
| เป้าหมาย / โฟกัส | `target`, `check` |
| การสื่อสาร / แชต | `bubble`, `phone`, `envelope` |
| เติบโต / ผลลัพธ์ | `linechart` เส้นขึ้น, `bars` แท่งสุดท้ายเด่น |
| ความยุ่ง / ความเครียด / งานล้น | ของชนิดเดียวกันหลายชิ้นซ้อนเอียง + `scribble` / `tangle` |
| ระบบ / ขั้นตอน | `flow` ไอคอน + จุดไข่ปลา, `card` |
| การเลือก / เปรียบเทียบ | `versus`, สองคอลัมน์ ฝั่งที่ชนะเรืองแสง ฝั่งที่แพ้หรี่ |

ไม่มีวัตถุที่ตรง → วาดใหม่ตาม `drawing.md` โดยยึดข้อ 2–3 ของไฟล์นี้.
