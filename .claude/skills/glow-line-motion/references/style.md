# ภาษาของลายเส้น — คู่มือสไตล์

คู่มือนี้ใช้ได้กับ **ทุกแบบ** ไม่ใช่แค่ก่อน→หลัง: อธิบายขั้นตอน, เล่าเรื่องเป็นฉาก, แผนผัง, โชว์สินค้า, ภาพอิสระ.
อ่านก่อนวาดอะไรใหม่ทุกครั้ง. ถ้าทำตามนี้ ภาพที่วาดใหม่จะดูเป็นชุดเดียวกับของเดิมเสมอ.

## 1. หลักใหญ่ 5 ข้อ

1. **มองจากด้านหน้าแบบแบน** — วัตถุเดี่ยวหันหน้าตรงเข้ากล้อง ไม่มี perspective ไม่มีเงา ไม่มีแสงตกกระทบ.
   ใช้มุมด้านข้าง (profile) เฉพาะตอนที่ท่าทางต้องการ เช่น คนเดิน วิ่ง นั่งทำงาน, กระเป๋าที่ต้องเห็นความหนา.
2. **รายละเอียดน้อย** — วัตถุหนึ่งชิ้น = เส้นโครง 1 เส้น + รายละเอียดข้างใน 1–3 เส้น.
   ทดสอบ: ถ้าลบเส้นไหนแล้วยังจำได้ว่าเป็นอะไร → ลบ.
3. **ตัดทอนของจริงให้เหลือเส้นสำคัญ** — หา "เส้นที่ทำให้จำได้" ของวัตถุนั้น แล้วเก็บไว้แค่นั้น (ตารางข้อ 5).
4. **กองของ / ของที่ต้องเห็นปริมาตร ใช้มุมเฉียงแบบ isometric** — กองกระดาษ, กล่องพัสดุซ้อนกัน, ชั้นวางของ, ตึก, เมือง.
   ใช้ isometric เมื่อ "จำนวน / ความหนา / ปริมาตร" คือสาร; วัตถุเดี่ยวยังวาดหน้าตรง.
   isometric = แกน X ลงขวา 30°, แกน Z ลงซ้าย 30°, แกน Y ตั้งตรง — ใช้ `GL.iso(X, Y, Z)` / `kit.isoBox` / `parts.paperStack`
   ห้ามผสม isometric กับ perspective (เส้นขนานต้องขนานกันเสมอ).
5. **ขาว-ดำ เรืองแสง** — สีมีแค่ในตาราง; ไม่ใช้สีอื่นถ้าผู้ใช้ไม่ขอ. ความเรืองแสงคือจุดเด่น สีจะไปแย่งมัน.

| token | สี | ใช้กับ |
|---|---|---|
| `C.ink` | `#f2f2f2` | เส้นหลักทุกอย่าง (ค่าเริ่ม) |
| `C.soft` | `#bdbdbd` | ขอบใน รายละเอียด ลูกศรเชื่อม เส้นชี้ (callout) ของที่อยู่ข้างหลัง |
| `C.mute` | `#8a8a8a` | ลูกศรกลางคู่ เส้นรองที่ต้องจางกว่า |
| `C.fill` | `#171717` | ถมรูปทรงปิดเพื่อบังเส้นที่อยู่ข้างหลัง |
| `C.sub` / `C.kicker` | เทา | ซับไทย / หัวข้อเล็ก (ไม่เรืองแสง / เรืองนิดเดียว) |

## 2. เส้นและผิว

| ใช้กับ | `sw` | `stroke` |
|---|---|---|
| โครงหลักของวัตถุ | 3 (ค่าเริ่ม) | ink |
| เส้นรายละเอียด ขอบใน ฝาซอง | 1.6–2.2 | ink หรือ soft |
| ลายมือ ลวดลาย texture | 1.2–1.6 | ink / soft |
| จุดเด่น (ติ๊ก ลูกศรกลางเป้า) | 3.4–7 | ink |
| ลูกศรเชื่อม เส้นชี้ | 2.2–2.6 | soft |

- **ถมดำบังเสมอ**: รูปทรงปิดทุกชิ้นที่ซ้อนกับอย่างอื่นใส่ `fill: C.fill` แล้ววาดของข้างหลังก่อน — ชิ้นหลังจะบังเส้นชิ้นก่อน
  ของซ้อนจึงอ่านออกโดยไม่ต้องมีเงา.
- **มุมมนเสมอ**: `rx` 6–32 ตามขนาด, ปลายเส้นมนตั้งไว้แล้ว. ไม่มีมุมแหลมยกเว้นหัวลูกศร ดาว ประกาย.
- **ของที่เป็น "ท่อ"** (แขน ขา นิ้ว หูหิ้ว สายคล้อง สายไฟเส้นหนา) ใช้ `p.tube(points, ความหนา)` — ได้ขอบขาว แกนดำ ปลายมน ในเส้นเดียว.
- **ไม่มีแรเงา ไม่มีไล่สี**: ผิว/ลายวัสดุ = เส้นสั้นซ้ำ 3–6 เส้นสีเทา (ลายกันลื่น เส้นบรรทัด เกล็ด).
- **ตัวหนังสือในภาพ**: น้อยที่สุด — ป้ายสั้น 1 คำ (`FILES`) หรือตัวเลขใน badge. ข้อความยาวไปอยู่ในเลย์เอาต์ ไม่ใช่ในภาพ.
- ไม่ต้องคูณ `sw` ตามสเกลเอง — เอนจินชดเชยให้เส้นดูหนาเท่ากันทุกขนาด.

## 3. การจัดวาง

- **ฉากละหนึ่งความคิด**: ของหลัก 1 ชิ้น + ของประกอบ ≤ 3 ชิ้น. ของประกอบเล็กกว่าของหลักอย่างน้อยครึ่งหนึ่ง.
- **ความโล่งคือสาร**: ของหลักกว้างราว 40–60% ของจอ ที่เหลือปล่อยว่าง.
- **พื้น**: ของที่วางบนพื้น/โต๊ะให้ใช้เส้นพื้นเดียวกัน (y เดียวกัน) — คน โต๊ะ เก้าอี้ ยืนบนพื้นเดียว.
- **ขนาดเท่ากันในชุดเดียว**: ภาพในลิสต์/กริด/โฟลว์ใช้สเกลเดียวกัน (เลย์เอาต์ทำให้เอง).
- **พื้นที่ปลอดภัย 9:16 (TikTok / Reels)**: เว้นบน 150 px, ล่าง 220 px (แถบแคปชัน), ขวา 120 px (ปุ่มไลก์) สำหรับตัวหนังสือ.
  เลย์เอาต์ใหม่ (`showcase`, `shots`, `caption`) เว้นให้แล้ว; `rows`/`flow` ใส่ `bottom: GL.H - 220`.

## 4. การเคลื่อนไหว

- **ทุกเส้นวาดตัวเอง** ด้วย Pen — ห้ามใช้รูป PNG / emoji / ไอคอนจากที่อื่น (จะไม่วาดตัวเองและหลุดสไตล์).
- **ลำดับการวาด** = ลำดับที่ตาควรอ่าน: ของข้างหลัง → ข้างหน้า, โครง → รายละเอียด, ซ้าย→ขวา / บน→ล่าง.
  รายละเอียดข้างในเริ่มเมื่อโครงวาดไปได้ครึ่งทาง.
- **จังหวะ**: รูปทรงใหญ่ `dur` .35–.55, รายละเอียด .1–.25; ชิ้นถัดไปห่าง .05–.12 วิ (ดูเหมือนมีคนวาดอยู่).
- **เรืองแสงเป็นจังหวะ (pulse)** = "คำตอบ / จุดจบ" ของแต่ละช่วง. ใช้ครั้งเดียวต่อช่วง ไม่ใช้กับทุกอย่าง.
- **หรี่ลง** = ลดความสำคัญ (ฝั่งรก ตัวเลือกที่แพ้ ขั้นตอนที่ผ่านไปแล้ว) — `GL.tween(g, at, .5, {o:1}, {o:.42})`.
- **ลูกศร** = เวลา / เหตุ→ผล / ทิศทาง. วาดหลังต้นทางเสร็จ ก่อนปลายทางเริ่ม — คนดูจะตามลูกศรไปเอง.
- **เปลี่ยนฉาก** = จางออกทั้งหน้า (`page`, `shots`). ไม่ใช้ wipe / หมุน / ซูมแรง.
- **ตัวหนังสือ** ขึ้นแบบจาง + ลอยขึ้นนิดเดียว (เลย์เอาต์ทำให้). เฟรมแรกต้องมีอะไรขึ้นภายใน ~0.5 วิ.

## 5. ตัดทอนของจริงให้เหลือเส้นสำคัญ

ขั้นตอน: (1) นึกถึงไอคอนที่คนทั่วไปจำได้ → (2) วาดเงาโครงนอกหนึ่งเส้น ถมดำ → (3) เติมเส้นที่ทำให้จำได้ 1–3 เส้น
→ (4) จุดเด่นเล็ก ๆ หนึ่งจุดถ้าเป็นของหลัก (ติ๊ก ประกาย badge) → (5) ดูที่ขนาดเล็ก (ใน `grid`) ว่ายังอ่านออก.

| ของ | เก็บ | ตัดทิ้ง |
|---|---|---|
| มือถือ | กรอบมน + ขอบจอเทา + ขีดลำโพง | ปุ่มข้าง กล้อง ไอคอนสถานะ |
| แก้วกาแฟ | ทรงถ้วย + หู + ไอ 3 เส้นโค้ง | ลาย โลโก้ จานรอง |
| รถยนต์ (ด้านข้าง) | หลังคาโค้ง + ตัวถัง + 2 ล้อ (วงกลมซ้อน) | ประตู กระจก ไฟ |
| บ้าน | สามเหลี่ยมหลังคา + กล่อง + ประตู | หน้าต่างทุกบาน กระเบื้อง |
| คน | หัวกลม + ลำตัว + แขนขาเป็นท่อ (`kit.person`) | หน้า ผม เสื้อผ้า นิ้ว |
| มือ | ฝ่ามือ + นิ้วเป็นท่อ + ข้อมือเสื้อ (`kit.hand`) | เล็บ ข้อนิ้ว ลายมือ |
| ขวด / กระบอกน้ำ | ฝา + ตัว + 1–2 แถบ | ฉลากเต็ม ตัวหนังสือ |
| กราฟ | แกน + แท่ง/เส้นเดียว | ตัวเลข grid ทุกช่อง |
| เงิน | ธนบัตรสี่เหลี่ยม + วงรีกลาง / เหรียญวงกลมซ้อน | ลายพิมพ์ ตัวเลข |

## 6. เล่าเรื่องแบบไหน ใช้อะไร

| สารที่ต้องสื่อ | เลย์เอาต์ | ดูวิธีที่ |
|---|---|---|
| ก่อน → หลัง (รก → เรียบ, เก่า → ใหม่) | `rows` · `grid` · `hero` | `pairs.md`, `drawing.md` |
| ทิป / นิสัย / เช็กลิสต์ (ไม่ต่อกัน) | `steps` | `api.md` |
| ขั้นตอนที่ต่อกัน (how-to, กระบวนการ, สูตร) | `flow` | `scenes.md` |
| เรื่องเป็นฉาก ๆ (หนึ่งวันของ…, เคสลูกค้า, ไทม์ไลน์) | `shots` | `scenes.md` |
| แผนผัง / ระบบ / ใครเชื่อมกับใคร | `diagram` | `scenes.md` |
| โชว์สินค้า / ฟีเจอร์ | `showcase` | `scenes.md` |
| อะไรก็ได้ที่ไม่เข้าแบบไหน | `place` / `art` + `connect` + `text` | `scenes.md` (ฉากอิสระ) |

ชิ้นที่วาดยาก (คน มือ ลูกศรเชื่อม badge เคอร์เซอร์ ประกาย กล่อง isometric) มีสำเร็จรูปใน `kit.md` — ใช้ของในชุดก่อนวาดเองเสมอ.

## 7. ห้าม

- รูปถ่าย / emoji / ไอคอนจากแหล่งอื่น / ฟอนต์อื่น
- สี (ยกเว้นผู้ใช้ขอ), ไล่สี, เงา, perspective 3 มิติ
- เส้นบางกว่า 1.2 หรือรายละเอียดห่างกัน < 8 px ตอนแสดงผล (จะกลายเป็นก้อนเรืองแสง)
- รูปทรงใหญ่ถมขาว (เรืองแสงจนฟุ้งทั้งจอ) — ถมขาวได้แค่จุดเล็ก ดาว badge
- ตัวหนังสือเต็มเฟรม — ภาพต้องเล่าเรื่องได้เกือบทั้งหมดโดยไม่ต้องอ่าน
