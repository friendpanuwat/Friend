# สำเนาเอกสาร CutPack ที่ผู้ใช้แนบมา (อ่านอย่างเดียว)

ผู้ใช้แนบ 2 ไฟล์นี้มาในแชท motion graphics เมื่อ 2026-11-12 เพื่อใช้ออกแบบ 21 หมวด. ต้นฉบับเป็นของงาน CutPack
และ **ไม่มีอยู่ใน branch นี้** — เก็บสำเนาไว้ที่นี่ แชทใหม่จะได้อ่านได้โดยไม่ต้องขอไฟล์ซ้ำ.

| ไฟล์ | เนื้อหา |
|---|---|
| `CATEGORIES.md` | 21 หมวดของภาพแบบละเอียด: หลักกลาง, ช่องข้อมูลของแต่ละหมวด (เช่น B05 `wrong` / `right`), กฎท่าขยับ §9 |
| `LEGO.md` | ระบบเลโก้ของ CutPack: จากประโยคที่คนพูด → หมวด → ช่องข้อมูล → ภาพในคลิป |

- เป็นสำเนา ณ 2026-11-12 — ถ้าผู้ใช้ส่งฉบับใหม่มา ให้เขียนทับที่นี่.
- **ห้ามแก้ไฟล์ในโฟลเดอร์ `cutpack/`** (คนละงาน คนละแชท). เส้นทางไฟล์ที่อ้างถึงในเอกสาร (เช่น `engine/uni/cat_ai.py`) หมายถึงใน `cutpack/`.
