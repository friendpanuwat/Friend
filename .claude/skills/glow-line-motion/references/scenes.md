# ฉากที่ไม่ใช่ก่อน→หลัง

ลายเส้นเดียวกัน (กติกาใน `style.md`) แต่เล่าเรื่องได้หลายแบบ. ทุกเลย์เอาต์ **คืนเวลาที่มันจบ** เอาไปต่อคิวได้
และใส่ใน `GL.page` เพื่อทำหลายหน้าในคลิปเดียวได้เหมือน `rows`. ตัวอย่างที่ render ผ่านแล้วอยู่ใน `examples/`.

## วางแผนก่อนเขียนโค้ด (ทุกแบบ)

1. **สารเดียว**: คลิปนี้ต้องการให้คนดูจำอะไร 1 อย่าง → เขียนเป็นประโยคเดียว.
2. **จังหวะ**: แตกเป็น 3–6 จังหวะ (ขั้นตอน / ฉาก / โหนด / ฟีเจอร์). มากกว่านี้แยกหน้า (`GL.page`).
3. **ภาพต่อจังหวะ**: จังหวะละ 1 ภาพหลัก. เลือกจาก `kit.md` → `pairs.md` / `api.md` (parts, icons) → ถ้าไม่มี วาดใหม่ตาม `style.md`.
4. **ข้อความ**: ป้าย 1–4 คำ + ซับ 1 บรรทัด. ภาพต้องเล่าได้เกือบหมดโดยไม่ต้องอ่าน.
5. เลือกเลย์เอาต์จากตารางข้อ 6 ใน `style.md`.

## ขั้นตอนต่อกัน — `GL.flow`  (`examples/flow-sell-online.html`)

```js
const top = GL.title({ kicker: 'HOW TO', main: 'SELL ONLINE', sub: 'เริ่มขายของออนไลน์ใน 4 ขั้น' });
GL.flow([
  { icon: 'hand-phone', label: 'ถ่ายรูปสินค้า', sub: 'แสงธรรมชาติ พื้นเรียบ' },
  { icon: 'bubble', label: 'โพสต์ + ตอบแชต' },
  { icon: 'package', label: 'แพ็กของ' },
  { icon: 'hand-thumb', label: 'ส่งถึงมือลูกค้า' },
], { top, bottom: GL.H - 200 });
```

- `dir`: `zigzag` (ค่าเริ่ม 9:16 — ไอคอนสลับซ้าย/ขวา ลูกศรโค้งตัดลง), `down` (ไอคอนเป็นคอลัมน์ ลูกศรตรงลง — 5–6 ขั้น),
  `right` (ค่าเริ่มจอนอน 16:9 / 1:1 — เรียงแนวนอน ป้ายใต้ไอคอน, ≤ 3 ขั้นถ้าเป็น 9:16).
- `connector`: สไตล์ลูกศร (`curve` `straight` `swoosh` `elbow` `loop`), `bend` = ความโค้ง, `numbers: false` = ไม่มี badge เลข.
- ลำดับต่อขั้น: ลูกศรวาด → ไอคอนวาด + badge → ป้าย → ซับ → เรืองแสง. ~1.4 วิ/ขั้น.
- 3–5 ขั้นดีที่สุดบน 9:16. 6+ ขั้น → `dir: 'down'` หรือแบ่ง 2 หน้า.

## เรื่องเป็นฉาก ๆ — `GL.shots`  (`examples/story-freelance.html`)

แต่ละ shot วาดเต็มจอ ค้าง แล้วจางออกก่อน shot ถัดไป; มีจุดบอกความคืบหน้าด้านล่าง.

```js
GL.shots([
  { kicker: '08:00', title: 'งานเข้า', caption: 'ลูกค้าทักมาตั้งแต่เช้า', draw: p => GL.kit.holdPhone(p, { size: 400 }) },
  { kicker: '10:00', title: 'ลงมือทำ', caption: 'โฟกัสทีละงาน', box: [520, 420], draw: p => { … } },
  { kicker: '18:00', title: 'ปิดงาน', icon: 'hand-thumb' },
], { hold: 1.3 });
```

| ฟิลด์ของ shot | |
|---|---|
| `draw` / `icon` / `pair` | ภาพของฉาก (ฟังก์ชันวาด / ชื่อไอคอน / ชื่อคู่ → ฝั่งเรียบ) |
| `box: [w, h]` | ขนาดที่ภาพใช้ในพิกัดของมันเอง (ค่าเริ่ม [400, 370] = กรอบมาตรฐาน). ฉากกว้าง เช่น คน+โต๊ะ ใส่ `[520, 420]` แล้ววาดให้อยู่ในนั้น — เลย์เอาต์ย่อให้พอดีจอ |
| `kicker` | ป้ายเล็กด้านบน: เวลา สถานที่ "ฉาก 1" |
| `title` | 1–3 คำ ตัวใหญ่เรืองแสง |
| `caption` | ประโยคสั้นใต้ภาพ (เทา) |
| `hold` | ค้างกี่วินาทีหลังวาดเสร็จ (ค่าเริ่มของทั้งชุด 1.3) |
| `more(at, {x, y, s})` | เพิ่มของเคลื่อนไหวในฉากนั้น (เช่น `GL.connect`, `GL.tween`) — คืนเวลาเสร็จ |
| `glow: false` | ไม่ต้องเรืองแสงเป็นจังหวะตอนจบฉาก |

- ฉากละ 2.5–3.5 วิ. 3–6 ฉาก. ตัวเอก (คน) ควรหน้าตาเหมือนกันทุกฉาก — ใช้ `kit.person` ที่ `h` ใกล้กัน.
- ฉากหลายชิ้น: วางของบนพื้นเดียวกัน (y เดียวกัน) แล้วค่อยใส่ของลอย (นาฬิกา ประกาย) ในที่ว่าง.
- ตรวจทุกฉาก: `render.js … --still --at <เวลาจบของแต่ละฉาก>` (ดูเวลาได้จาก storyboard ปกติก่อน).

## แผนผัง — `GL.diagram`  (`examples/diagram-shop.html`)

```js
GL.diagram({
  nodes: {
    buyer: { x: .5, y: .1, icon: 'bust', label: 'ลูกค้า', scale: .8 },
    order: { x: .5, y: .37, box: 'สั่งซื้อ + โอนเงิน' },
    pack:  { x: .24, y: .64, icon: 'package', label: 'แพ็กของ' },
    ship:  { x: .5, y: .92, box: 'ส่งของ', strong: true },
  },
  edges: [['buyer', 'order', { label: 'ทักแชต' }], ['order', 'pack', { style: 'curve', bend: .12 }], ['pack', 'ship', { dash: true }]],
}, { top, bottom: GL.H - 220 });
```

- **ลำดับใน `nodes` = ลำดับที่เล่า**: แผนผังโตทีละโหนด — ลูกศรที่ต่อกับโหนดก่อนหน้าวาดก่อน แล้วโหนดใหม่ขึ้นที่ปลายลูกศร.
- `x, y` ≤ 1 = สัดส่วนของพื้นที่ (x ทั้งจอ, y จาก `top` ถึง `bottom`); > 1 = px.
- ชนิดโหนด: `icon` / `draw` (ภาพ + `label` ใต้ภาพ, `scale` ย่อ/ขยาย), `box: 'ข้อความ'` (กล่องมนมีคำ, `\n` ขึ้นบรรทัด, `strong: true` = เส้นหนา + เรืองแสง = ผลลัพธ์), `dot: true` (จุด + ป้ายด้านขวา — ไทม์ไลน์).
- edge: `[จาก, ไป, { label, style, bend, dash, both, head, via }]` — ลูกศรหยุดที่ขอบโหนดพอดีเอง (รวมป้ายใต้ไอคอน).
- ≤ 7 โหนดต่อจอ 9:16. อย่าให้ลูกศรพุ่งเข้าทางป้ายใต้ไอคอน — ถ้าต้องเข้าจากด้านล่าง ใช้โหนด `box` แทน.
- `size` = ขนาดไอคอนพื้นฐาน (px), `boxSize` = ตัวอักษรในกล่อง (40), `labelSize` (36), `edge: {…}` = ค่าเริ่มของทุกเส้น.

## โชว์สินค้า — `GL.showcase`  (`examples/showcase-tumbler.html`)

สินค้าใหญ่กลางจอ แล้วเส้นชี้ทีละฟีเจอร์ ป้ายอยู่ริมซ้าย/ขวา.

```js
const top = GL.title({ kicker: 'MEET THE', main: 'TUMBLER' });
GL.showcase({
  box: [240, 580],                          // ขนาดภาพที่วาด (พิกัดของมันเอง)
  draw: p => { … },                         // วาดสินค้าหน้าตรง ตาม style.md ข้อ 5
  callouts: [
    { x: 28, y: -284, text: 'หูหิ้วในฝา', sub: 'คล้องนิ้วพกง่าย' },   // x, y = จุดบนภาพ (พิกัดเดียวกับที่วาด)
    { x: -80, y: 20, text: 'ผนัง 2 ชั้น' },
  ],
  caption: 'ขวดเดียว ใช้ได้ทั้งวัน',
}, { top });
```

- วาดสินค้าแบบหน้าตรง: ทรงนอก (ถมดำ) → ชิ้นส่วนหลัก (ฝา ปุ่ม หู) → ลายผิว 1 จุด. ห้ามมีโลโก้/ตัวหนังสือบนสินค้า.
- `callouts` ≤ 5; x < 0 ไปฝั่งซ้าย, x ≥ 0 ฝั่งขวา (หรือกำหนด `side`). เลย์เอาต์เรียงป้ายไม่ให้ชนกันเอง.
- ป้าย 1–3 คำ (ที่ว่างข้างละ ~260 px), `sub` สั้นกว่าป้าย. ข้อความต้องมาจากผู้ใช้ — ห้ามแต่งสเปก/ตัวเลขเอง.
- ตัวเลือก: `top`, `bottom` (ค่าเริ่ม H − 380 เว้นที่ caption), `scale`, `stagger` (เวลาระหว่างป้าย .55), `labelSize` (42).

## ฉากอิสระ — วางเองทุกชิ้น

เมื่อไม่มีเลย์เอาต์ไหนตรง (ภาพเปิดคลิป ภาพปิด เทียบ 2 ทางเลือก วงจร ไทม์ไลน์แนวนอน):

```js
GL.run(() => {
  GL.stage();
  const { kit, parts, C } = GL;
  GL.text('ทำซ้ำทุกสัปดาห์', { y: 300, size: 84, at: .2 });
  const a = GL.place(p => kit.cycle(p, { r: 150, sw: 4, hs: 24 }), { y: 900, w: 600, at: .5 });   // กรอบ [400,370] ย่อให้กว้าง 600 px
  GL.place(GL.icons['person-wave'], { x: 540, y: 900, w: 260, at: .9 });
  const b = GL.connect(240, 1300, 840, 1300, { style: 'loop', at: a.end, stroke: C.soft });
  GL.caption('วางแผน → ทำ → ทบทวน', { at: b - .2 });
  GL.pulse(a.g, b);
});
```

| ใช้ | |
|---|---|
| `GL.place(fn, {x, y, w, h, box, at})` → `{wrap, g, end}` | วางภาพให้กรอบ `box` (ค่าเริ่ม [400, 370]) พอดีพื้นที่ w × h px |
| `GL.art(fn, {x, y, s, at})` | วางด้วยสเกลตรง ๆ |
| `GL.connect(x1, y1, x2, y2, {style, at, …})` → เวลาจบ | ลูกศรบนเวที (ตัวเลือกเดียวกับ `kit.connect`) |
| `GL.text` · `GL.caption` · `GL.title` | ตัวหนังสือ |
| `GL.pulse(g, at)` · `GL.tween(el, at, dur, from, to)` · `GL.fade` | เรืองแสง / หรี่ / ย้าย / ซูมทั้งกลุ่ม |

เคล็ดลับ: คิดพิกัดเป็นสัดส่วนของ `GL.W` / `GL.H` (จะใช้ได้ทั้ง 9:16 และ 16:9), ต่อเวลาด้วยค่าที่ฟังก์ชันคืนมา
(`a.end`, ค่าที่ `connect` คืน) แทนการกะตัวเลขเอง.

## ผสมหลายแบบในคลิปเดียว

ห่อแต่ละช่วงด้วย `GL.page` — หน้าก่อนจางออก หน้าถัดไปวาดต่อ. หัวข้อ (`title`) ที่อยู่นอก page ค้างตลอด.

```js
let t = GL.page(.4, at => GL.hero({ pair: 'desk' }, { at }));                         // hook: ก่อน→หลัง
t = GL.page(t, at => GL.flow(steps, { top: 340, at }));                                // แล้วอธิบายวิธี
GL.page(t, at => GL.showcase(product, { top: 340, at }), { out: false });             // ปิดด้วยสินค้า
```

## QC เพิ่มเติมสำหรับฉากอิสระ

- ลูกศรไม่ทับตัวหนังสือ และไม่พุ่งออกนอกพื้นที่ปลอดภัย.
- คน/มือขนาดสมเหตุสมผลเมื่อเทียบกับของรอบตัว (คนสูงกว่าโต๊ะราว 2 เท่า; มือถือกว้างราวครึ่งหนึ่งของมือ).
- แต่ละฉากมีจุดเรืองแสงเป็นจังหวะไม่เกิน 1 จุด.
- ฉากหลายหน้า: ตรวจด้วย `--at` ทุกหน้า (ไม่ใช่แค่ `still.png` ซึ่งเห็นแค่หน้าสุดท้าย).
