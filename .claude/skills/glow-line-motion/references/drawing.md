# วาดคู่ภาพใหม่ให้เข้าสไตล์

ภาพทุกชิ้นวาดด้วย Pen (ดู `api.md`). กำหนดคู่ใหม่ได้ใน scene เลย:

```js
GL.run(() => {
  GL.stage();
  const { parts, C } = GL;
  GL.pair('kitchen', {
    messy(p) { ... },     // ฝั่งรก ~1.0–1.2 วิ
    clean(p) { ... },     // ฝั่งเรียบ ~0.5–0.9 วิ
  });
  GL.rows([{ label: '1. KITCHEN', pair: 'kitchen' }], { top: GL.title({ main: 'SIMPLIFY' }) });
});
```

## กรอบและพิกัด

- วาดรอบ (0, 0) ในกรอบ **x ±200, y ±185**. ห้ามล้น — เลย์เอาต์ย่อภาพตามกรอบนี้ ถ้าล้นจะชนเส้นแบ่ง/ภาพข้าง ๆ.
- ฝั่งรกใช้พื้นที่เต็มกรอบ; ฝั่งเรียบใช้ ~60–75% และอยู่กลาง (ความโล่งคือสาร).
- ของวางบนพื้น/โต๊ะ: ให้เส้นพื้นอยู่ราว y 28–40 และขาโต๊ะลงไปถึง y ~180 (เหมือน `desk`).

## ลำดับชั้น = ลำดับการวาด

วาดของที่อยู่ข้างหลังก่อน แล้วใส่ `fill: C.fill` ให้รูปทรงปิดทุกชิ้นที่ซ้อนกัน — ชิ้นหลังจะบังเส้นของชิ้นก่อน
ทำให้ของกองกันอ่านออก (ดู `inbox`: จดหมายวาดก่อน ซองวาดทับ). เส้นเปิด (เส้นตรง, ลายมือ) ไม่ต้อง fill.

## ความหนาเส้นและน้ำหนัก

| ใช้กับ | `sw` | `stroke` |
|---|---|---|
| โครงหลักของวัตถุ | 3 (ค่าเริ่ม) | ink |
| เส้นรายละเอียด ขอบใน ฝาซอง | 1.6–2.2 | ink หรือ `C.soft` |
| ลายมือ ลวดลาย texture | 1.2–1.6 | ink |
| จุดเด่นฝั่งเรียบ (ติ๊ก ลูกศรกลางเป้า) | 3.4–7 | ink |
| ของรอง/ไกล (เส้นโยง, ลูกศรกลาง) | 2 | `C.soft` / `C.mute` |

ไม่ต้องคูณ sw ตามสเกลเอง — เอนจินชดเชยให้เส้นดูหนาเท่ากันทุกขนาด (ถ้าใช้ `p.child` ที่มี `scale()` ให้ส่ง scale เป็นพารามิเตอร์ที่สองด้วย).
มุมมนเสมอ (`rx` 6–32 ตามขนาด) — เส้นปลายมน/มุมมนตั้งไว้ให้แล้ว.

## ทำให้ "รก" อ่านออกในครึ่งวินาที

- **จำนวน**: 5–20 ชิ้น ของประเภทเดียวกับฝั่งเรียบ (ซอง 6 → ซอง 1, แอป 20 → แอป 3) — คนดูเทียบได้ทันที.
- **เอียง/ซ้อน**: หมุน ±5–20° (`p.child({transform: 'translate(x y) rotate(r)'})`), ซ้อนกัน 20–40%.
- **เส้นยุ่ง**: `parts.scribble` (ลายมือ), `parts.tangle` (ความคิดพันกัน / กระดาษขยำ เมื่อ r เล็ก), สายไฟเป็น path โค้ง S.
- **สิ่งรบกวน**: จุดแจ้งเตือน `p.dot`, ไอคอนเล็กรอบ ๆ, ของหล่นบนพื้น.
- สุ่มด้วย `GL.rr(a, b)` / `GL.rnd()` เท่านั้น (ได้ผลเดิมทุกครั้ง).

ฝั่งเรียบ: ชิ้นเดียวหรือ 3 ชิ้นเรียงเท่ากัน, ตั้งตรง สมมาตร, มีจุดเด่นเล็ก ๆ หนึ่งจุด (ติ๊ก ดาว ป้าย) — เรืองแสงเป็นจังหวะให้เองหลังวาดเสร็จ.

## จังหวะ (`at` / `dur` ภายในภาพ)

- รูปทรงใหญ่ `dur` .35–.55, รายละเอียด .1–.25, ลายมือ .15–.25.
- ไล่ `at` ทีละชิ้น ห่าง .05–.12 วิ (กองซอง: `.1 + i * .12`) → ดูเหมือนมีคนกำลังวาด.
- รายละเอียดข้างในเริ่มเมื่อโครงวาดไปได้ครึ่งทาง (`at + d * .5`).
- ฝั่งรกรวม ~1.0–1.2 วิ, ฝั่งเรียบ ~0.5–0.9 วิ. ยาวกว่านี้คลิปจะยืด (ใช้ `ts` ของเลย์เอาต์ปรับทั้งชุดได้).

## ตรวจภาพใหม่

1. ใส่คู่ใหม่ใน `rows` แถวเดียว แล้ว `render.js --still` → เปิด `still.png`.
2. ครอปดูใกล้ ๆ: `ffmpeg -i out/still.png -vf crop=1080:560:0:340 crop.png`.
3. ดู `storyboard.jpg` ว่าเส้นวาดเป็นลำดับที่ดูเป็นธรรมชาติ (ของหลังก่อน ของหน้าทีหลัง, โครงก่อน รายละเอียดทีหลัง).
4. ใส่ใน `grid` ด้วย 1 ครั้งถ้าจะใช้ในโปสเตอร์ — ที่ขนาดเล็ก รายละเอียดที่ห่างกัน < 8px จะกลายเป็นก้อน (ลดจำนวนเส้นสำหรับ grid).
