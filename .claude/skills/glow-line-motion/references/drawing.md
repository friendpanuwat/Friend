# วาดภาพใหม่ให้เข้าสไตล์

อ่าน `style.md` ก่อน (รูปทรง ข้อ 2, น้ำหนักเส้น ข้อ 3). ไฟล์นี้คือ "วิธีลงมือ" ด้วย Pen (`api.md`).

ภาพวาดมี 2 แบบ ใช้กรอบเดียวกัน:
- **ภาพเดี่ยว** — ฟังก์ชัน `p => { … }` ใช้ได้ทุกที่: `icon:` ใน steps / flow / versus / spot / stat, หรือ `GL.art(fn, {...})` ในฉากอิสระ
- **คู่ก่อน→หลัง** — `GL.pair(name, { messy(p){…}, clean(p){…} })` ใช้ใน rows / grid / hero

```js
GL.run(() => {
  GL.stage();
  const { parts, C } = GL;
  const cup = p => {                                         // ภาพเดี่ยว: แก้วกาแฟ
    p.path('M -70 -60 L 70 -60 L 56 110 Q 54 124 40 124 L -40 124 Q -54 124 -56 110 Z', { fill: C.fill, dur: .5 });
    p.path('M 66 -20 Q 120 -20 116 30 Q 112 74 60 70', { at: .35, dur: .3 });             // หูแก้ว
    [-30, 0, 30].forEach((x, i) => p.path(`M ${x} -90 q 12 -22 0 -44 q -12 -22 0 -44`, { sw: 2, stroke: C.soft, at: .6 + i * .08, dur: .3 }));  // ไอร้อน
  };
  GL.spot({ icon: cup, label: 'COFFEE FIRST', caption: 'เริ่มวันช้า ๆ' });
});
```

## กรอบและพิกัด

- วาดรอบ (0, 0) ในกรอบ **x ±200, y ±185**. ห้ามล้น — เลย์เอาต์ย่อภาพตามกรอบนี้ ถ้าล้นจะชนป้าย เส้นแบ่ง หรือภาพข้าง ๆ.
- ภาพเดี่ยว/ฝั่งเรียบ ใช้ ~60–75% ของกรอบ อยู่กลาง; ฝั่งรกใช้เต็มกรอบ.
- ของวางบนพื้น/โต๊ะ: เส้นพื้นราว y 28–40, ขาโต๊ะลงถึง y ~180 (ดู `desk`).
- ใช้ parts ที่มีอยู่ก่อนวาดเอง (คน มือ เคอร์เซอร์ กราฟ เหรียญ ซอง ฯลฯ — `library.md`) — มันผ่านการจูนมาแล้ว.

## ลำดับชั้น = ลำดับในโค้ด, ลำดับการวาด = `at`

ชิ้นที่เขียนทีหลังในโค้ดจะอยู่ข้างหน้า (บัง) ชิ้นก่อน — ใส่ `fill: C.fill` ให้รูปทรงปิดทุกชิ้นที่ซ้อนกัน.
ส่วน "เส้นไหนวาดก่อน" กำหนดด้วย `at` แยกกันได้: เช่นคน — เขียนขาก่อน (อยู่หลังลำตัว) แต่ให้ `at` ช้ากว่า
เพื่อให้วาดหัว → ตัว → แขน → ขา ตามธรรมชาติ (ดู `parts.person`). เส้นเปิด (เส้นตรง ลายมือ) ไม่ต้อง fill.

## สร้างรูปทรงแบบเดียวกับชุดเดิม

- สี่เหลี่ยมมนเกือบทุกอย่าง (`p.rect(..., { rx })`), วงกลม, แคปซูล (`parts.capsule` — แขนขา ด้าม ท่อ), path โค้งด้วย `Q`/`C`.
- รายละเอียดข้างในใช้ `C.soft` + `sw` 1.4–1.8 และหดเข้าจากขอบ 8–14px (จอมือถือ, จอโน้ตบุ๊ก).
- จุดเด่น 1 จุดต่อภาพ: `p.dot` (badge), ติ๊ก, ดาว, แท่งกราฟสุดท้าย — วาดหลังสุด.
- หมุน/ย้ายกลุ่มย่อย: `p.child({ transform: 'translate(x y) rotate(r)' })`; ถ้ามี `scale(k)` ส่ง `k` เป็นพารามิเตอร์ที่สองเพื่อให้เส้นไม่บาง.

## ทำให้ "รก" อ่านออกในครึ่งวินาที (คู่ก่อน→หลัง)

- **จำนวน**: 5–20 ชิ้น ของชนิดเดียวกับฝั่งเรียบ (ซอง 6 → ซอง 1, แอป 20 → แอป 3) — คนดูเทียบได้ทันที.
- **เอียง/ซ้อน**: หมุน ±5–20°, ซ้อนกัน 20–40%.
- **เส้นยุ่ง**: `parts.scribble` (ลายมือ), `parts.tangle` (ความคิดพันกัน / กระดาษขยำเมื่อ r เล็ก), สายไฟเป็น path โค้ง S.
- **สิ่งรบกวน**: จุดแจ้งเตือน `p.dot`, ไอคอนเล็กรอบ ๆ, ของหล่นบนพื้น.
- ฝั่งเรียบ: ชิ้นเดียวหรือ 3 ชิ้นเรียงเท่ากัน ตั้งตรง สมมาตร + จุดเด่นหนึ่งจุด.
- สุ่มด้วย `GL.rr(a, b)` / `GL.rnd()` เท่านั้น (ได้ผลเดิมทุกครั้ง — `Math.random()` ทำให้เฟรมกระตุกเพราะ render หลาย worker).

## จังหวะ (`at` / `dur` ภายในภาพ)

- รูปทรงใหญ่ `dur` .35–.55, รายละเอียด .1–.25, ลายมือ .15–.25.
- ไล่ `at` ทีละชิ้น ห่าง .05–.12 วิ; รายละเอียดข้างในเริ่มเมื่อโครงวาดไปได้ครึ่งทาง (`at + d * .5`).
- ภาพเดี่ยว / ฝั่งเรียบ ~0.5–0.9 วิ, ฝั่งรก ~1.0–1.2 วิ. ยาวกว่านี้คลิปยืด (ใช้ `ts` ของเลย์เอาต์ปรับทั้งชุดได้).

## ให้ภาพใหม่ขยับ

ไอคอนโผล่มาครบทั้งชิ้นแล้วขยับต่อ (`style.md` ข้อ 6). ภาพใหม่ทุกภาพควรมีการขยับที่ "บอกนิสัย" ของมัน 1 อย่าง:
```js
const cup = p => { … };
cup.motion = { kind: 'bob', amp: 5 };                                       // ทั้งแก้วลอยเบา ๆ
// หรือขยับบางส่วน: ไอร้อนลอยขึ้นแล้วจาง
// p.loop({ kind: 'rise', amp: 24, period: 2 }, q => q.path('M 0 -90 q 12 -22 0 -44', { sw: 2 }));
```
เลือก: ของที่มีกลไก → ขยับส่วนนั้น (เข็ม แขน ฝา ใบพัด) · ของมีชีวิต/อารมณ์ → `bob` `hop` `beat` · ของแขวน → `swing` รอบจุดแขวน ·
ของหนัก/อาคาร → `breathe` เบามาก · เส้น/ตัวเชื่อม → ไม่ขยับ (วาดตัวเอง `reveal: 'draw'`).

## ย่อ/ขยายแล้วต้องเหมือนเดิม (บทเรียน 2026-11-13 — อ่านก่อนวาดไอคอนชุดใหม่)

ผู้ใช้: **"เวลาย่อและขยายมันต้องไม่เปลี่ยน"** — ไอคอนเดียวกันต้องหน้าตาเหมือนกันทั้งตอนเต็มจอและตอนเป็นไอคอนเล็กในแผ่น/ป้าย.
เคยพลาด 2 ครั้ง: คน (`human()`) แล้วก็ ~100 ไอคอนที่ใช้เส้นหนาเป็นเนื้อรูป (กากบาท ลูกศร % ห่วงโซ่ จุดของ ? ขนแปรง ร่องตัดของไอคอน -off)
— ย่อเหลือ ~80px แล้วกลายเป็นก้อนดำ เพราะเส้นหนาตามน้ำหนักเส้น ไม่ได้หดตามรูป (ภาพเทียบ `motion/glow-line-cats/icon-scale-fix.png`).

ตอนนี้เอนจินจัดให้เอง (`Pen._sw` + `fitStrokes`, ดู `api.md`): `sw` ≤ 3 = เส้น (หนาเท่าเดิมบนจอ) · ส่วนที่เกิน 3 = เนื้อ (หดขยายตามรูป) ·
ท่อ = เส้นขาวหนา + เส้น `C.fill` บางกว่าบน path เดียวกัน → ขอบคงที่ ไส้ตามรูป · ร่องตัด = เส้น `C.fill` หนากว่าเส้นขาว → ระยะตามรูปแต่ไม่แคบกว่าเส้น.
**กฎสำหรับไอคอนใหม่:**
1. วาดตามขนาดจริงในกล่อง ±200 แล้ว **ห้ามหาร/คูณ `sw` ด้วย `p.k` เอง** (เอนจินทำแล้ว — ทำซ้ำจะผิดสองต่อ). ต้องการความหนาที่เป็นขนาดจริงล้วน ๆ (ไม่มีขอบ) → `abs: true`.
2. ส่วนที่เป็น "เนื้อ" (แขนขา ท่อ แถบ จุดใหญ่) วาดเป็นคู่ท่อบน path เดียวกัน (`tubes()` หรือเส้นขาว `w + 7` แล้วเส้น `C.fill` `w`)
   หรือเป็นรูปปิด `fill` — อย่าใช้เส้นขาวหนาเปล่า ๆ เป็นก้อนเนื้อใหญ่.
3. ร่องตัด (ขีดทับของไอคอน -off, ช่องว่างรอบเส้นที่ไขว้กัน) = เส้น `C.fill` บน path เดียวกับเส้นขาว และหนากว่ามัน.
4. ห้ามเปลี่ยน `stroke-width` ทีหลังด้วย `setAttribute` หรือ kf — เอนจินไม่เห็น.
5. รายละเอียดที่ห่างกัน < ~25 หน่วย (ในกล่อง ±200) จะชนกันเมื่อย่อเหลือ 80px เพราะเส้นยังหนา ~2.4px — เว้นให้ห่างหรือลดเส้น.
6. **ตรวจทุกครั้ง:** `node scripts/check_scale.js --sheet <scratch>/scale.png <ชื่อไอคอน…>` → ต้องไม่มี `BLOB` และเปิดแผ่นดูเอง
   (แถวบน = 300px, แถวล่าง = 80px ขยายขึ้นมาเท่ากัน — ต้องดูเป็นภาพเดียวกัน; ตัวเลขจับก้อนได้ แต่ร่องที่กินรูป/จุดที่บวม ต้องดูด้วยตา).

## ตรวจภาพใหม่

1. วางภาพเดี่ยวใน `GL.spot` (หรือคู่ใน `rows` แถวเดียว) → `render.js --still` → เปิด `still.png`.
2. ครอปดูใกล้ ๆ: `ffmpeg -i out/still.png -vf crop=1080:700:0:600 crop.png`.
3. เทียบกับ `references/icons.jpg` / `catalog.jpg` — เส้นหนาเท่ากัน ถมดำ มุมมน รายละเอียดพอ ๆ กัน = เข้าชุด.
4. ดู `storyboard.jpg` ว่าลำดับการวาดเป็นธรรมชาติ (โครงก่อน รายละเอียดทีหลัง ข้างหลังก่อน ข้างหน้าทีหลัง).
5. จะใช้ในโปสเตอร์ (`grid`) หรือ `icons-catalog` ขนาดเล็ก: รายละเอียดที่ห่างกัน < 8px จะกลายเป็นก้อน — ลดจำนวนเส้น.
6. ไอคอน/ภาพที่จะถูกย่อขยาย: `node scripts/check_scale.js --sheet …` (หัวข้อข้างบน) — ไม่มี `BLOB` + ดูแผ่นแล้วเหมือนกันทั้งสองขนาด.

ภาพที่ผู้ใช้ชอบและน่าจะใช้ซ้ำ → ย้ายเข้า `assets/glowline.js` (`parts` / `icons` / `pairs`) แล้ว render
`examples/icons-catalog.html` / `grid-catalog.html` ใหม่เป็น `references/icons.jpg` / `catalog.jpg` + เพิ่มใน `library.md`.
