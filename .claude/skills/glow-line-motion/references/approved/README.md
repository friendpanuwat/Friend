# ผลงานที่ผู้ใช้ตอบ "ผ่าน" แล้ว — เก็บไว้ในสกิล (ผู้ใช้ 2026-11-13: "เก็บไว้ใน skill ด้วยนะครับ")

วิดีโอท่าขยับของหมวด CutPack ที่ผ่านแล้ว ใช้เป็นแบบอ้างอิงเวลาทำหมวดถัดไป (ระดับความละเอียด จังหวะ ท่าเข้า-ทำงาน-ผลตรงคำสำคัญ-ค้าง-ออก).
ต้นฉบับ (และภาพนิ่ง A/B) อยู่ที่ `motion/glow-line-cats/b0x/` ใน repo; โค้ดอยู่ที่ `examples/b0x/b0x.js`.

| หมวด | ไฟล์ | หมายเหตุ |
|---|---|---|
| B01 ตัวเลขเด่น | `b01/b01-motion-1-10.mp4`, `b01-motion-11-20.mp4` | ทำก่อนแก้เอนจินเรื่องย่อ/ขยาย (ผ่านแล้ว) |
| B02 เพิ่ม / ลด | `b02/b02-motion-1-10.mp4`, `b02-motion-11-20.mp4` | ทำก่อนแก้เอนจินเรื่องย่อ/ขยาย (ผ่านแล้ว) |
| B03 เปรียบเทียบ / ก่อน→หลัง | `b03/b03-motion-1-10.mp4`, `b03-motion-11-20.mp4` | ทำก่อนแก้เอนจินเรื่องย่อ/ขยาย (ผ่านแล้ว) |
| B04 ขั้นตอน / เช็กลิสต์ | `b04/b04-motion-1-10.mp4`, `b04-motion-11-20.mp4` | ทำด้วยเอนจินใหม่ |
