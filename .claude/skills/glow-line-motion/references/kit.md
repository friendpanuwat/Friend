# Kit — ชิ้นส่วนที่วาดยาก (วาดครั้งเดียว ใช้ได้ทุกครั้ง)

ดูทั้งหมดในภาพเดียว: `references/kit.jpg` (render จาก `examples/kit-catalog.html`).
ทุกชิ้นปรับสัดส่วนด้วยตาแล้ว — **ใช้ของในชุดก่อนเสมอ** อย่าวาดคน มือ หรือลูกศรเชื่อมเองใหม่ จะได้หน้าตาเหมือนกันทุกคลิป.

ใช้ได้ 2 แบบ:
1. **เป็นไอคอน** — ใส่ชื่อใน `icon:` ของ `steps` / `flow` / `diagram` / `shots` (หรือ `GL.art(GL.icons['hand-thumb'], …)`)
2. **วางเองในภาพ** — เรียก `GL.kit.ชื่อ(p, { … })` ข้างในฟังก์ชันวาด (`draw`, `messy`, `clean`, `GL.art`) ร่วมกับ Pen / parts

`at` / `d` = เวลาเริ่ม / เวลาวาดทั้งชิ้น (วินาที นับจากจุดเริ่มของภาพ). พิกัดเป็นพิกัดของ Pen ที่ส่งเข้าไป.

## ชื่อไอคอน (ขนาดพอดีกรอบ ±200 × ±185)

`person` `person-wave` `person-cheer` `person-think` `person-shrug` `person-point` `person-present` `person-walk` `person-run` `person-sit`
`bust` `team` `hand-point` `hand-thumb` `hand-open` `hand-tap` `hand-phone` `package` `cursor` `sparkle` `cycle`

## คน — `kit.person(p, { x, y, h, pose, face, dir, at, d })`

คนแบบเงาเรียบ ๆ (pictogram): หัวกลม ลำตัวมน แขนขาเป็นท่อ ไม่มีหน้า ไม่มีเสื้อผ้า — เป็นได้ทุกคน.

| ตัวเลือก | ค่าเริ่ม | |
|---|---|---|
| `x, y` | 0, 0 | **จุดบนพื้นใต้เท้า** — วางหลายคน/โต๊ะ/เก้าอี้บนพื้นเดียวกันได้ง่าย |
| `h` | 300 | ความสูงทั้งตัว (px ของ Pen) |
| `pose` | `stand` | `stand` `wave` (โบกมือ) `cheer` (ชูสองมือ) `think` (มือแตะคาง) `shrug` (ยักไหล่) `point` (ชี้ด้านข้าง) `present` (ชี้ขึ้นเฉียง — ชี้กระดาน/กราฟ) `walk` `run` `sit` (นั่งเก้าอี้ มีเก้าอี้ให้) |
| `dir` | point −6°, present −38° | มุมแขนที่ชี้ (องศา: 0 = ขวา, −90 = ขึ้น) |
| `face` | 1 | 1 = หันขวา, −1 = หันซ้าย (กลับทั้งตัว ใช้กับทุกท่า) |
| `d` | .9 | ขา → ลำตัว → หัว → แขนหน้า |

ท่าด้านข้าง (`walk` `run` `sit`) แขนขาข้างไกลเป็นสีเทาเพื่อบอกความลึก. นั่งทำงาน: `kit.table` + `parts.laptop` + `kit.person({pose:'sit'})`
บนพื้นเดียวกัน (ดูไอคอน `person-sit` ใน `glowline.js`). ท่าใหม่: ส่ง `pose` เป็น object `{ legs, back, front, side, lean, ground }`
ตามรูปแบบของ `POSES` ใน `glowline.js` (จุดข้อต่อ ไหล่ (±31, −90) สะโพก (±15, 10) เท้า y ≈ 165).

| ฟังก์ชัน | ตัวเลือก | |
|---|---|---|
| `kit.bust(p, {x, y, size, at, d})` | `size` = ความสูง (200) | หัว + ไหล่ (ลูกค้า ผู้ใช้ โปรไฟล์ ในแชต) |
| `kit.team(p, {x, y, size, at, d})` | `size` = ความกว้าง (360) | 3 คน คนหน้าใหญ่สุด (ทีม ลูกค้ากลุ่ม ชุมชน) |

## มือ — `kit.hand(p, { x, y, size, pose, rot, flip, at, d })`

มือแบบไอคอน: ฝ่ามือมน นิ้วเป็นท่อ มีข้อมือเสื้อ. `(x, y)` = กลางภาพ, `size` = ความสูง (240).

| pose | | ใช้กับ |
|---|---|---|
| `point` | นิ้วชี้ขึ้น | ข้อสำคัญ, "ข้อที่ 1", เตือน |
| `thumb` | ยกนิ้วโป้ง | ดี / สำเร็จ / รีวิว / ผ่าน |
| `open` | แบมือ 5 นิ้ว | สวัสดี / หยุด / ห้า |

`rot` หมุน (องศา), `flip: true` กลับซ้าย-ขวา.

| ฟังก์ชัน | |
|---|---|
| `kit.tap(p, {x, y, size, at, d, rings})` | มือชี้ที่ **ปลายนิ้วแตะจุด (x, y)** + วงกระเพื่อม — วาดหน้าจอ/ปุ่มก่อน แล้วค่อยวางมือ |
| `kit.holdPhone(p, {x, y, size, at, d, screen})` | มือถือมือถือ (นิ้วโป้งทับจอ นิ้วอ้อมขอบขวา), `size` = ความสูง (360). `screen(q, {x, y, w, h, at})` วาดของในจอ (ใต้นิ้วโป้ง) |

## ลูกศรเชื่อม — `kit.connect(p, x1, y1, x2, y2, { … })`

วาดตัวเองจากต้นไปปลาย หัวลูกศรขึ้นตอนท้าย. คืน `{ end, mid, ang }` (เวลาเสร็จ, จุดกลางเส้น, มุมที่จุดกลาง — ไว้วางป้าย).
บนเวที (นอกภาพวาด) ใช้ `GL.connect(x1, y1, x2, y2, { at, … })` → คืนเวลาเสร็จของคลิป.

| ตัวเลือก | ค่าเริ่ม | |
|---|---|---|
| `style` | `straight` | `straight` · `curve` (โค้งเดียว) · `swoosh` (โค้ง S แบบลายมือ) · `elbow` (หักมุมฉาก มุมมน) · `loop` (ม้วนหนึ่งรอบกลางทาง) |
| `bend` | curve .14, swoosh .16 | โค้งแค่ไหน (สัดส่วนความยาว). บวก = โค้งไปทางซ้ายของทิศที่วิ่ง (ลูกศร → โค้งขึ้น), ลบ = อีกฝั่ง. `loop`: บวก = ม้วนด้านบน |
| `via` | อัตโนมัติ | เส้นทาง elbow: `hv` `vh` `hvh` `vhv` (h = แนวนอน, v = แนวตั้ง) |
| `head` | `open` | `open` (หัว V) · `solid` (สามเหลี่ยมทึบ) · `none` |
| `both` | false | หัวลูกศรสองข้าง |
| `dash` | false | `true` หรือความยาวขีด (px) — เส้นประที่วาดทีละขีด (ความสัมพันธ์รอง / ทางเลือก / อนาคต) |
| `gap` `gap1` `gap2` | 0 | ตัดปลายออก (px) ไม่ให้ชนของ |
| `clip1` `clip2` | — | `(x, y) => true` ตอนอยู่ในรูปทรง — ลูกศรจะเริ่ม/หยุดที่ขอบรูปทรงพอดี แม้เป็นเส้นโค้ง |
| `sw` `stroke` `hs` | 2.6, ink, 16 | ความหนา สี ขนาดหัว |
| `at` `d` | 0, .45 | |

| ฟังก์ชัน | |
|---|---|
| `kit.cycle(p, {x, y, r, n, at, d, sw, hs})` | ลูกศร n อันวิ่งเป็นวง (ทำซ้ำ / วงจร / ต่ออายุ) |

## ของประกอบ

| ฟังก์ชัน | |
|---|---|
| `kit.badge(p, {x, y, r, n, at})` | วงกลมตัวเลข (ขั้นที่ 1 2 3, จำนวนแจ้งเตือน) — `n` เป็นตัวเลขหรือคำสั้น ๆ |
| `kit.cursor(p, {x, y, size, click, at})` | ลูกศรเมาส์ ปลายอยู่ที่ (x, y); `click: true` มีขีดคลิก 3 ขีด |
| `kit.sparkle(p, {x, y, r, at, fill})` | ประกาย 4 แฉก (ใหม่ / เด่น / สะอาด) — ใช้ 1–3 อัน ขนาดต่างกัน |
| `kit.burst(p, {x, y, r1, r2, n, from, spread, at})` | เส้นรัศมีเน้น; `from` = ทิศกลาง (องศา), `spread` = กว้าง (360 = รอบตัว) |
| `kit.ripple(p, {x, y, r, n, at})` | วงกระเพื่อม (แตะ สัญญาณ เสียง) |
| `kit.callout(p, {x, y, tx, ty, shelf, at})` | จุดที่ฟีเจอร์ → เส้นออกไป (tx, ty) → ชั้นยาว `shelf` px; คืนจุดวางป้าย (`showcase` ใช้ตัวนี้) |
| `kit.isoBox(p, {x, y, w, dp, h, tape, at, d})` | กล่อง isometric; `(x, y)` = กลางฐานบนพื้น, `w` แกน X, `dp` แกน Z, `h` สูง; `tape` = เทปกาว (พัสดุ) |
| `kit.table(p, {x, y, w, h, at})` | โต๊ะหน้าตรง; `(x, y)` = พื้นใต้กลางโต๊ะ |
| `GL.iso(X, Y, Z)` → `[sx, sy]` | แปลงพิกัด 3 มิติเป็นจอแบบ isometric — วาดชั้นวาง ตึก กองของเองให้มุมตรงกับ `isoBox` |
| `p.tube(points \| 'path', T, o)` | ท่อหนา T: ขอบขาว แกนดำ ปลายมน (แขนขา นิ้ว หูหิ้ว สายคล้อง) — ชิ้นหลังบังชิ้นก่อน |

## เพิ่มชิ้นใหม่เข้าชุด

เมื่อวาดอะไรที่ยาก (เช่น สัตว์เลี้ยง จักรยาน ร่ม) แล้วผู้ใช้พอใจ:
1. ย้ายฟังก์ชันเข้า `kit` ใน `assets/glowline.js` (รูปแบบ `kit.ชื่อ = function (p, { x, y, size, at, d }) {…}`) + เพิ่มใน `icons` ถ้าใช้เป็นไอคอนได้
2. เพิ่มชื่อใน `examples/kit-catalog.html` → `node scripts/render.js examples/kit-catalog.html <out> --still`
   → ตรวจที่ขนาดเล็กว่ายังอ่านออก → `ffmpeg -i <out>/still.png -vf scale=720:-2 -q:v 3 references/kit.jpg`
3. เพิ่มแถวในไฟล์นี้
