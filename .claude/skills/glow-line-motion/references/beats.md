# ฉากสำเร็จรูป 21 หมวด (B01–B21)

ชุดฉากสั้น 3–6 วิ สำหรับ "หนึ่งประโยค = หนึ่งฉาก" (B-roll แทรกคลิปพูด หรือร้อยเป็นคลิปอธิบายทั้งคลิป).
อยู่ใน `assets/beats.js` (โหลดเองพร้อม `glowline.js`). ภาพรวม: `references/beats.jpg` (ตัวอย่างจากประโยคในตาราง) ·
`references/beats-neutral.jpg` (ชุดเดียวกัน คนละเรื่องสิ้นเชิง: วิ่ง ท่องเที่ยว เรียน ทำอาหาร งาน).

```js
GL.run(() => {
  GL.stage();
  GL.beat('B05', { wrong: { icon: '-50%', label: 'ส่วนลด' }, right: { icon: 'target', label: 'สิ่งที่ลูกค้าต้องการจริง ๆ' } });
});
```
หลายประโยคในคลิปเดียว: `let t = .3; t = GL.page(t, at => GL.beat('B01', {...}, { at }));` ต่อกันไปเรื่อย ๆ (หน้าสุดท้าย `{ out: false }`) — ดู `examples/beats/all.html`.
ตัวอย่างพร้อมใช้ทุกหมวด: `examples/beats/B01.html` … `B21.html` (สร้างจาก `_spec.js` ด้วย `node examples/beats/_make.js`).

ทุกไอคอนในฉาก **โผล่มาครบแล้วขยับ** (หัวใจเต้น หมุดกระโดด หน้าแสดงอารมณ์ขยับตามอารมณ์ ฯลฯ) ส่วนเส้นโยง ไทม์ไลน์
เส้นใต้คำ ยังวาดตัวเอง — ดู `style.md` ข้อ 6. ป้ายคำ (คำที่ไม่มีในคลัง) ขยายหดเบา ๆ.

## กฎความเป็นกลาง (ทำไมใช้ได้กับทุกเนื้อหา)

1. **ทุกหมวดรับแค่ ข้อความ ตัวเลข และชื่อไอคอน** — ไม่มีคำ ภาพ หรือเรื่องที่ผูกกับธุรกิจ/หัวข้อใดอยู่ในโค้ด.
2. **ไอคอนเป็นอะไรก็ได้**: ชื่อใน `library.md` (`store` `heart` `face-fear` …), ฟังก์ชันวาดเอง `p => {…}`,
   หรือ **คำใดก็ได้** (`'-50%'`, `'ไข่'`, `'GPA 4.0'`) — คำที่ไม่มีในคลังจะกลายเป็นป้ายคำเรืองแสงในกรอบมน แทนการพัง.
   เลือกตามลำดับ: ไอคอนที่ตรงความหมาย → วาดใหม่ (`drawing.md`) → ป้ายคำ (เร็วและตรงเสมอ แต่ใช้เมื่อไม่มีภาพที่สื่อจริง ๆ).
3. ข้อความยาวตัดบรรทัดเองแบบภาษาไทย (ตัดที่ช่องว่างที่ผู้ใช้เว้นก่อน แล้วค่อยตัดคำ) และย่อเมื่อจำเป็น — แต่ฉากละ 3–8 คำอ่านง่ายที่สุด.
4. ทุกขนาดจอ (9:16 / 1:1 / 16:9) — ตำแหน่งคิดจากขนาดจอ; หมวดที่วางซ้อนแนวตั้ง (B05, B12) จะวางแนวนอนเองในจอกว้าง.
5. ห้ามแต่งตัวเลข/ข้อเท็จจริง — ใส่เฉพาะที่ประโยคพูด. ส่วนตกแต่งที่ไม่ใช่ข้อมูล (ป้าย "ระวัง", "เคล็ดลับ") เปลี่ยนคำได้ทุกหมวด.

## เลือกหมวดจากประโยค

อ่านประโยคแล้วถามตามลำดับ — เจอข้อแรกที่ใช่ หยุด:

| ถ้าประโยค… | หมวด |
|---|---|
| ชวนคนดูทำอะไร (ติดตาม เซฟ แชร์ คอมเมนต์) | B15 |
| บอกว่า X **ไม่ใช่** … แต่คือ Y / อันหนึ่งผิด อีกอันถูก | B05 |
| เตือน ห้าม ระวัง ความผิดพลาด ความเสี่ยง | B07 |
| ตัวเลขคือใจความ (ราคา % จำนวน ปี) | B01 |
| มีอะไร เพิ่ม/ลด/เข้า/ออก/โต/หาย | B02 |
| เทียบ A กับ B / เคยเป็นแบบหนึ่ง ตอนนี้เป็นอีกแบบ | B03 |
| ลำดับการทำ / รายการสิ่งที่ต้องทำ | B04 |
| เพราะ… จึง… / อันหนึ่งทำให้เกิดอีกอัน | B12 |
| ลำดับเวลา ระยะเวลา เดดไลน์ | B09 |
| ถาม สงสัย ลังเล | B06 (ถ้าเน้นอารมณ์ลังเลของใครสักคน → B19) |
| X คืออะไร | B16 |
| ทริก วิธีลัด จุดที่คนมองข้าม | B13 |
| ปลายทาง ผลลัพธ์ที่อยากได้ ความสำเร็จ | B08 |
| สำหรับใคร / คนประเภทหนึ่ง | B10 |
| ข้อความ แชต คอมเมนต์ รีวิว | B11 |
| รู้สึกอย่างไร | B19 |
| ความสัมพันธ์ระหว่าง 2 คน | B20 |
| อยู่ที่ไหน เกิดที่ไหน | B21 |
| เรื่องที่เกิดขึ้นแล้ว ใครทำ เมื่อไร | B18 |
| ยกตัวอย่าง / ส่วนประกอบ / เหตุผลหลายข้อ (ไม่ใช่ขั้นตอน ไม่ใช่สิ่งที่ต้องทำ) | B17 |
| ไม่เข้าหมวดไหนเลย แต่เป็นใจความที่อยากให้จำ | **B14** (หมวดกลางที่สุด — ใช้เป็นตัวเลือกสุดท้ายเท่านั้น) |

ไม่ต้องทำทุกประโยค — ประโยคเชื่อม/ทักทายไม่ต้องมีฉาก (ถ้าทำคลิปพูดหน้ากล้อง ให้เห็นหน้าคนพูดแทน).

## ข้อมูลของแต่ละหมวด

ทุกหมวดเรียก `GL.beat('Bxx', data, o)`; `o` = `{ at, top, bottom }` (ค่าเริ่ม: เริ่ม .3 วิ, ใช้พื้นที่ 10–88% ของความสูง).
`item` = `{ icon, label, sub }` หรือข้อความล้วน ๆ (`'ตัดต่อ'`). `icon` ตามกฎข้อ 2.

| หมวด | data | ภาพ / การเคลื่อนไหว |
|---|---|---|
| **B01 ตัวเลขเด่น** | `value`, `from 0`, `prefix`, `suffix`, `decimals`, `label`, `sub`, `trend 'up'│'down'`, `icon` | ตัวเลขใหญ่นับขึ้น + เส้นใต้ + ลูกศรขึ้น/ลงลอยเหนือตัวเลข (หรือข้างไอคอน) |
| **B02 เพิ่ม / ลด** | `dir 'up'│'down'`, `item` (ไอคอนของที่เพิ่ม/หาย), `count 2–8`, `owner` (เจ้าของตรงกลาง เช่น `store` `wallet`), `label`, `value` ('+38%') | ขึ้น: ของโผล่ทีละชิ้นรอบเจ้าของ · ลง: ของครบแล้วร่วงจางหายทีละชิ้น · ลูกศรขึ้น/ลง |
| **B03 เปรียบเทียบ / ก่อน→หลัง** | `left`, `right` (item), `mode 'vs'│'change'`, `win 'left'│'right'`; หรือ `pair` (คู่รก→เรียบ) | vs: สองฝั่ง + VS · change: ลูกศร ฝั่งก่อนหรี่ ฝั่งหลังเรืองแสง · pair: เต็มจอ แปลงร่าง |
| **B04 ขั้นตอน / เช็กลิสต์** | `items` (2–5), `mode 'steps'│'check'`, `mark` (เลขข้อที่เน้น เริ่ม 0), `title` | วงกลมเลข + เส้นต่อ (steps) หรือช่องติ๊ก (check) · `mark`: ลูกศรชี้ ข้ออื่นหรี่ |
| **B05 ถูกกับผิด** | `wrong`, `right` (item), `tags ['ไม่ใช่','แต่คือ']` | ฝั่งผิดวาด → โดนกากบาท หรี่ · ฝั่งถูกวาด → ติ๊กถูกเรืองแสง |
| **B06 คำถาม / สงสัย** | `question`, `who` (ค่าเริ่ม `think`), `options` (0–3), `answer` (เลขข้อ หรือไม่ใส่) | คนคิด + ? ลอย · มีตัวเลือก: เคอร์เซอร์ลังเลไปมา · มีคำตอบ: ไปหยุดที่คำตอบ ติ๊ก |
| **B07 คำเตือน / ปัญหา** | `icon`, `label`, `sign 'ระวัง'`, `cross` | ป้ายเตือน ! + ป้ายคำ กระพริบเรือง 2 ครั้ง · ของเสี่ยง (+ กากบาทถ้า `cross`) |
| **B08 เป้าหมาย / ผลลัพธ์** | `icon` (ค่าเริ่ม `flag`; `target` `cheer` `coins` …), `label`, `sub`, `start` (ไอคอนจุดเริ่ม) | จุดไข่ปลาไต่จากล่างซ้ายถึงเป้า มีจุดแสงวิ่งตาม → ติ๊กถูก |
| **B09 เวลา / ไทม์ไลน์** | `points` (2–5 item; `icon` = สิ่งที่เวลาพามา), `title`, `icon` (บนสุด เช่น `clock`) | เส้นเวลา + จุดแสงเลื่อนทีละจุด แต่ละจุดเผยป้ายและไอคอน |
| **B10 คน / กลุ่มเป้าหมาย** | `icon` (`person` `bust` `team` …), `label`, `tags` (≤ 2) | คนในวงโฟกัส + ป้ายย่อยโยงจุดไข่ปลา + ป้ายหลักเรืองแสง |
| **B11 แชต / คอมเมนต์ / รีวิว** | `kind 'chat'│'comment'│'review'`, `messages` [`{ from: 'them'│'me', text }`], `name`, `ghost` (หายไปไม่ตอบ), `mood 'good'│'bad'`, `stars` | chat: หน้าต่างแชต พิมพ์อยู่… → ข้อความ · `ghost`: "อ่านแล้ว" พิมพ์แล้วหยุด รูปจาง Zzz · review: การ์ดดาว |
| **B12 เหตุ → ผล** | `chain` (3 item), `links` (คำบนลูกศร เช่น `['เพราะ','จึง']`) | โซ่ 3 ข้อ ลูกศรวาดไปชน ข้อถัดไปเรืองแสงเหมือนโดมิโน |
| **B13 เคล็ดลับ / ความลับ** | `label`, `icon` (ค่าเริ่ม `bulb`), `tag 'เคล็ดลับ'` | หีบปิด → ฝาเปิด แสงพุ่ง → ไอคอนลอยขึ้นจากหีบ |
| **B14 ประโยคเด็ด** | `text`, `by`, `highlight` (เลขบรรทัดที่ขีดเส้นใต้) | เครื่องหมายคำพูด + ข้อความทีละบรรทัด + เส้นใต้บรรทัดสำคัญ |
| **B15 ชวนทำ / ปิดคลิป** | `actions` [`follow` `like` `comment` `save` `share` `notify`], `tap` (ปุ่มที่ถูกกด เลขลำดับ), `label`, `names` ({save:'เซฟ'}) | ปุ่มกลมเรียงกัน มือแตะปุ่ม → ปุ่มเปลี่ยนสถานะ + ประกาย |
| **B16 นิยาม** | `term`, `meanings` (1–3), `icon` | คำในกรอบเรืองแสง + "คือ" + ความหมายแตกกิ่งทีละข้อ |
| **B17 รายการ** | `title` (ชื่อกลุ่ม), `items` (2–4 item) | ชื่อกลุ่ม + วงเล็บแตกกิ่ง + ของ 2–4 ชิ้นพร้อมป้าย |
| **B18 เหตุการณ์** | `when`, `who` (ไอคอน), `whoLabel`, `what` (item) | ป้ายเวลา + ปฏิทิน · กรอบมุมเหมือนภาพบันทึกความทรงจำ · คน → สิ่งที่เกิด |
| **B19 ความรู้สึก** | `mood` (ด้านล่าง), `who` (ของใคร), `label` | หน้าใหญ่ + เอฟเฟกต์ตามอารมณ์ (ดาว น้ำตา ไอโกรธ เหงื่อ หัวใจลอย ? …) |
| **B20 ความสัมพันธ์** | `a`, `b` (item; ค่าเริ่มอวาตาร์), `relation`, `broken`, `power 'a'│'b'` | เส้นเชื่อม 2 คน + ป้ายความสัมพันธ์ · `broken`: เส้นขาด กากบาท แยกกัน · `power`: ฝั่งใหญ่กว่าอยู่สูงกว่า ลูกศรลง |
| **B21 สถานที่** | `kind 'building'│'map'│'store'│'house'│ไอคอนใดก็ได้`, `name`, `floors` (['G','1','2']), `spots` [`{ label, floor }` หรือ `{ label, at: [u, v] }` (−.5….5)] | สถานที่ + ป้ายชื่อ · หมุดหล่นลง 1–2 จุด พร้อมป้าย |

`mood` ของ B19 และไอคอน `face-…`: `happy` `sad` `angry` `fear` `relief` `love` `doubt` `surprise` `tired` `neutral`.

## ไอคอนที่เพิ่มมากับชุดนี้

`cross` `warn` `question` `up` `down` `store` `house` `building` `pin` `map` `heart` `bookmark` `share` `flag` `chest` `magnifier` `eye` `follow`
และหน้า 10 อารมณ์ `face-happy` … `face-neutral` (ดูทั้งหมดใน `icons.jpg`). parts ใหม่: `cross` `warn` `qmark` `trend` `store` `house` `building`
`pin` `face` `heart` `bookmark` `share` `flag` `chest` `chestLid` `magnifier` `eye` `mapPlan` `button`.
helper ที่ใช้ซ้ำได้ในฉากอิสระ: `GL.chip(text, x, cy, o)` (ป้ายกรอบมน), `GL.wrap(text, size, maxW)` (ตัดบรรทัดไทย), `GL.ic(ชื่อหรือคำ)` (หาภาพ หรือสร้างป้ายคำ).

## ตรวจงาน

ทุกฉาก: `render.js --still` แล้วดู still + storyboard ตาม QC ใน SKILL.md. จุดที่พลาดบ่อย:
ข้อความยาวเกินจนตัวเล็ก (ย่อคำ), ป้ายคำแทนไอคอนทั้งที่มีไอคอนที่ตรง, ใช้ B14 ทั้งที่ประโยคเข้าหมวดอื่น,
B02/B09 ใส่ของเกิน (B02 ≤ 8 ชิ้น, B09 ≤ 5 จุด).
