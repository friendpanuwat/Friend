# 21 หมวด — ภาพแทรกคลิปพูด

แม่แบบที่ render ผ่านแล้วอยู่ใน repo ที่ `motion/glow-21/<เลข-ชื่อ>/scene.html` (ภาพรวม `motion/glow-21/sheet.jpg`).
เริ่มงานใหม่: คัดลอก scene ของหมวดที่ตรง → แก้บรรทัดที่มี ✎ (ข้อความ / ตัวเลข / ชื่อภาพ) → `render.js --still` → MP4.
ข้อความในแม่แบบเป็นตัวอย่างทั้งหมด — ใช้ข้อความ/ตัวเลขของผู้ใช้แทนเสมอ (ห้ามแต่งตัวเลขเอง).
