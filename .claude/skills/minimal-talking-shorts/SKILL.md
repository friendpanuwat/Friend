# Minimal Talking Shorts

ตัดต่อคลิปพูดหน้ากล้องแนวตั้ง (1080×1920) ให้ดูเหมือนจ้างคนตัดต่อมืออาชีพ: หน้าคนพูดพร้อมซับเป็นวลีที่มีแถบสีวิ่งตามเสียง
สลับกับฉากกราฟิกมินิมอลพื้นขาวที่ "เล่า" สิ่งที่ประโยคนั้นพูด. งานทำด้วยโค้ด: HTML/CSS/WAAPI เรนเดอร์ทีละเฟรมใน Chromium แล้วรวมด้วย ffmpeg.
คุณ (Claude) เขียน 2 ไฟล์ต่อคลิป — `graphics.js` (ฉากของคลิปนี้) และ `timeline.js` (เวลา ซับ ซูม ฉาก); ที่เหลือ skill มีให้.

## ต้องรู้ก่อนเริ่ม

- **คุณฟังเสียงไม่ได้** → ต้องได้บทพูดพร้อมเวลา (บรรทัด `MM:SS ข้อความ` หรือ .srt). ถ้าไม่ครบความยาวคลิป ให้ถามส่วนที่ขาด อย่าเดาเนื้อหา.
  เวลาระดับวินาทีทำงานได้ แต่ซับอาจคลาด ~0.5 วินาที — บอกผู้ใช้.
- **คุณเห็นวิดีโอเป็นภาพนิ่งเท่านั้น** → ตรวจด้วย contact sheet / preview เสมอ.
- **ลูกค้าส่วนใหญ่สั่งจากมือถือ** — งานรันบนเครื่องคลาวด์. ห้ามขอให้ลูกค้าติดตั้งหรือรันอะไรเอง และห้ามเพิ่มขั้นตอนให้ลูกค้า.
- **ไม่ตัดช่วงเงียบ ไม่ตัดคลิป ไม่ปรับสีวิดีโอ ไม่ใส่เสียงประกอบ** — ใช้ภาพและเสียงต้นฉบับ.
- กฎทั้งหมดที่ผู้ใช้ยืนยันแล้วอยู่ใน `references/core.md` — **อ่านทุกครั้งก่อนเริ่ม** ห้ามเปลี่ยนเองโดยไม่ถาม.

## Workflow

ตั้ง `SK=<path ของ skill นี้>` และ `P=<โฟลเดอร์งาน>` (ชื่อสั้น ไม่มีช่องว่าง).

1. **ตรวจเครื่อง** — `bash $SK/scripts/check_env.sh` (ขาดอะไรให้ลองติดตั้งตามที่สคริปต์พิมพ์ ถ้ายังไม่ได้ให้บอกผู้ใช้ตรง ๆ)
2. **รับคลิป** — `bash $SK/scripts/fetch_video.sh $P <ลิงก์ Google Drive | ไฟล์แนบ | หลายท่อน>` → `$P/input.*`
   (ลิงก์ Drive ต้องแชร์แบบ "ทุกคนที่มีลิงก์"; ถ้าโหลดไม่ได้ให้บอกผู้ใช้ตามข้อความที่สคริปต์พิมพ์)
3. **บทพูด → ช่วงเวลา** — เขียนบทลง `$P/transcript.txt` แล้ว `python3 $SK/scripts/make_timeline.py $P/input.* $P/transcript.txt $P` → `$P/chunks.md`
4. **แยกเฟรม + ดูคลิป** — `bash $SK/scripts/pipeline.sh $P frames` แล้วเปิด `$P/face_sheet.jpg` (ภาพทุก 2 วินาที เส้นเหลืองทุก 200 px) จด:
   - แถบหัว (ผมบนสุด → คาง) เป็น y ของจอ 1920 — ถ้าคนขยับ/เปลี่ยนที่ถ่าย ให้จดแยกเป็นช่วงเวลา → `face(top, bottom, t0, t1)`
   - ช่วงที่ไม่มีหน้า (เช่นถ่ายหน้าจอ / B-roll) — ใช้ภาพจริงต่อ ไม่ต้องประกาศ `face()`
   - ตัวหนังสือที่ติดมากับคลิป — ห้ามวางอะไรทับ
   - หัวชิดขอบบนไหม (ถ้าใช่ ซูมเบาลง ≤ 1.08)
5. **วางแผนแล้วให้ผู้ใช้ดูก่อนเขียนโค้ด** — ตาราง `ช่วงเวลา · คำพูด · ภาพ` (บอกเป็นภาพที่เห็น ไม่ใช่ชื่อฟังก์ชัน) + สิ่งที่ต้องรู้จากข้อ 4
   + คำที่จะเติม/แก้จากบทพูด. **รอผู้ใช้ตอบ "ทำเลย"** แล้วค่อยทำ.
6. **เขียน `$P/graphics.js` และ `$P/timeline.js`** — อ่านก่อน: `references/core.md`, `references/retention.md`, `references/zoom.md`
   และดูตัวอย่างระดับงานที่ `examples/clip02-retire/` (ทำตามกฎปัจจุบันครบ). ฉากทุกฉากต้อง**ออกแบบใหม่ให้คลิปนี้** จากชุด `assets/minimal_kit.js`
   — ห้ามคัดลอกฉากจากตัวอย่างหรือคลิปก่อนมาเปลี่ยนคำ.
7. **Build + preview + ตรวจเอง** — `bash $SK/scripts/pipeline.sh $P build` (มี JS error หรือ `FACE:` error = หยุดและแก้)
   แล้ว `PREVIEW="0,t1,t2,..." bash $SK/scripts/pipeline.sh $P preview` อย่างน้อย 1 ภาพต่อฉากและต่อซับที่ยาว → เปิด `$P/prev.jpg`:
   เฟรม 0 เป็นหน้าคนพูด + hook, ไม่มีอะไรเลยเส้นแดง (ขวา x 900 · บน y 280), ซับไม่แตะหน้า/คาง, ฉากไม่มีชิ้นไหนหาย ทับกัน หรือเล็กจนอ่านไม่ออก.
8. **เรนเดอร์ + รวมไฟล์** — `bash $SK/scripts/pipeline.sh $P render` แล้ว `... encode` → `$P/edit.mp4` (≤ ~28 MB) + `$P/qc_sheet.jpg`
   (ใช้เวลาประมาณ 1 นาทีต่อวิดีโอ 7 วินาที — คลิป 1:40 ราว 15 นาที; รันแบบ background ได้)
9. **QC แล้วส่ง** — ดู `qc_sheet.jpg` (2 ภาพ/วินาที มีเส้นแดงที่ x 900 และ y 280) แล้วส่ง `edit.mp4` พร้อม:
   ตารางสรุปฉากแต่ละช่วง · คำที่แก้/เติม/ตัดจากบทพูด · ข้อจำกัด (เช่นเวลาในบทหยาบ) · ขอฟีดแบ็กแบบระบุวินาที.
   ไฟล์คุณภาพสูงสำหรับโพสต์จริง: `pipeline.sh $P hq` → `edit_hq.mp4` แล้ว `bash $SK/scripts/deliver_github.sh $P/edit_hq.mp4 <ชื่อ>.mp4`
   (ต้องรันจากในโฟลเดอร์ repo ของ session; ให้ลิงก์ `DOWNLOAD:` กับผู้ใช้). แก้ตามฟีดแบ็ก: แก้เฉพาะจุด → preview จุดนั้น → render ใหม่.

## timeline.js — สิ่งที่ใช้บ่อย

```js
face(420, 1180, 0, 59.5);                 // แถบหัว y ของจอ (ผม → คาง) ในช่วงเวลา — ซับ/กราฟิกจะหลบเอง
zoom(4.6, 1.06, .14); zoom(5.76, 1.0, .35);   // ซูมแบบ talking-head-motion เฉพาะคำเน้น (zoom.md) — เรียงตามเวลา
kcap(-.2, 1.98, 'นี่คือวันแรกของการหาเงิน', {key: 'วันแรก', keyColor: HILITE, size: 110});   // hook: เห็นตั้งแต่เฟรม 0
kcap(7.0, 8.98, 'เงินมันหยุดเข้ามา', {key: 'หยุด', keyColor: RED});   // ซับเป็นวลี ~1–1.5 วินาที
kcap(20.0, 20.7, 'รวยแล้ว', {color: HILITE});                           // ทั้งวลีเป็นคำเน้น
sceneIncome(2.0, 6.98, {...});            // ฉากของคลิปนี้ (เขียนใน graphics.js)
```

`graphics.js` — ฉากละฟังก์ชัน สร้างจาก `assets/minimal_kit.js`: `paper(t0, t1)` (ฉากพื้นขาวที่บีบเข้าช่วงปลอดภัยแล้ว),
`phase()` (หลายจังหวะในฉากเดียว), `svgLayer`, `label`, `pic` (คนดำทึบ), `HAND`, `card`, `redQ`, `countUp`, `loop`, `rise`, `popIn`,
สี `NIB` `G1` `G2` `G3` `RED` และ `OUT` (เส้นบาง). ดูการใช้จริงใน `examples/clip02-retire/graphics.js`.
