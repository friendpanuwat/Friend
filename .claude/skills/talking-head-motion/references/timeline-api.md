# timeline.js API

`timeline.js` คือสคริปต์ JavaScript ธรรมดาที่ถูกแทรกระหว่างเอนจินสองส่วนตอน build — ทุกฟังก์ชันด้านล่างเรียกได้ตรง ๆ.
หน่วยเวลาเป็น **วินาทีของคลิป** ทั้งหมด; ทุกอย่างคำนวณจากเวลา (seekable) จึงห้ามใช้ `Math.random()` / `Date` —
ถ้าต้องการสุ่ม ให้ใช้ตัวสุ่มแบบมี seed (เช่น `s = s * 16807 % 2147483647`).

พิกัด: ผืนงาน 1080×1920 px, (0,0) มุมซ้ายบน.

## ลำดับในไฟล์ (สำคัญ)

```js
scenes([[4.93, 8.58], [8.61, 12.57], ...]);   // 1) ประกาศช่วงฉากเต็มจอทั้งหมดก่อนอย่างอื่น
block({...}); keyHit(...); zoom(...);          // 2) ข้อความบนหน้าคนพูด (A-roll)
lowerThird(...); badge(...);                    // 3) ป้ายชื่อ / ไอคอน
{ const c = scene(4.93, 8.58, {seed: 1}); ... } // 4) ฉากเต็มจอ ฉากละหนึ่งบล็อก { }
```

`block()` ที่เริ่มในช่วง `scenes()` จะถูกซ่อนอัตโนมัติ (ข้อความช่วงนั้นต้องอยู่ในฉากแทน). ชั้นข้อความ A-roll อยู่ **เหนือ** ชั้นฉาก
→ ก้อน A-roll ต้องจบ (`t1`) ก่อนฉากถัดไปเริ่ม ไม่งั้นข้อความจะลอยทับฉาก.

## ข้อความบนหน้าคนพูด

```js
block({t0, t1, top?, center?, lines: [
  [['เวลาเรา', 's', 0.05], ['มีไอเดีย', 'k', 0.47]],   // หนึ่งบรรทัด = หลายวลีต่อกัน
  [['เริ่มทำธุรกิจ', 'm', 1.36, 120]],                   // [ข้อความ, สไตล์, เวลาขึ้น, ขนาด px (ไม่ใส่ก็ได้)]
]});
```
- สไตล์: `'s'` คำเชื่อมตัวเล็ก (ฟอนต์ small) · `'m'` เนื้อหา (mid, 90px) · `'k'` คำสำคัญ (key, 136px, สี accent + glow, ขึ้นเป็นสีขาวก่อนแล้วเปลี่ยนเป็น accent).
- `top` ค่าเริ่ม 1225 (โซนอก); `center: true` วางกลางจอ (760) ใช้กับจอดำ/statement.
- ก้อนกว้างเกิน 960 หรือสูงเกิน 440 จะย่อให้พอดีเอง — แต่ถ้าย่อมาก แปลว่าใส่เยอะไป ให้แยกเป็นสองก้อน.
- ก้อนเบลอหายเองที่ `t1` → ตั้ง `t1` = เวลาวลีถัดไปเริ่ม − 0.02.
- ตัดคำลงท้ายอย่าง "อ่ะ / น่ะ / เว้ย" ได้ เพื่อให้อ่านสะอาด (บอกผู้ใช้ว่าทำ).

```js
keyHit(t, db = -21)     // เสียงวูบนุ่มตอนคำสำคัญขึ้น (ใส่ทุกครั้งที่มี 'k' บน A-roll)
zoom(t, scale, dur=.14) // ซูมกล้อง A-roll ไปที่ scale ในเวลา dur (ease-out). กลับด้วย zoom(t2, 1.0, .35)
bloom(t, opacity=.45)   // แสงฟุ้งเต็มจอ ใช้กับประโยคแรง/ตอนเข้าจอดำ
sfx(name, t, db, pitch?)// วางเสียงเอง — ชื่อเสียงดู standards.md
```
แนวซูม: วลีปกติ 1.04–1.06 ค่อย ๆ (dur .5–.8), คำเน้น 1.07–1.10 เร็ว (dur .12), อย่าเกิน 1.14.

## ป้ายชื่อ และไอคอน

```js
lowerThird('Mark Zuckerberg', 'ผู้ก่อตั้ง Facebook', t0, t1, {top: 1560});  // ใช้เมื่อพูดถึงคนจริง แทนการพิมพ์ชื่อเป็นข้อความ
badge('bulb', t0, t1, top = 110);   // ไอคอนในวงกลมกระจกเหนือหัว: 'bulb' | 'heart' | 'glass' (นาฬิกาทรายขีดฆ่า)
IC.rocket = 'M50 10 ...';           // เพิ่มไอคอนเองได้: path SVG ใน viewBox 0 0 100 100 ใช้ stroke เท่านั้น
```
ไอคอนบน A-roll ไม่เกิน ~3 ตัวต่อคลิป — ใช้เฉพาะคำที่เป็นภาพได้ชัด (ไอเดีย, หัวใจ, เวลา).

## ฉากเต็มจอ

```js
{
  const c = scene(t0, t1, {seed: 1, tilt: 4});   // คืนค่า container ของฉาก (เวที 3D) — วางทุกอย่างลงใน c
  text(c, 'แล้วเราก็', 's', 8.65, 'top:150px');                 // ข้อความกลางจอ kinetic
  text(c, 'มัวแต่ไปวน', 'k', 9.0, 'top:220px', {size: 150});
  const card = div('left:110px;top:430px;width:860px;height:600px;padding:56px', c); card.className = 'glass';
  rise(card, 4.95, .6);
}
```
`scene()` เบลอคลิปต้นฉบับเป็นพื้น (ไม่มีพื้นสี — ผู้ใช้สั่ง), เฟดเข้า (เบลอ+ย่อ) และออกให้เอง, เวทีเอียง 3D ช้า ๆ,
และวางเสียง whoosh ตอนเข้า. (`seed` ยังรับได้ แต่ไม่มีผลแล้ว)

ตัวช่วยในฉาก:
| ฟังก์ชัน | ทำอะไร |
|---|---|
| `text(parent, txt, cls, t, css='', {size, stagger, color})` | ข้อความ kinetic กว้างเต็ม 1080 จัดกลาง; `css` ใส่ `top:` |
| `kinetic(parent, txt, cls, t, {stagger, color})` | ข้อความ kinetic ใส่ลงใน element ใด ๆ (เช่นในการ์ด/ปุ่ม) |
| `div(css, parent, html='')` | สร้าง element `position:absolute` |
| `rise(el, t, d=.55, y=120)` | ลอยขึ้น + เอียง 3D + เบลอ → ชัด (spring) |
| `fadeOut(el, t, d=.18)` | เบลอหาย |
| `svg(w, h, inner, css, parent)` | ห่อ SVG; ใช้ `stroke="${BLUE}"` สำหรับสี accent |
| `draw(pathEl, t, d=.7)` | วาดเส้น SVG (trim path) |
| `cursor(parent, [[t,x,y],...], [clickT,...])` | เคอร์เซอร์เคลื่อนที่ + คลิก (ใช้เฉพาะฉาก CTA) |
| `ripple(parent, x, y, t, scale=2.6)` | วงคลื่นจากจุดคลิก |
| `A(el, keyframes, t, d, {e, f, it, dir})` | Web Animation แบบมีเวลาเริ่ม — `e` easing (`SPRING`/`SMOOTH`/`INOUT`), `f` fill (`'both'` ค่าเริ่ม, `'forwards'`, `'none'`) |
| `HOOKS.push(t => {...})` | โค้ดที่รันทุกเฟรม (เช่นวาด canvas อย่างลูกโลกจุด) — เช็กช่วงเวลาเองแล้ว `return` นอกช่วง |

คลาส CSS: `glass` (การ์ดกระจก), `chip` (ป้ายแคปซูล), `dot` (จุดเรืองแสง accent). ค่าสี: `BLUE` = accent ของแบรนด์.

## กับดักที่พบบ่อย

- **keyframe แรกต้องเป็นสถานะก่อนเริ่ม** — fill `'both'` ทำให้ element อยู่ในสถานะ keyframe แรกก่อนถึงเวลา (เช่น `opacity:0`).
  element ที่ไม่ได้ animate และไม่ได้ตั้ง `opacity:0` จะโผล่ตั้งแต่ต้นฉาก.
- **element ที่ใช้ fill `'none'`** ต้องมี `opacity:0` ใน CSS เอง ไม่งั้นค้างจอตลอดเวลานอกช่วง animation.
- **ป้าย chip ใน container แคบ** — ใส่ตำแหน่งให้มีที่พอ; chip ไม่ตัดบรรทัดแล้วแต่จะล้นการ์ดได้.
- **ข้อความไทย** — ส่งเป็นวลีเต็ม เอนจินแยก grapheme ให้เอง (สระ/วรรณยุกต์ไม่หลุด). อย่าตัดคำเองกลางคำ.
- **ภาษาอังกฤษ** — ใช้ได้ทันที (ฟอนต์ Mitr/Sriracha มีตัวละติน). คำอังกฤษยาวใน 'k' อาจถูกย่อ ให้ใส่ `size` เล็กลงเอง.
- **ฉากติดกัน** (ฉากหนึ่งจบ อีกฉากเริ่มทันที) ทำได้ — เฟดออก 0.2 วินาทีซ้อนกับเฟดเข้า.
