# คลังฉากเต็มจอ (มีโค้ดจริงใน `examples/timeline_example.js`)

**ฉากต้องทำใหม่ให้คลิปนั้น (ผู้ใช้สั่ง)** — S1–S10 คือฉากที่ออกแบบให้คลิปตัวอย่าง (โค้ดใน `examples/timeline_example.js`, ค้น `/* S1 ·` ถึง `/* S10 ·`):
ใช้ดูระดับงาน ภาษาภาพ และวิธีใช้ฟังก์ชัน **ไม่ใช่เทมเพลตให้คัดลอกแล้วเปลี่ยนคำ**. ทุกคลิปให้คิดใหม่ทีละประโยค:
(1) พูดถึงอะไร — ของ คน หรือการกระทำที่ถ้าปิดเสียงแล้วยังเข้าใจ (จากคำพูดของคลิปนี้) (2) อะไรเกิดตรงคำสำคัญ
(3) ประกอบจากชิ้นใน kit ในภาษาภาพเดิม (กระจกฝ้า ตัวอักษร 3D สี accent). เวลาภายในฉากให้ตรงกับ chunks.json.
ตารางด้านล่างคือตัวอย่างวิธีคิด — ดูว่าความหมายกลายเป็นภาพยังไง แล้วคิดภาพของคลิปใหม่เอง.

| ฉาก | ในตัวอย่าง | เหมาะกับประโยคแบบ | ปรับอะไร |
|---|---|---|---|
| **S1 การ์ดรีวิว** — การ์ดกระจก หัวข้อ chip + ตัวนับ "รีวิว n/3", แถวมีแถบวัดผลที่เติมไม่ถึงแล้วขึ้นกากบาท | ยังไม่เจ๋ง / ล้ำ / ดีพอ | รายการ 2–4 ข้อ, ข้อดี/ข้อเสีย, สิ่งที่ "ยังไม่ผ่าน" | ข้อความแถว, เวลาแต่ละแถว, ค่าแถบ, ชื่อการ์ด |
| **S2 การ์ดเวอร์ชันซ้อน** — วงลูปมีแสงวิ่ง + การ์ด v1/v2/v3 สไลด์ทับกัน | ดีกว่าเดิม ×3 | การทำซ้ำ, แก้แล้วแก้อีก, วนลูป, ขั้นตอนต่อเนื่อง | ชื่อการ์ด, คำในการ์ด, จำนวนการ์ด |
| **S3 statement + เส้น ∞** | ลูปนรก | ประโยคแรงที่เป็นวังวน/ไม่จบ | คำ, เปลี่ยนรูป path ได้ |
| **S4 ลูกโลกจุด 3D** — 900 จุดหมุนจริงบน canvas + จุดเมืองเรืองแสง | บริษัทระดับโลก | ระดับโลก, ตลาดใหญ่, ทั่วประเทศ | ข้อความ, chip "GLOBAL", ตำแหน่ง pins |
| **S5 มือถือ + กราฟ** — มือถือกระจก, เส้นกราฟไล่เฉด, chip "ตอนเริ่ม"/"ทุกวันนี้" | แอปดังทุกวันนี้ | แอป, แพลตฟอร์ม, การเติบโต, ก่อน/หลัง | ชื่อแอป (เป็นตัวอักษร ห้ามโลโก้จริง), ป้าย |
| **S6 statement + วงคลื่น** | เริ่มทำไปก่อน | ข้อความหลักของคลิป (ใช้ครั้งเดียว) | คำ |
| **S7 เส้นทางแสงวิ่ง** — ถนนประ + เส้นแสงวิ่ง + หลอดไฟในวงกลมกระจกตามจุด | ผุดขึ้นมาระหว่างทาง | การเดินทาง, กระบวนการ, ค้นพบระหว่างทาง, milestone | จำนวนจุด, ไอคอนในจุด |
| **S8 ไฟล์ที่ว่างเปล่า** — การ์ด script.txt บรรทัดหายจนเหลือ "ว่างเปล่า" | ไม่มีสคริปต์ | ไม่มีแผน, ทิ้งของเดิม, เริ่มจากศูนย์ | ชื่อไฟล์, ข้อความ |
| **S9 ปุ่ม CTA** — ปุ่มกระจกเรืองแสง เคอร์เซอร์คลิก วงคลื่น แล้วคำใหญ่ลง | เริ่มทำเลย | call to action, "ลงมือ", "กดติดตาม" (ใช้เคอร์เซอร์ได้ที่ฉากนี้ฉากเดียว) | คำบนปุ่ม, คำที่ลงตาม |
| **S10 ตอนจบ** — ไอคอนในวงกลมกระจก + statement ใหญ่ ค้างถึงจบคลิป | ไม่รู้ตัว | ประโยคปิด | คำ, ไอคอน, ให้ `t1` เกินความยาวคลิป |

แนวจังหวะ: ฉากละ 1.5–5 วินาที (ผู้ใช้สั่ง — ฉากสั้นทำให้ทุกอย่างขยับรีบ); ประโยคสั้นกว่านั้นใช้ซับบนหน้าแทน. ในฉาก: ชิ้นหลักขึ้น 0.7–0.9 วินาที,
การเคลื่อนไหวที่สื่อความหมาย 1 อย่างตรงคำสำคัญ 0.6–1.0 วินาที แล้วค้างนิ่ง. ตัวเลขเวลาในไฟล์ตัวอย่างบางจุดสั้นกว่านี้ — อย่าลอก. ระยะห่างระหว่างฉากควรมี A-roll อย่างน้อย
~1.5 วินาที ให้คนดูได้เห็นหน้าคนพูด ยกเว้นต่อกันเป็นเรื่องเดียว (เช่น statement ตามด้วยภาพอธิบาย).

## ออกแบบฉากใหม่

ถ้าไม่มีฉากไหนเข้ากับประโยค ให้สร้างใหม่ด้วยภาษาเดียวกัน: **องค์ประกอบหลัก 1 ชิ้น** (การ์ดกระจก/รูปทรงเส้น/UI) +
ข้อความ kinetic ด้านบนหรือล่าง + การเคลื่อนไหวที่สื่อความหมาย (เติม, วาด, ซ้อน, หมุน). ใช้เฉพาะสีจากแบรนด์ (`BLUE`, ขาว, ความโปร่งใส).
ห้ามใส่ของตกแต่งที่ไม่สื่ออะไร (บาร์โค้ด, ป้ายรหัสมั่ว, กลิตช์, อีโมจิ). preview ฉากใหม่อย่างน้อย 3 เวลา (ต้น, กลาง, ก่อนจบ).
