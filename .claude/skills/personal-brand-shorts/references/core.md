# Core — หัวใจของ skill นี้ (ผู้ใช้ยืนยันแล้ว ห้ามเปลี่ยนเองโดยไม่ถาม)

## ขั้นตอนฝั่งลูกค้า
- **ไม่ตัดช่วงเงียบ** และไม่ให้ลูกค้าตัดเองก่อนส่ง — ใช้คลิปตามที่ส่งมา.
- ลูกค้าส่งคลิป + บทพูดพร้อมเวลา แล้วสั่ง — ที่เหลือ Claude ทำบนคลาวด์. ห้ามเพิ่มขั้นตอนให้ลูกค้า (เหตุผลที่เวอร์ชันลบพื้นหลังถูกยกเลิก).

## วิธีเล่าเรื่อง
1. **ประโยคไหนพูดถึงอะไร ภาพกลายเป็นสิ่งนั้น** — ฉากเต็มจอที่เป็น "หน้าจอ/วัตถุ" ของประโยค (แชท, กระดาษโน้ต, หน้าจ่ายเงิน, เวลาที่ผ่านไป, รายการ).
   ระหว่างฉากเต็มจอ ไม่มีซับ — ฉากเล่าประโยคนั้นเอง.
2. **สลับกับหน้าคนพูดเสมอ** — ฉากเต็มจอสั้น (1–3 วินาที, ยาวสุด ~7), คนดูต้องได้เห็นหน้ากลับมาเป็นระยะ.
3. **คำเปลี่ยนเรื่อง = จังหวะตัด** ("แต่…", "เพราะฉะนั้น…") — ขึ้นจอพิมพ์คำนั้นสั้น ๆ แล้วเปิดกลับเข้าคลิป.
4. **รายการเหตุผล = บรรทัดไล่ทีละข้อ** พร้อมสัญลักษณ์นำหน้า; คำดี/คำร้ายแยกสีให้ชัด.
5. **ความสงสัย/ความคิด = กราฟิกเล็กข้างหัว** (เช่นเครื่องหมายคำถาม) — ไม่ทับหน้า.

## กล้อง
- **ซูมแบบเดียวกับ talking-head-motion ทุกอย่าง** (ผู้ใช้สั่ง): `zoom(t, scale, dur)` — วลีปกติ 1.04–1.06 ค่อย ๆ, คำเน้น 1.07–1.10 เร็ว,
  ไม่เกิน 1.14, กลับ 1.0 (.35) ตอนขึ้นประโยคใหม่; สูตร จุดศูนย์กลาง และการหายใจของกล้องเหมือนกันทุกตัวเลข (`zoom.md`). ไม่ใช้ครอป/ดันเข้า/ตัดกระแทกแบบ `push` แล้ว.

## ฉากที่ไม่ใช่หน้าคนพูด (ผู้ใช้สั่ง)
- **มินิมอลแบบมืออาชีพ** (ผู้ใช้ชอบทั้ง A และ B จึงผสมกัน): พื้นขาว · **คนและมือเป็นรูปทรงดำทึบแบบป้ายสัญลักษณ์** · **สิ่งของ การ์ด หน้าจอ
  เป็นเส้นบางสีดำ พื้นเทาอ่อน มุมมน เงานุ่ม** · เลขเล็กสีเทา, คำไทยตัวหนาสีดำ · **สีแดงจุดเดียว**. ไม่ใช้คนก้างปลา.
- **ออกแบบใหม่ทุกฉากให้ตรงกับประโยคนั้นของคลิปนั้น** — ไม่ใช้เทมเพลตเดียวเปลี่ยนคำ. ชุดเครื่องมือ: `assets/minimal_kit.js`
  (`paper`, `phase`, `svgLayer`, `label`, `pic`, `HAND`, `card`, `redQ`, `vanishingPerson`, `countUp`); ตัวอย่างฉาก: `examples/graphics_ink.js` — อ่านเป็นไอเดีย อย่าคัดลอกฉากไปใช้กับคลิปอื่น.

## จังหวะ (retention — ผู้ใช้สั่ง)
- **เปิดคลิปด้วยหน้าคนพูดเสมอ** (ผู้ใช้สั่ง): เฟรม 0 เป็นหน้าคนพูด + hook เป็นซับตัวใหญ่ใต้คางที่เห็นตั้งแต่เฟรม 0; ฉากที่ไม่ใช่หน้าฉากแรกมาหลัง ~1.5–2 วิ.
- ตัดต่อให้เข้ากับคนสมาธิสั้น แต่ไม่เร็วเกินไป: ไม่มีภาพนิ่งสนิทเกิน ~2 วิ, ฉากละ 2–4.5 วิ (หลายจังหวะในฉากเดียว), ซับเป็นวลีแบบคาราโอเกะ, ซูมเฉพาะคำเน้น; ไม่ใส่เสียงประกอบ ไม่มีแถบความคืบหน้า (`retention.md`).

## ซับ
- ขึ้นตามเสียงพูด ใต้คาง **ห้ามบังหน้า** (`text-and-placement.md`), ซ่อนระหว่างฉากเต็มจอ.

## กฎถาวร
- **หลบแถบขวา** (ปุ่มไลก์/ติดตาม/แชร์ของ TikTok/IG — ผู้ใช้สั่ง): ตัวหนังสือและกราฟิกทั้งหมดอยู่ในช่วง x 60–900 (เว้นขวา 180 px), ซับจัดกลางที่ x 480;
  ฉากเต็มจอวาดใน `safeStage()` (เนื้อหาถูกบีบเข้าช่วงปลอดภัยเอง). ตรวจด้วย contact sheet ที่ตีเส้นที่ x 900.
- ห้ามบังหน้า (ทุกกราฟิก ทุกซับ).
- ห้ามแต่งข้อเท็จจริง — ข้อความในฉากมาจากคำพูด; คำที่ต้องเติมให้สั้น ไม่มีตัวเลข/ราคา/ชื่อ และบอกผู้ใช้.
- ไม่ใช้โลโก้/หน้าตาแอปจริง.
- ไม่ปรับสีวิดีโอ (no color grading).
- ไม่ทำหน้าแอปโน้ต (ผู้ใช้ให้เอาออก).
