# Core — หัวใจของ skill นี้ (ผู้ใช้ยืนยันแล้ว ห้ามเปลี่ยนเองโดยไม่ถาม)

## ขั้นตอนฝั่งลูกค้า
- **ไม่ตัดช่วงเงียบ** และไม่ให้ลูกค้าตัดเองก่อนส่ง — ใช้คลิปตามที่ส่งมา.
- ลูกค้าส่งคลิป + บทพูดพร้อมเวลา แล้วสั่ง — ที่เหลือ Claude ทำบนคลาวด์. ห้ามเพิ่มขั้นตอนให้ลูกค้า (เหตุผลที่เวอร์ชันลบพื้นหลังถูกยกเลิก).

## วิธีเล่าเรื่อง
1. **ประโยคไหนพูดถึงอะไร ภาพกลายเป็นสิ่งนั้น** — ฉากเต็มจอที่เป็น "หน้าจอ/วัตถุ" ของประโยค (แชท, กระดาษโน้ต, หน้าจ่ายเงิน, เวลาที่ผ่านไป, รายการ).
   ระหว่างฉากเต็มจอ ไม่มีซับ — ฉากเล่าประโยคนั้นเอง.
2. **สลับกับหน้าคนพูดเสมอ** — ฉากเต็มจอสั้น (1–3 วินาที, ยาวสุด ~7), คนดูต้องได้เห็นหน้ากลับมาเป็นระยะ.
3. **คำเปลี่ยนเรื่อง = จังหวะตัด** ("แต่…", "เพราะฉะนั้น…") — ขึ้นจอพิมพ์คำนั้นสั้น ๆ แล้วเปิดกลับเข้าคลิป.
4. **รายการเหตุผล = บรรทัดไล่ทีละข้อ** พร้อมสัญลักษณ์นำหน้า; คำดี/คำร้ายแยกสีให้ชัด.
5. **ความสงสัย/ความคิด = กราฟิกเล็กข้างหัว** (เช่นเครื่องหมายคำถาม) — ไม่ทับหน้า.

## กล้อง
- ครอปเข้าหาหน้า (~1.2–1.3×) แล้ว **ดันเข้าช้า ๆ ตลอดประโยค**, **ตัดกระแทก** (~1.4×) ตอนขึ้นประโยคใหม่/คำเน้น — `push(t0, t1, from, to)`.
- สูตรซูมพื้นฐาน + การหายใจของกล้อง = talking-head-motion (`zoom.md`).

## ซับ
- ขึ้นตามเสียงพูด ใต้คาง **ห้ามบังหน้า** (`text-and-placement.md`), ซ่อนระหว่างฉากเต็มจอ.

## กฎถาวร
- ห้ามบังหน้า (ทุกกราฟิก ทุกซับ).
- ห้ามแต่งข้อเท็จจริง — ข้อความในฉากมาจากคำพูด; คำที่ต้องเติมให้สั้น ไม่มีตัวเลข/ราคา/ชื่อ และบอกผู้ใช้.
- ไม่ใช้โลโก้/หน้าตาแอปจริง.
- ไม่ปรับสีวิดีโอ (no color grading).
- ไม่ทำหน้าแอปโน้ต (ผู้ใช้ให้เอาออก).
