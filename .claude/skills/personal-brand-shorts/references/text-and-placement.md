# ตัวอักษร และตำแหน่งซับ

## 1. ตัวอักษร — สไตล์เดียวกับ talking-head-motion

ใช้ชุดเดียวกับ talking-head-motion ทุกค่า ยกเว้นสีคำสำคัญ = ม่วงเข้ม `#5B2A86` (แทนฟ้าอ่อน) พร้อมขอบเรืองสีขาวให้อ่านออกบนคลิปมืด (`assets/engine_head.html` ส่วน typography + `kinetic()`).

| ชั้น | ฟอนต์ | ขนาด | สี | ใช้ |
|---|---|---|---|---|
| คำสำคัญ `k` | Mitr Bold | 136 (statement 150–250) | ม่วงเข้ม `#5B2A86` + ขอบเรืองสีขาว | 1–2 คำต่อประโยค |
| เนื้อหา `m` | Mitr SemiBold | 90 | ขาว | วลีเนื้อหา |
| คำเชื่อม `s` | Sriracha | 60 | ขาว | คำเชื่อม/คำนำ |

Motion: แยก grapheme (สระ/วรรณยุกต์ไทยไม่หลุด) พลิก rotateX 60–85° + เบลอ 10px → ชัด, spring, ไล่ทีละตัว 16 ms (คำสำคัญ 32 ms),
คำสำคัญขึ้นเป็นสีขาวแล้วเปลี่ยนเป็นม่วงเข้มใน 0.35 วินาที; จบก้อนเบลอลอยขึ้น 0.16 วินาที. เงาดำใต้ตัวอักษรช่วยให้อ่านออกบนทุกฉากหลัง.

```js
block({t0, t1, lines: [
  [['เวลาเรา', 's', 0.05], ['มีไอเดีย', 'k', 0.47]],   // หนึ่งบรรทัด = หลายวลีต่อกัน
  [['เริ่มทำธุรกิจ', 'm', 1.36, 120]],                   // [ข้อความ, สไตล์, เวลาขึ้น, ขนาด px (ไม่ใส่ก็ได้)]
]});
```
- เวลาขึ้นของแต่ละวลีมาจากบทพูดพร้อมเวลา — ตัวอักษรต้องตรงจังหวะพูด.
- ก้อนเบลอหายเองที่ `t1` → ตั้ง `t1` = เวลาวลีถัดไปเริ่ม − 0.02.
- ส่งข้อความเป็นวลีเต็ม อย่าตัดกลางคำเอง; ตัดคำลงท้ายอย่าง "อ่ะ / น่ะ / เว้ย" ได้เพื่อให้อ่านสะอาด (บอกผู้ใช้ว่าทำ).

## 2. ตำแหน่งซับ — ห้ามบังหน้า (กฎเด็ดขาด)

**ค่าเริ่ม = ตำแหน่งเดียวกับ talking-head-motion:** โซนใต้หน้า y 1225–1665 (กว้าง ≤ 960, สูง ≤ 440), เว้นล่าง ~255 px และขวา 140 px ให้ปุ่มของแพลตฟอร์ม.
**ปรับตามคลิปได้** — แต่ละคนนั่ง/ยืนไม่เท่ากัน จึงต้องวัดหน้าจากคลิปจริงทุกครั้ง:

1. ดู contact sheet ของคลิป (เฟรมทุก ~2 วินาที) หาแถบ y ของ **ศีรษะ: จากผมบนสุดถึงคาง** (เผื่อ ~30 px) ในช่วงที่คนพูดขยับมากที่สุด.
2. ประกาศใน timeline ก่อน `block()` ทุกตัว:
   ```js
   face(330, 1080);              // ทั้งคลิป
   face(420, 1180, 12.0, 20.5);  // ช่วงที่โน้มตัวเข้ากล้อง/ขยับลง — ประกาศเพิ่มเป็นช่วงเวลาได้
   ```
3. `block()` ที่ไม่ได้ใส่ `top` จะถูกวางให้อัตโนมัติ: เริ่มที่ 1225 หรือใต้คาง + 40 px (เอาค่าที่ต่ำกว่า)
   และย่อให้พอดีพื้นที่ที่เหลือถึง y 1665.
4. ใส่ `top` เองได้ (เช่นหน้าอยู่ต่ำมาก ให้ซับไปอยู่เหนือหัว) — เอนจินยังตรวจการทับหน้าเหมือนเดิม.

เอนจินตรวจทุกก้อนตอนเฟรมแรก: ถ้าก้อนไหนทับแถบหน้า หรือถูกย่อเหลือ < 60% เพื่อหนีหน้า จะพิมพ์ `FACE: …` เป็น error
→ **ห้ามส่งงานที่มี FACE error** แก้โดยแยกก้อนเป็นสองก้อน ลดข้อความ หรือย้าย `top`.
`center: true` (กลางจอ 760) ใช้ได้เฉพาะช่วงที่ไม่มีหน้าคนบนจอ (ไม่มี `face()` ครอบช่วงนั้น).

ตรวจด้วยตาอีกรอบเสมอ: preview อย่างน้อย 1 เฟรมต่อก้อนข้อความ แล้วดูว่าตัวอักษรไม่แตะหน้า คาง หรือมือที่ยกขึ้นมาหน้าหน้า.
