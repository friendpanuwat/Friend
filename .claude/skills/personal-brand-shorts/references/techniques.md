# เล่าเรื่องด้วยหน้าจอมือถือ (ชุดเก่า)

> **สไตล์หลักตอนนี้คือ overlay → `overlays.md`.** ตาม `core.md` ไม่ใช้ฉากเต็มจอ และไม่ใช้หน้าแอปโน้ต. ฟังก์ชันในไฟล์นี้ยังอยู่ใน engine แต่ยังไม่ได้ลบ.

แนวคิด: ประโยคไหนพูดถึงอะไร ให้ภาพกลายเป็น "หน้าจอ" ของสิ่งนั้น (แชท, กระดาษโน้ต, หน้าชำระเงิน) หรือแปะ UI ทับคลิป.
เลือกจาก **ความหมายของประโยค** — ไม่ต้องใช้ทุกเทคนิคในคลิปเดียว และเว้นช่วงหน้าคนพูดปกติให้คนดูเห็นหน้าเสมอ.
เวลาทั้งหมดเป็นวินาทีของคลิป (จาก chunks.json).

## เลเยอร์ (ล่าง → บน)

คลิป (+ ซูม) → `Q` UI ที่แปะทับคลิป (? รอบหัว) → `S` ฉากเต็มจอ (แชท, บอร์ด, ชำระเงิน, จอดำ) → ตัวอักษร (บนสุด).
ช่วงที่มีฉากเต็มจอ ก้อนซับที่เริ่มในช่วงนั้นจะถูกซ่อนเอง — ฉากเล่าประโยคนั้นแทน.

## เทคนิค

| เทคนิค | เรียก | เหมาะกับ |
|---|---|---|
| **หน้าแชท** — ข้อความเด้งทีละอัน + "อ่านแล้ว" | `chat(t0, t1, {name, msgs: [{from: 'them'\|'me', text, t}], read})` | ลูกค้าทัก/ถาม/เงียบ, บทสนทนา |
| **ซับบนแถบสี** — แถบสีหลักกวาดเข้า | `block({..., bar: true})` | ประโยคความคิด/ความกังวล (ใช้ไม่บ่อย) |
| **? รอบหัว** — เครื่องหมายคำถามเด้งข้างหัว | `qMarks(t0, t1)` | สงสัย, คิดไปเอง, "หรือเปล่า" |
| **จอดำพิมพ์ → วงกลมเปิด** | `blackType(t0, t1, 'แต่จริง ๆ แล้ว…')` | คำเปลี่ยนเรื่อง: แต่…, เพราะฉะนั้น…, สรุปคือ… |
| **ไอคอนเด้งเหนือหัว** → เข้าฉากถัดไปแบบ whip | `iconPop(t, {icon: 'wallet'\|'question'\|'chat'})` | ก่อนฉากเต็มจอ (ฉากถัดไปใช้ `enter: 'whip'`) |
| **กระดาษโน้ตปักบอร์ด** | `stickyBoard(t0, t1, {title, notes: [['ข้อความ', t], ...]})` | รายการ 2–3 อย่างที่เป็นสิ่งของ/การกระทำ |
| **หน้าชำระเงิน** — นิ้วเข้าใกล้ปุ่มแล้วถอย | `payment(t0, t1, {hover: [tIn, tOut], thought: ['…', t]})` | ไม่กล้าจ่าย, ลังเลก่อนซื้อ |
| **รายการ ◇** — ไล่ทีละบรรทัด คำดี/คำร้าย | `bullets(t0, t1, [{text, t, key, tone: 'good'\|'bad', tk}])` | เหตุผลหลายข้อ, ทำ/ไม่ทำ |

`bullets`: `key` = คำในบรรทัดที่เน้น (สไตล์คำสำคัญสีม่วง), `tone: 'bad'` = ขีดฆ่าคำนั้นที่เวลา `tk`, `tone: 'good'` = เติมสีใน ◇.
วางในโซนซับและหลบหน้าตามกฎเดียวกับ `block()`.

## กฎ

- **ห้ามบังหน้า** — UI ที่แปะทับคลิป (`Q`) อยู่ขอบจอ/เหนือหัว; ฉากเต็มจอไม่มีหน้าให้บัง.
- **สีทั้งหมดมาจากสีฟอนต์** (`TEXT` ขาว, `BLUE` ม่วง) และเฉดที่ผสมจากสองสีนี้: `KEY_LIGHT`, `KEY_SOFT`, `KEY_PAGE`, `KEY_DARK`, `INK`. ดำใช้เฉพาะเงา.
- **หน้าแอปแบบทั่วไป** — ไม่เลียนแบบแอปจริง ไม่ใส่โลโก้.
- **ห้ามแต่งข้อเท็จจริง** — ข้อความในแชท/โน้ต/ป้าย มาจากคำพูดในคลิป; คำที่ต้องแต่งเพิ่มให้สั้นและไม่มีตัวเลข/ราคา/ชื่อ แล้วบอกผู้ใช้ตอนส่งงาน.
- ตัวอักษรและการซูมเป็นแบบ talking-head-motion (`text-and-placement.md`, `zoom.md`).
