# 17 เทคนิค — ใช้ตามความเหมาะสม

**คลิปหนึ่งไม่ต้องใช้ทุกเทคนิค.** เลือกจากความหมายของประโยค ไม่ใช่ความสวย — ถามตัวเองว่า "ถ้าปิดเสียง เทคนิคนี้ยังช่วยเล่าประโยคนี้ไหม".
แนว: คลิป ~40–60 วินาที ใช้ 4–7 เทคนิค, เทคนิคละ 1.5–3 วินาที, เว้นช่วงหน้าคนพูดปกติอย่างน้อย ~2 วินาทีระหว่างเทคนิค,
ไม่ใช้เทคนิคเดียวซ้ำเกิน 2 ครั้ง. เวลาทั้งหมดเป็นวินาทีของคลิป (จาก chunks.json).

## เลเยอร์ (ล่าง → บน)

| ชั้น | อะไร |
|---|---|
| page (`#page`, `P`) | หลังวิดีโอทั้งหมด — สีพื้นหน้าแอป หรือคลิปเดียวกันแบบเบลอ (เห็นเมื่อวิดีโอถูกย่อ) |
| stage (`#stage`) | "กล้อง" — ห่อคลิปทั้ง 2 เลเยอร์ + กราฟิก B/F; ซูม/ย่อ/เลื่อนผ่านตัวนี้ → **2 คลิปขยับเท่ากันเสมอ** |
| 1 คลิปต้นฉบับ | อาจถูกครอปเป็นการ์ด (frame break, ui world, pull-back) หรือซ่อน (green screen) |
| `B` | กราฟิก **หลังตัวคน** — ทับตรงหัวได้ เพราะตัวคนอยู่บน |
| 2 คลิปลบพื้นหลัง | ตัวคน |
| `F` | กราฟิก **หน้าตัวคน** — ห้ามทับหน้า |
| `W` | UI ทับวิดีโอที่ถูกย่อ (หน้าต่าง, ช่องพิมพ์) — ห้ามทับหน้า |
| ซับ | บนสุดเสมอ |

ทุกเทคนิคเรียกใน `timeline.js` หลัง `face()`/`clip()` — ตำแหน่งเริ่มต้นคิดจากแถบหน้า (`face()`) ให้แล้ว.
**ห้ามแต่งข้อเท็จจริง:** ข้อความในการ์ด/ป้าย/รายการมาจากคำพูดในคลิปหรือผู้ใช้เท่านั้น; ไม่ใช้โลโก้แบรนด์จริง (พิมพ์เป็นตัวอักษรได้).

## ตาราง

| # | เทคนิค | เรียก | เหมาะกับประโยคแบบ |
|---|---|---|---|
| 01 | **orbit** — การ์ดหมุนรอบตัว ครึ่งหลังผ่านหลังตัวคน | `orbit(t0, t1, [{still: 5}, {img: 'a.jpg'}, 'ข้อความ', ...], {turns: .5})` | หลายสิ่งรอบตัว: ผลงาน, ช่องทาง, ไอเดีย, ลูกค้าหลายแบบ |
| 02 | **couch wall** — พื้นหลังกลายเป็นผนังภาพ (ภาพนิ่งจากคลิปเอง/รูปผู้ใช้) | `couchWall(t0, t1, {tiles?})` | ปริมาณเยอะ: "ทำคลิปมาเป็นร้อย", portfolio, ประสบการณ์ |
| 03 | **ui world** — วิดีโอลงไปครึ่งล่างของหน้าแอปสว่าง หัวทะลุขึ้นมา + ช่องพิมพ์พิมพ์ประโยค | `uiWorld(t0, t1, {prompt: '…'})` | สั่ง/ถาม/ค้นหา, พูดถึงเครื่องมือ/แอป |
| 04 | **frame break** — วิดีโอย่อเป็นการ์ดบนพื้นเบลอ ตัวคนทะลุกรอบออกมา | `frameBreak(t0, t1, {s: .8, inset?: [top,right,bottom,left]})` | ก้าวข้าม/หลุดกรอบ/คิดนอกกรอบ, จุดเปลี่ยน |
| 05 | **digital zoom** — ซูมกระแทกเข้าหน้า ค้าง แล้วออก | `digitalZoom(t0, t1, {z: 1.3})` | คำเน้น, punchline, "เฮ้ย!" (สั้น 0.5–1.5 วิ) |
| 06 | **phone mockup** — มือถือสไลด์เข้าข้างตัว (หลังตัวคน) แสดงหน้าจอแอปเรียบ ๆ | `phoneMockup(t0, t1, {title, rows: [...], button, tap, side})` | แชท/แอป/ลูกค้าทัก/สั่งซื้อ |
| 07 | **checklist** — การ์ดกระจกมืด ติ๊กทีละข้อตามคำพูด | `checklist(t0, t1, [['ข้อ 1', tTick], ...], {title, x, y})` | รายการ 2–4 ข้อ, ขั้นตอน, สาเหตุ |
| 08 | **headline wall** — กระดาษพาดหัว/ป้ายแคปซูล/โน้ต ปั๊มขึ้นรอบตัว (หลังตัวคน) | `headlineWall(t0, t1, ['…', {text, kind: 'paper'|'pill'|'quote', at: [x,y,rot]}])` | เสียงคนรอบข้าง, คำถามที่เจอบ่อย, ความคิดที่วนในหัว |
| 09 | **zoom-through cut** — พุ่งทะลุเฟรมที่เวลา t (เบลอเข้า-ออก) | `zoomThrough(t, {x, y})` | ขึ้นหัวข้อใหม่, "แต่…", เปลี่ยนเรื่อง (ใช้เป็นจุดเชื่อม) |
| 10 | **chart grow** — กราฟเส้นวาดตัวเองหลังตัวคน ช่วงพุ่งขึ้นเรืองแสง | `chartGrow(t0, t1, {pts?, label})` | โต/เพิ่มขึ้น/ยอดขาย/ผลลัพธ์ (ใช้ตัวเลขที่ผู้พูดพูดเท่านั้น) |
| 11 | **pull-back reveal** — ถอยกล้อง: คลิปอยู่ในหน้าต่างแอป มีแถบ render + รายการขั้นตอน | `pullBack(t0, t1, {title, panel, steps: [['…', t]], file})` | เบื้องหลัง, "ทั้งหมดนี้ทำด้วย…", กระบวนการ |
| 12 | **green screen** — ห้องหายไป ยืนหน้าจอใหญ่ที่เล่นคลิปตัวเอง | `greenScreen(t0, t1, {bg, screen?: {img}})` | นำเสนอ, ย้อนดูตัวเอง, "ลองดูนี่" |
| 13 | **paper cut** — คอลลาจกระดาษ: ตัวอักษรตัดแปะ, ขอบสติกเกอร์ขาวรอบตัวคน | `paperCut(t0, t1, {words: ['คำ', 'คำ']})` | คำสำคัญคำเดียว/สองคำ, หัวข้อ, ประโยคเปิด |
| 14 | **doodle boil** — เส้นวาดมือรอบตัวคนสั่นไหว + ดูเดิลข้างหัว | `doodleBoil(t0, t1, {doodles: [{type: 'heart'|'sparkle'|'star'|'swirl'|'arrow', x, y, size}]})` | อารมณ์/ความรู้สึก, ชอบ/รัก, ไอเดียผุด |
| 15 | **vertigo** — ซูมเข้าช้า ๆ ทั้งภาพ แล้วกลับเร็ว | `vertigo(t0, t1, {z: 1.35})` | ตระหนักรู้, ช็อก, ความตึงเครียด |
| 16 | **cover story** — ปกนิตยสาร: ชื่อตัวใหญ่ serif หลังหัว + ตัวเล็ก + tagline ตัวเอียง | `coverStory(t0, t1, {title, left: [], right: [], kicker, tagline, taglineY})` | เปิดหัวข้อ, แนะนำตัว, "เรื่องเด่น" |
| 17 | **glass type** — ตัวอักษรกระจกใหญ่หลังหัว เห็นห้องเบลอผ่านตัวอักษร | `glassType(t0, t1, {text, size})` | คำเดียวที่เป็นแก่นของคลิป (สั้น ≤ 6 ตัวอักษร) |

## ข้อควรระวัง

- **ซับกับเทคนิคที่ย้ายตัวคน** (ui world, frame break, pull-back, green screen, digital zoom, vertigo): ก้อนซับที่คร่อมจังหวะเข้า/ออกของเทคนิค
  จะไม่มีที่วางที่ไม่ทับหน้า (`FACE:` error) → **ตัดก้อนซับที่ t0 และ t1 ของเทคนิค**. ระหว่าง ui world/green screen ซับจะย้ายไปเหนือหัวเองถ้าใต้คางไม่มีที่.
- `cover story` tagline อยู่ชั้นหน้า (`F`) ที่ `taglineY` — อย่าให้ทับก้อนซับช่วงเดียวกัน (ย้าย taglineY หรือเว้นซับช่วงนั้น).
- เทคนิคที่ซ้อนกันในเวลาเดียวกัน: ใช้ได้เฉพาะคู่ที่ไม่ยุ่งชั้นเดียวกัน (เช่น checklist + digital zoom). อย่าซ้อน 2 เทคนิคที่ย้ายวิดีโอ.
- ข้อความในเทคนิคใช้ฟอนต์ของ skill: Mitr (หัว/เนื้อ), Sriracha (ลายมือ), Taviraj (serif ไทย+อังกฤษ — cover story, กระดาษพาดหัว).
- สีกราฟิก: ขาว, ม่วงแบรนด์ `BLUE` (#5B2A86) บนพื้นสว่าง/ปุ่ม, `BRAND_LIGHT` (#CDB8F0) สำหรับเส้น/แสงบนพื้นมืด. paper cut ใช้สีกระดาษหลายสีได้ (เป็นสไตล์คอลลาจ).
- preview อย่างน้อย 2 เวลาต่อเทคนิค (กลาง + ใกล้จบ) และดูว่า: หน้าไม่ถูกบัง, ข้อความไม่ล้นจอ, ไม่มีอะไรค้างหลัง t1.
