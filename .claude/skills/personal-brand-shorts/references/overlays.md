# Overlay motion graphics — สไตล์หลัก

กราฟิกวางทับคลิป หน้าคนพูดอยู่บนจอตลอด (`core.md`). Claude ออกแบบกราฟิกตามเนื้อหาของแต่ละประโยค
ตัวอย่างเต็มของคลิปทดสอบ 42 วินาทีอยู่ที่ `examples/timeline_example.js`.
โค้ดทั้งหมดอยู่ใน `assets/engine_head.html` ส่วน OVERLAY MOTION GRAPHICS.

## โซน

| โซน | ตำแหน่ง | ใช้กับ |
|---|---|---|
| **แถบบนเหนือหัว** | y ~180–440 (`TOPY` = 180) — พื้นที่ว่างมาก ใช้ให้เต็มที่ | สิ่งที่ประโยคพูดถึง เช่น แชท ป้ายราคา ไอคอน คน สวิตช์ หมุด |
| **ข้างหัวฝั่งซ้าย / เหนือหัว** | ใช้ `qChips` กำหนดจุดเอง | ความสงสัยเล็ก ๆ (?) |
| **ใต้คาง** | วางอัตโนมัติใต้แถบหน้า (`face()`) | ซับ ปุ่ม รายการ คำใหญ่ เส้นทางขั้นตอน |

**หลบแถบขวา:** ทุกอย่างอยู่ในช่วง x 60–900 (`SAFE`) เพราะ 180 px ทางขวาเป็นที่ของปุ่มไลก์/ติดตาม/แชร์ของ TikTok/IG. ซับจัดกึ่งกลางที่ x 480.
ห้ามวางของที่ x > 900. ถ้ากำหนดตำแหน่งเอง (`qChips`) ให้ x ≤ 790.
กราฟิกแถบบนต้องจบไม่เกิน y ~440 เพราะตอนซูมแรงสุด (~1.44×) หัวจะขึ้นมาถึงประมาณ y 470. ต้อง preview ดูทุกครั้ง.

**คลิปที่ไม่มีที่ว่างเหนือหัว** (หัวชิดขอบบน): ใส่ `band('chest')` ไว้ต้น timeline. กราฟิกแถบบนทุกตัวจะย้ายลงมาที่อก ใต้คาง (เริ่ม y 940 หรือใต้คาง + 40) และซับอยู่ใต้กราฟิก (เริ่ม y 1235).
ถ้ากราฟิกยาวลงไปชนซับ เอนจินจะขึ้น error `band …`. คลิปแบบนี้ให้ซูมเบาลง (1.08–1.24) เพื่อไม่ให้หัวหลุดขอบบน.

## ซับ (สไตล์ overlay)

- `ocap(t0, t1, 'ข้อความ', {keys: {'คำ': OV.red}, size})`
- ฟอนต์ Anuphan ตัวบาง สีขาว พิมพ์ทีละตัวพร้อมเบลอเล็กน้อย
- คำสำคัญใส่สี (`OV.red` = คำร้าย, `OV.green` = คำดี) พร้อมแสงเรือง
- วางใต้คาง ไม่บังหน้า และย่อให้พอดีความกว้าง 840
- ประโยคที่กราฟิกใต้คางบอกอยู่แล้ว (`uChips`, `olist`, `uButtons`, `uStretch`, `uStrike`, `uSteps`) ไม่ต้องมี `ocap` ซ้ำ

## กราฟิก

| ฟังก์ชัน | โซน | ภาพ | เหมาะกับ |
|---|---|---|---|
| `tChat(t0, t1, {text, from: 'them'\|'me', read, typing: [a, b], gone})` | บน | ข้อความแชทเด้งลงมา มีอ่านแล้ว / กำลังพิมพ์ แล้วแตกเป็นจุด | ลูกค้าทัก เงียบ หายไป |
| `tTag(t0, t1, {label})` | บน | ป้ายราคาห้อยเชือกลงมาแกว่ง | แพงไหม ราคา |
| `qChips(t0, t1, [[x, y, t], ...])` | บน / ข้างหัว | ? ลอยขึ้นมาเป็นจุด ๆ | สงสัย มีคำถามในใจ |
| `tIcons(t0, t1, [[icon, สี, t], ...], {label})` | บน | ไอคอนติดสีทีละอัน | เหตุผลหลายข้อ (ใช้คู่กับ `uChips`) |
| `tShop(t0, t1)` | บน | ร้านค้าเด้งขึ้น | เจ้าของธุรกิจ ร้าน |
| `tPeople(t0, t1, {n, fade})` | บน | คนค่อย ๆ จางไป + ลูกศรลง | ลูกค้าน้อยลง |
| `tToggle(t0, t1, {tOff, label})` | บน | สวิตช์เปิดแล้วปิด | เงียบ หยุด ปิด |
| `tAnswer(t0, t1, {tCheck})` | บน | กล่อง ? เปลี่ยนเป็น ✓ สีเขียว | คำตอบ ทางออก |
| `tDown(t0, t1)` | บน | ป้ายราคามีลูกศรแดงไหลลง | ลดราคา ลดลง |
| `tDoubts(t0, t1, [t, t, t], {label})` | บน | คน 3 คน มี ? ขึ้นทีละคน | ข้อสงสัยของแต่ละคน |
| `tPin(t, t1)` | บน | หมุดปักลงเป้า | ตรงจุด ถูกที่ |
| `tWage(t0, t1, {tStop, from, to, stop})` | บน | นาฬิกาเดิน เหรียญไหลเข้ากระเป๋าเงิน แล้วหยุดที่ `tStop` | เอาเวลาแลกเงิน, รายได้หยุด |
| `tCalendar(t0, t1, {head})` | บน | ปฏิทินมี ? | กี่เดือน กี่วัน นานแค่ไหน |
| `tLife(t0, t1, {tEnd, from, to, money})` | บน | แถบเงินเต็มตลอด ขณะที่จุดเวลาวิ่งจากต้นถึงปลาย | อยู่ได้ถึง… ไม่หมด |
| `uStretch(t0, t1, 'คำ')` | ใต้คาง | คำใหญ่ยืดเด้ง มีเงาเส้นซ้อน | คำเปลี่ยนเรื่อง: แต่…, เพราะฉะนั้น… |
| `uChips(t0, t1, [['ข้อความ', t], ...], {style: 'white'\|'outline'})` | ใต้คาง | ป้ายข้อความหล่นลงมาเรียงกัน | เหตุผล / ข้อสงสัยหลายข้อ |
| `olist(t0, t1, [{text, t, keys, mark: 'x'\|'check'}])` | ใต้คาง | รายการ ✕ / ✓ | ไม่ใช่… แต่คือ… |
| `uButtons(t0, t1, [['ป้าย', สี, tClick], ...])` | ใต้คาง | เคอร์เซอร์กดปุ่มทีละปุ่ม | รีบทำ… รีบ… (การกระทำ) |
| `uPay(t0, t1, {label})` | ใต้คาง | ปุ่มจ่ายเงินเรืองแสง เคอร์เซอร์วนแต่ไม่กด | ไม่กล้าจ่าย ลังเล |
| `uStrike(t0, t1, {pre, word, tStrike})` | ใต้คาง | คำใหญ่โดนขีดฆ่าสีแดง | ไม่ใช่การ… |
| `uSteps(t0, t1, [['ป้าย', t], ...])` | ใต้คาง | เส้นวิ่งผ่านจุดขั้นตอน จุดสุดท้ายสีเขียว | ขั้นตอน วิธีทำ |
| `uWin(t0, t1, 'คำ', {sub, tSub})` | ใต้คาง | คำใหญ่สีเขียวเรือง + ✓ และบรรทัดเล็กพิมพ์ตามมา | ประโยคปิด / คำตอบสุดท้าย |

ไอคอนที่ใช้ได้ (`sym`): `chat scale shield cart moon tag megaphone x check q`.
สี (`OV`): `ink blue green red orange`. แสงเรืองใช้เฉพาะสิ่งที่สำคัญที่สุดในจังหวะนั้น.

## วิธีเลือก

1. อ่านบทพูดทีละประโยค แล้วถามว่า "ประโยคนี้พูดถึงสิ่งไหน" แล้วเลือกกราฟิกที่เล่าสิ่งนั้น.
2. ใส่กราฟิกแถบบนในแทบทุกช่วง และใส่ของใต้คางหรือซับควบคู่กัน. หนึ่งจังหวะควรมีหนึ่งไอเดีย.
3. เวลาเข้าและออกของทุกกราฟิกต้องตรงกับคำพูด (จาก chunks.json). จุดเปลี่ยนในกราฟิก (`read`, `tOff`, `tCheck`, `tStrike`, เวลากด) ต้องตรงกับคำที่พูด.
4. ข้อความในกราฟิกต้องมาจากคำพูด ถ้าต้องเติมคำเอง ให้สั้น ไม่มีตัวเลข ราคา หรือชื่อ และต้องบอกผู้ใช้ตอนส่งงาน.
5. ถ้าต้องการภาพที่ยังไม่มีในตาราง ให้ออกแบบใหม่ด้วยภาษาภาพเดียวกัน แล้ววางในโซนเดียวกันและหลบแถบขวา.
