# Overlay motion graphics — ออกแบบใหม่ทุกคลิป

กราฟิกวางทับคลิป หน้าคนพูดอยู่บนจอตลอด (`core.md`).
**ไม่มีเมนูกราฟิกสำเร็จรูป.** ทุกคลิปต้องได้กราฟิกที่คิดขึ้นใหม่จากสิ่งที่คลิปนั้นพูดจริง ๆ.
ถ้าสองคลิปได้กราฟิกหน้าตาเดียวกัน แค่เปลี่ยนคำ ถือว่าผิด skill. ลูกค้าจ่ายเงินเพื่อให้ได้กราฟิกที่ทำมาเพื่อคลิปของเขา.

## สิ่งที่มีให้ใช้

| ชั้น | อยู่ที่ | ใช้ซ้ำได้ไหม |
|---|---|---|
| เอนจิน: กล้อง, กันบังหน้า, โซนวาง, ซับ `ocap` | `assets/engine_head.html` | ใช้ได้ทุกคลิป |
| ชิ้นส่วนการเคลื่อนไหว (primitives) | `assets/engine_head.html` ส่วน MOTION PRIMITIVES | ใช้ได้ทุกคลิป เป็นอิฐที่ใช้ก่อเป็นกราฟิก |
| กราฟิกของแต่ละคลิป | `$P/graphics.js` ซึ่งเขียนใหม่ทุกคลิป | **ห้ามคัดลอกข้ามคลิป** |
| ตัวอย่าง | `examples/NN-ชื่อ/graphics.js` + `timeline.js` | ใช้อ่านเป็นไอเดียและดูระดับความละเอียดที่ต้องการ ห้ามเอาไปใช้ตรง ๆ |

ไฟล์ `scene.html` ประกอบจาก `engine_head.html` + `graphics.js` + `timeline.js` + `engine_tail.html`.

### Primitives

| เรียก | ทำอะไร |
|---|---|
| `topBand(t0, t1, css, html, sc)` | กล่องเต็มความกว้างปลอดภัย (840) ในแถบกราฟิก (เหนือหัว หรือที่อก ถ้าใช้ `band('chest')`) |
| `lower(t0, t1, css)` | กล่องใต้คาง สำหรับกราฟิกที่ใช้แทนซับ วางอัตโนมัติไม่ให้บังหน้า |
| `pop(el, t, {from, y, rot})` | เด้งเข้าแบบ spring |
| `drawOn(path, t, d)` | วาดเส้น SVG ออกมา |
| `floatY` / `sway` | ลอยขึ้นลง / แกว่ง ตลอดช่วงที่อยู่บนจอ |
| `shake(el, t)` | สั่นตอนกระแทก |
| `burst(parent, x, y, t, {...})` | อนุภาคกระจายออก (ระวังอย่าให้พุ่งขึ้นไปทับหน้า ใช้ `up` เป็นค่าลบ) |
| `shine(el, t)` | แสงกวาดผ่าน ใช้กับการ์ดหรือกล่องเท่านั้น ห้ามใช้กับตัวหนังสือ |
| `flipText(el, [[text, t], ...])` | ป้ายพลิกแผ่น เปลี่ยนข้อความตามเวลา |
| `loop(el, kf, t0, t1, per)` | เล่นซ้ำเป็นรอบ เช่น ของตก ของไหล เข็มติ๊ก |
| `A(el, keyframes, t, d, {e, f, it, dir})` | แอนิเมชันพื้นฐาน |
| `typeIn`, `segments`, `sym`, `svg`, `div`, `chip` | ตัวหนังสือ ไอคอนเส้น SVG และ div |
| สี `OV` (`ink blue green red orange`), `BOLD`, `GL` (การ์ดกระจกมืด), `WHITE_CARD`, `SHADOW`, `glow(c)` | สไตล์ |

## วิธีออกแบบกราฟิกของคลิป

1. **หาโลกของเรื่อง.** อ่านบททั้งคลิป แล้วถามว่าเรื่องนี้อยู่ในโลกไหน: เงิน, ร้านค้า, ความรัก, สุขภาพ, งาน ฯลฯ
   จดของจริงในโลกนั้นที่ใช้เล่าได้ เช่น โลกของเงิน: สลิปเงินเดือน นาฬิกาทราย ก๊อกน้ำ แบตเตอรี่ ถังน้ำมัน มงกุฎ
2. **หนึ่งประโยค = หนึ่งภาพ.** สำหรับแต่ละจังหวะ เลือกของหนึ่งชิ้นที่ "แสดง" ความหมายของประโยค (ไม่ใช่แค่เอาคำมาวาง)
   แล้วคิดว่าของชิ้นนั้นต้องทำอะไรตอนคำสำคัญดังขึ้น เช่น ก๊อกถูกปิดตอนคำว่า "หยุด", มงกุฎแตกตอนคำว่า "ไม่"
3. **ห้ามซ้ำ.** ในคลิปเดียวห้ามใช้กราฟิกแบบเดียวกันสองครั้ง และห้ามใช้กราฟิกที่มีอยู่แล้วใน `examples/`
   ถ้าความหมายซ้ำกัน (เช่น "หยุด" สองครั้ง) ให้หาภาพใหม่
4. **เขียน `$P/graphics.js`.** ทำหนึ่งฟังก์ชันต่อหนึ่งกราฟิก ใช้ primitives เป็นอิฐ
   วาดของเป็น SVG หรือ div เอง ทำแบบเรียบ สะอาด ไม่ใช้โลโก้หรือหน้าตาแอปจริง และไม่ทำฉากเต็มจอ
   - ภาษาภาพ: หนึ่งไอเดียต่อจังหวะ, ตัวหนาแบบ Apple, เด้งแบบ spring
   - แสงเรืองใส่เฉพาะสิ่งที่สำคัญที่สุดในจังหวะนั้น
   - ทุกกราฟิกต้องมีการเคลื่อนไหวที่ตรงกับคำพูด ไม่ใช่แค่โผล่ขึ้นมาแล้วนิ่ง
5. **ข้อความในกราฟิกมาจากคำพูด.** ถ้าต้องเติมคำเอง ให้สั้น ไม่มีตัวเลข ราคา หรือชื่อ และต้องบอกผู้ใช้ตอนส่งงาน
6. **ตารางแผนต้องบอกภาพ ไม่ใช่ชื่อฟังก์ชัน.** เช่น "นาฬิกาทราย ทรายไหลลงกลายเป็นเหรียญ" ผู้ใช้ต้องเห็นภาพจากตารางได้

ดูระดับความละเอียดที่ต้องการได้จาก `examples/02-retire/graphics.js`
(11 กราฟิก ไม่ซ้ำกันเลย ทุกชิ้นวาดจากโลกของเงินและการเกษียณ)

## โซน

| โซน | ตำแหน่ง | ใช้กับ |
|---|---|---|
| **แถบบนเหนือหัว** (ค่าเริ่ม) | y ~180–440 (`TOPY` = 180) — ใช้ให้เต็มที่ | ภาพหลักของแต่ละจังหวะ |
| **ข้างหัวฝั่งซ้าย** | กำหนดพิกัดเอง x ≤ 790 | ของเล็ก ๆ เช่นความสงสัย |
| **ใต้คาง** | `lower()` / ซับ `ocap` | คำใหญ่ คำเปลี่ยนเรื่อง ประโยคปิด |

- **หลบแถบขวา:** ทุกอย่างต้องอยู่ในช่วง x 60–900 (`SAFE`) เพราะ 180 px ทางขวาเป็นที่ของปุ่มไลก์/ติดตาม/แชร์ของ TikTok/IG ซับจัดกึ่งกลางที่ x 480
- กราฟิกแถบบนต้องจบไม่เกิน y ~440 เพราะตอนซูมแรงสุด (~1.44×) หัวจะขึ้นมาถึงประมาณ y 470
- **คลิปที่ไม่มีที่ว่างเหนือหัว** (หัวชิดขอบบน):
  - ใส่ `band('chest')` ไว้ต้น timeline
  - กราฟิกของ `topBand` จะย้ายลงมาที่อกใต้คาง (เริ่มที่ y 940 หรือใต้คาง + 40) และซับจะเริ่มที่ y 1300 ใต้กราฟิก
  - กล่องสูงได้ประมาณ 280 px (ย่อขยาย 1.2) ถ้ายาวลงไปชนซับ เอนจินจะขึ้น error `band …`
  - ซูมเบาลง (1.08–1.24) เพื่อไม่ให้หัวหลุดขอบบน

## ซับ

- `ocap(t0, t1, 'ข้อความ', {keys: {'คำ': สี}, size})`
- ฟอนต์ Anuphan ตัวบาง สีขาว พิมพ์ทีละตัว คำสำคัญใส่สีพร้อมแสงเรือง
- วางใต้คาง (หรือใต้กราฟิกในโหมด chest) ไม่บังหน้า และย่อให้พอดีความกว้าง 840
- ประโยคที่กราฟิกใต้คางบอกอยู่แล้ว ไม่ต้องมีซับซ้ำ
