# ซูมเข้า / ซูมออก — แบบเดียวกับ talking-head-motion

```js
zoom(t, scale, dur = .14)   // ซูมกล้องไปที่ scale ภายใน dur วินาที (ease-out) แล้วค้างไว้จนถึง zoom() ถัดไป
zoom(t2, 1.0, .35)          // ซูมออกกลับขนาดปกติ
```

- สูตร จุดศูนย์กลาง (47% / 42% ของจอ — แถวใบหน้า) และการ "หายใจ" ช้า ๆ ของกล้อง (±1.4%) เหมือน talking-head-motion ทุกตัวเลข.
- ตัวอักษรไม่ซูมตาม.
- ช่วงที่การหายใจทำให้ภาพหดต่ำกว่า 1.0 เล็กน้อย ขอบจอถูกเติมด้วยภาพเฟรมเดียวกัน (talking-head-motion ใช้ vignette บัง
  — skill นี้ไม่ปรับสีวิดีโอ จึงเติมขอบแทน).

แนวซูม (จาก talking-head-motion):
- วลีปกติ 1.04–1.06 ค่อย ๆ (dur .5–.8)
- คำเน้น / คำสำคัญ 1.07–1.10 เร็ว (dur .12)
- อย่าเกิน 1.14
- ซูมออกกลับ 1.0 (dur .35) เมื่อขึ้นประโยคใหม่หรือก่อนประโยคแรง

**ซูมกับกฎห้ามบังหน้า:** ซูมเข้าทำให้หน้าใหญ่และคางเลื่อนลง — เอนจินคิดแถบหน้า (`face()`) ตามค่าซูมสูงสุดในช่วงของแต่ละก้อนข้อความให้อัตโนมัติ
แล้วดันซับลงตาม. ถ้าซูมแรงจนซับไม่มีที่ จะขึ้น `FACE:` error → ลดค่าซูมช่วงนั้น.
