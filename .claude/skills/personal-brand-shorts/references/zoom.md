# ซูมเข้า / ซูมออก — แบบเดียวกับ talking-head-motion

> **กฎเด็ดขาด:** ซูมแบบไหนก็ตาม (ช้า เร็ว ซูมกล้อง หรือซูมจากเทคนิค) ต้องซูม **คลิปทั้ง 2 เลเยอร์เท่ากันและจังหวะตรงกันเป๊ะ**
> เหมือนเป็นคลิปเดียว — ห้ามซูมเลเยอร์ใดเลเยอร์หนึ่งแยก. ในเอนจิน: ซูมกล้องตั้งค่าเดียวให้ทั้งสองเลเยอร์ในเฟรมเดียวกัน
> และเทคนิคต่าง ๆ ซูมผ่าน `#stage` ซึ่งเป็นกล่องที่ห่อทั้งสองเลเยอร์ไว้.

```js
zoom(t, scale, dur = .14)   // ซูมกล้องไปที่ scale ภายใน dur วินาที (ease-out) แล้วค้างไว้จนถึง zoom() ถัดไป
zoom(t2, 1.0, .35)          // ซูมออกกลับขนาดปกติ
```

- จุดศูนย์กลางซูม 47% / 42% ของจอ (แถวใบหน้า) — ค่าเดียวกับ talking-head-motion.
- ซูมทั้ง **เลเยอร์ 1 (คลิปต้นฉบับ) และเลเยอร์ 2 (คลิปลบพื้นหลัง) พร้อมกันเสมอ** — ภาพซ้อนกันจึงไม่เหลื่อม. ซับ (เลเยอร์ 3) ไม่ซูมตาม.
- มีการ "หายใจ" ช้า ๆ ของกล้องตลอดคลิปเหมือน talking-head-motion (±1.4%) แต่ไม่ต่ำกว่า 1.0 เพื่อไม่ให้เห็นขอบเฟรม
  (talking-head-motion มี vignette บังขอบ — skill นี้ไม่มี เพราะไม่ปรับสีวิดีโอ).

แนวซูม (จาก talking-head-motion):
- วลีปกติ 1.04–1.06 ค่อย ๆ (dur .5–.8)
- คำเน้น / คำสำคัญ 1.07–1.10 เร็ว (dur .12)
- อย่าเกิน 1.14
- ซูมออกกลับ 1.0 (dur .35) เมื่อขึ้นประโยคใหม่หรือก่อนประโยคแรง

**ซูมกับกฎห้ามบังหน้า:** ซูมเข้าทำให้หน้าใหญ่และคางเลื่อนลง — เอนจินคิดแถบหน้า (`face()`) ตามค่าซูมสูงสุดในช่วงของแต่ละก้อนข้อความให้อัตโนมัติ
แล้วดันซับลงตาม. ถ้าซูมแรงจนซับไม่มีที่ จะขึ้น `FACE:` error → ลดค่าซูมช่วงนั้น.
