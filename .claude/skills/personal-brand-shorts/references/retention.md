# ตัดต่อให้เข้ากับคนสมาธิสั้น (retention)

คนดูคลิปสั้นตัดสินใจภายใน 1–2 วินาทีแรก และปัดทิ้งเมื่อภาพนิ่งนานเกินไป. ทุกคลิปใช้กฎนี้ (ผู้ใช้สั่ง).
ไม่ตัดช่วงเงียบและไม่ตัดคลิป: ความเร็วมาจากภาพ ซับ ซูม และเสียงที่เปลี่ยนตลอด.

## กฎ

1. **Hook ตั้งแต่เฟรมแรก** — 1.5–2 วินาทีแรกต้องบอกปัญหาของคลิปด้วยคำใหญ่ที่มาจากคำพูดในคลิป (เช่น "ลูกค้าทักมา" → "แล้วก็หายไป").
   เฟรม 0 ต้องเห็นแล้ว (ฉากเริ่มก่อน 0 เล็กน้อย: `solid(t0 - .05, ...)`) ห้ามเปิดด้วยจอว่างหรือจางเข้า.
2. **มีอะไรเปลี่ยนทุก ≤ 1.5 วินาที** — ซับชุดใหม่, ซูม, กราฟิกชิ้นใหม่ หรือจังหวะในกราฟิก. ไล่ timeline ทั้งคลิปแล้วหาช่องที่ว่างนานกว่า 1.5 วินาที.
3. **ฉากเต็มจอไม่เกิน ~2 วินาที** แล้วกลับมาที่หน้าคนพูด — ฉากยาวให้แตกเป็นหลายฉากสั้นสลับกับหน้าคนพูด (เปลี่ยนสีพื้นสลับกันได้).
4. **ซับสั้น 1 ชุด = 1 ท่อนพูด** (ท่อนละ 1–3 คำจาก chunks.json): `kcap(t0, t1, 'ข้อความ')`
   - ตัวใหญ่ (Anuphan Bold 100), เด้งเข้า, แถบสีเหลืองวิ่งทับตามเวลาที่พูด (คาราโอเกะ)
   - คำสำคัญทั้งท่อน: `kcap(t0, t1, 'คำ', {color})` — ทั้งท่อนเป็นสีนั้น ใหญ่ขึ้น 15% มีแสงเรือง (แดง = คำร้าย, เขียว = คำดี, `HILITE` = คำเน้น)
   - วางใต้คาง ไม่บังหน้า ซ่อนเองระหว่างฉากเต็มจอ
5. **ซูมถี่** — ยังเป็น `zoom()` แบบ talking-head-motion (1.0–1.10, ไม่เกิน 1.14) แต่เปลี่ยนระดับทุกประโยคหรือทุกคำเน้น ให้รู้สึกเหมือนสลับมุมกล้อง.
6. **แถบความคืบหน้า** — `progressBar(ความยาวคลิป)` เส้นบางที่ขอบบน วิ่งตามเวลาคลิป.
7. **เสียงประกอบทุกจังหวะเปลี่ยน** — `sfx(ชื่อ, t, dB)`: `swipe`/`whoosh` ตอนเข้าฉาก, `pop` ตอนของเด้ง, `thud` ตอนของตกถึงพื้น,
   `tick` ตอนคลิก/สวิตช์, `impact` ตอนคำเปลี่ยนเรื่อง, `womp` ของลดลง, `sparkle`/`ding` ตอนเจอคำตอบ.
   มิกซ์: `scripts/sfx.py cues.json sfx_track.wav <ความยาว>` (cues จาก `window.SFX`) แล้วผสมใต้เสียงพูด −6 dB และปรับรวมเป็น −14 LUFS.

## ตรวจก่อนส่ง

- เฟรม 0 เห็น hook แล้ว
- contact sheet 2 เฟรมต่อวินาที: ไม่มีช่วงไหนที่ 3 เฟรมติดกันเหมือนกันทุกอย่าง
- ไม่มีฉากเต็มจอยาวเกิน ~2 วินาที
