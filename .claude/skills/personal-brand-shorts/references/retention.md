# ตัดต่อให้เข้ากับคนสมาธิสั้น (retention)

คนดูคลิปสั้นตัดสินใจภายใน 1–2 วินาทีแรก และปัดทิ้งเมื่อภาพนิ่งนานเกินไป. ทุกคลิปใช้กฎนี้ (ผู้ใช้สั่ง).
ไม่ตัดช่วงเงียบและไม่ตัดคลิป: ความเร็วมาจากภาพ ซับ ซูม และเสียงที่เปลี่ยนตลอด.

## กฎ

1. **เปิดคลิปด้วยหน้าคนพูดเสมอ** (ผู้ใช้สั่ง): เฟรม 0 ต้องเป็นหน้าคนพูด ห้ามเปิดด้วยฉากพื้นขาวหรือฉากกราฟิก
   - hook อยู่บนหน้าคนพูด: ซับตัวใหญ่ใต้คางที่บอกปัญหาของคลิป (คำจากคำพูดในคลิป) ต้องเห็นแล้วตั้งแต่เฟรม 0 ไม่จางเข้า
     (เริ่มก่อน 0 เล็กน้อย เช่น `kcap(-.2, t1, ...)`) จะมีกราฟิกเล็กข้างหัวหรือเหนือหัวเสริมก็ได้
   - ฉากที่ไม่ใช่หน้าฉากแรก เริ่มได้หลังจากคนดูเห็นหน้าคนพูดแล้วอย่างน้อย ~1.5–2 วินาที
2. **ไม่เร็วเกินไป** (ผู้ใช้บอกว่า v4 เปลี่ยนไวเกิน): ไม่มีช่วงที่ภาพนิ่งสนิทเกิน ~2 วินาที แต่ก็**ไม่ตัดไปมาถี่**
   - ฉากที่ไม่ใช่หน้าคนพูดยาวได้ 2–4.5 วินาที ถ้าข้างในยังขยับตามเสียง: ใช้ `phase()` ให้หลายจังหวะเลื่อนต่อกันในฉากเดียว
     แทนการตัดกลับไปหน้าคนพูดแล้วตัดกลับมา (เช่น เหตุผล 3 ข้อในการ์ดเดียว, ข้อสงสัย 01 → 02 → 03 ในฉากเดียว)
   - รวมประโยคที่ต่อกันเป็นฉากเดียว (ลูกค้าน้อยลง → เงียบ → รีบลดราคา)
3. **ซับเป็นวลี ~1–1.5 วินาที** (รวมหลายท่อนจาก chunks.json): `kcap(t0, t1, 'วลี', {key, keyColor})`
   - ตัวใหญ่ (Anuphan Bold 100), เด้งเข้า, แถบสีเหลืองวิ่งทับตามเวลาที่พูด (คาราโอเกะ); วลียาวจะย่อตัวเองให้พอดี
   - คำสำคัญในวลี: `key` + `keyColor` (แดง = คำร้าย, `HILITE` = คำเน้น); ทั้งวลีเป็นคำสำคัญ: `{color}`
   - วางใต้คาง ไม่บังหน้า ซ่อนเองระหว่างฉากเต็มจอ
4. **ซูมเฉพาะคำเน้นจริง ๆ** — `zoom()` แบบ talking-head-motion (1.0–1.10, ไม่เกิน 1.14).
5. **เสียงประกอบ / แถบความคืบหน้า: ไม่ใช้** (ผู้ใช้เลือก) — `sfx()` / `progressBar()` ยังอยู่ใน engine ถ้าลูกค้าคนไหนอยากได้.

## ตรวจก่อนส่ง

- เฟรม 0 เห็น hook แล้ว
- contact sheet 2 เฟรมต่อวินาที: ไม่มีช่วงไหนที่ 4 เฟรมติดกันเหมือนกันทุกอย่าง และไม่มีการตัดหน้า ↔ ฉาก ถี่กว่า ~2 วินาที
