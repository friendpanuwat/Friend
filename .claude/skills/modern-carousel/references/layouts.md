# Layouts

เลย์เอาต์ที่จูนแล้ว (พิกัดสำหรับ 1080×1080) — ตัวอย่างจริงใน `examples/deck_showcase.js` (S1–S8) และ `examples/deck_steps.js` (L1–L7).
ทุกเลย์เอาต์ใช้ได้กับทุกธีม. ระยะขอบซ้าย/ขวา 80 px; พาดหัวเริ่มที่ y ≈ 250–420; แถบบน y < 100 เป็นของ chrome.

## หลักจัดวาง

- ตัวอักษรเป็นตัวเอก; กราฟิกหลัก **หนึ่งชิ้น** + ชิ้นรองไม่เกิน 2.
- ชิดซ้ายเป็นหลัก (แบบ reference); จัดกลางเฉพาะ orbit / ตัวเลขเดี่ยว / quote สั้น.
- เว้นที่ว่างให้หายใจ แต่ไม่ให้กองครึ่งบนแล้วปล่อยครึ่งล่างว่าง (QC `unbalanced`).
- ของที่เหลื่อมขอบ (การ์ดล้นขอบขวา, มือถือเอียง) ใช้ได้กับกราฟิก แต่ห้ามกับข้อความ.
