# มาตรฐานงาน (modern carousel)

## ขนาดและโซน (1080×1080)

- ขอบซ้าย/ขวา 80 px (ข้อความ), กราฟิกล้นขอบได้.
- **แถบบน y < 100**: handle (ซ้าย) + เลขหน้า `01 / 08` (ขวา). **มุมขวาล่าง 150×150**: ลูกศรเลื่อน (ทุกสไลด์ยกเว้นสุดท้าย).
- ปก: เนื้อหาสำคัญใน x 135–945 (กริดโปรไฟล์ IG แสดงแนวตั้ง ครอปสองข้าง).
- 4:5 (`SIZE=1080x1350`): โซนเดียวกัน แต่ความสูงเพิ่ม 270 px — ขยับบล็อกล่างลง / ขยายกราฟิก.

## กราฟิก

- ทุกสไลด์มีกราฟิกอย่างน้อยหนึ่งชิ้น — ไม่มีรูปจากผู้ใช้ = กราฟิก + ตัวอักษร 100% (ไม่ดึงรูปจากเน็ต ไม่สร้างภาพคน).
- กราฟ/ตัวเลข: ค่าที่แสดงเป็นตัวเลขต้องมาจากผู้ใช้. กราฟที่ไม่มีตัวเลขกำกับ (แค่ทิศทางขึ้น/ลง) ใช้ประกอบความหมายได้.
- ชื่อแพลตฟอร์ม/เครื่องมือเขียนเป็นตัวอักษรใน chip ได้; ไม่วาดโลโก้แบรนด์จริง.
- สีแดง `--neg` เฉพาะความหมายลบ.

## MP4

- 30 fps, H.264, `dur` 3–4 วิ; แอนิเมชันจบใน ~1.5 วิ แล้วค้าง. ค่าเริ่มเงียบ (มีแทร็กเสียงว่าง); `SFX=1` ใส่เสียงประกอบสังเคราะห์.
- เฟรมแรกของปก = ภาพตัวอย่างในกริด → พื้น + texture + glow อยู่ตั้งแต่เฟรมแรกอยู่แล้ว; ถ้าอยากให้ปกเต็มตั้งแต่เฟรมแรก แนะนำให้ใช้ PNG เป็นปก.

## QC ก่อนส่ง (เปิด PNG ทุกใบ)

1. `pipeline.sh … stills` ขึ้น `QC clean` (ตรวจขอบ, chrome, ลูกศร, ข้อความทับกราฟิก, ชิ้นเล็กโดนขอบตัด, สมดุลบน-ล่าง).
2. พาดหัวอ่านจบใน 2 วิ, ไม่มีบรรทัดล้น, สระ/วรรณยุกต์ไม่ชนกัน, markup วาดถูกที่ (วงกลมล้อมคำ, ขีดฆ่ากลางคำ).
3. ปกมี tag + พาดหัว + กราฟิกเด่น; สไลด์สุดท้ายมี CTA และไม่มีลูกศร.
4. ทุกสไลด์มีกราฟิกที่สื่อความหมาย; โทนสลับกันไม่ซ้ำเกิน 2 ใบ; accent 1–2 ใบต่อชุด.
5. ข้อความ/ตัวเลขตรงกับที่ผู้ใช้ให้ ไม่มีข้อมูลแต่งเพิ่ม; สะกดถูก.
6. คอนทราสต์: ตัวอักษรบน accent และ `[accent]` บนพื้นสว่างอ่านชัด (สำคัญเมื่อใช้สีแบรนด์เอง).
7. MP4 (ถ้าทำ): ดูเฟรมเข้า + ท้ายของ 1–2 สไลด์ — ตัวเลขนับถึงค่าจริง, เส้น/วงกลมวาดครบ, จบแล้วนิ่ง.
