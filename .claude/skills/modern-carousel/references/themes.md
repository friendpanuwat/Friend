# Themes

ตั้งใน `brand.json` → `"theme": "<ชื่อ>"` (หรือ `THEME=<ชื่อ>` ตอน build เพื่อลองทั้งชุด). ทุกธีมมี 3 โทนต่อสไลด์: `dark` · `light` · `accent`.

| ธีม | ลุค | เหมาะกับ | texture / glow · การ์ด · มุม |
|---|---|---|---|
| `lime` | ดำอมเขียว + เขียวมะนาว, แสงเรือง, การ์ดกระจก | แอป, ครีเอเตอร์, การตลาดออนไลน์, คอร์ส | grain + glow · glass · 36 |
| `glow` | ดำสนิท + นีออนเขียวมิ้นต์, เส้นกริดจาง | AI, SaaS, เทคโนโลยี, automation | grid + glow · glass · 28 |
| `cobalt` | ขาว/ดำ + ก้อนน้ำเงินโคบอลต์มีเกรน, ตัวบาง, มุมเหลี่ยม | agency, บัญชี/การเงินแบบพรีเมียม, แบรนด์ดีไซน์ | grain + blob · outline · 0 |
| `ember` | ดำถ่าน/ขาวนวล + ส้ม, ตัวหนา, asterisk | startup, ที่ปรึกษา, คอนเทนต์ความรู้ | – · solid · 28 |
| `crimson` | แดงสด + ดำ + ขาว, กริดกระดาษบนพื้นแดง | tips / ข่าวอัปเดต / LinkedIn, แบรนด์กล้า ๆ | paper · solid · 18 |
| `mono` | ขาว/ดำ แสงลอด + ม่วง, ตัวเลขบางยักษ์ | fintech, product, B2B, รายงานตัวเลข | leak · solid · 22 |

เลือกจาก: สีแบรนด์ของผู้ใช้ (ถ้ามี) → อารมณ์ของหัวข้อ → ความหลากหลาย (ไม่ใช้ธีมเดียวกับโพสต์ก่อนหน้าถ้าผู้ใช้อยากให้ต่าง).

## สีแบรนด์เอง

เริ่มจากธีมที่ลุคใกล้ที่สุด แล้วแทนสีใน brand.json:
```json
{"theme": "ember", "accent": "#FF7A00", "accent_ink": "#FFFFFF", "accent_on_light": "#D96500", "handle": "@shop", "logo": "S"}
```
- `accent` = สีหลักหนึ่งเดียว (ไฮไลต์, ปุ่ม, แท่งกราฟ, พื้นโทน accent).
- `accent_ink` = สีตัวอักษรบน accent (ขาวหรือดำ — ต้องอ่านออกชัด).
- `accent_on_light` = accent ที่ใช้เป็นตัวอักษรบนพื้นสว่าง (เข้มขึ้นถ้า accent สว่าง เช่นเขียวมะนาว → เขียวมะกอก).
- แก้โทนพื้นได้ด้วย `"dark": {"bg": "#…"}` / `"light": {"bg": "#…"}` (คีย์อื่นในโทนคงเดิม).
- คีย์อื่น: `texture` (`grain|grid|dots|paper|leak|none`), `glow` (`true|false|"blob"`), `card` (`glass|solid|outline`), `radius`,
  `title_weight` (300–700), `num_weight`, `ornament` (`asterisk|plus|cross|sparkles|dot`), `neg` (สีความหมายลบ).

ตรวจคอนทราสต์ทุกครั้งหลังเปลี่ยนสี: เปิด PNG ของสไลด์ light และ accent อย่างน้อยหนึ่งใบ.
