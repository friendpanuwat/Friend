# มาตรฐานงาน (editorial carousel)

## Brand (`brand.json`)

คัดลอก `assets/brand.default.json` → `<project>/brand.json` แล้วแก้. ถ้าผู้ใช้มีคลิป editorial ที่ทำแล้ว ให้ใช้ brand.json ชุดเดียวกับคลิป
(เพิ่มแค่ `handle`).

| คีย์ | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `accent` | `#DDFF45` | สีเดียวของชุด: คำสำคัญบนพื้นมืด, กล่องไฮไลต์, ป้ายเลข/รายการ, ชิป "เลื่อนดู", พื้นสไลด์ CTA |
| `navy` | `#14213D` | ตัวอักษรบนพื้นสว่าง, tile เข้ม, แท่งกราฟ |
| `cream` | `#F2EDE2` | พื้นโปสเตอร์ |
| `ink` | `#000000` | พื้นสไลด์ดำ (ดำสนิท — รูปพื้นดำกลืน) |
| `pill` | `#1B2A52` | ป้ายเม็ดยา |
| `handle` | `""` | ข้อความเล็กซ้ายล่างทุกสไลด์ เช่น `@ชื่อร้าน` (ว่าง = ไม่แสดง) |
| `fonts.*` | Mitr Bold / Sriracha / Mitr Regular / Mitr SemiBold | ไฟล์ .ttf (path อิงจาก brand.json แล้วจึง assets/) |
| `sfx_db` | `-11` | ไม่ใช้ใน carousel (คงไว้ให้ brand.json ใช้ร่วมกับคลิปได้) |

accent ต้องอ่านออกบนพื้นดำ และเป็นพื้นของตัวดำได้ (สีสว่างอิ่ม). ฟอนต์ไทยต้องครบสระ/วรรณยุกต์และใช้เชิงพาณิชย์ได้
(Mitr, Sriracha = OFL; ไอคอน Lucide = ISC — license ใน `assets/licenses/`).

## ขนาดและโซน

- ค่าเริ่ม **1080×1080** (1:1). `SIZE=1080x1350` (4:5) / `1080x1920` (9:16) ได้ — ตำแหน่งในสไลด์ต้องคิดใหม่.
- ขอบปลอดภัย: ซ้าย/ขวา 60–80 px, บน 60 px. **แถบล่าง y > 980** = handle (ซ้าย) + เลขหน้า/ชิปเลื่อน (ขวา).
- ปก: เนื้อหาสำคัญใน x 135–945 (กริดโปรไฟล์ IG แสดงแนวตั้ง ครอปสองข้าง).
- ข้อความกว้าง ≤ 920 px; คำใหญ่บรรทัดเดียวไม่ควรถูกย่อต่ำกว่า 70% (QC เตือน).

## ตัวอักษร

| ชั้น | ฟอนต์ | ขนาด (1080×1080) | สี |
|---|---|---|---|
| คำนำ `l` | Mitr Regular | 46–60 | ขาว / กรมท่า |
| วลีกลาง `m` | Mitr SemiBold | 70–84 | ขาว / กรมท่า |
| คำสำคัญ `k` / `kw` | Mitr Bold, letter-spacing −2 | 104–146 (ปก/ประโยคปิด 170–190) | accent (มืด) · ขาว · กรมท่า |
| ลายมือ `i` / `iw` | Sriracha | 110–150 (ปก 180–200) | accent (มืด) · ขาว · กรมท่า |
| ไฮไลต์ `hl` | Mitr Bold บนกล่อง accent | 80–116 | ดำ |
| รายการ `rows` | Mitr SemiBold | 46–54 | ขาว / กรมท่า |
| ย่อหน้า `para` | Mitr Regular, line-height 1.5 | 40–46 | ขาว / กรมท่า, `**ตัวหนา**` = accent บนมืด |
| handle / เลขหน้า | Mitr SemiBold | 30 | ขาว 62% / กรมท่า 58% |

ต่อสไลด์: คำสำคัญใหญ่ **หนึ่ง** คำ (หรือหนึ่งวลี) + คำนำ ≤ 2 บรรทัด. สลับ Mitr หนา / Sriracha ระหว่างสไลด์.
Motion (MP4): คำนำลอยขึ้น 16 px + เบลอ 7→0 ใน 0.2 วิ; คำสำคัญย่อ 1.16→1 + เบลอ 14→0 ใน 0.26 วิ; สไลด์เข้า 1.035→1.

## รูป

- ไม่เกรดสี ไม่มี filter / vignette / grain. `shade()` (ไล่ดำใต้ข้อความ) ใช้ได้เฉพาะตอนข้อความทับรูปเต็มผืน.
- ไม่ดึงรูปจากเน็ต, ไม่ใช้โลโก้แบรนด์จริง, ไม่สร้างภาพคนขึ้นเอง.
- รูปคน: ไม่ครอปตัดหน้าผาก/คาง, `pos` เน้นหน้า. ความละเอียดต้นฉบับต่ำกว่าขนาดกรอบ ×1 → ย่อกรอบ.

## MP4

- 30 fps, H.264 yuv420p, CRF 17, `dur` 3–4 วิต่อสไลด์ (แอนิเมชันจบใน ~1.5 วิ แล้วค้างให้อ่าน).
- ค่าเริ่มเงียบ (มีแทร็กเสียงว่างเพื่อให้ทุกแพลตฟอร์มรับไฟล์); `SFX=1` ใส่เสียงประกอบสังเคราะห์ (ไม่มีลิขสิทธิ์) — pop, swipe, whoosh, thud.
  **ไม่ใส่เพลง** (ลิขสิทธิ์) — แนะนำให้ผู้ใช้เลือกในแอปตอนโพสต์.
- IG/FB carousel ผสมรูปกับวิดีโอได้: ผู้ใช้อาจใช้ MP4 แค่บางสไลด์ + PNG ที่เหลือ — บอกทางเลือกนี้ตอนส่ง.
- **เฟรมแรกของ MP4 สไลด์ 1 = ภาพตัวอย่างในกริดโปรไฟล์** — ต้องไม่ว่าง: พื้น/รูปหลักอยู่ตั้งแต่เฟรมแรก (`anim: 'none'` กับรูปเต็มผืน,
  `mood` อยู่แล้ว) ให้แค่ข้อความ/ชิ้นเล็กเคลื่อนเข้า. ถ้าปกไม่มีอะไรอยู่ตั้งแต่เฟรมแรก แนะนำให้ใช้ PNG เป็นปก.

## QC ก่อนส่ง (เปิด PNG ทุกใบ)

1. `pipeline.sh … stills` พิมพ์ `QC clean` (ไม่มีข้อความล้นขอบ/ทับแถบล่าง/บรรทัดถูกบีบ).
2. สระบน/วรรณยุกต์ไม่ชนบรรทัดบน, ไม่มีตัวอักษรถูกตัด, ไม่มีฟอนต์สำรอง (ตัวเหลี่ยม/ช่องว่างแปลก).
3. ปกอ่านจบใน 2 วิ และมีเหตุให้ปัด; สไลด์กลางหนึ่งความคิดต่อสไลด์; สไลด์ท้ายมี CTA.
4. คำสำคัญหนึ่งคำต่อสไลด์ และสลับ Mitr/Sriracha; accent สีเดียว; พื้นไม่ซ้ำติดกันเกิน 2 ใบ.
5. ภาพ/MG ตรงความหมาย และอ่านรู้เรื่องในสถานะสุดท้าย (PNG); ไม่มีของสำคัญหายไปตอนจบ.
6. ข้อความตรงกับที่ผู้ใช้ให้ ไม่มีข้อมูลที่แต่งเพิ่ม; สะกดถูก.
7. สมดุล: ไม่มีพื้นที่ว่างก้อนใหญ่ด้านเดียว (ขยับบล็อกให้ค่อนกลาง), ระยะขอบสม่ำเสมอทั้งชุด.
8. MP4 (ถ้าทำ): ดูเฟรมช่วงเข้า + ท้ายของ 1–2 สไลด์ — เฟรมแรกของปกไม่ว่าง (ภาพตัวอย่าง), สไลด์อื่นไม่ว่างนานเกิน 0.3 วิ, จบแล้วค้างนิ่ง.
