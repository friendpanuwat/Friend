# Slide library

ทุกสไลด์ต้อง **เล่าความหมายของข้อความ** ไม่ใช่แค่ตกแต่ง — ถามตัวเองว่า "ถ้าลบข้อความออก ภาพนี้ยังสื่อไหม".
ทุกสูตรมีตัวอย่างจริงใน `examples/deck_mg.js` (S1…S8) / `examples/deck_photo.js` (P1…P6) — คัดลอกแล้วเปลี่ยนเนื้อหา.
พิกัดด้านล่างสำหรับ 1080×1080 (แถบล่าง y > 980 เป็นของ handle + เลขหน้า).

## 1. ปก (สไลด์ 1) — ต้องหยุดนิ้วคนเลื่อน

| แบบ | หน้าตา | ใช้เมื่อ | ตัวอย่าง |
|---|---|---|---|
| **ปก MG มืด** | `mood` + ไอคอน 2–3 ชิ้นแถวบน (ชิ้นกลางขาวใหญ่ 200, ข้าง glass 140–150) + `m` + คำใหญ่ `i`/`k` 170–200 + บรรทัดหักมุมพร้อม `hl` | ไม่มีรูป / หัวข้อเป็นปัญหาหรือความเชื่อผิด | S1 |
| **ปกหน้าเต็ม** | `photo()` เต็มผืน `radius: 0` + `shade()` ล่าง + หัวเรื่องที่ y 620–900 | มีเฟรมจากคลิป/รูปคนที่หน้าชัด แสดงอารมณ์ | P1 |
| **ปกขาวตัวอักษร** | คำนำ `l` + คำใหญ่ `kw` 170 + `hl` + tile navy หนึ่งชิ้น | หัวข้อเป็นคำถาม/ตัวเลขข้อ ("3 เรื่องที่…") | — |
- หัวเรื่องปก ≤ 2 บรรทัดใหญ่ + 1 บรรทัดเล็ก. เนื้อหาสำคัญอยู่ใน x 135–945 (กริดโปรไฟล์ IG ครอปข้าง).
- ชิป "เลื่อนดู" ขวาล่างมาเอง — อย่าวางของสำคัญที่มุมนั้น.

## 2. สไลด์ตัวอักษร

| ชนิด | หน้าตา | ใช้กับ | ตัวอย่าง |
|---|---|---|---|
| **ขาว ประกอบคำ** | 3 บรรทัด: `l` → `kw` 104 → `l` + `iw` + `hl`, ขีดฆ่าคำสุดท้ายด้วย `strike` | ประโยคหักมุม / "ไม่ใช่ X" | S5 |
| **ขาว คำถาม** | tile navy ใหญ่ (300) + tile accent เล็กด้านบน, ข้อความ `l` + `kw` + `i` ใต้ภาพ | "คิดว่า…ใช่ไหม?" | S2 |
| **กรมท่า หัวเรื่อง + รายการ** | `l` + `k` 130 บนสุด, `rows()` 3–5 ข้อที่ y 470 | สรุป / ขั้นตอน / เช็กลิสต์ | S6, P5 |
| **กรมท่า สีไล่** | `l` 66 + `kw` `{wipe: true}` กลางสไลด์ | ประโยคที่อยากให้ค้างในหัว (ใน PNG เป็นสี accent ทั้งคำ) | — |
| **ย่อหน้า** | หัวเรื่อง `m` + `para()` 2–3 บรรทัดที่มี `**ตัวหนา**` / `==ไฮไลต์==` | ต้องมีคำอธิบายจริง ๆ (ไม่เกิน 2 สไลด์ต่อชุด) | — |

## 3. สไลด์รูป (เมื่อผู้ใช้ส่งรูป / เฟรมจากคลิป)

| ชนิด | หน้าตา | ตัวอย่าง |
|---|---|---|
| **โปสเตอร์ครีม** | `curl()` + `photo()` 480×560 กลาง + tile navy มุมขวาบนของรูป, หัวเรื่องบน `l` + `iw`, ล่าง `l` + `hl` | P2 |
| **ภาพทั้งใบบนดำ** | `pic()` contain (สกรีนช็อต, รูปพื้นดำ, ภาพตัดพื้น) y 60–700 + ข้อความล่าง y 715+ | P3 |
| **แบ่งครึ่ง** | `photo()` ซ้าย 440×680 + tile `quote` + ข้อความขวา `txt(..., 'top:310px;left:540px', {W: 480})` | P4 |
| **หน้ากลม (CTA)** | `photo()` 300×300 `radius: 150` ขอบขาว + tile เล็กเกาะขอบ | P6 |
- เลือกรูปให้ตรงประโยค; รูปที่ไม่เข้ากับสไลด์ไหนไม่ต้องใช้ (บอกผู้ใช้ว่าไม่ได้ใช้รูปไหน).
- เฟรมจากคลิป: หน้าชัด ตาเปิด ปากไม่เบี้ยว — ดูจาก `scan.jpg` แล้ว grab เวลาใกล้ ๆ หลายเฟรมเลือกอีกที. `pos` เน้นหน้า (`'50% 20–30%'`).
- รูปจากคลิปแนวตั้ง 1080×1920 ครอปเป็นสี่เหลี่ยมได้คมพอ; ถ้าต้นฉบับเล็กกว่า 1080 ใช้ในกรอบเล็ก (≤ 600 px) แทนเต็มผืน.

## 4. Motion graphics (เมื่อไม่มีรูป) — Jitter × Swishy

ภาษาภาพเดียวกับ editorial:
- **Jitter** = รูปทรงแบน มุมมนใหญ่ (radius ≈ 26%), ไอคอนเส้น Lucide, เด้งเข้าแบบ overshoot, ไล่เวลาทีละชิ้น 0.1–0.2 วิ.
- **Swishy** = พื้นดำมีแสงฟ้า/ม่วง + ตารางจุดจาง (`mood()`), กล่องกระจกฝ้า (`bg: 'glass'`, `panel style 'glass'`).
- ชิ้นหลัก 1 ชิ้น (ขาว/accent/navy, 200–420 px) + ชิ้นรอง 1–3 ชิ้น (glass, 120–150 px). ไม่เกิน 5 ชิ้นต่อสไลด์.
- จัดวางสไลด์ 1080: **MG ครึ่งบน (y 90–560) + ข้อความครึ่งล่าง (y 560–960)** หรือกลับกัน, หรือ **MG ซ้าย + ข้อความขวา** (S3).
- PNG แสดงตอนจบ → ภาพต้องอ่านความหมายได้ในสถานะสุดท้าย (กราฟร่วงแล้ว, ลูกศรปักเป้าแล้ว, กากบาทวาดแล้ว).

| ความหมาย | สูตร MG | ตัวอย่าง |
|---|---|---|
| หายไป / เงียบ / ไม่ตอบ | `mood` + tile `message-circle` glass, `ghost` ขาว, `eye-off` glass แถวบน | S1 |
| แพง / ราคา / เงิน | tile `tag` navy 300 กลาง + `banknote`/`wallet` accent หรือ glass ข้าง ๆ | S2 |
| ลูกค้าถาม / ลังเล | มือถือ `panel glass` ซ้าย + `bubble` คำถามจากเนื้อหา + tile `circle-help` accent + `pill` รายการล่าง | S3 |
| ยอดตก / ลูกค้าน้อยลง | โปสเตอร์ครีม + `panel` ขาว: tile `store`, `skel`, `bars(..., {to, tTo})` + `trend` แดงลง | S4 |
| สิ่งที่ต้องทำ / เป้าหมาย / ถูกจุด | `target()` 420 + `lightbulb`, `search` glass | S7 |
| เซฟ / แชร์ (CTA) | พื้น accent + tile `bookmark` navy + `send` ขาว แถวบน + `kw` "เซฟไว้" | S8 |
| ไม่ควรทำ | tile ใหญ่ของสิ่งนั้น + `cross()` + `strike` บนคำ | — |
| ขั้นตอน | `num(n)` บนสุด + หัวเรื่อง + tile ใหญ่ของสิ่งนั้น (หนึ่งข้อต่อสไลด์) หรือ `rows()` | — |
| เติบโต / ยอดขึ้น | `bars` สูงขึ้น + `trend` accent ขึ้น (`trending-up`) | — |
| เวลา / รอ | `hourglass` / `clock` + `calendar` glass | — |
| ความเชื่อมั่น / รีวิว | `shield-check` + `stars(5, n)` บน panel ขาว | — |
| ไอเดีย / เริ่มต้น | `lightbulb` accent + `sparkles`, `rocket` glass | — |
ไม่ใส่ตัวเลข/ราคา/ชื่อแบรนด์ที่ผู้ใช้ไม่ได้ให้ — ข้อความใน MG (ปุ่ม ป้าย บับเบิล) ใช้คำจากเนื้อหาหรือคำ UI กลาง ๆ.

## 5. สไลด์ปิด

| ชนิด | หน้าตา | ตัวอย่าง |
|---|---|---|
| **สรุป** | กรมท่า `rows()` หรือ ดำ `target()` + ประโยคปิด `k` 170 | S6, S7 |
| **CTA เซฟ/แชร์** | พื้น accent: tile `bookmark` + `send`, `kw` "เซฟไว้" 130 + เหตุผลสั้น `l` | S8 |
| **CTA ดูคลิป** | ครีม: หน้ากลม + tile `bookmark`, `kw` + `hl` "คลิปเต็ม" | P6 |
