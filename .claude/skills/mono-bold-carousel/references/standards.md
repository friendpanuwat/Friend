# มาตรฐานงาน (mono-bold carousel)

## ขนาดและโซน (1080×1080)

- ขอบซ้าย/ขวา 80 px (ข้อความ), กราฟิกล้นขอบได้.
- **แถบบน y < 100**: handle (ซ้าย) + เลขหน้า `01 / 08` (ขวา). **มุมขวาล่าง 150×150**: ลูกศรเลื่อน (ทุกสไลด์ยกเว้นสุดท้าย).
- กริดทุกสไลด์: **tag y140 → พาดหัว y205 → บล็อกเนื้อหา y≈440–900**. ให้ตำแหน่งนี้คงที่ทั้งชุด = ดูเป็นระบบ.
- ปก: เนื้อหาสำคัญใน x 135–945 (กริดโปรไฟล์ IG ครอปสองข้าง).
- 4:5 (`SIZE=1080x1350`): โซนเดียวกัน แต่ความสูงเพิ่ม 270 px — ขยับบล็อกล่างลง / ขยายการ์ด.

## สีและการเน้น (กฎตายตัวของ skill นี้)

- **ขาว-ดำล้วน**: พื้น `dark` = ดำ, `light` = เทาอ่อนเกือบขาว, `accent` = ขาวล้วน. ห้ามเพิ่มสีอื่น (ห้ามใส่ `accent` สีใน brand.json).
- **ตัวอักษรสีเต็มเสมอ**: พาดหัวขาวเต็มบนพื้นดำ / ดำเต็มบนพื้นขาว. **ห้ามทำพาดหัวสีเทา** (ผู้ใช้บอกว่าอ่านยาก โดยเฉพาะเทาบนขาว).
- **เน้นคำ = `__เส้นใต้__` หนึ่งจุดต่อพาดหัว** เท่านั้น.
- **ห้าม**: `{กล่องไฮไลต์}` (กรอบรอบตัวหนังสือ), `~ขีดฆ่า~`, `((วงกลม))`, `[สี accent]` — `build_deck.py` จะหยุดพร้อมบอกบรรทัด.
- ความต่างของโทนให้มาจาก **การ์ด**: การ์ด `accent` (ขาวบนพื้นดำ / ดำบนพื้นขาว) สำหรับฝั่ง "คำตอบ / ทางที่ดีกว่า", การ์ด `solid` / ค่าเริ่ม สำหรับฝั่ง "ปัญหา / ทางเดิม".

## กราฟิก

- ทุกสไลด์มีกราฟิกอย่างน้อยหนึ่งชิ้นที่ "เล่า" ความหมาย — ไม่มีรูปจากผู้ใช้ = กราฟิก + ตัวอักษร 100%.
- ที่เข้ากับธีมนี้: การ์ดเปรียบเทียบสองฝั่ง, `hbar()` เทียบสัดส่วน, การ์ดขั้นตอน 01–03, แถวไอคอน, `line()` ทิศทางขึ้น/ลง (ไม่มีตัวเลขกำกับ), `list(mark: 'icon')`, `cta()`, `path()`.
- ไม่ใช้: `coin()` (ดูเป็นของเล่นในขาว-ดำ), `glow` / `blob`, `ornament` ที่ไม่ได้สื่อความหมาย.
- ค่าตัวเลขในกราฟ / `num()` / `hbar()` ต้องมาจากผู้ใช้.

## MP4

- 30 fps, H.264, `dur` 3–4 วิ; แอนิเมชันจบใน ~1.5 วิ แล้วค้าง. ค่าเริ่มเงียบ; `SFX=1` ใส่เสียงประกอบ.

## QC ก่อนส่ง (เปิด PNG ทุกใบ)

1. `pipeline.sh … all` ไม่ติด `STYLE:` และขึ้น `QC clean`.
2. พาดหัวสีเต็ม, เส้นใต้อยู่ใต้คำที่ตั้งใจ, สระ/วรรณยุกต์ไม่ชนกัน.
3. ไม่มีตัวหนังสือสีเทาอ่อนบนพื้นขาว (เนื้อความ/label ต้องอ่านชัด).
4. ทุกสไลด์มีกราฟิกที่สื่อความหมาย; โทนสลับ dark/light ไม่ซ้ำติดกันเกิน 2 ใบ; โทน `accent` ใช้ 1 ใบ (สรุป).
5. ข้อความ/ตัวเลขตรงกับที่ผู้ใช้ให้ ไม่มีข้อมูลแต่งเพิ่ม; สะกดถูก.
6. สไลด์สุดท้ายมี CTA และไม่มีลูกศร.
