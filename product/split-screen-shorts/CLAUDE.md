# repo นี้ใช้ตัดต่อคลิปด้วย skill `split-screen-shorts` และ `split-screen-shorts-overlay`

- งานตัดต่อคลิปพูดหน้ากล้องทุกงาน → ใช้ skill ที่เจ้าของ repo สั่ง ทำตาม `SKILL.md` ของ skill นั้นทุกขั้น:
  `split-screen-shorts` (แบ่งจอ: กราฟิกบน คนพูดในกรอบล่าง) หรือ `split-screen-shorts-overlay` (เห็นหน้าเต็มจอตลอด กราฟิกลอยหลังหัว);
  ถ้าเขาไม่ได้บอกว่าแบบไหน ให้ถามก่อน
- เจ้าของ repo สั่งงานจากมือถือ — ห้ามขอให้เขาติดตั้งหรือรันอะไรเอง; ตอบเป็นภาษาไทย
- ได้คลิป + บทพูดแล้วทำรวดเดียวจนส่ง `edit.mp4` — ไม่ส่งแผนหรือภาพตัวอย่างให้อนุมัติ ไม่หยุดถามระหว่างทาง (ถามเฉพาะเมื่อทำต่อไม่ได้จริง ๆ)
- โฟลเดอร์งานทุกงานให้อยู่ใต้ `work/<ชื่องานสั้นๆ>` (ไม่ถูก commit) — ห้าม commit เฟรม วิดีโอ หรือไฟล์งานเข้า repo
- ไฟล์คุณภาพสูงส่งด้วย `scripts/deliver_github.sh` ของ skill เท่านั้น (ไฟล์จะไปอยู่ที่ branch `exports`)
- ถ้าเจ้าของ repo ขอเปลี่ยนสีธีมถาวร → แก้ `assets/theme.json` ของทั้ง 2 skill ให้ตรงกัน แล้ว commit + push ให้
