# Split-Screen Shorts — คู่มือการใช้งาน

ตัดต่อคลิปพูดหน้ากล้องแนวตั้ง (TikTok / Reels / Shorts) ให้เป็นคลิปอธิบายแบบงานโมชันกราฟิกมืออาชีพ
ด้วย Claude — สั่งจากมือถือได้ ไม่ต้องติดตั้งโปรแกรม

**ได้ 2 สไตล์ในชุดเดียว** — เลือกได้ทุกครั้งที่สั่ง
| สกิล | หน้าตา |
|---|---|
| `split-screen-shorts` | แบ่งจอ: กราฟิกด้านบน ซับตรงกลาง คุณอยู่ในกรอบด้านล่างโดยหัวทะลุขอบกรอบขึ้นมา ตัดไปเต็มจอเฉพาะคำเน้น |
| `split-screen-shorts-overlay` | เห็นหน้าคุณเต็มจอตลอด กราฟิกลอยเหนือหัว (ส่วนล่างอยู่หลังหัว) ซับอยู่แถวมือ |

**ได้อะไร (ทั้ง 2 สไตล์)**
- กราฟิกแบบ "จอจริง" ที่ออกแบบใหม่ให้ตรงกับสิ่งที่คุณพูดในคลิปนั้น (กราฟที่วาดตัวเอง ทรงกลมอนุภาค ภาพประกอบ ฯลฯ) — ใช้ภาพแทนตัวหนังสือ
- ซับภาษาไทย 2 บรรทัด คำสว่างขึ้นตามเสียงพูด มีเงานุ่ม ๆ อ่านง่าย ไม่บังหน้า
- คำใหญ่ตรงคำเน้น (บางคำอยู่ด้านหลังหัว)
- ใช้ชุดสีเดียวทั้งคลิป (เปลี่ยนเป็นสีแบรนด์ของคุณได้ — ดูข้อ 5) · ฟอนต์ไทยไม่มีหัวแบบเดียวทั้งคลิป
- ไม่มีอะไรไปทับปุ่มไลก์ / แชร์ด้านขวา แถบด้านบน และชื่อช่อง / ชื่อคลิปด้านล่างของ TikTok และ IG
- ไฟล์ MP4 1080×1920 พร้อมโพสต์

**ไม่ทำ:** ตัดช่วงเงียบ · ตัดคลิป · ปรับสีวิดีโอ (ใช้ภาพและเสียงต้นฉบับของคุณ)

---

## 1. สิ่งที่ต้องมี

- บัญชี **Claude** แพ็กเกจที่ใช้ **Claude Code** ได้ (เช่น Pro หรือ Max)
- บัญชี **GitHub** (สมัครฟรีที่ github.com)
- repo นี้อยู่ในบัญชี GitHub ของคุณ (ตั้งเป็น Private)

## 2. ตั้งค่าครั้งแรก (ทำครั้งเดียว)

**ขั้นที่ 1 — เอา repo มาไว้ในบัญชีของคุณ**
เปิดลิงก์ repo ที่ได้รับ → กด **Use this template** → **Create a new repository** →
ตั้งชื่อ (เช่น `my-shorts`) → เลือก **Private** → **Create repository**

**ขั้นที่ 2 — เชื่อม GitHub กับ Claude**
เปิด https://claude.ai/connect-github → ล็อกอิน GitHub → อนุญาตให้ Claude GitHub App เข้าถึง repo ที่สร้างในขั้นที่ 1

**ขั้นที่ 3 — อนุญาตให้ Claude โหลดคลิปจาก Google Drive**
เปิด Claude Code (แอป Claude หรือ https://claude.ai/code) → เลือก repo ของคุณ →
กดเมนู environment (ชื่อ environment ด้านบน) → **Edit** → **Network access** แล้วเลือกอย่างใดอย่างหนึ่ง:
- **Full** — ง่ายที่สุด หรือ
- **Limited** แล้วเพิ่ม 2 โดเมนนี้ใน **Allowed domains** (ติ๊ก Allow package managers ไว้เหมือนเดิม):
  ```
  drive.google.com
  drive.usercontent.google.com
  ```

เสร็จแล้ว ต่อไปสั่งงานได้เลยทุกครั้ง

## 3. วิธีสั่งตัดต่อ

1. อัปโหลดคลิปขึ้น **Google Drive** → แชร์ → ตั้งเป็น **"ทุกคนที่มีลิงก์"** → คัดลอกลิงก์
2. เตรียม **บทพูดพร้อมเวลา** — Claude ฟังเสียงไม่ได้ จึงต้องมีบทพูดเสมอ
   - ไฟล์ .srt หรือ
   - ข้อความแบบนี้ (คัดจากซับอัตโนมัติของ CapCut ได้):
     ```
     00:00 เวลาลูกค้าทักมาถามรายละเอียดสินค้า
     00:01 แล้วก็หายไปเนี่ย
     00:02 หลายคนก็อาจจะคิดว่า
     ```
3. เปิด Claude Code → เลือก repo ของคุณ → พิมพ์ `/effort high` แล้วส่งก่อน 1 ครั้ง
   (ตั้งให้ Claude คิดละเอียดขึ้น — ตัดต่อทั้งคลิปควรใช้ระดับ high งานจะออกมาดีกว่า)
   จากนั้นพิมพ์:
   ```
   ตัดต่อคลิปนี้ตาม skill split-screen-shorts
   <ลิงก์ Google Drive>
   <บทพูดพร้อมเวลา>
   ```
   ถ้าอยากได้แบบเห็นหน้าเต็มจอตลอด ให้พิมพ์ `split-screen-shorts-overlay` แทน
4. รอรับคลิปได้เลย — Claude ทำให้ครบรวดเดียว ไม่ต้องตอบอะไรระหว่างทาง (คลิป 40 วินาทีประมาณ 20–30 นาที)
5. ได้คลิป `edit.mp4` ในแชท (ไฟล์เล็ก ดูบนมือถือได้ทันที)
   ถ้าต้องการ **ไฟล์คุณภาพสูงสำหรับโพสต์จริง** พิมพ์ "ขอไฟล์ HQ" → ได้ลิงก์ดาวน์โหลด
   (เปิดลิงก์ขณะล็อกอิน GitHub บัญชีเดียวกับเจ้าของ repo)

## 4. ขอแก้

บอกเป็นวินาที เช่น
```
วินาทีที่ 12 ซับผิด "โปรโมชัน" → "โปรโมชั่น"
กราฟิกวินาทีที่ 20–24 อยากให้เป็นรูปกระปุกออมสินแทน
```
Claude จะแก้เฉพาะจุดแล้วส่งคลิปใหม่

ขอแก้จุดเล็ก ๆ แบบนี้ ใช้ `/effort medium` ได้ (พิมพ์ส่งก่อนข้อความขอแก้) — เร็วกว่าและประหยัดโควตาการใช้งาน

## 5. เปลี่ยนสีเป็นสีแบรนด์ของคุณ

ชุดสีเริ่มต้นมี 6 สี: `#477390` `#97B9CE` `#E5EFF5` `#C4B5E8` `#F3F0FA` `#625080`
ทั้งคลิปใช้เฉพาะสีในชุดนี้ (กราฟิก ตัวหนังสือ เส้น เงา) — ภาพวิดีโอของคุณไม่ถูกปรับสี

อยากเปลี่ยน พิมพ์บอก Claude ได้เลย เช่น
```
เปลี่ยนชุดสีของ skill เป็น #1B2A41 #324A5F #CCC9DC #FFFFFF #F2A65A #0C1821 ตั้งเป็นค่าเริ่มต้น
```
Claude จะตั้งให้ทั้ง 2 สไตล์ และใช้กับทุกคลิปต่อจากนี้ (ถ้าอยากเปลี่ยนเฉพาะคลิปเดียว ให้บอกว่า "เฉพาะคลิปนี้")

## 6. ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| `DOWNLOAD FAILED` / โหลดคลิปไม่ได้ | ตรวจว่าแชร์ไฟล์เป็น "ทุกคนที่มีลิงก์" และทำขั้นที่ 3 ของการตั้งค่าแล้ว |
| `NOT A VIDEO` | ลิงก์ไม่ได้ชี้ไปที่ไฟล์วิดีโอ หรือสิทธิ์การแชร์ยังไม่เปิด |
| `NO GIT REPO` | เริ่มแชทใหม่โดยเลือก repo ของคุณก่อนพิมพ์สั่ง |
| ซับคลาดจากเสียงเล็กน้อย | เวลาในบทพูดเป็นวินาทีเต็ม ซับอาจคลาด ~0.5 วินาที — บอกวินาทีที่คลาดให้ Claude แก้ |
| ลิงก์ไฟล์ HQ เปิดไม่ได้ | ล็อกอิน GitHub บัญชีเจ้าของ repo ก่อนเปิดลิงก์ |
