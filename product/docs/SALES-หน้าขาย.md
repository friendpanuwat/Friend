# Talking Head Motion — ตัดคลิปพูดหน้ากล้องให้ดูแพง ด้วย Claude

**จากคลิปพูดธรรมดา → คลิปสาย motion graphics แบบ Swishy ภายในครั้งเดียวที่สั่ง**
ตัวอักษรพลิก 3D ทีละตัวตรงจังหวะพูด · ฉากกราฟิกกระจกฝ้า + แสงออโรร่า · ป้ายชื่อ · ไอคอน · เสียงประกอบมิกซ์พร้อมโพสต์

(ดูคลิป before/after ด้านบน)

### 📱 ทำได้ทั้งหมดบนมือถือ — ไม่ต้องลงโปรแกรม ไม่ต้องมีคอมแรง
ส่งคลิปจากมือถือ พิมพ์สั่ง รับไฟล์ MP4 กลับมาโพสต์ได้เลย การเรนเดอร์ทั้งหมดเกิดบนคลาวด์
คลิปตัวอย่างด้านบนก็ทำจากมือถือล้วน ๆ

## เหมาะกับใคร
- ครีเอเตอร์สายความรู้ ธุรกิจ แรงบันดาลใจ ที่ถ่ายคลิปพูดหน้ากล้องทุกวัน
- คนที่อยากได้งานระดับ motion designer แต่ไม่มีเวลา/งบจ้างนักตัดต่อทุกคลิป
- เอเจนซีหรือแอดมินเพจที่ต้องทำคลิปลุคเดียวกันจำนวนมาก

## ได้อะไรบ้าง
- **ตัวอักษร kinetic ภาษาไทยที่ไม่เพี้ยน** — แยกสระ/วรรณยุกต์ถูกต้อง พลิก 3D ทีละตัว คำสำคัญเรืองแสง
- **คลังฉากกราฟิกเต็มจอ 10 แบบ** — การ์ดรีวิว, การ์ดเวอร์ชันซ้อน, ลูกโลกจุด 3D หมุนจริง, มือถือ + กราฟ, เส้นทางแสงวิ่ง, ปุ่ม CTA ฯลฯ
  Claude เลือกฉากให้ตรงความหมายของประโยค และออกแบบฉากใหม่ได้
- **เปลี่ยนเป็นแบรนด์ของคุณ** — สี 4 ค่า + ฟอนต์ 4 ชั้น ทุกฉากเปลี่ยนตามอัตโนมัติ
- **รองรับคลิปไทยและอังกฤษ** — รับไฟล์ .srt จาก CapCut ได้ทันที ระบบจับเวลาให้ตรงจุดหยุดหายใจจริง
- **เสียงพร้อมโพสต์** — ทำเสียงพูดให้ใส ลด noise, เสียงประกอบนุ่ม ไม่การ์ตูน, ความดัง -14 LUFS มาตรฐานแพลตฟอร์ม
- **ไฟล์ 1080×1920 พร้อมลง TikTok / Reels / Shorts** + QC checklist ในตัว
- **คู่มือภาษาไทย** ทั้งติดตั้งและการใช้งาน

## ใช้ยังไง
1. เปิดแอป Claude บนมือถือ → Code
2. แนบไฟล์ skill + คลิป + ไฟล์ซับ แล้วพิมพ์ว่า "ตัดต่อคลิปนี้ตาม skill"
3. ดูแผนและภาพตัวอย่าง → ได้ MP4 → สั่งแก้แบบระบุวินาทีได้ไม่จำกัด

## สิ่งที่ต้องมี
- มือถือ (หรือคอม) ที่มีแอป Claude + แพ็กเกจที่ใช้ Claude Code ได้ (แนะนำโมเดล Opus)
- **ไม่ต้องติดตั้งโปรแกรมใด ๆ**
- บทพูดพร้อมเวลา (.srt จาก CapCut)

## คำถามที่พบบ่อย
**ต้องมีคอมไหม?** ไม่ต้อง — ทำบนมือถือได้ครบทุกขั้น ตั้งแต่ส่งคลิปจนได้ไฟล์
**ต้องเขียนโค้ดเป็นไหม?** ไม่ต้อง — คุยกับ Claude เป็นภาษาไทยธรรมดา Claude เขียนโค้ดและเรนเดอร์ให้
**ใช้กับคลิปแนวนอนได้ไหม?** ออกแบบมาสำหรับแนวตั้ง 9:16 คลิปแนวนอนจะถูกครอปกลางเป็นแนวตั้ง
**มีเพลงไหม?** ไม่ใส่เพลงในไฟล์เพื่อเลี่ยงปัญหาลิขสิทธิ์ ใส่เพลงจากแอปตอนโพสต์ได้เลย
**ได้งานเหมือนตัวอย่างทุกคลิปไหม?** ได้มาตรฐานเดียวกัน แต่ฉากจะถูกเลือกให้เข้ากับเนื้อหาของแต่ละคลิป
