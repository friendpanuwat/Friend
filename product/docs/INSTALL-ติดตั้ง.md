# วิธีเริ่มใช้ — Talking Head Motion (มาตรฐาน v9)

## ใช้บนมือถือได้ทั้งหมด ไม่ต้องติดตั้งโปรแกรมอะไรเลย

Skill นี้ทำงานใน **Claude Code บนเว็บ/แอป Claude** ซึ่งรันบนเครื่องคลาวด์ของ Anthropic.
การเรนเดอร์ภาพ มิกซ์เสียง และทำไฟล์ MP4 เกิดบนคลาวด์ทั้งหมด มือถือของคุณใช้แค่ส่งไฟล์ พิมพ์สั่ง และดาวน์โหลดคลิป.
คลิปตัวอย่างในหน้าขายตัดต่อจากมือถือแบบนี้ทั้งหมด.

**สิ่งที่ต้องมี:** แอป Claude (iOS/Android) หรือเบราว์เซอร์ + แพ็กเกจ Claude ที่ใช้ Claude Code ได้.

## วิธีใช้ทุกครั้ง (3 ขั้น)

1. เปิดแอป Claude → ไปที่ **Code** → เริ่ม session ใหม่
2. แนบ 3 ไฟล์ในข้อความแรก:
   - `talking-head-motion.zip` (ไฟล์ skill ในแพ็กเกจนี้ — เก็บไว้ในมือถือ/iCloud/Drive)
   - วิดีโอแนวตั้ง `.mp4` (ตัดโลโก้ CapCut ท้ายคลิปออกก่อน)
   - ไฟล์ซับ `.srt` (ใน CapCut: คำบรรยายอัตโนมัติ → Export .srt) หรือพิมพ์บทแบบ `00:04 ข้อความ` ลงในแชท
3. พิมพ์:
   > แตก skill ใน talking-head-motion.zip แล้วใช้ตัดต่อคลิปนี้ ข้อความหลักของคลิปคือ "…"

Claude จะ: ตรวจเครื่องอัตโนมัติ → ทำตารางแผนให้ดู → เขียนกราฟิก → ส่งภาพตัวอย่าง → เรนเดอร์ → ส่ง MP4 ให้ดาวน์โหลด.
คลิป 50 วินาทีใช้เวลาเรนเดอร์ราว 5–10 นาที ระหว่างนั้นปิดแอปได้ งานยังเดินต่อบนคลาวด์.

> **ตรวจเครื่องไม่ผ่าน?** แทบไม่เกิดบน Claude Code บนเว็บ แต่ถ้าขึ้น `NOT READY` ให้ส่งข้อความนั้นมาหาเรา
> — คุณไม่ต้องติดตั้งอะไรเอง.

## ไม่อยากแนบ skill ทุกครั้ง? (ทางเลือก ตั้งครั้งเดียว)

ถ้ามีบัญชี GitHub: สร้าง repository ส่วนตัว แล้ววางโฟลเดอร์ skill ไว้ที่ `.claude/skills/talking-head-motion/`
(ข้างในมี `SKILL.md` ชั้นบนสุด). ทุกครั้งที่เปิด Claude Code โดยเลือก repo นี้ skill จะโหลดเอง แค่แนบวิดีโอ + ซับ แล้วสั่ง
"ตัดต่อคลิปนี้ตาม skill talking-head-motion".

## ข้อจำกัดที่ควรรู้

- Claude **ฟังเสียงไม่ได้** — ต้องมีบทพูดพร้อมเวลาเสมอ (.srt จาก CapCut ง่ายที่สุด)
- Claude ตรวจงานจากภาพนิ่ง — ความลื่นของ motion และความดังเสียง ให้คุณดู/ฟังยืนยันแล้วบอกแก้แบบระบุวินาที
- ไม่มีเพลงประกอบในไฟล์ (เรื่องลิขสิทธิ์) — ใส่เพลงจากคลังของ TikTok / CapCut ตอนโพสต์
- ใช้ในแชท Claude ธรรมดา (ที่ไม่ใช่ Code) ไม่ได้ เพราะไม่มีเครื่องมือเรนเดอร์วิดีโอ
- แนะนำโมเดล Opus effort high สำหรับงานเต็มคลิป

## ภาคผนวก: ใช้ Claude Code บนคอมของตัวเอง (ไม่จำเป็น)

สำหรับคนที่ใช้ Claude Code แบบติดตั้งในคอมอยู่แล้วเท่านั้น — งานจะรันบนคอมเครื่องนั้น จึงต้องมีโปรแกรมเหล่านี้:

**macOS:** `brew install ffmpeg node python && npm install -g playwright && npx playwright install chromium`
**Windows:** ติดตั้ง ffmpeg, Node.js LTS, Python 3 แล้ว `npm install -g playwright && npx playwright install chromium` (ใช้ผ่าน WSL หรือ Git Bash)

แล้ววางโฟลเดอร์ skill ไว้ที่ `~/.claude/skills/talking-head-motion/`.
