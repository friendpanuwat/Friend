# ข้อมูลอ้างอิง: เงินที่ต้องใช้ก่อนเปิดร้านในไทย

เอกสารนี้รวมตัวเลขจากเว็บ ใช้ทำร้านตัวอย่างและคำใบ้ "เช่น" ในเครื่องมือเช็กก่อนเปิดร้าน

วิธีอ่าน
- ตัวเลขทุกตัวมีลิงก์ที่มาต่อท้าย
- **ค่าประมาณ** คือตัวเลขที่ไม่มีแหล่งไทยยืนยันตรงๆ ทีมเขียนเองจากหลายแหล่ง ใช้ได้แค่เป็นตัวอย่าง
- เรื่องเงินกู้ ระดมทุน กฎหมาย ใบอนุญาต และภาษี ไม่ได้ใส่ไว้ เพราะเจ้าของห้ามไว้
- หลายแหล่งเป็นบทความของธนาคารหรือบริษัทขายระบบ ตัวเลขเป็นช่วงกว้าง ไม่ใช่สถิติทางการ

## 1. เงินก้อนแรกก่อนเปิดร้าน (แยกตามประเภทร้าน)

### 1.1 ร้านกาแฟเล็ก

ภาพรวม
- ร้านกาแฟเล็กงบน้อย ใช้ประมาณ 50,000–300,000 บาท https://www.nespresso.com/th/th/10-small-coffee-cafe-idea
- ร้านหน้าบ้าน แบ่ง 3 ระดับ: 30,000–50,000 บาท (เน้นขายกลับบ้าน ชงแบบง่าย) / 50,000–100,000 บาท (มีเครื่องบด ตู้เย็นเล็ก เครื่องปั่น เคาน์เตอร์ ป้าย) / 100,000–200,000 บาท (มีเครื่องเอสเปรสโซ ระบบน้ำไฟ ตู้แช่) https://www.ktc.co.th/article/knowledge/business/home-cafe-budget-guide
- ร้านมีหน้าร้านในทำเลดี เริ่มที่ 500,000 บาทขึ้นไป https://www.ktc.co.th/article/knowledge/business/cost-to-start-mobile-coffee-business
- ตัวอย่างร้านใหญ่ 50 ตร.ม.: ค่าก่อสร้างและอุปกรณ์ 1,100,000 บาท + เงินหมุนเวียน 510,000 บาท = 1,610,000 บาท https://www.wongnai.com/pos-articles/coffee-shop-business-plan

แยกรายการ
- ตัวอย่างร้านมินิมอล 10 ตร.ม. งบ 150,000 บาท = อุปกรณ์ 80,000 + ตกแต่ง 40,000 + เงินหมุนเวียน 30,000 https://www.nespresso.com/th/th/10-small-coffee-cafe-idea
- โครงร้านและตกแต่ง 30,000–100,000 บาท https://www.nespresso.com/th/th/10-small-coffee-cafe-idea
- เครื่องชงกับเครื่องบดรวมกัน 40,000–150,000 บาท https://www.nespresso.com/th/th/10-small-coffee-cafe-idea
- เครื่องชงกึ่งอัตโนมัติสำหรับมือใหม่ 15,000–30,000 บาท https://www.ktc.co.th/article/knowledge/business/cost-to-start-mobile-coffee-business
- ตัวอย่างเครื่องชงในแผนร้าน 90,000 บาท https://www.wongnai.com/pos-articles/coffee-shop-business-plan
- วัตถุดิบและของใช้ตอนเปิด (เมล็ด นม แก้ว บรรจุภัณฑ์) 10,000–20,000 บาท https://www.nespresso.com/th/th/10-small-coffee-cafe-idea
- ค่าเช่าและเงินมัดจำ ให้เตรียมไว้ประมาณ 3–6 เดือน https://www.nespresso.com/th/th/10-small-coffee-cafe-idea

รถขายกาแฟหรือรถเข็น (ใช้เป็นตัวอย่างร้านเล็กที่สุดได้)
- ระดับเริ่มต้น 30,000–80,000 บาท: รถเข็น 10,000–25,000 / อุปกรณ์ชง (ม็อกค่าพอต เครื่องบดมือ) 5,000–15,000 / ตู้แช่เล็ก เครื่องปั่น ถังน้ำแข็ง 5,000–10,000 / วัตถุดิบและบรรจุภัณฑ์ 5,000–10,000 / ป้าย ป้ายราคา ของตกแต่ง 3,000–8,000 https://www.ktc.co.th/article/knowledge/business/cost-to-start-mobile-coffee-business
- ระดับกลาง 80,000–200,000 บาท: ทำแบรนด์ (สติกเกอร์ ป้าย โลโก้ บรรจุภัณฑ์) 10,000–15,000 / วัตถุดิบ 10,000–15,000 / ชุดอุปกรณ์ (ตู้แช่ เครื่องปั่น ซิงก์ ระบบไฟ) 15,000–30,000 https://www.ktc.co.th/article/knowledge/business/cost-to-start-mobile-coffee-business

### 1.2 ร้านอาหารริมทาง / ร้านอาหารเล็ก

- เงินลงทุนร้านอาหารมีตั้งแต่หลักหมื่นถึงหลักล้าน ร้านปิ้งย่างเล็กในตลาดนัดชานเมืองใช้หลักแสนต้นๆ รวมค่าเช่าและตกแต่ง https://www.ofm.co.th/blog/%E0%B9%80%E0%B8%87%E0%B8%B4%E0%B8%99%E0%B8%97%E0%B8%B8%E0%B8%99-%E0%B9%80%E0%B8%9B%E0%B8%B4%E0%B8%94%E0%B8%A3%E0%B9%89%E0%B8%B2%E0%B8%99%E0%B8%AD%E0%B8%B2%E0%B8%AB%E0%B8%B2%E0%B8%A3/amp/
- ตัวอย่างร้านปิ้งย่างเล็ก: ตกแต่ง 50,000–100,000 บาท / โต๊ะเก้าอี้ชุดละ 1,000–3,000 บาท / เตาแก๊ส 2,000–5,000 บาท / ตู้เย็น 5,000–10,000 บาท (ซื้อมือสองได้) https://www.ktc.co.th/article/knowledge/business/open-bbq-restaurant-investment
- ตัวอย่างงบ 500,000 บาท (เปิดเอง): ตกแต่ง เฟอร์นิเจอร์ ครัว ระบบน้ำไฟ 87,500 บาท / ค่าเบ็ดเตล็ด เช่น ออกแบบโลโก้ ทำความสะอาด ค่าเดินทาง ถ่ายรูปและสื่อเปิดร้าน 37,500 บาท / เงินหมุนเวียน (ค่าเช่า ค่าแรง น้ำไฟ วัตถุดิบ) 300,000 บาท / การตลาด 75,000 บาท https://www.wongnai.com/business-owners/which-restaurant-business-start-with-500k
- ต้นทุนต่อจาน อาหารตามสั่ง: ราดหน้าหมู ต้นทุน 22 บาท ขาย 35 บาท (บทความปี 2021 ราคาวัตถุดิบตอนนี้น่าจะสูงกว่านี้) https://www.wongnai.com/business-owners/cost-main-dish-restaurant
- **ค่าประมาณ** รถเข็นหรือแผงอาหารริมทาง ทั้งหมด 20,000–60,000 บาท (รถเข็น เตา ถังแก๊ส อุปกรณ์ วัตถุดิบล็อตแรก) ไม่พบแหล่งไทยที่ให้ยอดรวมตรงๆ

### 1.3 ร้านเสื้อผ้าออนไลน์ (ซื้อมาขายไป)

- เปิดร้านบน Shopee / Lazada ใช้ทุนเริ่มต้นประมาณ 2,000–5,000 บาท (ภาพรวมสินค้าทุกประเภท ไม่เฉพาะเสื้อผ้า) https://www.trueplookpanya.com/knowledge/content/96570-bussme-bus-
- ต้นทุนหลัก 7 อย่างของร้านออนไลน์ (ไม่มีตัวเลข): ค่าน้ำไฟเน็ต / สต็อกสินค้าและค่าไปรับของ / บรรจุภัณฑ์ เทป ฉลาก เครื่องพิมพ์ฉลาก / ค่าส่ง / ค่าโฆษณา / ค่าออกแบบ เช่น รูปสินค้า โลโก้ / ระบบหลังร้าน เช่น ตัวเก็บออร์เดอร์ตอนไลฟ์ https://www.bangkokbiznews.com/business/947853
- แหล่งต่างประเทศ: ต้นทุนสินค้ามักเป็น 30–50% ของราคาขาย https://closo.co/blogs/beginner-guides-how-tos/how-to-sell-clothes-online
- แหล่งต่างประเทศ: แนะนำให้แบ่ง 10–20% ของทุนไว้ทำการตลาด https://ecommerce.folio3.com/blog/how-to-start-an-online-clothing-store/
- **ค่าประมาณ** ร้านเล็ก ทั้งหมด 20,000–40,000 บาท: สต็อกแรก 15,000–25,000 บาท (เช่น 100–150 ชิ้น ชิ้นละ 120–170 บาท) / ซองและเทป 500–1,500 บาท / ไฟถ่ายรูปกับฉากหลัง 1,500–3,000 บาท / เครื่องพิมพ์ฉลาก 1,500–3,000 บาท / โฆษณาเดือนแรก 3,000–5,000 บาท
- ค่าเปิดร้านบน Shopee / Lazada / TikTok Shop: ในบทความเรื่องค่าธรรมเนียมไม่มีค่าเปิดร้าน แต่ Shopee เก็บ 20 บาท/เดือนกับร้านที่ไม่มีการขาย https://flowaccount.com/blog/commission-fees-ecommerce-shopee-lazada-tiktok/

### 1.4 ร้านทำผม / ร้านบริการเล็ก

- งบร้านเล็ก (ร้านในบ้าน หรือสตูดิโอเล็ก) 50,000–150,000 บาท / ร้านริมถนนหรือในคอมมูนิตี้มอลล์ 200,000–500,000 บาท / ร้านในห้าง 600,000–1,500,000 บาทขึ้นไป https://www.sherwepos.com/post/open-a-beauty-salon
- ร้านเสริมสวยเล็ก ใช้ทุนประมาณ 100,000–200,000 บาท https://www.storehub.com/th/th/blog/techniques-to-open-salon
- แยกรายการ (แหล่งเดียวกัน https://www.sherwepos.com/post/open-a-beauty-salon)
  - มัดจำ 2–3 เดือน + ค่าเช่าเดือนแรก รวมประมาณ 15,000–60,000 บาท
  - ตกแต่ง (ฉากกั้น พื้น ป้าย) 30,000–150,000 บาท
  - เฟอร์นิเจอร์และกระจก (กระจกบานใหญ่ เคาน์เตอร์ โซฟา ชั้นวาง ไฟ) 15,000–50,000 บาท
  - เตียงสระ 6,000–18,000 บาทต่อตัว อย่างน้อย 2 ตัว
  - เก้าอี้ทำผม 3,500–12,000 บาทต่อตัว เตรียม 3–4 ตัว
  - ไดร์ เครื่องหนีบ เครื่องม้วน เครื่องอบไอน้ำ รวม 20,000–60,000 บาท
  - ของชิ้นเล็ก (กรรไกร หวี ผ้าขนหนู 30–50 ผืน ผ้าคลุม) 8,000–15,000 บาท
  - ผลิตภัณฑ์ (แชมพู ทรีตเมนต์) 10,000–25,000 บาท
  - เคมี (สี ฟอก ดัด ยืด) 15,000–40,000 บาท
  - การตลาดช่วงเปิดร้าน 10,000–25,000 บาท
  - ระบบขายหน้าร้าน (POS) 5,000–15,000 บาท หรือจ่ายรายเดือน
  - เงินสำรองประมาณ 3 เดือน 50,000–150,000 บาท
- ราคาเริ่มต้นแบบถูก: กระจกบานใหญ่ 1,000–2,000 บาท / เก้าอี้ลูกค้า เริ่ม 2,500 บาท / เตียงสระพร้อมอ่าง เริ่ม 3,000 บาท https://www.storehub.com/th/th/blog/techniques-to-open-salon
- ร้านตัดผมชาย: อุปกรณ์รวม 10,000–20,000 บาท (ไม่รวมตกแต่งและค่าเช่า) / ค่าเรียนตัดผม 5,000–30,000 บาท https://cheechongruay.smartsme.co.th/content/28153/

## 6. ร้านตัวอย่าง 3 ร้าน (ทุกตัวเลขในส่วนนี้เป็น **ค่าประมาณ** ที่ทีมรวมจากข้อ 1–5)
