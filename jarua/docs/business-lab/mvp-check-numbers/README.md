# MVP ตัวที่ 1 "เช็กตัวเลขร้าน" (Business Lab)

- ดูบนมือถือ: ลิงก์ Business Lab ใน `../HANDOFF.md` ข้อ 7.6 (หน้ารวม → “เช็กตัวเลขร้าน”) · ลิงก์เดิม https://claude.ai/artifact/P7cgLjD3i8m4YFNqBoE5uE เป็นรุ่นก่อนมีหน้ารวม ไม่อัปเดตแล้ว
- ใช้ตัวเลขร้านชุดกลางร่วมกับเครื่องมืออื่น (`../shared/lab-shop.js` ใส่ใน `build.sh`) · ปุ่มกลับหน้ารวมขึ้นเมื่อเปิดผ่านหน้ารวม (`window.LAB_HUB`)
- สถานะ ความเห็นเจ้าของ และสิ่งที่ยังต้องตัดสินใจ: `../HANDOFF.md` ข้อ 7.4

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `check-numbers.html` | ไฟล์เดียวที่สร้างแล้ว เปิดในเบราว์เซอร์ หรือ publish เป็น artifact ได้เลย |
| `src/style.css` | หน้าตา ขาว ดำ เทา มีโหมดมืดและสว่าง |
| `src/data.js` | 8 รูปแบบรายได้ · ช่องกรอก · ตัวเลขที่ปรับได้ · คลังคำถาม → จุดที่ควรเช็ก → เครื่องมือ PL1 (ตาราง `TOOLS` จำลอง `pl1dev.tool_meta` อ้างด้วยรหัส) |
| `src/engine.js` | เรียกตัวคำนวณ PL2 (`calculateV4`) แล้วแปลงเป็นภาพร้าน เรื่องที่ตัวเลขบอก เกณฑ์ และขนาดเป็นเงิน ไม่มีสูตรกำไรของตัวเอง |
| `src/app.js` | หน้าจอทั้งหมด: เริ่ม → กรอกทีละข้อ → ภาพรวม → รายละเอียดเรื่อง / หาจุดที่ควรเช็ก / ทดลอง |
| `build.sh` | คอมไพล์ `../reference/pl2-calc-v4.ts` (ไม่แก้ไฟล์) แล้วรวมทุกอย่างเป็น `check-numbers.html` |
| `tests/unit.js` | ตัวเลขตรงกับ v4 · ตัวเลขที่ทำให้ไม่ขาดทุนถึงจุดคุ้มทุนจริงทุกรูปแบบ |
| `tests/fuzz.js` | ตัวเลขสุ่มและตัวเลขแปลก 600 ชุด ต้องไม่พังและไม่มี NaN |
| `tests/flows.js` | ไล่ทุกหน้าทั้ง 8 รูปแบบบนจอมือถือ ทั้งโหมดมืดและสว่าง |

## วิธีแก้แล้วส่งให้เจ้าของดู

1. แก้ไฟล์ใน `src/`
2. `./build.sh`
3. `node tests/unit.js && node tests/fuzz.js`
4. `tests/fetch-fonts.sh` (ครั้งแรกครั้งเดียว) แล้ว `node tests/flows.js` · ถ่ายภาพหน้าจอด้วย `tests/harness.js` (ภาพอยู่ใน `.out/shots/`)
5. `../mvp-lab/build.sh` แล้ว `node ../mvp-lab/tests/lab.js` · ส่งให้เจ้าของดูที่ลิงก์ Business Lab (วิธี publish ใน `../mvp-lab/README.md`)
