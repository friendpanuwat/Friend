## วิธีใช้ที่ต้องรักษา (รอบ 4)

- **ทุกช่องต้องตอบ** ปุ่ม "ถัดไป" ไม่เป็นสีเทา กดตอนยังไม่ครบแล้วพาไปช่องที่ขาด และบอกในช่องนั้นว่า "ยังไม่ได้ตอบข้อนี้" (แบบเดียวกับตัวที่ 3) · ช่องที่คำตอบเป็นศูนย์ได้มีปุ่ม "ไม่มี" (`chip` ใน `FIELDS`) · กำลังสูงสุดที่ไม่รู้มีปุ่ม "ยังไม่รู้" (`unk` = ไม่จำกัด)
- **ข้อสุดท้าย "รายละเอียดเพิ่ม"** ต้องตอบ มี / ไม่มี (`inp.advMode`) · ถ้ามี เลือกกลุ่มที่รู้ (`inp.advPick`) แล้วตอบทุกช่องในกลุ่มนั้น · ตอบ "ไม่มี" หรือเอากลุ่มออก = ล้างตัวเลขของกลุ่มนั้น · ตัวเลขชุดเดิมที่ไม่มีคำตอบนี้ ระบบเดาให้จากตัวเลขที่มี (`advNormalize` ใน `src/data.js`) · กติกาทั้งหมดอยู่ใน `src/data.js` ใช้ร่วมกับตัวที่ 3
- **ปุ่มย้อนกลับ** ปุ่มซ้ายบนกับปุ่มย้อนกลับของมือถือไปที่เดียวกันทุกหน้า (`goBack()` ใน `src/app.js`): ข้อคำถาม → ข้อก่อนหน้า · แก้ทีละข้อ → แก้ตัวเลข → ภาพรวม → หน้าแรก · หน้าทดลอง → หน้าที่เปิดมา · หน้าแรกกดย้อนกลับของมือถือ = ออกไปหน้า Business Lab · หน้าแรกมีแถบ "ตัวเลขร้านคุณ · ดูผล" เมื่อมีตัวเลขร้านครบ
- **ปุ่มค้างล่างจอของภาพรวม** "แก้ตัวเลข | หาจุดที่ควรตรวจสอบ" · ปุ่มซ้ายบนของภาพรวม "‹ หน้าแรก"
- คำถามทุกข้อลงท้ายด้วย "?" (`qmark()` ใน `src/data.js` เติมให้ตอนแสดง) · ปุ่มคำตอบของคำถามเช็กตั้งแยกทีละข้อได้ (`ans` / `risk` ใน `QBANK`)

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `check-numbers.html` | ไฟล์เดียวที่สร้างแล้ว เปิดในเบราว์เซอร์ หรือ publish เป็น artifact ได้เลย |
| `src/style.css` | หน้าตา ขาว ดำ เทา มีโหมดมืดและสว่าง |
| `src/data.js` | 8 รูปแบบรายได้ · ช่องกรอก · ตัวเลขที่ปรับได้ · คลังคำถาม → จุดที่ควรตรวจสอบ → เครื่องมือ PL1 (ตาราง `TOOLS` จำลอง `pl1dev.tool_meta` อ้างด้วยรหัส) |
| `src/engine.js` | เรียกตัวคำนวณ PL2 (`calculateV4`) แล้วแปลงเป็นภาพร้าน เรื่องที่ตัวเลขบอก เกณฑ์ และขนาดเป็นเงิน ไม่มีสูตรกำไรของตัวเอง |
| `src/app.js` | หน้าจอทั้งหมด: เริ่ม → กรอกทีละข้อ → ภาพรวม → รายละเอียดเรื่อง / หาจุดที่ควรตรวจสอบ / ทดลองปรับตัวเลข |
| `build.sh` | คอมไพล์ `../reference/pl2-calc-v4.ts` (ไม่แก้ไฟล์) แล้วรวมทุกอย่างเป็น `check-numbers.html` |
| `tests/unit.js` | ตัวเลขตรงกับ v4 · ตัวเลขที่ทำให้ไม่ขาดทุนถึงจุดคุ้มทุนจริงทุกรูปแบบ |
| `tests/fuzz.js` | ตัวเลขสุ่มและตัวเลขแปลก 600 ชุด ต้องไม่พังและไม่มี NaN |
| `tests/flows.js` | ไล่ทุกหน้าทั้ง 8 รูปแบบบนจอมือถือ ทั้งโหมดมืดและสว่าง |
| `tests/back.js` | ปุ่มย้อนกลับของมือถือไปที่เดียวกับปุ่มในแอปทุกหน้า ไม่วนระหว่างแก้ตัวเลขกับภาพรวม หน้าแรกกดแล้วออกจากเครื่องมือ |
| `tests/required.js` | ทุกช่องต้องตอบ · ปุ่ม "ไม่มี" / "ยังไม่รู้" · ข้อสุดท้ายตอบ มี / ไม่มี · ร้านตัวอย่างทุกรูปแบบตอบครบ |

## วิธีแก้แล้วส่งให้เจ้าของดู

1. แก้ไฟล์ใน `src/`
2. `./build.sh`
3. `node tests/unit.js && node tests/fuzz.js`
4. `tests/fetch-fonts.sh` (ครั้งแรกครั้งเดียว) แล้ว `node tests/flows.js && node tests/back.js && node tests/required.js` · ถ่ายภาพหน้าจอด้วย `tests/harness.js` (ภาพอยู่ใน `.out/shots/`)
5. `../mvp-lab/build.sh` แล้ว `node ../mvp-lab/tests/lab.js` · ส่งให้เจ้าของดูที่ลิงก์ Business Lab (วิธี publish ใน `../mvp-lab/README.md`)
