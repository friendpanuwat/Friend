# Business Lab ทั้งชุด (หน้ารวม + เครื่องมือที่มี MVP แล้ว)

- ดูบนมือถือ (artifact ส่วนตัวของเจ้าของ ลิงก์เดียวสำหรับทุกเครื่องมือ): ลิงก์อยู่ใน `../HANDOFF.md` ข้อ 7.6
- สถานะ ความเห็นเจ้าของ และสิ่งที่ยังต้องตัดสินใจ: `../HANDOFF.md` ข้อ 7.6

## ทำอะไร

ผู้ใช้กด Business Lab แล้วเจอหน้ารวม เลือกเครื่องมือที่จะใช้ แล้วเข้าหน้าของเครื่องมือนั้น หน้าเริ่มของแต่ละเครื่องมือมีปุ่ม ‹ กลับหน้ารวม

- หน้ารวมโชว์ 4 เครื่องมือ ใช้ได้ทั้ง 4 ตัว: ตัวที่ 1 "เช็กตัวเลขร้าน" · ตัวที่ 3 "เช็กก่อนตัดสินใจเรื่องใหญ่" · ตัวที่ 4 "กำไรรายสินค้าและรายช่องทาง" · ตัวที่ 2 "เช็กก่อนเปิดร้าน" · ตัวเลขร้านที่มาจากตัวที่ 2 ขึ้นว่า "ตัวเลขที่ตั้งใจไว้ก่อนเปิดร้าน"
- **ตัวเลขร้านชุดกลาง** (`../shared/lab-shop.js`): กรอกตัวเลขร้านในเครื่องมือไหนก็ได้ เครื่องมืออื่นใช้ต่อ ไม่ต้องกรอกใหม่ · ช่องที่เหมือนกันใช้ข้อมูลเดียวกัน ช่องที่ต่างให้ผู้ใช้กรอกเพิ่มในเครื่องมือนั้น (เช่น ตัวเลขของแต่ละเรื่องในตัวที่ 3) · เก็บเฉพาะตัวเลขร้านของผู้ใช้เอง ไม่เก็บร้านตัวอย่าง · อยู่ในแท็บนั้นเท่านั้น ปิดแท็บแล้วหาย · หน้ารวมบอกว่ามีตัวเลขร้านแล้วหรือยัง
- โหมดมืดและสว่างใช้ค่าเดียวกันทุกหน้า
- หน้าตาแบบมินิมอล (HANDOFF ข้อ 7.8): การ์ดเทา ไอคอน ชื่อ และคำถามของเครื่องมือ · คำอธิบายและ "เหมาะสำหรับ…" อยู่หลังปุ่ม "?" ของการ์ด (`.tc-w` ห่อ `a.tcard` กับปุ่ม "?" เพราะปุ่มซ้อนในลิงก์ไม่ได้)

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `src/hub.html` | หน้ารวม (ใช้ token สีและฟอนต์จาก `../mvp-check-numbers/src/style.css`) |
| `build.sh` | สร้างตัวที่ 1 3 และ 4 จากโฟลเดอร์ของตัวเอง แล้วรวมเป็น `site/` |
| `site/index.html` | หน้ารวม = หน้าหลักของ artifact (ไม่มีโครง html เพราะระบบใส่ให้) |
| `site/check-numbers.html` · `site/big-decisions.html` · `site/product-channel.html` · `site/before-opening.html` | หน้าของเครื่องมือ มีโครง html ของตัวเอง และบอกเครื่องมือว่ามีหน้ารวม (`LAB_HUB`) จึงขึ้นปุ่มกลับ |
| `tests/lab.js` | ทดสอบทั้งชุดผ่านเว็บเซิร์ฟเวอร์ในเครื่อง ทั้งโหมดมืดและสว่าง: หน้ารวม → ตัวที่ 1 กรอกตัวเลขร้าน → หน้ารวมเห็นว่ามีแล้ว → ตัวที่ 3 ไม่ถามซ้ำ → แก้ตัวเลขร้านในตัวที่ 3 → ตัวที่ 1 เห็นตัวเลขใหม่ · ร้านตัวอย่างไม่ทับตัวเลขจริง · ตัวที่ 4 ใช้ค่าใช้จ่ายคงที่ชุดเดิม ใส่แค่สินค้าและช่องทาง → กดใช้ยอดจากรายสินค้า → ตัวที่ 1 กำไรเท่ากัน · ตัวที่ 2 ไม่ถามตัวเลขร้านซ้ำ ใส่แค่ช่วงเปิดร้าน เงินก่อนเปิด เงินที่มี → เขียนกลับพร้อมป้ายก่อนเปิดร้าน → ตัวที่ 1 กำไรเท่ากัน → "ร้านเปิดแล้ว" ป้ายหายและตัวที่ 2 ไม่ใส่กลับ · ไม่ล้นจอ ปุ่มอย่างน้อย 44px |

เครื่องมือแต่ละตัวยังเปิดเดี่ยว ๆ ได้ (ไฟล์ในโฟลเดอร์ของตัวเอง) แต่จะไม่มีปุ่มกลับหน้ารวม

## วิธีแก้แล้วส่งให้เจ้าของดู

1. แก้ไฟล์ในโฟลเดอร์ของเครื่องมือนั้น หรือ `src/hub.html` แล้วรันทดสอบของเครื่องมือนั้นตาม README ในโฟลเดอร์ของมัน
2. `./build.sh` แล้ว `node tests/lab.js`
3. อ่าน artifact เดิมก่อน (Artifact tool `action: "read"` กับลิงก์ใน HANDOFF ข้อ 7.6) แล้ว publish `site/index.html` ด้วย `url` เดิม พร้อม `files`: `check-numbers.html` `big-decisions.html` `product-channel.html` และ `before-opening.html` จาก `site/`

## เพิ่มเครื่องมือตัวใหม่

1. ทำในโฟลเดอร์ของตัวเอง (`mvp-…/`) ใช้ส่วนกรอกตัวเลขร้านชุดเดียวกับตัวที่ 1 และใส่ `../shared/lab-shop.js` ใน build: เขียน `LabShop.put(...)` เมื่อผู้ใช้กรอกตัวเลขร้านเอง และอ่าน `LabShop.get()` ตอนเปิด
2. ขึ้นปุ่ม ‹ กลับหน้ารวมที่หน้าเริ่มเมื่อมี `window.LAB_HUB`
3. ใน `build.sh` ของโฟลเดอร์นี้ เพิ่มการสร้างและ `page …` ของตัวใหม่ · ใน `src/hub.html` เปลี่ยนการ์ด "เร็ว ๆ นี้" เป็นลิงก์
