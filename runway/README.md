# RUNWAY — เกมจำลองการสร้างสตาร์ทอัพ

เกมบริหารธุรกิจแบบตัวเลขล้วน ไม่มีกราฟิก 3D ไม่มีตัวละคร — มีแค่งบการเงิน ทีมงาน ลูกค้า นักลงทุน และการตัดสินใจที่มีผลตามมาเป็นเดือนหรือเป็นปี
ตัวเลขอ้างอิงตลาดไทย (ภาษี ประกันสังคม กฎหมายแรงงาน VAT, GP แอปเดลิเวอรี, ค่าเช่าทำเล ฯลฯ) โดยประมาณ

## เล่นอย่างไร

เปิด `dist/runway.html` ในเบราว์เซอร์ได้เลย (ไฟล์เดียว ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต ยกเว้นฟอนต์) เกมเซฟอัตโนมัติทุกสัปดาห์ใน localStorage และ export เป็นรหัสเซฟได้

1. เลือกพื้นเพผู้ก่อตั้ง ธุรกิจ (B2B SaaS / แบรนด์ออนไลน์ D2C / ร้านอาหาร-คาเฟ่) ผู้ร่วมก่อตั้ง ความยาก และโหมดท้าทาย
2. กด **สัปดาห์ถัดไป** (หรือ Space) — 1 ตา = 1 สัปดาห์ ปิดงบทุกปลายเดือน ปีละ 52 สัปดาห์
3. เกมหยุดเมื่อมีเรื่องให้ตัดสินใจ — หลายเรื่องมีผลตามมาภายหลัง
4. จบเมื่อเงินสดติดลบ 6 สัปดาห์, คุณถังแตกส่วนตัว, ถูกบอร์ดปลด, ขายกิจการ, IPO, ปิดบริษัท หรือครบกำหนดเวลา
5. คะแนนคือ **ความมั่งคั่งสุทธิของคุณ** ไม่ใช่ขนาดบริษัท

## มีอะไรในเกม

- **บัญชีจริงแบบ double-entry** — งบกำไรขาดทุน งบดุล กระแสเงินสด รายได้รับล่วงหน้า ลูกหนี้ หัก ณ ที่จ่าย 3% ภาษีนิติบุคคล SME ขาดทุนสะสม 5 ปี VAT เมื่อรายได้เกิน 1.8 ล้าน ค่าเสื่อม เงินกู้ (ธนาคาร/venture debt/RBF/ผู้ก่อตั้ง)
- **คน** — ผู้สมัครที่ฝีมือจริงไม่ตรงกับเรซูเม่ นิสัยซ่อนเร้น สัมภาษณ์เชิงลึก notice period ช่วงเรียนรู้งาน ขวัญกำลังใจ ความเครียด การลาออก ช่วงการบริหาร ค่าชดเชยตามกฎหมาย โบนัส ปรับเงินเดือน ESOP
- **ตัวคุณเอง** — ชั่วโมงทำงาน การแบ่งเวลา พลังงาน ความเครียด สุขภาพ ชีวิตส่วนตัว อาการหมดไฟ เงินเก็บส่วนตัวและภาษีบุคคล รับงานที่ปรึกษาหาเงินเลี้ยงบริษัท คอร์สพัฒนาทักษะ ผู้ร่วมก่อตั้งที่อาจทะเลาะกัน
- **ระดมทุน** — นักลงทุนหลายประเภท (angel, accelerator, VC, CVC, กองทุนต่างประเทศ, family office) pipeline การพิตช์ term sheet (liquidation preference, anti-dilution, ที่นั่งบอร์ด, option pool shuffle, founder vesting, Singapore flip) SAFE, down round, บอร์ดที่ปลด CEO ได้, ข้อเสนอซื้อกิจการ, IPO และ waterfall ตอนขาย
- **โลกภายนอก** — วัฏจักรเศรษฐกิจ บรรยากาศ VC ค่าเงิน ค่าแรง คู่แข่งที่ระดมทุน ทำสงครามราคา และล้มหายตายจาก
- **เหตุการณ์และ dilemma กว่า 80 แบบ** — ลูกค้าเทา สินบน ข้อมูลรั่ว ยักยอก คดีหุ้น ภาวะโรคระบาด ฯลฯ
- **3 ธุรกิจที่เล่นต่างกันจริง**
  - *B2B SaaS* — กลุ่มลูกค้า 4 ระดับที่ต้องการต่างกัน (ต้องค้นหาเอง) roadmap ฟีเจอร์ หนี้เทคนิค บั๊ก ระบบล่ม ช่องทางการตลาดที่อิ่มตัว pipeline การขาย สัญญารายปี ลูกค้าองค์กร ขยาย SEA
  - *แบรนด์ D2C* — พัฒนาสินค้า + อย. สั่งผลิต MOQ/มัดจำ/นำเข้า สต็อก FIFO และวันหมดอายุ marketplace/โซเชียล/เว็บ/ค้าปลีก วันเซลใหญ่ COD ตีกลับ KOL CRM
  - *ร้านอาหาร/เชน* — หาทำเล (ตัวเลขโบรกเกอร์ไม่ตรงจริง) สัญญาเช่า ค่าตกแต่ง เช่าซื้ออุปกรณ์ ที่นั่ง/รอบโต๊ะ ค่าแรงขั้นต่ำ เดลิเวอรี GP 30% P&L รายสาขา ครัวกลาง แฟรนไชส์
- **งานวิจัยแบบจ่ายเงิน** — สัมภาษณ์ลูกค้า ศึกษาความเต็มใจจ่าย ทดสอบตลาด นับคนเดินผ่านทำเล ชิมแบบปิดตา
- **ธีมกลยุทธ์ประจำปี, ความสำเร็จ 26 รายการ, ทำเนียบผู้ก่อตั้ง, บทส่งท้ายที่เล่าว่าเกิดอะไรขึ้นหลังจากนั้น**
- **โหมดท้าทาย** — Bootstrap ล้วน (ห้ามขายหุ้น), เริ่มกลางวิกฤต, Sprint 5 ปี

## โครงสร้างโค้ด

```
src/core/     เอนจินจำลอง (ไม่มี DOM — รันใน Node ได้)
  util.js       RNG แบบ seed, ฟอร์แมตตัวเลข, ปฏิทิน 4-4-5
  ledger.js     บัญชีคู่, ภาษี, เงินกู้
  data.js       ตำแหน่งงาน นิสัย พื้นเพ ความยาก นักลงทุน
  team.js founder.js funding.js world.js events.js events2.js
  engine.js     tick รายสัปดาห์, ปิดงบรายเดือน, KPI, จบเกม, บทส่งท้าย
  actions.js    ทุกการกระทำของผู้เล่น
src/models/   saas.js ecom.js fnb.js (+ *_ui.js หน้าจอเฉพาะธุรกิจ)
src/ui/       หน้าจอ (vanilla JS + SVG charts) และ styles.css
tools/        build, บอททดสอบสมดุล, fuzz, Playwright tests
```

## Build และทดสอบ

```bash
node tools/build.js                     # → dist/runway.html (เต็มหน้า) และ dist/artifact.html
node tools/bot.js 16 156 saas normal    # บอทเล่น 16 เกม 3 ปี ดูอัตรารอด (CH=bootstrap|crisis|sprint)
node tools/fuzz.js 2                    # สุ่มตัดสินใจ 10 ปี ทุกธุรกิจ/ความยาก/โหมด ตรวจ NaN และงบดุล
NODE_PATH=$(npm root -g) node tools/uifuzz.js   # เรนเดอร์ทุกหน้าใน Chromium ตลอดเกมยาว
```

`index.html` โหลดไฟล์ใน `src/` ตรงๆ สำหรับพัฒนา

ทุกบริษัท นักลงทุน และบุคคลในเกมเป็นเรื่องสมมติ ไม่ใช่คำแนะนำทางการเงินหรือกฎหมาย
