## Glow Line Motion

- `.claude/skills/glow-line-motion/` — skill ทำ motion graphics ลายเส้นขาวเรืองแสงบนพื้นดำ ที่ทุกเส้นวาดตัวเอง.
  เล่าได้หลายแบบ: ก่อน→หลัง, อธิบายขั้นตอน (`flow`), เล่าเรื่องเป็นฉาก (`shots`), แผนผัง (`diagram`), โชว์สินค้า (`showcase`).
  คู่มือสไตล์อยู่ที่ `references/style.md`, ชุดคน/มือ/ลูกศรสำเร็จรูปอยู่ที่ `references/kit.md` (ภาพรวม `kit.jpg`).
  สั่งได้เลย: "ทำคลิปลายเส้นเรืองแสง อธิบาย 4 ขั้นตอน …" หรือ "ทำแบบ glow-line-motion โชว์สินค้านี้"
