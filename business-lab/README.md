# Jarua · Business Lab (MVP)

Business Lab คือ product line ใหม่ของ Jarua ที่รวม **เครื่องมือคำนวณและวางแผนธุรกิจที่ไม่ใช้ AI และไม่เรียก API ใดๆ**
ทุกอย่างคำนวณด้วยสูตรในเบราว์เซอร์ของผู้ใช้ → ผลขึ้นทันทีขณะพิมพ์, กรอกเดิมได้คำตอบเดิม, ใช้ได้ไม่จำกัด, ต้นทุนต่อการใช้งานของ Jarua = 0 และตัวเลขไม่ออกจากเครื่องผู้ใช้

เปิดดูต้นแบบได้ทันที: `prototype/jarua-business-lab.html` (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)

## เครื่องมือใน MVP (7 ตัว)

| เครื่องมือ | คำถามที่ตอบ | จุดเด่น |
|---|---|---|
| จุดคุ้มทุน | ต้องขายวันละเท่าไหร่ถึงไม่ขาดทุน? | ตัวช่วยแยกค่าใช้จ่าย (กันลืมเงินเดือนตัวเอง), เทียบยอดขายจริง, ราคาที่ต้องขายเพื่อคุ้มทุนที่ยอดเดิม, แถบลองขยับราคา, กราฟรายได้–ต้นทุน |
| ตั้งราคาขาย | ตั้งราคาเท่าไหร่ให้เหลือกำไรจริง? | รวมค่าธรรมเนียมแพลตฟอร์ม ค่าแอด VAT, ราคาสวย (฿279), กับดัก markup vs margin, ROAS ขั้นต่ำ, แถบ "ลูกค้าจ่าย ฿X ไปอยู่ไหน" |
| ลดราคาคุ้มไหม | จัดโปรต้องขายเพิ่มเท่าไหร่ถึงคุ้ม? | ลด % / ลดบาท / ซื้อ X แถม Y, ส่วนลดสูงสุดที่ยังคุ้ม, กราฟความชันของยอดที่ต้องเพิ่ม |
| เงินสดพอไปกี่เดือน | เงินใช้ได้อีกกี่เดือน หมดเมื่อไหร่? | จำลองรายเดือน 36 เดือน, วันที่แบบ พ.ศ., เพดานรายรับ, ลองลดรายจ่าย/เพิ่มรายรับพร้อมเส้นเทียบ, ตารางรายเดือน |
| ดอกเบี้ยแท้จริง | 1% ต่อเดือนจริงๆ แพงแค่ไหน? | แปลง flat → ลดต้นลดดอก (Effective rate), เทียบดอกเบี้ยรวมสองวิธี, ตารางรายปี |
| VAT & หัก ณ ที่จ่าย | ออกบิลเท่าไหร่ เงินเข้าเท่าไหร่? | ก่อน VAT / รวม VAT / คิดย้อนจากเงินที่อยากได้, อัตรา 1–5%, แสดงแบบใบแจ้งหนี้ |
| Business Model Canvas | ธุรกิจทำเงินยังไง ในหน้าเดียว | เติม 9 ช่องตามลำดับ, ไอเดียตัวอย่าง, มุมมองแผ่นเต็ม, ระบบเช็กช่องที่ยังไม่เชื่อมกัน |

ทุกเครื่องมือมี: ตัวอย่างพร้อมใช้ (เปิดมาเห็นคำตอบเลย), แถบผลลัพธ์ลอยบนมือถือ, "สิ่งที่ตัวเลขบอก" (ข้อสังเกตจากกฎตายตัว), "ดูสูตรที่ใช้คำนวณ" พร้อมแทนค่าจริง, คัดลอกสรุปไปวางใน LINE, ส่งตัวเลขต่อไปเครื่องมืออื่น (จุดคุ้มทุน ⇄ ตั้งราคา ⇄ ลดราคา), จำค่าที่กรอกไว้ในเครื่อง, โหมดมืด/สว่าง

หน้า Lab มี: เดโมสดในหน้าแรก, ค้นหา + กรองตามกลุ่ม, "ทำต่อจากครั้งก่อน" พร้อมคำตอบล่าสุด, ตัวอย่างคำตอบบนการ์ดทุกใบ (คำนวณจาก engine จริง), รายการที่กำลังมา

## โครงสร้าง

```
src/features/business-lab/      ← โฟลเดอร์นี้ยกไปใส่ Jarua ได้ทั้งก้อน
  LabRoot.tsx                   routes: /lab และ /lab/:toolId (lazy-load ทีละเครื่องมือ)
  registry.ts                   รายชื่อเครื่องมือ คำถาม คีย์เวิร์ด สถานะ live/soon
  samples.ts                    ตัวอย่างคำตอบบนการ์ด (คำนวณจาก engine)
  lib/calc/*.ts                 engine คำนวณ (pure functions) — มี unit test
  lib/canvasModel.ts            9 ช่อง BMC + กฎตรวจความเชื่อมโยง
  lib/format.ts                 รูปแบบตัวเลขบาท/เปอร์เซ็นต์/เดือน พ.ศ.
  lib/storage.ts, lib/hooks.ts  จำค่าใน localStorage, ส่งตัวเลขข้ามเครื่องมือ
  components/                   ฟิลด์ตัวเลข สไลเดอร์ การ์ดผลลัพธ์ กราฟ SVG ฯลฯ
  pages/LabHome.tsx             หน้ารวมเครื่องมือ
  tools/*.tsx                   หน้าเครื่องมือแต่ละตัว
src/index.css                   โทเคนสี .lab-shell (ดำ-ขาวแบบ Jarua, รองรับ html.light)
src/test/calc.test.ts           unit tests ของสูตรทั้งหมด
scripts/interact.mjs            ทดสอบการใช้งานจริงใน Chromium (พิมพ์ ส่งต่อ ล้างค่า ฯลฯ)
```

## คำสั่ง

```bash
npm install
npm run dev            # เปิดดูที่ http://localhost:5173/#/lab
npm test               # unit tests ของสูตร
npm run typecheck
npm run build:single   # สร้างไฟล์เดียว prototype/jarua-business-lab.html
npm run e2e            # (หลัง build:single) ทดสอบการใช้งานจริงใน Chromium
```

## ย้ายเข้า Jarua (โปรเจกต์ Lovable)

ต้นแบบนี้ใช้ stack เดียวกับ Jarua (Vite + React 18 + TypeScript + Tailwind 3 + lucide-react + react-router-dom 7) และไม่แตะไฟล์เดิมของ Jarua เลย

1. คัดลอก `src/features/business-lab/` ไปไว้ที่ path เดียวกันใน Jarua
2. ต่อท้าย `src/index.css` ของ Jarua ด้วยบล็อก `.lab-shell` และ components (`lab-gutter`, `lab-grid-bg`, `lab-card`, `lab-tnum`, `lab-range`) จาก `src/index.css` ของที่นี่ — โทเคนทั้งหมดอยู่ใต้ `.lab-shell` จึงไม่ชนกับสีเดิม
3. เพิ่มใน `tailwind.config.ts` ของ Jarua: `colors.lab`, `fontFamily["lab-display"|"lab-mono"]`, `borderRadius["lab-card"|"lab-field"]`, keyframes `lab-in` (คัดลอกจาก `tailwind.config.ts` ที่นี่)
4. เพิ่ม `IBM+Plex+Mono:wght@400;500` ในลิงก์ Google Fonts ของ `index.html`
5. ใน `App.tsx`: `<Route path="/lab/*" element={<LabRoot />} />`
6. ใน `Navbar.tsx` ของ Jarua เพิ่มแท็บ "Business Lab" ไป `/lab` แล้วให้ `LabHome` ใช้ Navbar ของ Jarua แทน `LabNavbar`
7. (ถ้าต้องการ) เปลี่ยน `useToast()` เป็น `toast()` ของ sonner และใช้ `ThemeToggle` ของ Jarua — พฤติกรรมและคีย์ `promptdd-theme` เหมือนกันอยู่แล้ว
8. ต้นแบบใช้ `HashRouter` เพื่อให้เปิดเป็นไฟล์เดียวได้ ใน Jarua ใช้ `BrowserRouter` เดิมได้เลย ไม่ต้องแก้โค้ดใน feature

## ขั้นต่อไปที่แนะนำ

- เปิดเครื่องมือที่ "กำลังมา" (ลูกค้าหนึ่งคนคุ้มค่าแอดไหม, ต้นทุนต่อเมนู, เงินเดือน & ประกันสังคม, SWOT, เทียบไอเดีย)
- ส่งตัวเลขจาก Business Lab เข้า "แผนธุรกิจฉบับเต็ม" ของ Jarua (เช่น ราคา ต้นทุน ค่าใช้จ่ายคงที่) เพื่อลดการกรอกซ้ำ
- บันทึกหลายสถานการณ์แล้วเทียบกัน (A/B) และลิงก์แชร์ที่เก็บตัวเลขไว้ใน URL
- ปุ่มส่ง Feedback ต่อเครื่องมือ ผูกกับระบบ feedback เดิมของ Jarua
