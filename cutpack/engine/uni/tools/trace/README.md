# ตัวลอกภาพจากแผ่นไอเดียของ Friend (รอบที่ 12 ลายเส้น)

แผ่นภาพ ("20 … IDEAS") อยู่ใน uploads ของแชท `ccr-5d4c53b3-q87bwd` เท่านั้น ไม่เก็บเข้า repo · แชทใหม่ต้องขอ Friend ส่งแผ่นใหม่ แล้วแก้ `U` ใน `cells.py`

- `cells.py` ช่องของแต่ละร่างในแผ่น (ไฟล์ กรอบ หมวด ชื่อ)
- `picks.py` ส่วนที่เลือก สีเน้น เกณฑ์ และกฎแก้เฉพาะร่าง (ทุกตัวเลขเป็นสัดส่วนของช่อง ยกเว้นที่เขียนว่า px)
- `trace2.py` ลอกทุกร่าง → `traced.json` + `tr_<ร่าง>.png` (ภาพตรวจ: เขียว = ตัวของ · ฟ้า = สีเทาในแผ่น · เหลือง = เส้น · เหลืองเข้ม = สีเน้น)
- `edgecheck.py` เส้นของแผ่นที่ชนขอบครอป (ภาพถูกตัด) · `edgeview.py out ids…` ภาพช่องพร้อมกรอบครอปกับจุดที่ตัด
- `dbg.py out ids…` ต้นฉบับข้างผลลอก มีตารางสัดส่วน · `tz.py id x0 y0 x1 y1 out` ซูมผลลอก · `cell.py out id[:x0,y0,x1,y1]` ซูมต้นฉบับ

รันในโฟลเดอร์นี้: `python3 trace2.py` แล้วเอา `traced.json` ไปแทน `G12D` ใน `sketches/r12g.js` (คีย์ w h lines body acc accl hl hole fade) · วิธีตรวจก่อนส่ง: LESSONS 56
