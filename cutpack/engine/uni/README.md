## สไตล์ที่มีตอนนี้
- `card` หน้าตาคลิปที่ 1 ของ Friend (talking-head-editorial): ตัดเข้าการ์ดเต็มจอ พื้นสลับดำเรืองแสง ครีม ขาว
- `glass` หน้าตาคลิปที่ 2 (talking-head-motion): ภาพคนพูดเบลอเป็นพื้น กระจกฝ้า เส้นเรืองแสงฟ้า ตัวอักษรพลิก 3D (ท่าตัวอักษรคัดลอกจาก skill มาปรับ)
- `split` หน้าตาคลิปที่ 3 (ยังไม่รู้ว่า skill ไหน เขียนกฎจากคลิปอย่างเดียว): แบ่งจอ หน้าต่างพาสเทลด้านบน ภาพคนพูดหดลงกรอบด้านล่าง ตำแหน่งหน้า `SPLIT.faceY` ยังเป็นค่าคงที่ของคลิปตัวอย่าง (ใช้จริงต้องมาจาก `faces.json`)

## เพิ่มสไตล์ใหม่
เขียน `styles/<ชื่อ>.js` ไฟล์เดียว ตอบครบ 7 ข้อ แล้วรัน `render_test.sh` ทุกบทจะออกมาเป็นสไตล์ใหม่โดยไม่ต้องแก้บท ถ้าสไตล์ต้องการสิ่งที่ kit ยังไม่มี (เช่น ลายเส้นวาดมือ) ให้เพิ่มใน kit หรือในกฎของสไตล์ครั้งเดียว

## ข้อควรรู้ทางเทคนิค
- ของแต่ละชิ้นมี 3 ชั้น (`o` เข้า/ออก, `m` เปลี่ยนสถานะ, `p` เด้ง/สั่น) เพื่อไม่ให้ท่าทับกัน ท่าเข้าเติมค่าทั้งก่อนและหลัง (`fill: both`), ท่าออกและการเปลี่ยนสถานะเติมเฉพาะหลัง (`forwards`), ท่าชั่วคราวไม่เติม (`none`)
- ตัวที่ต้องเริ่มจากที่อื่น (เช่น ชิ้นจิ๊กซอว์ที่ลอยมา) ใช้ `move(..., {hold: true})`
- ห้ามวางตำแหน่งด้วย `transform` ใช้ `left/top` เพราะท่าขยับเขียนทับ `transform`
- ยังไม่ได้ต่อเข้าแผน D, ตัวตรวจ และชุดทดสอบของ `plan/` เป็นต้นแบบแยกไว้ก่อน
