# แผน: เกษียณคือ... รวยคืออะไร (I)

การ์ดเต็มจอ 5 ใบ รวม ~10.2 วินาที (~44% ของ 22.9 วินาที รวม HOLD 1.0)

| ช่วงเวลา | คำพูด | การจัดการ |
|---|---|---|
| 0.15–1.05 | เกษียณคือ | ซับ A-roll: "เกษียณ" (k, hook เฟรมแรก) + "คือ" |
| 1.07–2.13 | ถ้าวันเนี่ย | ซับ A-roll: "ถ้าวัน" (l) + "เนี่ย" (i) |
| 2.15–4.10 | เงิน Active income คุณ / แปลว่าเงินเดือนคุณ | **การ์ด C1 ขาว** — ป้าย "Active income" + ไอคอนนาฬิกาใหญ่ (แลกเวลากับเงิน) |
| 4.15–5.13 | หรือเงิน | ซับ A-roll: "หรือ" + "เงิน" (k) |
| 5.15–6.13 | ที่คุณต้องเสียสละ | ซับ A-roll: "ที่คุณต้อง" + "เสียสละ" (hl) |
| 6.15–7.13 | เวลาไปหามาเนี่ย | ซับ A-roll: "เวลา" (k) + "ไปหามา" |
| 7.15–9.05 | เงินมันหยุดเข้ามา | **การ์ด C2 ดำ Glow** — ธนบัตรขาวใหญ่ถูกขีดกากบาทแดงตรงคำ "หยุด" (hl) |
| 9.15–10.12 | คุณอยู่ได้กี่เดือน | ซับ A-roll: "คุณอยู่ได้" + "กี่เดือน" (k) |
| 10.15–10.56 | ถ้าวันนี้ | ซับ A-roll |
| 10.58–13.10 | คำตอบของคุณคือ / 1 ปี 2 ปี 3 ปี | **การ์ด C3 ครีม** — หัวเรื่องกรมท่า + ป้ายเม็ดยา 1 ปี, 2 ปี, 3 ปี ขึ้นทีละอันตามเสียง |
| 13.15–14.13 | เขาไม่เรียกว่ารวย | ซับ A-roll: "เขาไม่เรียกว่า" + "รวย" (k) |
| 14.15–15.13 | แต่ถ้าคุณบอกว่า | ซับ A-roll |
| 15.15–16.05 | ถ้าวันนี้ | ซับ A-roll |
| 16.07–17.12 | ผมไม่ทำงานเลย | **การ์ด C4 ขาว (ประกอบคำ)** — "ทำงานเลย" เป็น hl กล่องสีเน้นตรงคำ |
| 17.15–19.12 | แต่ผมอยู่ได้ถึงแบบ | ซับ A-roll: "อยู่ได้" (k) |
| 19.15–20.12 | วันตาย | ซับ A-roll: "วันตาย" (k) |
| 20.15–22.90 | รวยแล้ว / อันเนี่ยเขาเรียกว่ารวย | **การ์ด C5 ดำ Glow (ปิดท้าย)** — ไอคอนเหรียญสีเขียว (accent) เด้งเข้า, คำ "รวย" เป็น accent Sriracha |

ชนิดการ์ดสลับ: ขาว → ดำ → ครีม → ขาว → ดำ; ไม่มีการ์ดติดกัน; ช่วง A-roll ระหว่างการ์ดไม่เกิน 3 วินาที.
ไม่มีตัวเลข/ข้อมูลนอกเหนือจากที่ผู้พูดพูด (ปี 1/2/3 มาจากบท). ไม่มีบาร์โค้ด, ไม่เกรดสี.
