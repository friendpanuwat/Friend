# เทียบโมเดลรอบ 0: editorial, Sonnet 5.5 กับ Opus 5.5 ที่ effort low / medium / high

**เป้าหมาย:** ให้ Friend ดูภาพนิ่งเทียบกันว่าแต่ละโมเดลและแต่ละ effort ออกแบบฉากเองได้ดีแค่ไหน

**วิธีทดสอบ**
- ทั้ง 6 แบบได้คำสั่งเดียวกัน บทพูดเรื่องเกษียณยาว 22 วินาทีชุดเดียวกัน เวลาชุดเดียวกัน และคลิปแทนชุดเดียวกัน
- คลิปแทนคือคลิปดิบฝั่ง BEFORE ใน `product/docs/before_after.mp4` ปากจึงไม่ตรงกับเสียงพูด
- บทพูดมาจาก `minimal-talking-shorts/examples/clip02-retire` ซึ่งไม่มีอยู่ใน skill editorial จึงไม่มีโมเดลไหนลอกการ์ดจากตัวอย่างได้
- แต่ละแบบทำตาม skill `talking-head-editorial` เหมือนตอนที่ Friend ใช้เอง แต่ไม่มีคนช่วยแก้ระหว่างทาง และดูภาพตัวอย่างแล้วแก้ได้ไม่เกิน 4 รอบ
- ไม่ได้เรนเดอร์เป็นคลิป จึงยังไม่ได้ตรวจความลื่นของการเคลื่อนไหวและเสียง

**ไฟล์ในโฟลเดอร์นี้**
- `editorial_models_1.jpg`, `editorial_models_2.jpg`: ภาพนิ่งที่วินาทีเดียวกันของทั้ง 6 แบบ เรียงเป็นคอลัมน์ Sonnet low → high แล้วต่อด้วย Opus low → high
- `timeline_X.js`, `plan_X.md`: งานของแต่ละแบบ (ตัวอักษรตรงกับแบบไหน ดูใน `MAPPING.txt`)
- `RUNLOG.txt`: รุ่นโมเดลที่แต่ละแบบรายงาน, token รวม, เวลาที่ใช้, จำนวนรอบที่ดูภาพตัวอย่างแล้วแก้ และสิ่งที่แต่ละแบบเลือกทำเอง
- สร้างแผ่นเทียบใหม่ได้ด้วย `../make_sheets.sh`

**ข้อจำกัด**
- เป็นการเทียบแบบ "โมเดลออกแบบเองทั้งหมด" เหมือน skill ส่วนตัว ยังไม่ใช่แผน D (เลือกจากคลังชิ้นส่วน)
- ใช้บทเดียวและดูจากภาพนิ่งเท่านั้น
- ผลการเทียบด้วยคลิปจริง 20–30 คลิปตาม `../../DECISIONS.md` ข้อ 7 ยังต้องทำต่อ
