ทดสอบ overlay

หน้าคนพูดอยู่บนจอตลอด ภาพเป็นการ์ดเล็กเหนือหัว ใช้ร่างชุดเดิมทุกร่าง ไม่ได้วาดใหม่ เปลี่ยนแค่การจัดจอกับตัวหนังสือในกฎของสไตล์ หน้าตาของการ์ดทำตาม skill overlay ของ Friend (การ์ด → editorial-overlay, กระจก → talking-head-overlay) แตะคลิปเพื่อดูใหญ่

6 ร่าง2 สไตล์2 ขนาดไม่ต้องวาดร่างใหม่

กฎที่ได้จากการทดสอบ

  1. ร่างเดิมใช้ได้เลย โปรแกรมวัดว่าร่างวาดอะไรไว้จริง แล้วย่อให้พอดีกรอบรูปในการ์ด ภาพแนวกว้าง (โดมิโน) ได้กรอบกว้างขึ้นเอง
  2. ภาพเล็กต้องเรียบ ตัดของตกแต่งเล็ก ๆ (แสงหลังภาพ เส้นข้อความจำลอง ประกาย การ์ดซ้อนหลัง) และคำในภาพออก เพราะการ์ดมีประโยคอยู่แล้ว
  3. การ์ดที่เป็นทั้งภาพจะแบนลง เพราะการ์ด overlay คือการ์ดนั้นอยู่แล้ว ภาพข้างในเลยใหญ่ขึ้น (เช่น แถบราคากับคุณค่า ดาวรีวิว) ส่วนการ์ดที่เป็นตัวของ (มือถือ ใบเสร็จ แจ้งเตือน) ยังอยู่
  4. ภาพแนวตั้งเล็กที่สุด (แชตในมือถือ) ตอนต่อเข้าคลิปจริงควรใช้การ์ดแคบข้างหัว (210 × 380) ที่ระบบเดิมมีอยู่แล้ว
  5. ร่างใหม่ในรอบที่ 3 จะออกแบบตามนี้ตั้งแต่แรก ภาพหลักต้องอ่านออกแม้ตัดของตกแต่งออก ไม่พึ่งคำในภาพ และเหตุการณ์ตรงคำสำคัญต้องเห็นชัดแม้ภาพเล็ก

เรื่องที่อยากให้ Friend ดู

  1. แบบเล็กอ่านออกและสวยพอไหม (ขนาดนี้คือที่ระบบใช้กับคลิปจริงอยู่ตอนนี้)
  2. แบบใหญ่ที่ย่อคนพูด ควรใช้เมื่อไหร่ เฉพาะคลิปที่ไม่มีที่ว่างเหนือหัว (แบบที่ Friend ผ่านไว้) หรือให้ใช้บ่อยกว่านั้น
  3. สไตล์แบ่งจอจะมีแบบ overlay ไหม ถ้ามี ควรหน้าตาแบบไหน
