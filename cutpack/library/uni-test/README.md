# ทดสอบชุดฐานเดียวข้าม 3 สไตล์ (2026-11-07)

หน้าให้ Friend ดู: **https://claude.ai/artifact/3vrjAJsDyCay1pLjFpZw8S** (`page.html` คือสำเนาของหน้า, คลิปอยู่ใน `clips/`)

## ที่มา
- Friend: ทำชุดฐานก่อน เพราะใช้ได้ครอบคลุมกว่า "เผลอ ๆ ถ้ามีชุดฐานมากพอ อาจไม่ต้องทำเฉพาะหมวด"
- Friend: ชุดฐานต้องใช้ได้กับทุกสไตล์ อนาคตอาจมีร้อยหรือหลายร้อยสไตล์ และแต่ละสไตล์ "ต่างกันที่หน้าตาทั้งหมด" ไม่ใช่แค่ฟอนต์กับสี (ส่งคลิปพูดเดียวกันที่ตัด 3 สไตล์มาให้ดู)
- Claude เสนอ: เขียนบทครั้งเดียว แล้วให้แต่ละสไตล์เป็น "กฎการวาด" 1 ชุด (แบบฟอร์ม 7 ข้อ: จัดจอ, กรอบและพื้น, วิธีวาดของ, ชุดสี, ตัวหนังสือ, ท่าขยับ, เสียง) Friend: "งั้นเราก็ต้องออกแบบสไตล์ใหม่ ๆ ให้เข้ากับระบบของชุดฐานที่เราวางไว้ด้วย" แล้วสั่ง "เริ่มทดสอบ 6 ฉาก 3 สไตล์เลย"

## สิ่งที่ทำ
- บท 6 ฉาก จากประโยคในคลิปของ Friend (`engine/uni/scenes/base6.js`): ลดราคาแล้วก็ยังไม่ซื้อ (แถบราคา + ตะกร้า), ไม่คุ้ม (ตาชั่ง), ลังเล (สวิตช์), ลูกค้าน้อยลง (การ์ดร้าน + ลูกค้า 4 คน), ข้อแรกไม่ใช่ (เช็กลิสต์), แก้ให้ถูกจุด (จิ๊กซอว์)
- กฎ 3 ชุด (`engine/uni/styles/`): `card` แบบคลิปที่ 1, `glass` แบบคลิปที่ 2, `split` แบบคลิปที่ 3 รายละเอียด 7 ข้อของแต่ละชุดอยู่ในหัวไฟล์และในหน้าที่เผยแพร่
- เรนเดอร์ 18 คลิป คลิปละ 5 วินาที (หน้า 0.5 → ฉาก 4 → หน้า 0.5) บนคลิปตัวอย่างเดิม ไม่มีเสียง ใช้เวลาเรนเดอร์รวม 2.5 นาทีบน 4 CPU
- ทำซ้ำ: `bash engine/uni/render_test.sh <งาน> library/uni-test/clips`

## ผลที่เห็นเอง (ยังไม่ใช่ความเห็นของ Friend)
- บททั้ง 6 ฉากไม่มีโค้ดเฉพาะสไตล์เลย ทั้ง 18 คลิปมาจากบทชุดเดียว ต่างกันแค่ไฟล์กฎที่ใส่
- ทั้ง 3 สไตล์ต่างกันทั้งการจัดจอ สี เส้น แสง ตัวหนังสือ และท่าขยับ แต่ภาพในฉากวางตำแหน่งเหมือนกัน (เช่น ตาชั่งอยู่กลางเสมอ) ถ้า Friend เห็นว่าคล้ายกันเกินไป ทางแก้ที่คิดไว้: ให้กฎของสไตล์จัดวางได้ด้วย (ขนาด ระยะ ตำแหน่งในกรอบ) และให้บทมี 2–3 แบบให้สไตล์เลือก
- สไตล์ต้องการเทคนิคใหม่ 3 อย่างตามที่คาด และทำเป็นกฎของสไตล์ได้ทั้งหมด: เบลอภาพคนพูดเป็นพื้น (`glass`), หดภาพคนพูดลงกรอบ (`split`), เส้นเรืองแสง (`glass`)
- ภาพยังเรียบกว่าคลิปของ Friend เพราะเป็นบทชุดแรกและไม่มีของประกอบรอง
