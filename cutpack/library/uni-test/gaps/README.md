## วิธีจัด
- 1 ช่วง = ประโยคหรือความคิดหนึ่งที่มีเนื้อหาพอจะมีภาพ ข้ามคำเติม ("ถูกต้องไหมคะ") และช่วงที่พูดต่อจากบรรทัดก่อน
- **ok** = มีหมวดที่ภาพบอกตรงความหมาย · **ฝืน** = เข้าหมวดได้แต่ภาพจะผิดความหมาย (เช่น รายการที่ไม่ใช่สิ่งที่ต้องทำ ถ้าใช้รายการติ๊ก จะดูเหมือนบอกว่าต้องทำ) · **ไม่มี** = ไม่มีหมวดไหนวาดได้
- การแนะนำตัวคน ("เขาคือยังเติร์ก ศิลปินจากแอตแลนตา") นับเป็น B10 (ร่างการ์ดตัวตน) แต่คำอธิบาย B10 ใน `cat_ai.py` ยังเขียนว่ากลุ่มเป้าหมาย ต้องเขียนให้รวมการแนะนำตัวคนด้วยถ้าจะใช้
- ประโยคที่บอกความเห็นแต่เนื้อหาเป็นเหตุกับผล ("ผมมองว่า…เลยไม่ยื่น") นับตามเนื้อหา กลุ่มความเห็นนับเฉพาะช่วงที่งานหลักคือบอกจุดยืน
- Claude จัดคนเดียว ช่วงที่ก้ำกึ่งอาจตัดสินต่างจาก Friend ได้
