# คลิปจริงคลิปแรกของ Friend (2026-11-04)

คลิปพูด 52 วินาที เป็นคลิป TikTok ที่ตัดต่อแล้ว (มีลายน้ำและซับเดิมฝังอยู่) จึงไม่ได้เก็บไฟล์วิดีโอไว้ใน repo ใช้ทดสอบทั้งระบบตอนที่ยังไม่มีคีย์ API

| ขั้น | ใครทำ | ไฟล์ |
|---|---|---|
| ถอดเสียง | Typhoon ASR Realtime (ระบบจริง) ชื่อภาษาอังกฤษเอามาจาก Whisper แทนขั้นที่ลูกค้าตรวจซับ | `input.json` (`words`) |
| จัดกลุ่มซับ (ปกติ Haiku) | Claude ใน session ทำแทน | `input.json` (`captions`) |
| หาหน้า + ตำแหน่ง | `faces.py` (ระบบจริง) หน้าใหญ่เต็มเฟรม วิดเจ็ตเตี้ยลงไประดับอก ซับเลื่อนเป็น 1328 | `faces.json` |
| วางแผนฉาก (ปกติ Sonnet 5.5) | Claude ใน session ทำแทน ตามคำสั่งใน `prompt/system.md` | `answer_ed.json`, `answer_ov.json` |

| ตรวจ รอบแก้ ตัวสำรอง เรนเดอร์ | ระบบจริง (`plan_d.py`, `pipeline.sh`) | |

**สิ่งที่ตัวตรวจจับได้จากแผนที่เขียนแทน AI:** overlay มีจังหวะคำสำคัญชิดต้นหรือท้ายวิดเจ็ตเกินไป 2 จุด และวิดเจ็ตห่างกันไม่ถึง 0.4 วินาที 1 จุด รอบแก้ (`answer_ov_fix.json`) แก้ครบ

**บั๊กที่เจอและแก้แล้ว:** ชื่อไอคอนที่มีตัวเลข ("share-2") ถูกนับเป็นตัวเลขบนจอที่ไม่ได้พูด, โหมดทดสอบออฟไลน์ไม่ใช้โค้ดฉากเดิมซ้ำหลังรอบแก้, ที่ระดับอกไม่พอเมื่อหน้าใหญ่ (ซับเลื่อนลงให้)

รันซ้ำ: `plan_d.py input.json editorial <out> --faces faces.json --answer answer_ed.json --code-answer codes_ed.json` และ overlay เพิ่ม `--fix-answer answer_ov_fix.json`
