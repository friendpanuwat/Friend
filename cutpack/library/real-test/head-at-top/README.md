Friend ถามว่าถ้าลูกค้าอัปคลิปที่หัวเกือบติดขอบบน จะวาง motion graphic ตรงไหน จึงเพิ่มตำแหน่ง "ระดับอก" ให้วิดเจ็ตเตี้ย (Friend เห็นด้วย)

- คลิปจำลองทำจากคลิปทดสอบ 18 วินาที (`../clip_18s.mp4`) 2 แบบ

  - **B (ขวา / แถวล่าง):** ขยายภาพ 1.25 เท่าแล้วครอปให้หัวชิดบน หน้าใหญ่เหมือนนั่งใกล้กล้อง
- ใช้แผน overlay เดิมของคลิป 18 วินาที ตัวหาหน้า (`engine/plan/faces.py`) คำนวณตำแหน่งจากภาพจริง
