# เว็บแอป CutPack โทนโมโนโครม (prototype)

หน้าที่กดลองได้: https://claude.ai/artifact/C4jZsFkbvFe9x2N7RJK8pf (สร้างจากชนิด Design, 2026-11-05)

Friend ส่งเว็บตัวอย่างมาให้ (https://thedankoe.eden.so/) แล้วบอกว่าอยากได้ UI สไตล์นี้ ชุดนี้จึงใช้แค่ "หน้าตา" ของเว็บนั้น ไม่ได้เอาชื่อ รูป หรือเนื้อหาของเขามาใช้:

- พื้นดำ #0C0C0D มีแสงเทาจาง ๆ ด้านบน ตัวหนังสือขาวนวล #F2F2F0 ตัวรองขาวโปร่ง 72% และ 50%
- ฟอนต์ Geist (อังกฤษ/ตัวเลข) + Anuphan (ไทย)
- ปุ่มหลักเป็นแคปซูลขาวตัวหนังสือดำ ปุ่มรองเป็นแคปซูลเส้นขอบ
- การ์ดสีเกือบดำ #151516 เส้นขอบบาง มุมโค้ง 16–20
- แถวรายการ: รูป/ไอคอน + ชื่อ + คำอธิบาย + ลูกศร
- ตัวเลือกแบบวงกลมตัวอักษร A / B (เลือกแล้ววงกลายเป็นขาว)
- หัวข้อมีป้ายนับจำนวนข้าง ๆ

เนื้อหาเหมือนชุด dark mode เดิม (`../webapp-mockup/`) ต่างแค่หน้าตา และปรับตามที่ตัดสินแล้วหลังจากนั้น:
หน้าเต็มเฟรมไม่ใช่คำเตือนแล้ว แต่บอกว่าระบบจะย่อภาพคนพูดลงชั่วคราวตอนกราฟิกขึ้น (DECISIONS: ย่อภาพคนพูด)

ขนาดหน้าจอ 390×844 เท่าจอมือถือจริง (iPhone ขนาดทั่วไป) เปิดลิงก์แล้วขึ้นหน้าหลักเต็มจอทันที แต่ละหน้ามีแถบบน (ปุ่มย้อนกลับ + ขั้นที่) และปุ่มหลักติดอยู่ด้านล่าง ส่วนกลางเลื่อนขึ้นลงได้ถ้าเนื้อหายาวกว่าจอ หน้าหลักปุ่มกรองเลื่อนซ้ายขวาได้ หน้าผลงานวิดีโอยืดเต็มพื้นที่ที่เหลือ

ไฟล์ในโฟลเดอร์นี้เป็นสำเนาของไฟล์ที่ publish ไว้ ถ้าจะแก้ให้ publish ไปที่ URL เดิมพร้อม `canvas.json`

| ไฟล์ | หน้า | สิ่งที่กดลองได้ |
|---|---|---|
| `Main.dc.html` | หน้าหลัก | คลิปที่เหลือในแพ็ก แถบใช้ไป 18 จาก 50 ปุ่มสร้างคลิปใหม่ ปุ่มกรอง 4 แบบ (ทั้งหมด / เสร็จแล้ว / กำลังสร้าง / รอตรวจซับ) คลิปล่าสุด และเคล็ดลับการถ่าย A–C |
| `Upload.dc.html` | 1 อัปโหลด | กดลบไฟล์แล้วเลือกใหม่ได้ ผลตรวจ 4 ข้อ (ข้อสุดท้ายบอกเรื่องย่อภาพคนพูด) |
| `Style.dc.html` | 2 เลือกสไตล์ | A Editorial / B Overlay พร้อมภาพตัวอย่างสองภาพต่อแบบ |
| `Look.dc.html` | 3 สีและฟอนต์ | สีคำเน้น 6 สี ฟอนต์ตัวหนา (Mitr) / ลายมือ (Sriracha) ภาพตัวอย่างเปลี่ยนตามทันที |
| `Captions.dc.html` | 4 ตรวจซับ | สวิตช์ตัดคำลงท้าย (ครับ ค่ะ นะ หายจากซับทันที) แตะเลือกบรรทัด คำที่ไม่แน่ใจมีเส้นประใต้ แทนที่คำทั้งคลิป |
| `Confirm.dc.html` | 5 ยืนยันและสร้าง | สรุป 4 แถว (แตะกลับไปแก้ได้) คลิปในแพ็ก 32 → 31 กดสร้างแล้วเห็นความคืบหน้า 5 ขั้น |
| `Result.dc.html` | 6 ผลงาน | สลับ ก่อน / หลัง ปุ่มดาวน์โหลด แชร์ สั่งแก้ |
| `Fix.dc.html` | 7 สั่งแก้ | จุดที่จะแก้ A, B เลือกประเภท (ซับผิด / กราฟิก / บังหน้า / เสียง / อื่น ๆ) ลบจุด เพิ่มจุด แล้วส่ง |

**สิ่งที่สมมติไว้ ยังไม่ได้ตัดสิน**
- ชื่อ "CutPack" เป็นชื่อชั่วคราว
- นับเป็น "คลิป" ตามแพ็ก 450 บาท = 50 คลิป (ยังไม่ได้เลือกแพ็กจริง) ตัวเลขในหน้าเป็นข้อมูลสมมติ
- คลิปยาวไม่เกิน 3 นาที ไฟล์ไม่เกิน 500 MB เวลาสร้างราว 4 นาที
- วันรีเซ็ตแพ็ก อายุไฟล์ และเงื่อนไขการสั่งแก้ เว้นเป็นช่องว่าง `[...]` ไว้
- เคล็ดลับการถ่าย A–C บนหน้าหลัก เขียนจากสิ่งที่ระบบทำได้ตอนนี้
