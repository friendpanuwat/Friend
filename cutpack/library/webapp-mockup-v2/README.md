# เว็บแอป CutPack แบบ "เลือกสไตล์ก่อน" (prototype ชุดที่ 2)

หน้าที่กดลองได้: https://claude.ai/artifact/W95WYP8LXdm6UK3tHAwh3V (สร้าง 2026-11-07 ในแชท `ccr-b98c112b-nsqyx0`)

Friend ดู mockup โทนขาว-ดำชุดเดิม (`../webapp-mockup-mono/`) แล้วบอกว่า "ยังไม่ตรงกับภาพในหัว" และเล่าลำดับที่อยากได้ว่า
"ให้ลูกค้าเห็นสไตล์ของวีดีโอต่าง ๆ ตอนที่กดเข้ามาในเว็บเลย ... เลือกสไตล์คลิปที่ตัวเองอยากได้ เสร็จแล้วกดเข้าไปในสไตล์นั้น กดใช้ template หรือกดสร้างคลิปก็ได้
แล้วหลังจากนั้นอัปโหลดคลิป แล้วก็ถอดเสียง แก้ซับ แล้วก็รอจนกว่าจะได้วีดีโอ อันนี้คือจบ 1 งาน"

เรื่องที่ Friend ตัดสินแล้ว (2026-11-07):
- ยังไม่มี "สั่งแก้" ("ไว้เป็นเรื่องที่ต้องอัปเดตในอนาคต")
- สีและฟอนต์ย้ายไปอยู่หน้าเดียวกับแก้ซับ
- หน้าตาโทนขาว-ดำแบบชุดเดิม (สีพื้น ฟอนต์ ปุ่ม การ์ด เหมือน `../webapp-mockup-mono/README.md`)
- ขอเข้าสู่ระบบตอนกด "ใช้สไตล์นี้" (ก่อนหน้านั้นดูได้โดยไม่ต้องมีบัญชี)
- เว็บทำคลิปด้วยแบบ D เป็นค่าเริ่มต้น

ขนาดหน้าจอ 390×844 เท่าจอมือถือ เปิดลิงก์แล้วขึ้นหน้าแรกเต็มจอ ปุ่มทุกปุ่มที่ลิงก์ไปหน้าอื่นกดได้จริง
ไฟล์ในโฟลเดอร์นี้เป็นสำเนาของไฟล์ที่ publish ไว้ ถ้าจะแก้ให้ publish ไปที่ URL เดิมพร้อม `canvas.json` (`/_blob/` ในไฟล์คือ asset ของ artifact นี้)

**สิ่งที่สมมติไว้ ยังไม่ได้ตัดสิน**
- ชื่อ "CutPack" เป็นชื่อชั่วคราว
- วิธีเข้าสู่ระบบ (Google / LINE / อีเมล) ใส่ไว้ทั้ง 3 แบบให้เห็นหน้าตา ยังไม่ได้เลือก
- เครดิตตามตัวเลขเดิม: คลิปไม่เกิน 60 วินาที 100 เครดิต, 61–90 วินาที 140 เครดิต, แพ็ก 450 บาท = 5,000 เครดิต (ยังไม่ได้เลือกแพ็กจริง) ตัวเลขในหน้าเป็นข้อมูลสมมติ หักเครดิตตอนกด "สร้างคลิป"
- คลิปยาวไม่เกิน 90 วินาที ไฟล์ไม่เกิน 500 MB ถอดเสียงราว 1 นาที ทำคลิปราว 4–6 นาที
- การแจ้งเตือนตอนคลิปเสร็จยังไม่ได้เลือกวิธี ในหน้าเขียนแค่ว่า "เสร็จแล้วคลิปจะอยู่ใน คลิปของฉัน"
- **18 สไตล์ในหน้าแรกเป็นของสมมติ** มีจริงแค่ Editorial กับ Overlay ช่องของสไตล์สมมติวาดด้วยโค้ดให้เห็นหน้าตาคร่าว ๆ (คนเป็นเงาสีเทา ไม่ใช้หน้าคนจริง) บางแบบมาจาก skill ของ Friend (Minimal, Minimal Overlay, Motion 3D, Glass UI, Pop Overlay, Bold Mono) ที่เหลือคิดขึ้นเอง (Karaoke, Poster, Neon, Handwritten, Data, Newsroom, Podcast, Comic, Sticker, Cinematic, Retro, Clean) กดช่องสไตล์สมมติแล้วไปหน้าสไตล์ Editorial (ถ้าเป็นแบบการ์ดเต็มจอ) หรือ Overlay (ถ้าเห็นหน้าตลอด) แทน ป้าย "ยอดนิยม" "ใหม่" และหมวดของแต่ละสไตล์ก็สมมติ
- หน้าเข้าสู่ระบบ หน้าอัปโหลด และหน้าถัดไปแสดงสไตล์ Editorial เสมอ (mockup ไม่จำว่ากดมาจากสไตล์ไหน)
