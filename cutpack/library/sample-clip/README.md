# คลิปตัวอย่างจาก Friend

- `character_talking.mp4` Friend ส่งมาเมื่อ 2026-11-03 ให้ใช้เป็นคลิปตัวอย่างของงานคลังชิ้นส่วน
- ยาว 10 วินาที ขนาด 720×1280 ที่ 24 fps มีเสียงพูด 4 ช่วง ภาพขาวดำ คนนั่งบนพื้นดำ หน้าเบลอ
- ตำแหน่งในจอ (คิดเป็น % ของความสูงหรือความกว้าง):
  - ผมเริ่มที่ประมาณ 19% จากขอบบน
  - หัวกว้างจาก 24% ถึง 70% ของความกว้าง
  - คางอยู่ที่ประมาณ 50%
- ผลต่อการออกแบบ: เหนือหัวมีที่ว่างแค่ราว 8–19% ของจอ (หักแถบบนของแอปแล้ว) แต่ข้างหัวซ้ายและขวามีที่ว่างมากกว่า ชิ้นแบบ overlay จึงต้องมีทั้งขนาดเตี้ย (วางเหนือหัว) และขนาดแคบ (วางข้างหัว)
- ยังไม่ได้ถอดเสียง เพราะใน session นี้ยังไม่มีเครื่องมือถอดเสียงหรือคีย์ API
