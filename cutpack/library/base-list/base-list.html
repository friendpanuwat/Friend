ชิ้นฐาน CutPack

ชิ้นฐาน 15 หมวดที่แบ่งตามหน้าที่ของประโยค ใช้ได้กับคลิปทุกเรื่อง เรื่องของคลิปมาจากไอคอนและคำในบทที่ AI เติมลงช่อง และจากชุดเฉพาะหมวดเนื้อหาที่จะทำเพิ่มทีหลัง

ทุกหมวดมีแบบย่อย 4 แบบ แต่ละแบบวางได้หลายตำแหน่งและใช้พื้นการ์ดได้ 4 สีตาม skill ระบบจะจำว่าลูกค้าแต่ละคนใช้แบบไหนไปแล้ว คลิปถัดไปจะได้ไม่ซ้ำ ทุกแบบมีสองร่าง: การ์ดเต็มจอ สำหรับสไตล์ editorial และวิดเจ็ตเล็ก สำหรับสไตล์ overlay

กด เอา / ปรับ / ตัด ท้ายแต่ละหมวด ถ้ากด "ปรับ" ให้พิมพ์ในช่องหมายเหตุว่าอยากให้ปรับอะไร ท้ายหน้ามีช่องให้บอกหมวดที่ยังขาด ยังไม่มีภาพตัวอย่างของแต่ละชิ้น จะเรนเดอร์หลังคุณยืนยันรายการนี้

เอา 0 ปรับ 0 ตัด 0 ยังไม่เลือก 15

กำลังเชื่อมต่อที่เก็บข้อมูล… ปุ่มจะกดได้เมื่อแถบนี้เปลี่ยนเป็นสีเขียว

แถบบนของแอป ว่าง: เหนือหัว ว่าง ว่าง หน้า ห้ามบัง ซับ ปุ่มแอป ชื่อบัญชีและแคปชัน

ที่ว่างในคลิปตัวอย่างของคุณ

  • หัวอยู่ค่อนข้างสูง ที่ว่างเหนือหัวมีแค่ราว 10% ของจอ
  • ข้างหัวซ้ายและขวามีที่ว่างมากกว่า
  • วิดเจ็ตแบบ overlay ทุกชิ้นจึงต้องมีสองขนาด
    • ขนาดเตี้ย วางเหนือหัว
    • ขนาดแคบ วางข้างหัว
  • ระบบจะหาหน้าในแต่ละคลิปแล้วเลือกช่องที่ว่างเอง
  • พื้นหลังดำของคลิปนี้เข้ากับการ์ดดำแบบ Glow ของ skill
