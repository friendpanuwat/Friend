**สิ่งที่สมมติไว้ ยังไม่ได้ตัดสิน**
- ชื่อ "CutPack" เป็นชื่อชั่วคราว
- ลำดับ 7 ขั้น ขั้นที่ 3–5 ตามที่คุยกันไว้ ที่เหลือจัดเอง
- เครดิต: คลิปไม่เกิน 60 วินาที 100 เครดิต, 61–90 วินาที 140 เครดิต, แพ็ก 450 บาท
- คืนเครดิตอัตโนมัติถ้าสร้างไม่สำเร็จ, แจ้งเตือนทางมือถือและอีเมล, เก็บไฟล์ 30 วัน
- เงื่อนไขการสั่งแก้ (แก้ฟรีกี่ครั้ง แก้อะไรได้) ยังเป็นช่องว่าง
