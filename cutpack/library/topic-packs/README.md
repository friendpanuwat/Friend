- โค้ดชิ้นส่วนอยู่ที่ `engine/styles/editorial/packs/<หมวด>.js` ของประกอบลงทะเบียนเป็นแบบหนึ่งของชิ้นฐาน (`PART('B01', 'biz1', …)`) ใช้ช่องที่ AI เติมชุดเดิม ส่วนชิ้นเด่นเป็นหมวดใหม่ (`PART('BIZ', 'h1', …)`) ทุกชิ้นมี `pack` ใน meta ซึ่งทำให้ยังไม่เข้าคลังของ AI (`plan/catalog.js`) จนกว่า Friend จะเลือกและต่อเข้าแผน D
- `samples.json` ประโยคตัวอย่าง 2 เรื่องต่อชิ้น ตัวเลขทุกตัวอยู่ในประโยค
- `pack_check.py <หมวด>` วัดบนภาพจริงแบบเดียวกับคลังชิ้นฐาน (ทุกชิ้น × ทุกสีพื้น × 2 ตัวอย่าง) ชุดธุรกิจ 66 ฉาก ไม่มีข้อผิดพลาด
- `clips_<หมวด>.txt` รายการคลิป แล้วเรนเดอร์ด้วย `SAMPLES=samples.json ../base-parts/make_clips.sh <work> clips clips_<หมวด>.txt`
- `make_gallery.py <หมวด> gallery_<หมวด>.html clips` สร้างหน้าแกลเลอรีจากโค้ด ผลเก็บใน collection `variants` แต่ละ document มี id เป็นรหัสชิ้น (`BIZ-P1` …) และ `_general` เก็บความเห็นรวม อ่านด้วย `ArtifactData` `list` (อ่านได้ระดับ `view` เขียนได้เฉพาะเจ้าของ ตรวจแล้วด้วย document ทดสอบที่ลบทิ้งแล้ว)

## หน้ารายการตัวอักษรเดิม (ไม่ใช้แล้ว)

- หน้าที่เผยแพร่: https://claude.ai/artifact/HbgpX4ehhSEAwmsYtrwbHh ไฟล์คือ `topic-packs.html`
- ที่มา: Friend ตกลง 4 หมวดแรกตามที่ Claude เสนอ และให้ AI เลือกหมวดของคลิปจากบทพูดตอนวางแผนฉาก (2026-11-04 ดู `../../DECISIONS.md` ข้อ 3)
  1. ธุรกิจและการตลาดออนไลน์ (`biz`, รหัส `BIZ-`)
  2. การเงินและการลงทุน (`fin`, `FIN-`)
  3. สุขภาพและฟิตเนส (`fit`, `FIT-`)
  4. ความรู้และพัฒนาตัวเอง (`edu`, `EDU-`)
- แต่ละหมวดมีของ 2 แบบ
  - **ของประกอบ** (`-P1`…`-P6`): ใช้ชิ้นฐานตัวเดิมและท่าเดิม แต่เปลี่ยนรูปเป็นของในหมวด เช่น ตาราง 10 ช่องของ B01 ใช้เหรียญในคลิปการเงิน หลายข้อมาจากคอลัมน์ "ชุดเฉพาะหมวด" ในหน้ารายการชิ้นฐาน (`../base-list/`) ที่ Friend เห็นแล้ว
  - **ชิ้นเด่น** (`-H1`…`-H5`): ชิ้นใหม่เฉพาะหมวด เสนอหมวดละ 5 ชิ้น ตามข้อตกลงต้องเหลือ 3–5 ชิ้น
- ทุกชิ้นต้องมีการ์ดเต็มจอ (editorial) และวิดเจ็ต 2 ขนาด (overlay) หน้าตาตาม editorial ไม่มีโลโก้แบรนด์หรือแอปจริง ตัวเลขบนจอต้องมีในบท
- เอนจินยังไม่มีที่เสียบชุดเฉพาะหมวด ต้องออกแบบใหม่ตอนวาดชิ้นแรก

## อ่านผล

ผลเก็บใน collection `packs` ของหน้านั้น อ่านด้วย `ArtifactData` `list` แต่ละ document มี id เป็นรหัสชิ้น เช่น `BIZ-P1` หรือ `FIN-H3` และเก็บค่า `{choice: keep|tweak|drop|null, note}` ส่วน document `_general` เก็บของที่ยังขาดและความเห็นรวม กติกาการเข้าถึง: `packs` อ่านได้ระดับ `view` เขียนได้เฉพาะเจ้าของ

ตรวจแล้วหลังเผยแพร่ (2026-11-04): เขียน document ทดสอบ อ่านกลับได้ที่ระดับ `view` แล้วลบทิ้ง ส่วนการกดปุ่มจริงบนหน้าทดสอบจากที่นี่ไม่ได้
