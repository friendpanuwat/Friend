# ชุดเฉพาะหมวดเนื้อหา

- หน้าที่เผยแพร่: https://claude.ai/artifact/HbgpX4ehhSEAwmsYtrwbHh (เปิดได้เฉพาะ Friend) ไฟล์คือ `topic-packs.html`
- ที่มา: Friend ตกลง 4 หมวดแรกตามที่ Claude เสนอ และให้ AI เลือกหมวดของคลิปจากบทพูดตอนวางแผนฉาก (2026-11-04 ดู `../../DECISIONS.md` ข้อ 3)
  1. ธุรกิจและการตลาดออนไลน์ (`biz`, รหัส `BIZ-`)
  2. การเงินและการลงทุน (`fin`, `FIN-`)
  3. สุขภาพและฟิตเนส (`fit`, `FIT-`)
  4. ความรู้และพัฒนาตัวเอง (`edu`, `EDU-`)
- แต่ละหมวดมีของ 2 แบบ
  - **ของประกอบ** (`-P1`…`-P6`): ใช้ชิ้นฐานตัวเดิมและท่าเดิม แต่เปลี่ยนรูปเป็นของในหมวด เช่น ตาราง 10 ช่องของ B01 ใช้เหรียญในคลิปการเงิน หลายข้อมาจากคอลัมน์ "ชุดเฉพาะหมวด" ในหน้ารายการชิ้นฐาน (`../base-list/`) ที่ Friend เห็นแล้ว
  - **ชิ้นเด่น** (`-H1`…`-H5`): ชิ้นใหม่เฉพาะหมวด เสนอหมวดละ 5 ชิ้น ตามข้อตกลงต้องเหลือ 3–5 ชิ้น
- ทุกชิ้นต้องมีการ์ดเต็มจอ (editorial) และวิดเจ็ต 2 ขนาด (overlay) หน้าตาตาม editorial ไม่มีโลโก้แบรนด์หรือแอปจริง ตัวเลขบนจอต้องมีในบท
- เอนจินยังไม่มีที่เสียบชุดเฉพาะหมวด ต้องออกแบบใหม่ตอนวาดชิ้นแรก
