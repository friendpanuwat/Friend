# วิดเจ็ต overlay (editorial-overlay)

- โค้ดอยู่ที่ `../../engine/styles/editorial/widgets/W1.js–W3.js` และชุดเครื่องมือของวิดเจ็ตอยู่ท้าย `motion.js` (`WIDGET`, `widgetAt`, `wbox`, `WSIZE`, `WAT`)
- หน้าตาและท่าเคลื่อนไหวเหมือน editorial แต่เป็นการ์ดขาวเล็กที่เด้งขึ้นระหว่างที่หน้าคนพูดอยู่บนจอ ท่าเข้า-ออกเอามาจาก `widget()` ของ skill editorial-overlay (ขึ้น 46 px + ย่อ .78 แบบเด้ง 0.48 วินาที / ย่อ .86 + จาง 0.16 วินาที)
- กฎจาก skill: การ์ดขาว ไม่ใช้กระจก ข้อความไม่เกิน 3 คำ ชิ้นหลัก 1 ชิ้น ห้ามทับหน้า
- **2 ขนาด** วัดจากคลิปตัวอย่างของ Friend
  - ขนาดเตี้ย 600×190 วางเหนือหัว (ที่ว่างเหนือหัวในคลิปนี้สูงแค่ราว 190 px)
  - ขนาดแคบ 210×380 วางข้างหัวด้านซ้าย
- **หมวดละ 2 แบบ (Friend ตกลง 2026-11-03)** ผมเลือกจากแบบ editorial ที่ Friend เก็บไว้ โดยเลือกแบบที่อ่านออกในพื้นที่เล็กที่สุด รายการอยู่ใน `widgets.txt`
- ข้อความในวิดเจ็ตย่อขนาดเองเมื่อยาวเกิน เพื่อไม่ให้ตัดคำไทยกลางคำ
- `render_widget.sh` เรนเดอร์ 1 วิดเจ็ตบนคลิปตัวอย่าง พร้อมซับระดับอก `make_clips.sh` เรนเดอร์ทั้งหมด (คลิป `_0` คือขนาดเตี้ย `_1` คือขนาดแคบ) และ `gallery.html` คือหน้าให้ Friend เลือก (สร้างด้วย `../base-parts/make_gallery.py --widgets`)
