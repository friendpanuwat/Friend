# ชิ้นฐานรอบแรก (editorial การ์ดเต็มจอ)

- 5 หมวด ได้แก่ B01 ตัวเลขเด่น, B02 เพิ่มขึ้น / ลดลง, B03 เปรียบเทียบ, B04 ขั้นตอน และ B14 ประโยคเด็ด หมวดละ 4 แบบ รวม 20 แบบ โค้ดอยู่ที่ `../../engine/styles/editorial/parts/`
- `samples.json` เนื้อหาตัวอย่าง 2 เรื่องต่อหมวด ทุกตัวเลขมีอยู่ในประโยคตัวอย่าง
- `clips.txt` รายการคลิปของแกลเลอรี (หมวด แบบ ตัวอย่าง สีพื้น) แต่ละแบบมี 2 คลิป คนละเรื่องและคนละสีพื้น
- `render_part.sh` เรนเดอร์ชิ้นเดียวบนคลิปตัวอย่างของ Friend: หน้าคนพูด 0.4 วินาที → การ์ด 3 วินาที (คำสำคัญที่วินาที 1.5) → หน้าคนพูด 0.4 วินาที
- `make_clips.sh` เรนเดอร์ทุกบรรทัดใน `clips.txt` ลง `clips/`
- `gallery.html` หน้าให้ Friend กด เอา / ปรับ / ตัด ทีละแบบ ผลเก็บใน collection `variants` แต่ละ document มี id แบบ `B01-v1` และ `_general` เก็บความเห็นรวม
