# CutPack: ต้นทุนต่อคลิป รอบที่ 0 (ก่อนทดสอบกับคลิปจริง)

**สถานะ:** ยังไม่ได้ทดสอบกับคลิปจริง และยังไม่ได้เรียก API จริงเลย เพราะเครื่องนี้ยังไม่มีคลิปลูกค้าและยังไม่มีคีย์ API
ส่วนที่วัดได้จริงคือ **เวลาเรนเดอร์** ส่วนต้นทุน AI ยังเป็น **ตัวเลขประมาณ** ที่คิดจากขนาดไฟล์ของ skill และราคาต่อหน่วยที่ตรวจเมื่อ 3 พ.ย. 2026

## 1. สรุป

1. **ค่าเครื่องเรนเดอร์ไม่ใช่ตัวที่ทำให้ขาดทุน** เรนเดอร์คลิป 43 วินาทีบน 2 คอร์ใช้ 3.5–5.7 นาที เครื่องเดียวจึงรับงานได้ประมาณ 75–110 คน ค่า VPS ยังเป็นค่าใช้จ่ายคงที่รายเดือนตามที่เอกสารคิดไว้ ไม่ได้เพิ่มตามจำนวนคลิป
2. **ต้นทุนส่วนใหญ่มาจากขั้นที่ให้ Sonnet สร้างฉาก** ถ้าให้ AI เขียนโค้ดฉากเองทุกคลิปแบบที่ skill ทำอยู่ตอนนี้ คลิป 45 วินาทีจะใช้ประมาณ 2–7 บาท คลิป 90 วินาทีประมาณ 4–12 บาท ซึ่งเกินเพดาน 7 บาทได้ตั้งแต่รอบแรก
3. **ถ้าให้ AI แค่เลือกชิ้นส่วนแล้วเติมค่าลงเทมเพลต (JSON)** ต้นทุนรอบแรกจะเหลือประมาณ 0.4–1.7 บาทต่อคลิป 45 วินาที และ 0.8–2.7 บาทต่อคลิป 90 วินาที ยังมีที่ว่างให้ทำซ้ำฟรีหนึ่งครั้งโดยไม่หลุดกรณีดีที่สุด
4. **Kimi K3.1 Pro ราคาเท่า Sonnet 5.5** ($2 / $10 ต่อล้าน token) ส่งฉากยากไป Kimi จึงไม่ได้ช่วยลดต้นทุน
5. **การเข้ารหัสวิดีโอใน skill ตอนนี้ช้าที่สุดในทุกขั้น** (ใช้ 52–55% ของเวลาทั้งหมด) ถ้าเปลี่ยน preset ขั้นนี้จะเร็วขึ้นเกือบ 3 เท่า โดยคุณภาพแทบไม่ต่างกัน

## 4. ประมาณต้นทุนต่อคลิป (บาท, ทำรอบเดียว ยังไม่รวมการทำซ้ำ)

รวมค่าถอดเสียง (Groq), ค่าจัดกลุ่มซับ (Haiku) และค่าสร้างฉาก
- "cache อุ่น" หมายถึงมีคลิปอื่นเพิ่งส่งเข้ามาไม่เกิน 5 นาทีก่อนหน้า ทำให้อ่าน prompt ยาวจาก cache ได้ในราคาถูก
- "cache เย็น" หมายถึงต้องเขียน prompt ลง cache ใหม่ ช่วงเปิดตัวที่ยังมีผู้ใช้น้อยจะเจอกรณีนี้เป็นส่วนใหญ่

| แบบการสร้างฉาก | cache | 30 วิ | 45 วิ | 60 วิ | 90 วิ |
|---|---|---|---|---|---|
| **A** Sonnet เขียนโค้ดฉากเองทุกคลิป (แบบ skill ตอนนี้) | อุ่น | 1.3–3.6 | 2.0–5.4 | 2.6–7.1 | 3.8–10.6 |
| | เย็น | 2.3–5.3 | 2.9–7.0 | 3.5–8.7 | 4.8–12.2 |
| **B** Sonnet เลือกชิ้นส่วน + เติมค่าลงเทมเพลต (JSON) | อุ่น | 0.3–0.8 | 0.4–1.1 | 0.5–1.4 | 0.8–2.1 |
| | เย็น | 0.6–1.4 | 0.7–1.7 | 0.8–2.1 | 1.1–2.7 |
| **C** แบบ B แต่ใช้ Haiku แทน Sonnet | อุ่น/เย็น | 0.04–0.10 | 0.05–0.13 | 0.07–0.16 | 0.10–0.22 |
| **D (แผนที่ตกลง)** แบบ B + AI เขียนเอง 1 ฉาก | อุ่น | 0.5–1.5 | 0.6–1.8 | 0.7–2.2 | 0.9–2.8 |
| | เย็น | 1.3–2.9 | 1.4–3.2 | 1.5–3.6 | 1.7–4.3 |
| **D** แบบ B + AI เขียนเอง 2 ฉาก | อุ่น | 0.6–2.1 | 0.7–2.4 | 0.8–2.8 | 1.1–3.4 |

ที่มาของตัวเลข
- แบบ A: prompt ของ skill ทั้งชุดมีประมาณ 12,000–21,000 token ส่วนโค้ดฉากในตัวอย่างมีประมาณ 3,300–4,700 token ต่อคลิป 42 วินาที (นับจากไฟล์จริง และเป็นช่วงเพราะภาษาไทยนับ token ได้ไม่แน่นอน)
- แบบ A ยังไม่ได้รวมรอบที่โค้ดพังแล้วต้องแก้ และยังไม่ได้รวมการดูภาพตัวอย่างเพื่อตรวจงาน ต้นทุนจริงจึงน่าจะสูงกว่าในตาราง
- แบบ B และ C ใช้ข้อสมมติว่า prompt ยาว 4,000–8,000 token, output ยาว 15–30 token ต่อวินาทีของคลิป และ token ที่ใช้คิดเท่ากับ 0.3–1 เท่าของ output ทั้งหมดนี้ต้องวัดจริง
- แบบ D: ฉากที่ AI เขียนเองใช้การเรียก Sonnet รอบที่สอง โดยส่งคู่มือเฉพาะส่วนชิ้นส่วน 6,200–10,400 token และให้เขียนโค้ด 200–463 token ต่อฉาก (ขนาดการ์ดในคลิปตัวอย่าง) ช่วงสูงเผื่อไว้ว่า 30% ต้องแก้หนึ่งรอบ ข้อตกลงทั้งหมดของแผนนี้อยู่ใน `../DECISIONS.md`
- คลิป 61–90 วินาทีใช้ 140 เครดิต คิดเป็นรายได้ 12.6 บาท ไม่ใช่ 9 บาท เพดาน 7 บาทจึงตึงน้อยลงสำหรับคลิปยาว

## 5. ตกลงแล้ว / ยังต้องตัดสินใจ

**ตกลงแล้ว (ไม่แตะ):** ราคา 450 บาทต่อแพ็ก, ลำดับการใช้งาน 7 ขั้น, ซับต้องเปิดในรอบแรก, ผู้ใช้ต้องได้คลิปเสมอ และถ้าเรนเดอร์ไม่สำเร็จต้องคืนเครดิตเต็ม

**ยังต้องให้ Friend ตัดสินใจ**
1. **สร้างฉากแบบ A หรือ B** (สำคัญที่สุด) — แนะนำ B
   - ใน B ทุกคลิปยังได้ภาพที่คิดจากประโยคของคลิปนั้น เพราะ AI เลือกชิ้นส่วน (ไอคอน กราฟ แผง เคอร์เซอร์ เป้า ฯลฯ) และกำหนดว่าอะไรเกิดตรงคำสำคัญ แต่ AI ไม่ได้เขียนโค้ดเอง
   - B ตรวจด้วยโค้ดได้ก่อนเรนเดอร์ และแก้เฉพาะจุดที่ผิดได้
   - ต้องสร้างชุดเทมเพลตก่อน จึงยังทดสอบ B ทันทีไม่ได้ ส่วน A ทดสอบได้ทันทีเพราะ skill มีอยู่แล้ว
   - ข้อเสียของ B คือหน้าตาอาจซ้ำกันมากกว่า A ต้องดูจากคลิปทดสอบจริง
2. **ตัด Kimi ออกจากไปป์ไลน์หรือไม่** — แนะนำให้ตัด เพราะราคาไม่ถูกกว่า และเพิ่มผู้ให้บริการอีกเจ้าที่อาจล่มได้ ฉากยากส่งให้ Sonnet คิดละเอียดขึ้นแทน
3. **เปลี่ยนการเข้ารหัสวิดีโอเป็น `medium` crf 21 หรือไม่** — แนะนำให้เปลี่ยน แต่ Friend ควรดูคลิปเทียบด้วยตาก่อน
4. **ถอดเสียงด้วย Groq API หรือรัน Whisper บนเครื่องเอง** — แนะนำ Groq เพราะถูกมาก และไม่แย่ง CPU กับงานเรนเดอร์ แต่ต้องทดสอบความแม่นของภาษาไทยกับคลิปจริงก่อน (เทียบกับ OpenAI)

## 6. สิ่งที่ต้องมีก่อนทดสอบคลิปจริง 20–30 คลิป

1. **คลิปจริง 20–30 คลิป** ที่หลากหลาย: ความยาว 15–90 วินาที คนพูดหลายคน พูดเร็วและช้า มีทั้งเสียงสะอาดและเสียงรบกวน ส่งในแชทได้ไฟล์ละไม่เกินประมาณ 30 MB หรือส่งลิงก์ Google Drive ที่เปิดแบบ "ทุกคนที่มีลิงก์"
2. **คีย์ API** ให้ใส่ในตั้งค่า environment ไม่ต้องส่งในแชท:
   - เปิดเมนู environment ที่แถบชื่อ session แล้วกด Edit จากนั้นเพิ่มในหัวข้อ Network secrets (บางแอปเรียกว่า API credentials) หรือเพิ่มเป็น environment variable
   - ชื่อที่ต้องใช้: `ANTHROPIC_API_KEY`, `GROQ_API_KEY` และใส่ `OPENAI_API_KEY` ด้วยถ้าต้องการเทียบความแม่นของการถอดเสียง
   - ใส่แล้วต้องเปิด session ใหม่
3. ไฟล์ใน `/workspace/finance/` และ `/workspace/marketing/` ที่เอกสารส่งต่องานอ้างถึง **ไม่มีอยู่ใน repo นี้** ไฟล์เหล่านี้ไม่จำเป็นต่อการทดสอบต้นทุน แต่ถ้าต้องการให้ใช้ ต้องนำเข้ามาใน repo ก่อน
