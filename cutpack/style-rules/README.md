# ทะเบียนสไตล์ใหม่ของ CutPack

Friend ยกเลิกสไตล์เก่าทั้ง 8 แบบ แล้วแทนด้วย 12 สไตล์จากรูปที่ Friend ให้ AI ทำ (2026-11-17) โดยทำทีละสไตล์

**วิธีทำงานที่ตกลงกัน (Friend 2026-11-18)**
- Friend: "ผมคิดว่าผมจะเก็บอันนี้ไว้เป็นดราฟแรก แล้วทำสไตล์ต่อไปเลยพอครบทุกสไตล์ที่อยากทำแล้วก็ค่อยกลับมาแก้รายละเอียดเล็กๆน้อยๆของสไตล์นั้นๆ"
- ทุกสไตล์ทำถึง **ดราฟแรก** ก่อน แล้วไปสไตล์ถัดไป เมื่อครบทุกสไตล์แล้วค่อยกลับมาเก็บรายละเอียด
- **ด่านขั้นต่ำของดราฟแรก**
  1. ภาพนิ่งครบ 12 ช็อต เทียบกับรูปของ Friend
  2. ตัวตรวจผ่าน: สีตัดกัน · โซนปุ่ม TikTok · ไม่ทับหน้า
  3. รันคลิปจริงผ่านระบบ 1 รอบโดยไม่มีข้อผิดพลาด (ใช้คลิปที่ Friend ส่งมาแล้วได้)
  4. **ไฟล์สกิลละเอียด** ของสไตล์นั้น อ่าน `common.md` + ไฟล์ของสไตล์ แล้วทำคลิปได้โดยไม่ต้องเปิดโค้ด (Friend 2026-11-18: "ดราฟแรกที่ผ่านแล้วอ่ะ ก็ต้องทำไฟล์สกิลโดยละเอียดให้สไตล์นั้นๆด้วย ถ้าไม่ทำมันก็จะเท่ากับว่าสิ่งที่เราทำมันมามันสูญเปล่าเลยอ่ะดิ" · LESSONS 64)
- Friend ดูภาพเทียบ แล้วบอกเฉพาะเรื่องใหญ่ ส่วนเรื่องเล็กจดไว้ในตารางด้านล่าง
- **จากดราฟเป็น final** (หลังครบทุกสไตล์): เก็บรายการค้างของสไตล์นั้น แล้วทำไฟล์สกิลให้ละเอียดขึ้นด้วย (Friend 2026-11-18: "ค่อยไปทำให้ละเอียดขึ้นในตอนที่แก้จากดราฟเป็น final")

**ไฟล์สกิล**: `common.md` (ขั้นตอนทำคลิปทุกขั้นที่เหมือนกันทุกสไตล์) + ไฟล์ของแต่ละสไตล์ (หัวข้อเดียวกันทุกไฟล์) อ่านคู่กันแล้วทำคลิปได้โดยไม่ต้องเปิดโค้ด

**แก้โค้ดกลางที่กระทบสไตล์ที่เสร็จแล้ว ต้องถาม Friend ก่อน** (LESSONS 63 · ค่าเริ่มต้นเปิดเฉพาะสไตล์ใหม่)

**กฎที่ใช้กับทุกสไตล์** อยู่ใน `engine/uni/styles/common.js` (โซนปุ่ม · ขอบล่าง 1660 · กรอบไม่ขึ้นไปใต้แถบค้นหา · ซับกลาง · วิดีโอเต็มกรอบ · ไม่ทับหน้า · สุ่มทุกรอบ) และ `DECISIONS.md` ข้อ 3 · AI ทำ 2 งานเหมือนกันทุกสไตล์ (`neon.md` หัวข้อ 1)
