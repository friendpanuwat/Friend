## 5. ซับ (ครบทุกคำ ตามที่พูด)

- **รูปแบบ:** 2 ชั้น คำนำตัวเล็ก (Anuphan 600 ขนาด 46) + คำสำคัญตัวใหญ่ (Anuphan 700 ขนาด 104 ช่องไฟ −1) ห่างบรรทัด 6 กว้างไม่เกิน 860 ยาวกว่านั้นย่อ ห้ามตัดคำ
- **คำสำคัญ:** ตัวหนังสือไล่สีบนลงล่าง `#FFE09A → #FF8A1F` แสงเรือง `drop-shadow(0 0 22px rgba(255,130,30,.6))`
  - สีไล่ทาได้แค่ในกล่องของคำ สระบน ล่าง และวรรณยุกต์ของไทยยื่นออกนอกกล่องแล้วหายไป (Friend: "สระมันหายอะครับ … ◌ู ◌ุ") จึงเผื่อกล่องบน .32em ล่าง .36em แล้วหักคืนด้วย margin (`.gd-k` ใน `styles/gold.js`) ข้อความไล่สีแบบนี้ในสไตล์ใหม่ต้องทำแบบเดียวกัน
- **ขึ้น:** คำนำขึ้นทีละวลีตามเวลาที่พูด (จางเข้า + เลื่อนขึ้น 10 ใน .25 วินาที) คำสำคัญขึ้นตรงคำ: เบลอ 12 → 0 และย่อ 1.08 → 1 ใน .3 วินาที · หาย: จางออก .2 วินาที บรรทัดที่ต่อกันสลับทันที ไม่มีช่วงว่าง
- **บนคนพูด (A-roll และ overlay):** คำนำขาว เงา `0 2px 12px rgba(0,0,0,.55)` วางระดับอก: บรรทัดบนสุดที่ใต้คาง + 40 (จากตัวหาหน้า, คลิปทดสอบ y 1230) ไม่บังหน้า ไม่มีแถบมืด
- **บนพื้นตารางเทาอ่อน (แบบ A):** คำนำ `#1C1C1E` คำสำคัญไล่ส้มเข้ม `#FF9A2E → #E56A0A → #B84C00` (ทองอ่อนจางบนพื้นเทา 1.4 เท่า กฎข้อ 10) เรืองอ่อนลงครึ่งหนึ่ง
- **บนพื้นมืด (แบบ B):** แบบเดียวกับบนคนพูด
- ซับไม่มีเสียง

## 6. กล้องและท่าขยับ (ล็อกในโค้ด)

- **ซูมตัดสลับ (reference ข้อ 7):** ช่วงพูดเฉย ๆ แต่ละช่วงใช้กรอบเดียว สลับ 1.0 กับ 1.12 (ซูมรอบหน้า) ทุกครั้งที่กลับจากฉาก ไม่ซูมระหว่างช่วง ไม่ซูมตามคำ (Friend เคยว่าซูมทุกคำ "พร่ำเพรื่อเกินไป")
- **ท่า:** นุ่มแบบเบลอเข้า
| ท่า | ค่า |
|---|---|
| `pop` | จาง + ย่อ .9 → 1 + เบลอ 8 → 0 · .4 วินาที · `cubic-bezier(.2,.8,.2,1)` |
| `rise` | จาง + เลื่อนขึ้น 50 + เบลอ 10 → 0 · .5 วินาที |
| `drop` | จาง + เลื่อนลง −50 + เบลอ · .45 วินาที |
| `lead` `chip` | จาง + เลื่อนขึ้น 10 · .25 / .3 วินาที |
| `key` | เบลอ 12 → 0 + ย่อ 1.08 → 1 · .3 วินาที |
| `leave` | จาง + เบลอ 8 · .25 วินาที |
| `punch` | ขยาย 1.06 แล้วกลับ · .35 วินาที |
| `shake` | ส่าย ±8 สามครั้ง · .45 วินาที |
| `move` `tilt` `snap` | .5 / .6 / .45 วินาที เส้นเดียวกับ `pop` |
| อื่น | `swap` .25 · `draw` .6 · `stroke` .2 · `stagger` .1 · `fall` 1.0 · `float` ±4 รอบละ 3 วินาที · `glow` .5 |

| ตัดเข้าฉาก | `whoosh` −24 dB |
| คำสำคัญในซับ | `softswish` −22 dB |
| ตรงคำสำคัญในภาพ (`hit`) | `pop` −24 dB |
| ติ๊กถูก | `pop` −24 dB |

## 8. แบบ overlay (`gold-overlay`)
- คนพูดเต็มจอตลอด ไม่ย่อ (ยกเว้นขนาดใหญ่ `gold-overlay-big` ย่อ 80% ตามกฎ overlay เดิม)
- ร่างเล็ก (ผืน 600 × 340) อยู่บน **การ์ดหลักดำขอบส้มเรือง** (ข้อ 2) เผื่อขอบด้านละ 24 เหนือหัว (ตำแหน่งจากตัวหาหน้า) ขึ้นด้วย `pop` หายด้วย `leave`
- ซับทองระดับอก (ข้อ 5)
- ซูมตัด 1.0 → 1.08 ตรงคำสำคัญของฉาก แล้วตัดกลับตอนการ์ดหาย (แบบ card-overlay)

## 9. ขั้นตอนทำ (เสนอ Friend ก่อนเขียนโค้ด)

2. **ภาพนิ่งก่อนคลิป:** ภาพนิ่งแบบ A แบบ B และ overlay วางข้างภาพจาก reference ให้ Friend ดูก่อน (บทเรียนจาก iOS: Friend เห็นปัญหาตอนคลิปเสร็จแล้ว)
3. ตรวจครบ: ร่างเลโก้ทุกร่างในสไตล์นี้ (`check_contrast.js` `check_overlap.js` ภาพทีละเฟรม)
4. คลิปจริง: คลิปของ Friend (`VID_20261110_...`) ตัดใหม่ด้วยสไตล์นี้
