# สไตล์ใหม่ (ร่าง ยังไม่ตั้งชื่อ ยังไม่ได้ Friend ยืนยัน): ทองส้มบนการ์ดดำมันวาว

ที่มา: Friend ส่งคลิป reference ในแชท (2026-11-11 หลังลบ iOS style) "นี่คือ ref ของสไตล์ใหม่" คลิปไม่เก็บใน repo (เป็นคลิปของคนอื่น) ยาว 20 วินาที 720×1280 24 fps
คลิปเป็นโฆษณาผลงานของคนตัดต่อ: จอแบ่ง 2×2 โชว์ 4 จังหวะของคลิปที่ตัดสไตล์เดียวกันพร้อมกัน มีแถบดำกลางจอ "To get Ads that convert DM "Ads"" **ตาราง 2×2 กับแถบ DM เป็นโฆษณาของเขา ไม่ใช่สไตล์** (รอ Friend ยืนยัน)
หลักเดิม: แกะสไตล์ ไม่ลอกเป๊ะ ไม่ใช้คำ โลโก้ หรือภาพจาก reference

## สิ่งที่เห็นในคลิป (แกะจากภาพทุก 0.5 วินาที)

| # | ส่วน | ที่เห็น |
|---|---|---|
| 1 | ซับ | คำนำตัวเล็กสีขาว ขึ้นทีละคำ + คำสำคัญตัวใหญ่หนาแน่น ไล่สีส้มถึงทอง มีแสงเรืองสีส้มรอบตัวอักษร วางระดับอก ทับตัวคนพูด (ไม่ใช่ใต้คาง) บางคำเบลอแล้วชัดตอนขึ้น |
| 2 | ป้ายกระจกดำ | การ์ด / ชิปสีดำมันวาว ไล่เงาจากบนลงล่าง ขอบสว่างบาง ๆ ตัวหนังสือขาวหรือทอง (เช่น ป้ายคำสั้น ป้ายชื่อตำแหน่ง ป้ายเบอร์ติดต่อ) ลอยข้างตัวคนพูด |
| 3 | ไอคอน | ไอคอนเส้นในกรอบสี่เหลี่ยมมุมมนขอบส้ม · แถวไอคอนทองซ้อนกัน 3 อันพร้อมคำ · ของ 3D สีทองในกรอบหกเหลี่ยมเรืองแสง |
| 4 | แบ่งจอพื้นขาว | หน้าขาว รูปคนพูดเล็กมุมมนด้านบน + การ์ดดำขอบส้มเรืองด้านล่าง ข้างในเป็นรายการ ติ๊กเงินกับคำสีส้มเรือง ขึ้นทีละข้อ (หรือจุดส้มนำหน้า) |
| 5 | ภาพจริงเต็มจอ (B-roll) | ภาพถ่ายจริง: เอกสารในมือ มือใส่แหวน บ้าน ค้อนผู้พิพากษา จับมือ แหวนทองเรืองแสงในโบสถ์มืด + ซับหรือป้ายกระจกดำทับ |
| 6 | เอกสาร | กระดาษเอกสาร (ขาว / เขียวมะนาว) เลื่อนขึ้นมาทับคนพูด มีหัวเรื่องตัวหนา |
| 7 | กล้อง | ตัดสลับภาพกว้างเห็นทั้งตัว กับภาพใกล้ครึ่งตัว (ซูมตัด) |
| 8 | สี | พื้นสตูดิโอเทาอ่อน · ดำมันวาว · ส้ม / ทอง เป็นสีเน้นสีเดียว · ขาว |

## สิ่งที่ระบบเรายังทำไม่ได้ (ต้องให้ Friend ตัดสิน)
- ข้อ 5 ภาพจริงเต็มจอ: ระบบตอนนี้เป็น motion graphics อย่างเดียว (DECISIONS ข้อ 3: รุ่นแรกไม่รับ B-roll) ต้องมีคลังภาพก่อน (ไอเดียของ Friend 2026-11-11: คลังภาพที่เจนด้วย AI ยังไม่ตัดสิน)
- ข้อ 3 ของ 3D สีทอง: เราใช้ไอคอนเส้น (Lucide) ไม่มีของ 3D
- ข้อ 7 ภาพกว้างกับภาพใกล้: คลิปที่ถ่ายใกล้ (เห็นแค่หน้ากับไหล่) ทำภาพกว้างไม่ได้ ซูมได้แค่ใกล้ขึ้น
