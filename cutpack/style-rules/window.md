## 4.1 ขนาดหน้าต่าง: มาตรฐาน 7 ขนาด (2026-11-19 · `WIN_STD` `WIN_ORDER` `WIN_MIN` `winShape`)
กฎกลาง `common.md` ข้อ 4.1 · ของสไตล์นี้:
1. **หน้าต่างทั้งบาน (รวมแถบหัวสูง 64) = ขนาดมาตรฐาน × s เป๊ะ** · ภาพอยู่ข้างในตามเดิม (`winInner` = ขอบซ้ายขวา 22 · ใต้แถบหัว 76 · ล่าง 22)
2. s = ใหญ่สุดที่ห้องให้ ไม่เกิน 1 (100%) · **ต่ำกว่า .65 = ขนาดนั้นใช้ไม่ได้** ลองขนาดถัดไปตามลำดับ
3. ไม่มีขนาดไหนถึง 65%: **จอ ก = ไม่ใช้จอนั้น** (`winFit` คืน null · ไปจอน้ำเงินตามข้อ 5.2) · จอ ข ได้เสมอ (ห้องใหญ่พอทุกจอ)
4. ไม่ใช้ขนาด 4 และ 7 (สไตล์นี้ไม่มีฉากภาพข้างตัว)
5. หน้าต่างติด `data-std="<ขนาด>:<s>"` ให้ `tools/card_sizes.js` วัด

## 16. ทำคลิปหน้าต่างแอป 1 คลิป
ทำตาม `common.md` ข้อ 2 ขั้น 1–8 (คำสั่งเต็มเหมือน `neon.md` หัวข้อ 15) โดยใส่ `window`:
```
cd uni
python3 tools/clip_plan.py $W $W/faces.json window --history <ลูกค้า.json>        # แผน + fit pick (~30 วินาที)
NODE_PATH=$(npm root -g) bash tools/build_only.sh $W window $W/bo                   # ดูก่อนเรนเดอร์
NODE_PATH=$(npm root -g) node tools/picture_sizes.js $W/bo                          # OUTSIDE 0 · LOW
NODE_PATH=$(npm root -g) node tools/card_sizes.js $W/bo $W/sizes                    # หน้าต่างตรงขนาดมาตรฐาน (หัวข้อ 4.1)
NODE_PATH=$(npm root -g) node tools/page_frames.js $W/bo $W/frames 1                # เฟรมทุก 1 วินาที
NODE_PATH=$(npm root -g) bash tools/clip_all_styles.sh $W window                    # เรนเดอร์ (~3.5 นาที คลิป 42 วินาที บน 2 คอร์)
```
ตรวจก่อนส่ง: แผนพิมพ์ `hook:` และภาพแรกเป็นจอ ก (ถ้าหน้าให้ที่) · หน้าต่างทุกบานตรงขนาด 65–100% · `OUTSIDE` 0 · ก กับ ข ใกล้เคียงกัน · จอ ก มีทั้งหน้าต่างบนหัวและล่าง (ถ้าหน้าให้ที่) · หน้าต่างจอน้ำเงินอยู่กลางจอ ภาพกลางหน้าต่าง · คำไม่ชนวงแหวน · คำในภาพไม่มีกล่อง (ยกเว้นวางบนภาพอื่น)
